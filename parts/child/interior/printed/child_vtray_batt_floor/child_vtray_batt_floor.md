## 役割

∩ チャンネルの電池箱の底を塞ぐ板。**皿ねじ 1 本**で着脱でき、外すと電池が −Y へ出る。

| 端 | 保持 |
|---|---|
| +Z | 板の両縁のフック (1.3 × 3 × 2mm 突出、x 18.4..19.7 / y −40.5..−37.5) がリップのスロットに入り、−Y への抜けを止める |
| −Z | 板を端壁の下 (z 14..20) まで延ばしたタブ (x ±7、3t) に **M3×8 皿ねじ**。端壁の柱の下穴 (Ø2.5、深さ 6) へ +Y に締める |

着脱: 皿ねじを外す → 板を −Z へ 2mm ずらしてフックを外す → −Y へ抜く。
取付は逆: 電池を箱へ入れて押さえ、板を −Z に 2mm ずらした位置で −Y から当て、+Z へ 2mm 押して
フックを入れ、皿ねじ。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `cav_x / floor_y1 / floor_t` | 20 / −40 / 3 | 箱の内幅の半分 / 板の上面 / 板厚 (箱と共通) |
| `side_clear / end_clear` | 0.3 / 0.5 | 壁との片側すきま / +Z 端とリップのすきま |
| 導出: 板 | **39.4 × 3 × 111.5** | x ±19.7、y −43..−40、z 20..131.5 (世界) |
| `hook_w / hook_h / hook_l / hook_base` | 1.3 / 3 / 2 / 4 | フック (厚み / 高さ / スロットへの突出 / 板上の根元) |
| `tab_x / tab_t / screw_z` | 7 / 3 / −3 | −Z タブ (半幅 / 厚み / ねじの Z = 世界 17) |
| `screw_d / csk_d` | 3.4 / 5.8 | M3 バカ穴 / 90° 皿座ぐり (JIS M3 頭 5.5) |

(rad(7, −43) = 43.6)。板と面一 (3t) なので寝かせて印刷してもサポート不要。皿頭 (1.25) は板に沈む。

## 印刷向き・条件

**板を寝かせ、フックとタブを上**にして印刷。サポート不要。PLA・0.2mm 層・壁 3 本・インフィル 30 %。
皿座ぐりは下面側 (ベッド側) に来るので、ベッドの初層が座ぐりのエッジを潰さないようブリム無しで印刷する。

## 部品外の考慮

- 皿ねじは −Z 端の y −43 面 (電池箱の下、下リブの 8mm 上) にあり、内装をチューブから抜けば
  −Y 側からドライバが届く。下キャップ側のハーネス (リブの開口 x ±20) が上を通るので、
  結束は皿ねじの真上を避ける。
- フックのスロット嵌合 (片側 0.3) は印刷後に現物合わせ。きつければフックを削る。

## 要確認

1. フック / タブの嵌合クリアランス (印刷後)
2. 電池の実寸 (幅 35 + 公差) とフック (x ≥ 18.4) の干渉

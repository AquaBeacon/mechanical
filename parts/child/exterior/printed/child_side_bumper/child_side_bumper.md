# child_side_bumper — カメラ側面バンパ (左右共通 ×2)

外装改善要件 (2026-09-04, [要件書](../../../../../docs/子機外装_改善要件.md) §3.2) と
同日のコーディネータ決定に基づく新規部品。防水ケース側面 (x=±122.35) の外側に
立つ t9 の保護板。`child_cam_bridge` のウイング端板フランジに M5×2 で締結する。
輸送時はブリッジごと外れる (C7「外せる部品」)。

## 役割

`child_cam_mount` (横向き搭載) の防水ケース側面を輸送時の側方衝突から守る。
ケース外側面 (`case_outer_x = lens_x(75) + cm_case_w(94.7)/2 = 122.35`。
**2026-09-04 修正**: 横向きでは機体 X 方向に来るのは「ケース幅」`case_w` であり、
旧式 `lens_x + cm_case_h/2` (=117.05、高さを使う誤り) は指摘を受けて修正した)
との間に 2mm のクリアランスを置き、`child_cam_bridge` のウイング端板 (x=±120) へ
M5×2 で締結する。

## 外形の導出

```
inner_x = case_outer_x(122.35) + case_gap(2)      = 124.35
outer_x = inner_x + bumper_t(9)                    = 133.35   (assert <= 280枠半幅140)
z0 = deck_bot(44.95)                                          // ブリッジのデッキ面まで下ろす (フランジ締結)
z1 = case_z1(167.05) + top_margin(5)               = 172.05   // ケース上端+5
y0 = case_y0(74.1) - y_margin(5)                    = 69.1
y1 = lens_y(120) + y_margin(5)                      = 125.0
```

`case_outer_x`/`deck_bot`/`case_z1`/`case_y0`/`lens_y` はすべて `child_cam_bridge.scad`
と同じ導出式をこのファイル内にも複製している (二重定義、下記インタフェース参照)。
外面 133.35 は「隙間ゼロ」を仮定した要件書の 131.35 (=122.35+9) より **2mm 隙間の分
だけ広い**。ケース側面クリアランス ≥2mm を確保するための正しい値として採用した
(280 枠には十分余裕があるため問題なし)。

### L 形フット (2026-09-04 追加、FLOATING 修正)

`check_asm_contacts.py` で本部品と `child_cam_bridge` の距離が **4.35mm
(FLOATING)** と判定された。原因は、立て壁が `inner_x`(124.35)..`outer_x`(133.35)
にしかなく、ブリッジの端板外面 (x=`wing_x1`=120) との間に隙間があったこと
(124.35−120=4.35mm、報告値と一致)。

対策として **L 形フット** を追加し、端板の外面まで内側に伸ばして密着させた:

```
foot: x = wing_x1(120) .. outer_x(133.35)   // 端板外面から立て壁外面まで連続
      y = y0(69.1) .. y1(125.0)             // 立て壁と同じ Y 範囲
      z = z0(44.95, デッキ面) .. foot_z1(78) // ケース底面 (case_z0=82.95) より
                                              //  1mm 以上下の帯のみ (ケースと非干渉)
```

M5 締結穴 (`bump_bolt_y`/`bump_bolt_z`) も、立て壁の厚み (9mm) だけでなく
フットを含めた全長 (`outer_x − wing_x1` = 13.35mm) を貫通するよう修正した。

再検査結果 (`check_asm_contacts.py assemblies/child_frame2_assembly/placement.json
--root . --groups all --ignore-threads`):

```
side_bumper_stbd  <-> cam_bridge   0.09 mm  ok
side_bumper_port  <-> cam_bridge   0.13 mm  ok
penetrations: 該当なし
```

## 干渉チェック (`.scad` 冒頭の assert)

- ケース側面とのクリアランス ≥2mm (`case_gap`)
- バンパ外面 ≤ 280 枠半幅 140 (現状 133.35、余裕 6.65mm)
- バンパ下端がブリッジのデッキ面 (44.95) 以下 (フランジに届く)
- バンパ上端がケース上端+5 以上
- 締結穴 (`bump_bolt_y`) がバンパ端から縁距離 ≥3mm
- 締結穴の z がブリッジ端板フランジの高さ範囲内
- **フット (`inner_x > wing_x1`)**: ブリッジ端板の外面まで届くこと (2026-09-04 追加。
  これが無かったために FLOATING が発生した)
- **フットとケースの非干渉 (`foot_z1 <= case_z0 - 1`)**: フットは x 方向で
  ケース (x 27.65..122.35) と 120..122.35 の範囲で重なるが、z 方向を
  ケース底面 (82.95) の 1mm 以上下に分離することで回避する

## 荷重ケースと安全率

L2 輸送 300N が側方 (−X、バンパ面に垂直) から入る想定。バンパは
片持ちではなく、ブリッジの端板フランジ (t6) に M5×2 で固定された**単純支持に
近い板**として働く。M5×2 のせん断・引抜き:

- `quick_strength.py boss` 相当 (M5、板厚 end_plate_t=6、締結先はブリッジ側の
  ナットトラップ): 300N を 2 本で受けると 1 本あたり 150N。M5 ねじ山のせん断
  許容 (PETG ナットトラップ、二面幅 8.2) は既存部品 (`child_cam_mount` の
  ナットトラップ) と同等寸法のため定性的に十分と判断。**詳細な `quick_strength
  boss` 数値計算は未実施** (要確認に記載)
- バンパ本体 (板厚9、高さ127.1、幅55.9) 自体の曲げは、締結部からの片持ちが
  ほぼ無い (下端がデッキ面まで届き、実質 2 点固定+デッキ面での支持) ため
  支配的でないと判断

| サポート | オーバーハング 4.7% と小さく、基本的にサポート不要
  (フット下面の小さな張り出しのみ要確認) |
| レイヤ | 0.2mm、ノズル 0.4mm。最小肉厚 18.72mm (2 周 0.8mm を大きく上回る) |

  外す運用は想定していない (バンパの M5×2 は常時締結)
- ケース側面のボタン・ラッチ等へのアクセスは**ケース実物入手後に確認**
  (バンパがアクセスを塞がないか)

# test_bracket — ツールチェーン検証用サンプル

**機体部品ではない。** `.scad → STEP` の変換品質と Fusion 360 での編集性を
確認するためのサンプル。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / 治具 (検証用) / 3Dプリント |
| 設計ソース | `test_bracket.scad` |
| 外形 | 40 × 30 × 30 mm |
| 体積 | 9.95 cm³ |
| STEP | 1 ソリッド / **18 面** (14 平面 + 真円柱 4) |

## 役割

L 字ブラケット + M3 取付穴 ×4。cube / cylinder とブーリアンだけで構成し、
STEP に変換したときに**真の平面・真円柱面**になることを示す。

このリポジトリの 2 つの設計規約の実装例:

1. **角丸を .scad で作らない** — 角丸あり版は 426 面、この基本形状版は 18 面。
   角丸/フィレットは Fusion 側で付ける。
2. **assert でフィーチャ干渉を検査する** —
   `min_dx = thick/2 + screw_d/2 + clearance` で壁の取付穴と補強リブの
   X 距離を検査し、近すぎればビルドを止める。

## 主要寸法

| 変数 | 値 |
|---|---|
| `plate_w / plate_d / wall_h / thick` | 40 / 30 / 30 / 4 |
| `screw_d / hole_inset` | 3.2 / 7 |
| `gusset_run / gusset_rise` | 14 / 20 |
| `clearance` | 1.0 |

## 既知の観察事項 — STL に開口エッジ 333

`inspect_mesh.py` が STL に **333 の open edge** を報告する
(STEP は 1 ソリッド 18 面で健全)。三角形分割の縮退か自己接触が原因と思われる。
**検証用サンプルなので実害はない**が、実部品で同じ報告が出たら必ず原因を調べること。

## 印刷向き

底板を下に平置き。

## 使い方

```powershell
.\build.ps1 parts\common\jigs\test_bracket
```

`test_bracket.step` を Fusion 360 で開き、面・エッジが個別に選択でき、
押し出し/フィレット/穴編集ができることを確認する。

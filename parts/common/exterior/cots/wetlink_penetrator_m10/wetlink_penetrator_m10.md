## 構造と向き (間違えると水が入る)

バルクヘッド (M10 本体) / シール (ゴム) / プラグ (シールを潰す) / O リング / ナット。

```
   濡れ側 (外)                 壁            乾き側 (箱の中)
 ケーブル →[プラグ][六角頭]|===========|[ナット]  → 素の導体
           ←── 18-26 ──→   O リング座    ←─ ねじ 20 - 壁厚 ─→
```

- **O リング座 (六角頭側) は必ず外**。組立ガイド:
  *"only the cable side of the penetrator is sealed. The back side — where the
  wires exit — is not sealed and must stay dry."*
- したがって**容器内に出るのは素の導体**で、ケーブル外被は容器の外で終わる。
  → **容器内に端子台/コネクタが要る** (親機側 未設計)。
- 壁厚 3.1 mm のとき容器内へ **16.9 mm** ねじが出る。ここに M10 ナット (厚 8.4) が乗る。

## 参考モデル `wetlink_penetrator_m10_ref.scad`

ベンダ 3D データの代わりに置いた**空間占有モデル**。座標系は
**軸 = Z、z=0 が壁の外面 (O リング座面)、+Z が容器内側**。

| 変数 | 値 | 出典 |
|---|---|---|
| `thread_d` / `thread_l` | 10 / 20 | ベンダ公称 |
| `hex_af` / `plug_af` | 16 / 14 | 組立ガイドの工具寸法 |
| `out_h` | 22 | 公称 18–26 の中央 |
| `head_h` | 8 | **仮値・要確認** |
| `nut_af` / `nut_h` | 17 / 8.4 | ISO 4032 M10 (**要確認**: 付属ナットの実物) |
| `bore_d` / `cable_d` | 5.7 / 7.5 | **ケーブル未選定**のため 7.5mm シールで仮置き |
| `wall_t` | 3.1 (既定) / **6.1 (`bcas` バリアント)** | ナット位置だけがこれで決まる |

`variants.txt` の **`bcas`** が親機アセンブリで使う版。値 6.1 は
`bcas212310g.scad` の**モデル上の**側壁厚 (外形 230 − 有効内寸 217.8) で、
実壁は 3.08。実機ではナットが 3 mm 外側 (箱内 y≈3.1–11.5) に来るので、
**内側クリアランスもねじ掛かりもモデルより広い = モデルは保守側**。

ビルドは (フォルダ名と .scad 名を意図的にずらしてあるので一括ビルド対象外):

```powershell
.\build.ps1 parts\common\exterior\cots\wetlink_penetrator_m10\wetlink_penetrator_m10_ref.scad
```

## 親機での使い方 (2026-08-29)

| # | 箱座標 | ケーブル | 落とし先 |
|---|---|---|---|
| `pen_tether` | 南壁 (Y=0) x=120, z=65 | C1 テザー | P-MAIN `J_TETH1` (箱 x≈123) |
| `pen_td04a` | 南壁 (Y=0) x=85, z=65 | C3 TD04A | TX (右列) |

`assemblies/parent_interior_p1` / `_p2` の両方に同じ位置で入っている。

**東へ寄せられない理由**: SPRESENSE (箱 X 134.5–188) の拡張ボード スタック高が
仮値 30 mm で、その上を通すと z=65 のナット (Ø19.7) との隙間が 0.3 mm しか
残らない (`spec/parent_interior_layout.py` の `check_penetrators()` が止める)。
**SPRESENSE の実高を測れば x を 135 / 170 へ戻せる** — そのほうが TD04A → TX
の箱内配線が 150 mm 短くなる。

## 部品外の考慮

- **ケーブル外径でモデルが変わる**。使うケーブルを決めてから型番を選ぶこと。
  径が合っていないとシールしない。ケーブル選定 → ペネトレータ選定 の順。
- **TD04A (C2/C3) は 3P プラグ付きの完成品ケーブル。プラグは Ø10 のボアを通らない。**
  ペネトレータを使う以上、ケーブルを切って容器内で端子台に落とすことになる。
  3m は延長できないので**切る位置 = 据付長を先に決める**こと。
- **張力はペネトレータで受けない。** 親機側テザーのストレインリリーフは**未設計**。
- 3.1 mm の ABS 壁に 3.5 N·m。**座面が潰れないか要検討** (内側にワッシャ/当て板)。
  タカチ箱の側壁には抜き勾配があるので、**O リング座 Ø16 が平坦か**も要確認。
- **未使用穴にはブランクプラグ**を必ず入れる。
- 3Dプリント品 (`parent_pod_body`) にペネトレータを付ける場合、
  M10 のねじ山をプリントで作らず**タップ立て**または**インサート**にすること。
  加えて壁 4mm では 3.5 N·m の締付に耐えるか要検討 (詳細設計書 1.6 節の
  内面エポキシコート + 気密試験が前提)。
- 締付にはトルクレンチが必要。**工具が入る周囲クリアランス**を配置時に確保する。
- ケーブルは容器内側で**サービスループ**を取る (基板・トレイを引き出せる長さ)。

## 要確認

1. 各ケーブルの実測外径 → 型番 (-045 / -055 / -065 / -075 / -085) 決定
   (テザー **未選定** / TD04A **未実測**)
2. `parent_pod_body` (3Dプリント) への M10 締結方法 (タップ / ヘリサート / インサート)
3. 参考モデルの仮値: `head_h` 8 / 付属ナット 17×8.4 / 導体ボア
4. **タカチ BCAS212310G の側壁 3.1 mm × 3.5 N·m の締付が成立するか**
   (座面の潰れ・抜き勾配で O リング座が平坦か・内側に当て板が要るか)
5. 箱の**外側**の干渉: 外部取付耳と、未設計の防水ボックスマウント／浮子。
   南壁の外に 22 mm 出るので、マウントがここに来ると成立しない
6. 親機側テザー ストレインリリーフ (未設計)
7. **SPRESENSE 拡張ボードのスタック実高** — これが確定すればペネトレータを
   東 (x 135 / 170) へ戻せる (TD04A → TX の配線が 150 mm 短くなる)
8. カバー (高さ 20) が本体上端にどう被るか。六角頭の頂点は z=74.2 で本体上端
   80.3 まで 6 mm。**16 mm ソケットの外径ぶん入るか**は実物で確認

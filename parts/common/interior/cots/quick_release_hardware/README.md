# twist Cの購入金具とゴム模型

購入品で印刷しない。`quick_release_hardware.scad`は既存twist Cの公開モジュールを使い、六角M3×40、AF5.5×厚2.4のナット、外径7×厚0.5のワッシャ、5×8×1 mmゴム2枚の圧縮状態を表示する。寸法の正本は `parts/common/jigs/quick_release_prototypes/quick_release_prototypes.scad`。模型の座標もそのCメス座標に従う。

`python tools/build_child_horizontal_accessories.py`で再生成する。金具の実寸、ゴム硬さ、接着、耐食性、保持力は実物で確認する。

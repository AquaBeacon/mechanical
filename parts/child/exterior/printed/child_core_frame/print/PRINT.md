# child_core_frame v5 — 印刷指示 (X1-Carbon)

`child_core_frame_print.stl` は印刷姿勢に回転済み・ベッド (z=0) 中央に置いた STL。Bambu Studio にそのまま読み込める。
スライス済みプロジェクトは `mechanical/print_jobs/child_core_frame/child_core_frame.3mf` (設定込み)。

| 項目 | 指示 |
|---|---|
| 材料 | **PETG** (Bambu PETG Basic プロファイル、テクスチャ PEI プレート) |
| 姿勢 | **+Z up (モデル姿勢のまま)。プレート = 部品の z −17 面 (下ポケット帯の底)** — 向きを変えない (FEA の層方向がこの姿勢) |
| 外形 | 152 × 128 × 235.5 mm (X1C 256 × 256 × 256 に収まる) |
| レイヤ / ノズル | 0.20 mm / 0.4 mm (`0.20mm Strength` ベース) |
| 壁 / 上下 | **壁 4 周 / 上下 5 層** |
| インフィル | **gyroid 40 %** (板厚 4〜6 mm の部材はほぼ壁だけで埋まる) |
| サポート | 自動サポート (45°)。実際に要るのは ナックル間隙の下面、把持バー下 (21 mm ブリッジ)、HP1 座面板 (21 mm ブリッジ)、ガードボス下面 3 mm。ラッチ/耳ボス・棚・柱の頭・ペデスタル側壁は 45° 面取り済みでサポート不要 |
| ブリム | 外側 5 mm |
| 見積 (Bambu Studio 02.05 CLI) | **23 h 56 m、667 g** (サポート・ブリム込み)、1541 層 |

- 
熱圧入インサート帯 (HP1/HP2/HP3 座面板とボス、ラッチ/耳ボス) は 60 % 以上のインフィルにする (スライサーの modifier で指定)- ラッチ板窓・手穴の入隅は Fusion でフィレット R3 以上を付けてから印刷 (FEA の応力集中位置)- ブリム 5 mm (外側のみ)。235 mm の背の高い部品なので剥がれ対策必須

# 親機・カメラ角度ストップ

既存のDJI Osmo Action 6用マウントへ後付けする、取り外し可能なケース当たりストップ。マウント前壁の既存工具穴（局所X=±20 mm、Z=20 mm）をM4×20ねじ2本で使い、穴ピッチ40 mmで固定する。2本のM4×8ソケットねじを個別に調整してカメラケースの当たり高さを合わせ、ロックナットで保持する。

Rev.2では支持足前端を局所Y=14 mm、調整ねじ中心をY=18 mm、初期接触高さをZ=36.5 mmとする。前壁からナットを離し、連結腕の上端もZ=36.5に揃えてケースへの食い込みを除いた。カメラケースは暫定参照形状であり、この位置・ケース当たりは仮設定である。実ケースを取り付けて傾きと接触を調整する。既存マウントのM3工具アクセス時はこのストップを外し、作業後に同じ壁面と穴へ戻す。カメラマウント本体は変更しない。

設計元は `spec/prepare_parent_oneplate.py` と `spec/parent_oneplate_sensor_sources.py`。座標はカメラマウントのローカル座標。生成SCADを直接編集しない。必要金具と配置は `assemblies/parent_exterior/README.md` を参照する。

実ケースでの視野、取付強度、締結後の角度再現性は未確認。ねじ先端やストップがケースを押し過ぎないことを実機で確かめる。

Rev.4では調整ねじをM4×8へ短縮し、頭座面を局所Z=28.5へ上げる。先端Z=36.5と接触位置は維持し、橋固定ねじ・ナットとの金具干渉を解消する。橋の固定はM4×20のまま。調整は角度ストップをマウントから外してM4用3 mm六角キーを入れる。装着中は橋固定ねじがドライバー経路を塞ぐ。設定・ナット固定後に同じ基準面へ戻す。両ナットの全厚がねじに掛かる。実ケースで接触を調整する。

Rev.6では背面Y=35をベッドへ当て、X=-90°で造形する。背板上端をZ=36.5、腕幅を10 mmへ揃え、途中で足が横へ張り出さない形にした。足前端Y=8.5、奥端22。調整軸Y=18、接触Z=36.5、既存M4x8/M4x20は維持する。調整穴とナット穴は印刷上向き55°屋根で、ナット二面幅7.2と保持座を残す。PETG Basic・0.2 mm層・8壁・100%・ブリム3 mm。自動サポート検出の結果はassembly READMEを参照。実ケース当たりと実印刷は未確認。

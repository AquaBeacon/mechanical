## 操作と配置

- **LiPo：** 箱内でふたを開け、電源を切りリードを外す。電源リードと台固定ねじ4本を外し、閉じた電池ボックスを上へ約90 mm持ち上げる。蓋のM3ねじ1本を外し、南108 mmへ引き抜いて電池を取り出す。公称102×34×23、X153–187/Y22.6–124.6/Z23–46、蓋Z49–52。他の基板と同軸を動かさない。
- **両microSD：** 箱内の設置高さで南へ水平に抜き、上へ取り出す。MAIN口X62/Y26.29/Z44.5、Sony口X165.16/Y134.72/Z68。
- **両電源スイッチ：** PWR原点X25.8/Y115/Z28.3、Z回転90°。SW_PWR中心X33.26/Y199.54、SW_TX中心X63.34/Y130.46。Ø20の指の進入経路とØ12のレバー動作包絡を確保。
- **TX：** 原点X148/Y140.5/Z24.8、Z回転90°。実装上端40.195、予約Z40.195–60.195、X148–198/Y136.5–211.926。印刷スペーサはこのXY外形の外に置く。
- **SPRESENSE：** 原点X202.34/Y208/Z65.6、Z回転180°。厚1.6 mmの肉抜き固定板と4点のねじ座。板下面Z60.5、上面62.1、ねじ座上面65.55。TX予約上面60.195との間は0.305 mm、裏面部品最下端62.65との間は0.55 mm。左右スペーサ本体41.7 mm＋位置決め突起0.8 mm、床上18.8から接合面60.5へ。左Ø7、右Ø5.4、穴Ø3.45。専用追加バッテリーなし。
- **MAIN固定板：** 厚2.4 mm、下面33.1、上面35.5、ねじ座上面41.95。裏面部品最下端37.245との余裕1.745 mm。柱4本は14.3 mm、ねじ穴に対応する上の座だけを浮かせる。
- **MAIN USB：** MAIN原点X18/Y112/Z42、USB口X39.11/Y24.73/Z46.6。内装を箱から取り出して南から接続する。無分解での取り出しではなく、各上部モジュールとケース側ハーネスを先に外す。
- **GNSS：** 60×80ユニバーサル基板X69–129/Y139–219/Z56–57.6。穴はX71.5／126.5、Y141.5／216.5、ピッチ55×75 mm（箱のX/Y）。M3×10／M3ナット各4で四隅を貫通固定。印刷穴は対辺3.45 mmの補正八角穴、入口0.2 mm逃げ。ねじとナット、SMA/XHを外して基板一式を上へ取り出す。GNSS受信基板・ヘッダー・SMAも西6 mm、同軸の端の直線だけ6 mm短縮。基板穴径3.2 mmはM3用の仮包絡で、実穴径は未実測。
- **アンテナと同軸：** ANN-MB1は箱内、中心X60/Y60、下面64.6・上端87.1。88×60×1鋼板上。切らない5 m同軸用にOD100/ID75/H10、Z22.3–32.3を予約し、中心Ø75を全高で空洞にする。外壁4窓へ柔らかい糸を通し、結び目を含め包絡内に収める。指定包絡は実際の5 m巻き容量を保証しない。設計曲げ半径R20以上、MAIN固定板下面Z33.1との公称隙間0.8 mm。

## 組立

1. 床板を上から入れ、M4×12低頭ボタン3本でケースへ固定（南西25/25・南東185/25・北西25/205、頭座16.8）。北東185/205はねじを入れない。床板の座下面は実ボス上面Z10へ接する。公称ねじ込み5.2 mm、購入ねじ型番・インサート実深さは実物確認。床上からM3ナット16個を六角穴へ入れる（AF5.5、厚2.4、下面16.2、Z回転30°）。東端の一部開放穴は台を載せるまで仮保持する。
2. 同軸リング、空のアンテナラックをキーで合わせ、M3×50の4本で共締め。MAIN柱4本と固定板を、北92 mm／上14.2 mmから南へ滑らせ下げる。MAIN基板は北92 mm／上4.8 mmから南へ滑らせ下げる。固定板前左M3×25を1本、柱と基板共締めM3×30を3本、残る基板穴M3×8を1本。鋼板は上からM3×6／ナット各4、アンテナはM4×12／ナット各2で固定する。
3. PWRとTXを固定した後、切り離したSonyスペーサ4本を床へ置く。固定板のキー穴を合わせ、M3×50を4本、頭座62.1で床ナットへ締める。Sony基板はM2.5×6の4本。TXの周囲に壁はない。
4. GNSS前支柱2本・後支柱2本を床へ置き、上台のキー穴を合わせ、M3×40を4本、頭座52.5で共締め。GNSS基板をM3×10／ナット各4で四隅固定し、LIS3MDLをナイロンM2×8／ナット各4で固定して、同軸・配線を取り付ける。
5. 電池台と電池を取り付け、蓋を配線側の端から両側溝へ全長分滑らせ、M3×12ねじ1本を締める。配線をスイッチ・SD・電池の取り出し経路へ結束しない。整備は逆順。南西・北西のケース固定ねじは内装を組み付けたまま、南東はLiPo・蓋・上面フォームだけを外して操作する。詳しい工具姿勢はcase_screw_access_report.mdを参照。

今回の工具穴は電池台・同軸リング0.2 mm、MAIN固定板0.15 mm面取り。囲い外周0.2 mm、長い縦の根元0.1 mm面取り。外周は既存0.05–0.25 mm面取り、新スペーサは0.1–0.15 mm面取り。座面・穴・キーと切離し首の機能寸法は保持。配線の正本は [配線・ケーブル計画](../../docs/配線・ケーブル計画.md)。

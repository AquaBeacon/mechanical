ユーザーがDJI純正Action 6防水ケースであることを確認。写真は穴付きの一体型2枚爪を示す。以下の旧記載にある磁気クイックリリースとの混同は訂正する。

## 寸法の解釈 — **要現物確認**

DJI 公称の軸表記がカメラ本体とケースで揃っていない (ケースの「幅 45.9」は
カメラの「幅 47.2」より小さく、そのままでは内包できない)。
`child_osmo_holder` は下記のように解釈して設計している。

| ケース公称 | 本設計での割り当て | 根拠 |
|---|---|---|
| 94.7 | X = 基線方向 (横幅) | カメラ 72.8 + 壁 ≈ 11/側 |
| 45.9 | Y = 前後 (レンズ〜背面) | カメラ 33.1 + 壁 ≈ 6.4/側 |
| 84.1 | Z = 上下、**底面タブ込みの全高** | カメラ 47.2 + 底面タブ + 上部ラッチ |

3 軸とも公称が本体を内包でき、他の割り当てでは矛盾するのでこの解釈にした。
**現物で 3 軸・底面タブ・レンズ中心高さを測ること。**

## 部品外の考慮

- **カメラの視野 (155°) にテザー・振動子・ライト・アーム・ホルダ自身が入らないこと**。
  `child_osmo_holder` はケース前面より前に出る構造を前リップだけに限り、
  角度余裕を assert で検査している (現在 5.8°)。`assemblies/child_assembly` の
  プレビューでも確認する。
- 充電 / データ用のポートに水中でアクセスしない。**運用前に充電・設定・SD を済ませる**。
  電池交換はストラップ (M4 ×2) を外す必要がある。
- 公称約 4 時間だが**水中・低温で目減り**する。予備電池を用意
  (`../docs/AquaBeacon_確定仕様メモ.md`)。
- カメラ同期は「両 Osmo のタイムコードを同一スマホに合わせる + 潜行前後に水中ライトを
  既知時刻でブリンク」。子機 Osmo の内蔵水深計も活用する。
- ケーブルは無し (独立電源・独立記録)。

## 要選定・要確認

1. **防水ケースの 3 軸・底面タブ寸法・レンズ中心高さの実測**

2. ケースのラッチ位置 → `child_osmo_holder` の `strap_y`
3. 基線の決定 (250 / 300 / 350)
4. 予備電池 / 充電器の手配 (BOM)

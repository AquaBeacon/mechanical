## 構成 (2026-09-04/05 人間決定)

旧計画 (リング浮子 4 分割 + φ20 アルミマスト + Pi Zero カメラポッド) は**廃止**。
2026-09-04 のアーチ式クレードル (`parent_float_cradle`) も、浮子が円筒ではなく挟めないため
**2026-09-05 に廃止**し、中心の空洞に紐を通す方式に変えた。

```
parent_fender ×2 (市販の紡錘形フロート、仮 Ø100×300・空洞 Ø15、軸 = Y、中心 X ±178 / z 0 = 箱底の高さ、浮子は箱の下半分と重なる)
  └ parent_float_yoke ×4 (a ×2 + b ×2。両端の柱の 45° 円錐座で浮子の端を受け、空洞に通した紐で引き寄せる)
      └ parent_deck (216×236、側壁 HP40 ×2/側 にヨークのアダプタ板を M5 ×4 で締結)
          ├ (上) bcas212310g 防水ボックス — 箱底コーナー外部取付穴 Ø4.2 ×4 → デッキ M4 インサート
          │     └ (内) parent_interior_p1 と同一 (plate p1 / P-MAIN / P-PWR / TX / SPRESENSE / LiPo トレイ)
          │     └ (南壁) WetLink M10 ×2 (テザー x=120 / TD04A x=85, z 65)
          └ (下) キール HP40 ×3 (z −60): 南 = xdcr_socket_parent (TD04A 開口下向き)
                                          北 = Osmo Action 6 固定ジグ (★未設計・座は予約)
                                          中央 = 予備
```

- **支柱 (マスト) 無し** — TD04A と Osmo はデッキ下面キールに直付け。振動子面 z ≈ −104。
- **カメラ = DJI Osmo Action 6 + 純正防水ケース** (内装パターン 1)。固定ジグは後日 HP40 北座へ。
- **浮子は端面だけで受ける** (胴には触れない)。紐は「前ヨーク → 空洞 → 後ヨーク」。
- **拡張**: HP40 座は 側壁 4 (ヨークが使用中) + キール 3 = **7 面**。紐穴は 側壁 4 + ヨーク (紐穴 1 + 留め 2) ×4。

## 座標系

箱中心 = 原点、デッキ上面 = 箱底外面 z=0、+Y = 北、+Z = 上。
**箱座標 (x, y, z) → 本座標 (x − 105, y − 115, z)**。
`parent_interior_p1` の内装アイテムはこの平行移動だけで転記した (配置根拠は p1 の md)。
ヨーク: 右舷後 `a` (108, 70, −25) / 右舷前 `b` (108, −70, −25) / 左舷後 `b` 180° (−108, 70, −25) / 左舷前 `a` 180° (−108, −70, −25)。

## 部品外の考慮

- **浮力・復原力** (`spec/parent_hydrostatics.py`、質量 3.14 kg): 喫水線 z −2.7、横揺れ GM 639 mm、縦揺れ GM 201 mm。
  浮子軸を z 0 にしたのは縦揺れ GM が最大になる高さだから (−40 で 107、+50 で 169)。箱は防水なので水面に接して
  よい (人間了承 2026-09-05)。**転倒しないこと**が最優先の要求。**進水時に傾斜試験**で GM を実測する。
- 予備浮力: 浮子 2 本の全没排水量 4.0 L に対し浮子が受け持つのは約 1.6 L。箱・デッキ・ヨークが残りを受ける
  (プリント品は密閉インフィルで浮く)。浮子が大きいほど喫水線が下がり、乾舷が増える。
- テザーは南壁ペネトレータ → 南縁切欠き → キール南端フェアリードで張力止め → 水中へ。
  ヨークのフィンは側壁の外側 (X ±108..±122) なので、キール真下からの経路は塞がない。
- TD04A 面 (z −104) は喫水線 (−2.7) の 101 mm 下。Osmo 座 (−60) も水中。
- Osmo はレンズが喫水線より下に来るジグ高さにする (座面 −60 から 10 mm 以上下げる)。
- 箱固定 M4 は**蓋を開けて上から**の想定 (現物確認待ち。`parent_deck.md` 要確認 1)。
- 最下点は TD04A (−104)。陸上に置くと振動子で接地する → **陸上用の脚か置き台が要る** (未設計)。浮子下面は −90。

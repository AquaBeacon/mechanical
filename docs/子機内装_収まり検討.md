## 2. CHILD_MAIN はフランジ貫通口を通らない

`CHILD_MAIN` は幅 88mm。貫通口は Ø88.49。

- 素の基板 (88 × 1.6) の外接直径 = 88.01 → **紙一重で通らない**
- 部品込み (88 × 24.85) の外接直径 = **91.4** → 明確に通らない
- Ø87.5 (クリア 0.5/側) の円に中心置きできる最大板幅 = **83.9mm**

→ **フランジを付けたままでは内装を出し入れできない。**
ユーザー判断 (2026-07-31) により、**上フランジを外してチューブ内径 101.6 へ
直接落とし込む**方式を採用した。したがって:

- 内装の外形は **Ø101.6 − 壁クリア** に収まればよい (Ø87.5 の制約は端部だけ)
- 内部にアクセスするたびに**上フランジのロッキングコードを抜く**運用になる
  (ドームの M3 を外すだけでは基板に手が届かない)。`child_vertical_assembly.md`
  の分解手順を更新済み

## 3. 断面のパッキング (実プロファイルで探索)

各基板の**幅方向 1mm ごとの上面/下面高さ**を `_mech.stl` から起こし、
「板状アイテムを円筒断面へ積む」総当たり探索 (DFS + 枝刈り) を行った。

| 条件 | CHILD_MAIN + CHILD_PWR + RX + LiPo を 1 断面に |
|---|---|
| 壁クリア 2.0 / 棚 4.0 / 配線ダクト無 | **成立** (ただし余裕ゼロ) |
| 壁クリア 3.0 / 棚 5.0 / 配線ダクト無 | 不成立 |
| 壁クリア 2.5 / 棚 4.0 / 配線ダクト有 | 不成立 |

→ 4 点を 1 断面に詰めるのは**幾何学的には可能だが、実装余裕が無い**
(基板間 4mm・アクリルまで 2mm では、コネクタも配線も工具も入らない)。

いっぽう **CHILD_PWR を外した 3 点 + 配線ダクト**なら:

| 条件 | MAIN + RX + LiPo + 配線ダクト |
|---|---|
| 壁クリア 2.0〜4.0 / 棚 3.0〜5.0 | **全条件で成立** |

## 4. 軸方向の収まり — ここで CHILD_PWR が落ちる

幅広部 (Ø101.6) は 200mm チューブで **160mm**。

| 置き方 | 必要な軸長 | 判定 |
|---|---|---|
| MAIN(112) と PWR(100.4) を軸方向に並べる | 112 + 100.4 + すきま = **216 以上** | ✗ 160 に入らない |
| MAIN と PWR を同一断面に並べる | 断面の積み厚 24.85 + 33.27 = 58.1 | ✗ §3 のとおり実装余裕なし |
| MAIN を横に寝かせる | 幅 112 > 101.6 | ✗ |
| PWR を断面内で寝かせる (100.4 を横) | 100.4 > 101.6 − クリア | ✗ |

**結論: 現行の CHILD_PWR (100.4 × 70 × 33.3) は 200mm チューブに入らない。**

### A案の予算はどう決まったか

> **⚠ 訂正 (2026-07-31)**: 初出時にこの欄を「軸長 68mm 以下」と書いたが**誤り**。
> `RX_improved_mini` も同じデッキ上面を使うことを勘定に入れていなかった。
> 正しくは下記のとおり、**RX をデッキ下面へ移したうえで 56mm** となる。

デッキ上面/下面それぞれの軸方向の取り合いは次のとおり。

```
  デッキ全長      z = -2 .. 202          (両端はフランジ貫通口の中)
  リブ帯 (下)     z = -2 .. 9            ← ここには基板を置けない
  リブ帯 (上)     z = 191 .. 202         ← 同上
  幅広部          z = 20 .. 180          ← 幅 88 の CHILD_MAIN はここにしか置けない

  上面: CHILD_MAIN  20..132 (112)   CHILD_PWR 134..190 (**56**)
  下面: LiPo ベイ    20..132 (112)   RX_improved_mini 134..180 (46)
```

**RX を「90度回してデッキ下面へ吊る」のが効いている。** 3 枚とも上面に並べると:

| RX の置き場 | CHILD_PWR に残る軸長 |
|---|---|
| デッキ上面 (MAIN と直列) | **約 18mm** — 実質不可能 |
| デッキ上面 (下端の貫通口側へ逃がす) | 約 30mm |
| **デッキ下面 (採用)** | **56mm** |

RX は 68 × 46 × 17.3 と薄いので、デッキ下面に **M2** スペーサ 6mm (実穴 Ø2.2) で吊っても
断面に収まる (部品先端の軸心距離 46.3mm / アクリルまで 4.5mm)。
デッキに貫通穴を開けるだけなので**追加の印刷部品は要らない**。

## 6. 部品外の考慮

- **ケーブルは全部 下キャップから**来る。下リブの大開口 (40 × 22) →
  デッキ左右の配線スリット (14 × 26 ×3箇所) → 基板側、という経路にしてある。
  リブの結束スロット (±26) でストレインリリーフを取る。
- **LiPo のリードは +Z 側 (上)** に向ける。ベイ上端 z=134 から MAIN の
  `J_PWR1` (基板端 u≈0 → z≈21) までは逆方向なので、**リード線が 110mm 以上要る**。
  T プラグ + XT60 変換の全長を実測して足りるか確認すること。足りなければ
  ベイの向きを 180° 回す (`box_z0` はそのまま、LiPo だけ逆向きに入れる)。
- **上フランジを抜かないと内装が出ない**。ドームを開けてからフランジの
  ロッキングコードを抜く手順・工具スペースを実物で確認すること。
- **DS3231 ZS-042 の 10mm はピン先端込みの実測値**で、ソケット挿入分だけ
  下がる可能性がある (KiCad 側 `pcb/3d/README.md` 参照)。下がれば
  MAIN 高背ゾーンのすきま 3.8mm はさらに増える方向。
- 密閉容器内なので**放熱は容器壁だけ**。CHILD_PWR の LDO とライト定電流回路が
  発熱源になる。t300 にする場合は PWR をチューブ壁に近い側へ置くとよい。

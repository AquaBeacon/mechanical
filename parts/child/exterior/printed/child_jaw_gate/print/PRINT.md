# child_jaw_gate v2 — 印刷指示 (X1-Carbon)

`child_jaw_gate_print.stl` は印刷姿勢に回転済み・ベッド (z=0) 中央に置いた STL。Bambu Studio にそのまま読み込める。
スライス済みプロジェクトは `mechanical/print_jobs/child_jaw_gate/child_jaw_gate.3mf` (設定込み)。

| 項目 | 指示 |
|---|---|
| 材料 | **PETG** (Bambu PETG Basic プロファイル、テクスチャ PEI プレート) |
| 姿勢 | **+Z up (モデル姿勢のまま)。プレート = 下ポケット帯の底** — 向きを変えない (FEA の層方向がこの姿勢) |
| 外形 | 152 × 74 × 235 mm (X1C 256 × 256 × 256 に収まる) |
| レイヤ / ノズル | 0.20 mm / 0.4 mm (`0.20mm Strength` ベース) |
| 壁 / 上下 | **壁 4 周 / 上下 5 層** |
| インフィル | **gyroid 40 %** (板厚 4〜6 mm の部材はほぼ壁だけで埋まる) |
| サポート | 自動サポート (45°)。中帯・上帯の下面 (873 mm² ×2)、ヒンジ中・上ブロック下面、HP4/HP5/HP-L 座面板の下面。ノブ頭ポケット底と 45° コーンは不要 |
| ブリム | 外側 5 mm |
| 見積 (Bambu Studio 02.05 CLI) | **10 h 39 m、297 g** (サポート・ブリム込み)、1702 層 |

- 
ブリム推奨 (接地 1,722 mm²)- ノブボルト頭 Ø16 と容器の干渉 (latch_hx) が未解決。印刷前に判断すること- HP40 インサートボスの壁 2.8 mm (規格値) — インサートは座面に垂直に圧入

# DJI Action 6：背面M3直接固定版

2026-09-17改訂。背板の空き部分へM3・40×40 mmの4穴を設けた一体部品。別体アダプターは不要。ユーザー指定によりインフィル15%に変更。

![子機frontへの取付状態](_work/images/frame_view.png)

## 印刷するファイル

- [印刷用3MF](../../../../../print_jobs/dji_osmo_action6_mount_m3/camera_mount_x1c_petg.3mf)：1個、印刷向き・15%インフィル設定済み。
- [STL](camera_mount.stl)／[STEP](camera_mount.step)／[SCAD](camera_mount.scad)：部品座標、底面Z=0。
- [機体座標のSTEP](assembly.step)：直接固定する位置の部品1個。筐体やカメラは含まない。
- [印刷手順](../../../../../print_jobs/dji_osmo_action6_mount_m3/PRINT.md)。以前のアダプターは不要。旧データはarchive_adapter_obsoleteに退避。

## 形状変更

- 背面のM3通し穴4個：40×40 mm、設計クリアランス径Ø3.45以上。横穴の上部に45°屋根を設ける。
- 背板厚8 mm。カメラ側から深さ3.6 mm・径6.8 mm以上の座ぐり。M3キャップボルトの頭（径5.5、高さ3 mm）を背板表面より0.6 mm内側に収める。
- 背面リブをx=±38へ移動し、厚さ6 mmにする。筐体の取付板だけでなく補強リブも避ける。背面中央の底板張り出しを幅62 mmで除去し、背板が筐体に直接当たる。
- アダプター接続に使っていた底面M5穴4個とその工具逃げは廃止。追加のM5締結部品は不要。
- 下側M3ボルトに六角レンチを通すため、前側支持壁に径5 mmの屋根付き工具穴2個を追加。
- 前側支持壁と接触座の**+Y方向8 mm移動を維持**。カメラの3枚爪、ねじ軸、背面接触位置、前側座の高さ・幅・奥行は維持。
- 背板と前壁の屋根付き肉抜き窓、底板の側面スロット、底板幅100 mmを維持。根元・穴周りの材料を残す。

## マウント規格とねじ

[CHILD-SIMPLE-M3-40x40 Rev.1](../../../../../docs/child_simple_mount_interface.md)に対応。筐体の既存穴は変更しない。

機体座標の取付面中心 `(0,82,100)`、穴中心 `(±20,82,80/120)`。部品のローカル穴中心はx=±20、z=20/60。機体へは `[0,113.45,60]` の移動で配置する。

- **M3×20 キャップボルト4本**（頭径5.5・高さ3 mm）、外付けM3ナット4個、ナット側ワッシャ4枚。
- 頭側は座ぐりへ直接着座。頭側ワッシャは入れない。大径頭・つまみねじはこの座ぐりの対象外。
- 座ぐり後の保持部厚4.4＋筐体厚8＋ワッシャ約0.5＋ナット約2.4 mm。20 mmねじで先端は約4.7 mm突出する計算。実物のねじ・ナットで確認。
- カメラを載せる前に本体を固定する。下2本は前壁の工具穴から2.5 mm六角レンチを通す。工具軸の許容包絡はØ3 mm。大径ドライバービットは使わない。
- カメラ側の既存ねじ・ナットは別途そのまま使用。

## 印刷見積もり

X1 Carbon、0.4 mm、Generic PETG、Textured PEI。0.20 mm、壁6周、上下6層、**Gyroid 15%**、外側ブリム3 mm、**サポートなし**。底板を下に印刷する。

|対象|同じ15%設定の推定時間|材料（ブリム込み）|
|---|---:|---:|
|元の指定STL|3時間16分|110.5 g|
|背面直接固定版|3時間05分|101.0 g|

同じ設定で材料約8.6%、時間約5.2%（約10分）削減。ソリッド体積は144.20→124.78 cm³、約13.5%減。前のアダプター付き2部品セットは廃止し、この1個だけを印刷する。

## 確認範囲

- OpenSCADレンダリング、閉メッシュ、単一連結、有効な単一STEPソリッド、STEP/STLの外形・体積照合を実施。
- 子機frontとの交差体積0 mm³。M3の4穴同軸・貫通、ねじ頭の収まり、前方Ø3 mm工具、後方Ø10 mmナット工具をCAD確認。
- Bambu Studioのスライス成功、警告なし。3MF破損検査、G-code内のサポート経路0。実機印刷は未実施。小さな横穴とナット座の垂れ・バリは印刷後に確認。
- 肉抜きと15%インフィルは軽量化設定であり、強度向上を実証したものではない。変更後の強度解析・荷重試験は未実施。
- 「手前」はカメラ正面の+Yと解釈し、前座はy=24〜30へ移動済み。古いケース仮包絡の前端y=22.95とは一致しないため、再印刷後の接触確認は必要。ユーザーの試作結果を反映した位置変更であり、カメラとの再適合は未検証。

元のTO_printingのSTLは変更していない。再生成は `spec/build_camera_mount_m3.py`、`spec/export_camera_mount_m3.py`、`spec/slice_camera_mount_m3.py`。確認記録はmesh_checks.json、cad_checks.json、印刷フォルダのcomparison.json。

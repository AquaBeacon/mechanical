# parent_spar_disk

親機ねじ固定外装。数量 1。寸法 [225.0, 225.0, 5.0] mm（印刷姿勢）。

設計ソースは `scad/lib/parent_spar_bolted.scad` の `disk`。
印刷用STLは `print_jobs/parent_spar_bolted/parent_spar_disk.stl`。部品フォルダのSTL/STEPは組立座標。

締結表・材料・組立順・未検証条件は `assemblies/parent_spar_bolted/README.md` を参照。
閉じた単一メッシュ・250 mm枠・5 mmブリムを含む保守的なベッド配置を機械確認。
実荷重の安全率・疲労・水密性は未評価。

# child_vtray_rib — 子機 縦置き内装 センタリング バルクヘッド

| 項目 | 値 |
|---|---|

| 設計ソース | `child_vtray_rib.scad` |

## 役割

`child_vtray_deck` の**両端 (幅 76mm の細い部分)** に挿して、内装を
フランジ貫通口 (Ø88.5) の中心に保持する。上下 2 枚で内装の姿勢が決まる。

軸方向は、デッキ先端から差し込んで**内側ショルダー (幅 84mm) 1 本**に当て、先端側は
デッキ板を貫く **M2.5×6 なべ (頭 Ø4.5、板上面に座る)** で抜け止めする。
**2026-09-03 変更**: 以前は先端側にもショルダーがあり、リブのスロット (76.4) が
幅 84 のショルダーを越えられず物理的に嵌められなかった (人間指摘)。先端側ショルダーを
廃止し、止めねじに置き換えた。組立: リブをデッキ先端に通す → ショルダーまで押し込む →
M2.5 を板上面から締める (先端が板下面に 2mm 出てリブを止める)。
挿入経路の掃引検査 (デッキ ∩ リブ掃引体積 = 空) は `assemblies/child_interior/views/rib_sweep.scad`。

中央下寄りは**ケーブル通路**として大きく開けてある。下キャップのペネトレータから
来るケーブルはすべてここを通る。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `flange_bore / bore_clear` | 88.5 / 1.0 | 貫通口Ø (実測) / 径クリアランス → 外径 Ø87.5 |
| `rib_t` | 6 | 板厚 |
| `lead_chamfer` | 0.8 | 両面外周の挿入ガード面取り |
| `deck_wn / deck_t / deck_y0` | 76 / 4 / −10 | デッキ端部の断面 (deck と一致させること) |
| `slot_clear` | 0.4 | 嵌合クリアランス (片側 0.2) → スロット 76.4 × 4.4 |
| `duct_w / duct_y0 / duct_y1` | 40 / −36 / −14 | ケーブル通路 (40 × 22) |
| `tie_x / tie_y / tie_w / tie_l` | ±26 / −19 / 3.5 / 10 | 結束バンド スロット |
| `side_d / side_x / side_y` | 14 / ±29 / 12 | 上側の補助通し穴 (基板側へ上げる線用) |

導出: スロット横に残る肉 **5.55mm** — ここでリブの上下がつながっている。

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_vtray_deck` | 嵌合 + M2.5×6 止めねじ。内側ショルダーと止めねじ頭の間 (Z 方向 7mm) に収まる |
| アクリルチューブ / フランジ | Ø87.5 で貫通口 Ø88.5 に対し片側 0.5mm |

**`child_vtray_deck.scad` の `deck_wn` / `deck_t` / `deck_y0` と同じ値を
このファイルにも書いている。片方だけ直さないこと。**

## 干渉チェック (`.scad` の assert)

- 嵌合スロットの角が円板の縁からはみ出さないこと
  (はみ出すとリブが 2 枚に割れる)
- スロット横に残る肉が `min_web` 以上 ← **最初 `deck_wn = 82` で 2.55mm しか
  残らず assert が止まった**。デッキ端部を 76 に細くして 5.55mm を確保した
- ケーブル通路・結束スロット・補助通し穴が円板の中に収まること
- 各開口が嵌合スロットに食い込まないこと

## 印刷向き

**円板を寝かせて (Z を上に) 印刷。** 全フィーチャが貫通なのでサポート不要。
外周両面の0.8mm面取りが、フランジ穴とアクリル内壁への引っ掛かりを防ぐ。

## 部品外の考慮

- **下側のリブがケーブルの要**。テザー / 振動子 / ライトの 3 本 + 予備が
  下キャップのペネトレータ (M10 ×5) からここを通って基板側へ上がる。
  通路 40 × 22 = 880mm² に対し、Ø7.5 のケーブル 4 本で約 177mm² なので余裕はある。
- **ストレインリリーフは結束スロット (±26) で取る。** ペネトレータのシール部に
  引張をかけないこと。
- リブは薄い (t6) わりに開口が多い。**印刷は壁 4 本以上・インフィル 30% 以上**を
  推奨。とくにスロット横の 5.55mm の肉は割れやすい。
- 上側のリブは配線が通らないなら塞いでもよいが、**同じ部品を 2 枚使う**方が
  管理が楽なので同形状にしてある。

## 要確認

1. 貫通口 Ø88.5 の実物ノギス確認 (STL からの読み取り値)
2. ケーブル実本数・実外径 → 通路 40 × 22 の妥当性
3. ショルダー嵌合のがたつき (Z 方向 1mm の遊びがある)。大きければ
   `child_vtray_deck.rib_gap` を詰める

# child_bottom_guard — 下部ガード / 脚 / バラスト座

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_bottom_guard.scad` |
| 個数 | 1 |
| 外形 | **Ø198 × 55 mm** (z -37..18) |
| 体積 | 250.8 cm³ (STEP) → PETG 約 190 g |
| STEP | 1 ソリッド / 130 面 |

## 役割

縦置き子機の一番下。**4 つの役目を 1 部品で持つ**。

1. **アルミエンドキャップとペネトレータを着底衝撃から守る**
   (スキッド底面 z=-37 が、ペネトレータ先端より約 3mm 下)
2. **容器の重量を 3 点パッド (r 42..50) で受ける** — シェルのクランプ力に頼らない
   軸方向ストッパ。アクリルチューブに軸方向の摩擦荷重を掛けない
3. **陸上で自立させる脚** (スキッドリング Ø198)。ドームを接地させずに置ける
4. **バラスト (鉛) の取付座**。M6 ×5 の取付位置を変えて**吊り姿勢をトリムする**

## ケーブルの逃げ (★ 最重要)

**中央 r<42 は完全に素通し。後方 (-Y) ±40° のセクタには構造物を置いていない。**

| ケーブル | 経路 |
|---|---|
| テザー | キャップ → 真下 → リング後方の結束スロット (±10°) でストレインリリーフ → 機体外周を上へ |
| TD04A | キャップ → 後方セクタ → 後半シェルのパイロン内 (導管) → 上のソケット |
| ライト | キャップ → 後方セクタ → 機体外周 → 前半シェルのデッキ結束スロット → ライト |

**ペネトレータの締付け (バルクヘッド 3.5 N·m / プラグ 約 14 N·m) は、
このガードを外した状態で行うこと。** ガードは M5 ×4 で後半シェルの底フレアに
留まっているだけなので、工具アクセスのために外せる。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `cap_z` | -13.8 | アルミキャップ下面 (STL 実測から導出) |
| `pad_r0..r1` / `pad_w` | 42..50 / 24 | キャップ支持パッド ×3 |
| `pen_or` | 39 | ペネトレータ外形の外端半径 (BCD/2 28 + 六角半幅 11) |
| `cap_scr_bcd` | 108 | キャップ取付 M3 の BCD **要確認** |
| `ring_r0..r1` / `ring_z0..z1` | 79..99 / -37..-25 | スキッドリング |
| `spoke_w` / `spoke_t` | 30 / 6 | スポーク ×3 (リング ↔ 支柱) |
| `arm_a` | 60 / 180 / 300 | スポーク・支柱の方位角 (0 = 真後ろ) |
| `lug_r` / `lug_a` / `lug_z1` | 70 / ±40, ±68 / 18 | シェルへの取付ラグ ×4 |
| `leg_w` / `leg_t` / `leg_ang` | 24 / 20 / 21.6° | 脚 ×4 (垂直からの傾き) |
| `bal_d` / `bal_r` / `bal_a` | 6.5 / 89 / 0, ±100, ±140 | バラスト M6 ×5 |

支持パッドの半径は「**ペネトレータ (r≤39) より外、キャップの M3 頭 (r=54) より内**」
の隙間に置いてある。r 42..50 はこの窓のほぼ中央。

## インタフェース (**二重定義。片方だけ直さないこと**)

`child_shell_aft` と共有: `lug_r=70` ↔ `guard_r=70`、`lug_a=[40,-40,68,-68]` ↔
`guard_a`、`lug_z1=18` ↔ `shell_z0=18`。

締結は **M5 ×4 (M5×30)**。ナットは後半シェル側のフレア上面のポケットに入る。

## 干渉チェック (`.scad` 冒頭の assert — 実際に止まったもの)

1. **脚の根元がリングの帯幅からはみ出して宙に浮く** → リング幅を 12 → 20mm に広げた
   (Ø190 → Ø198)。「assert を緩める」のではなく形状を直した
2. **バラスト穴の干渉判定が方位角の巻き戻しを扱えていなかった** (a=0 と a=180 を
   「同じ角度」と誤判定) → `angdiff()` を導入して弦長で判定するよう直した

常時検査しているもの:

- 支持パッドがペネトレータにもキャップの M3 頭にも掛からないこと
- **真後ろのケーブル用セクタが ±25° 以上開いていること** (**現在 ±40°**)
- 支柱がスポークの上に載ること / 支柱の下端がスポーク上面と一致すること
- 脚の傾き < 45° (**現在 21.6°** → 無サポート) / 脚がラグ下面を支えられる太さか
- スキッド径 ≤250 / 全高が 300 枠を超えないこと / ベッド高さに入ること
- バラスト穴・結束スロットが脚/スポークに掛からないこと

## 強度

| 項目 | 値 |
|---|---|
| 容器の自重 (1.85kg × 3g = 54N) を 4 本の脚で受ける | 脚断面 24×20 → **0.03 MPa** |
| 陸上で自立 (全備 5.7kg) | リング全周で受ける → 無視できる |
| 着底衝撃 | **塑性変形で吸収する前提の消耗品**。割れたら刷り直す |

ガードは「壊れることで容器とペネトレータを守る」部品。
**強度を上げすぎない方がよい** (硬くすると衝撃がキャップへ抜ける)。

## 印刷向き

**このまま。** スキッドリング底面 (z=-37) が約 6700mm² のベッド接地面。
脚は垂直から 21.6° なのでサポート不要。スポークもベッドに接する層にある。

## 部品外の考慮

- **バラストは 1.1〜2.2 kg の鉛**を M6 ×5 の好きな位置に付ける
  (浮力の見積りは `docs/AquaBeacon_機体設計.md`)。
  **前後の取付位置で吊り姿勢 (前傾/後傾) をトリムできる** — 重心が吊り点より
  約 6mm 前にあるので、後ろ寄り (a=0 付近) に置くと水平に近づく。
- 鉛は**海水で溶出する**。エポキシで包むか、ステンレスの錘を使うこと。
- **陸上での置き方**: 3 本脚 + リングで自立する。傾転角は約 33°
  (重心 z≈69 / 脚半径 99)。**波打ち際や船上では必ず固縛すること。**
- リング後方の結束スロット ×2 は**テザーのストレインリリーフ**。
  張力はここで受け、ペネトレータのシール部には掛けない。
- 砂地に着底するとリングの中に砂が入る。**引き上げ後に真水で洗うこと**
  (中央が開いているので流し落とせる)。
- ガードを外さないとペネトレータの工具が入らない。**分解順序**:
  ガード (M5×4) → 前半シェル (M5 蝶ボルト ×4) → 容器を真上へ。
  ただし**内部アクセスだけならドームを開ければよく、ガードもシェルも外さない**。

## 要確認

1. **キャップ取付 M3 の BCD** (`cap_scr_bcd = 108` は公称からの推定)。
   実物で M3 頭の位置を測り、支持パッド r 42..50 と当たらないことを確認する
2. **ペネトレータの突出量**。`ring_z0 = -37` は「キャップ下面から 23.2mm」で
   決めている。実物が長ければ `ring_z0` を下げる (ただし全高 300 の枠を食う)
3. 実際に必要なバラスト量 (浮力計算は仮値だらけ)。**進水前にプールで実測すること**
4. M5×30 ×4 / M6 ボルト (バラスト用、長さは鉛の厚みによる)

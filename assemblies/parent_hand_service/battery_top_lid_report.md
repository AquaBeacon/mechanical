# 電池ボックス：上方取り外し蓋（2026-10-29）

全長スライド溝を廃止し、蓋を真上へ外す構造へ変更。ボックスを持ち上げるために底の固定ねじ4本を外す操作は不要。防水容器の外蓋を開け、電池蓋のM3×12を1本外してから、蓋を上へ取り外す。

再印刷は **battery_base と parent_lipo_retainer_lid_slide を各1個**。後者は既存参照との互換性のためファイル名だけを保持しており、形状はスライド式ではない。旧蓋と新本体、または新蓋と旧本体を組み合わせない。印刷用データの入口は [parts/PRINT.md](parts/PRINT.md)。

## 構造と締結

- 蓋厚3 mm、上面補強リブ高さ3 mm。下面は平面で、電池上面の既存フォームに接する。
- M3×12はボックス局所座標X50／Y5の1か所。蓋の通し穴は対辺3.45 mmの補正八角形、ボックスの樹脂下穴は直径2.8 mm。新しいナットは不要。
- ねじ頭座面Z32 → 蓋3 mm → ボックス一体ボス上面Z29 → ボス内部の樹脂ねじ部、の順に荷重を伝える。ねじ先端Z20、下穴底Z18で底付き余裕2 mm、名目ねじかかり9 mm。ねじは蓋をボックスへ押さえ付ける。
- 4本の位置決めピンは局所X12／91、Y5／50。1.4 mm角、高さ2 mm。蓋の2.0 mm角の穴に片側0.3 mmのすきまで入り、横ずれを抑える。ピンに上向きの抜け止めはなく、ねじを外せば真上へ離れる。
- 電池の位置、既存フォーム、配線側の開口、床への取付4か所は維持。配線をねじ座や位置決めピンへ挟まない。

樹脂への直接ねじ固定は既存方式を継承する。CADで確認できるのは座面・経路・名目かかり長さであり、ねじ山の破損荷重、繰返し開閉、蓋のたわみ、波浪荷重やPETGのクリープの保証ではない。実物で過締めせず、嵌合と保持を確認する。

## 印刷とエッジ

ボックスは底面をベッド、蓋は平らな下面をベッドとして双方とも原姿勢（回転0°）。位置決めピンとリブは上へ積層する。旧側溝用・旧ナット用のサポート禁止モディファイアは使用しない。ねじ下穴は縦向きの盲穴で、空洞上の屋根を持たない。下穴底の既存45°逃げにスライサが微小な支持材を生成するため、`battery_lid_pilot_support_blocker` を新しい穴位置X50／Y5へ移動して同梱した。これは印刷する部品ではなく、穴内だけのサポート禁止設定として使う。

蓋の縁・リブ・穴口は0.15 mmを基本に面取り、ピンは0.1 mm面取り。ボックスの既存面取りと機能接触面は継承する。樹脂下穴は既存の円形2.8 mmの嵌合を保持する。

## 生成と証拠

正本は `scad/lib/parent_battery_slide.py` と `spec/build_parent_hand_service.py` の電池生成部。新しい基盤レシピ `spec/build_parent_battery_top_lid.py` は同じ正本を呼び出す。SCAD／STEP／STLは同じ形状からの生成物。過去の解析・印刷ジョブは履歴として残す。

再生成：`python -X utf8 spec/revise_parent_battery_top_lid.py`。配置検証：同コマンドに `--verify`。検証後の同期：`python -X utf8 spec/publish_parent_battery_top_lid.py`。

今回の記録は [_work/analysis/battery_top_lid_20261029/](_work/analysis/battery_top_lid_20261029/)。`build_run.json` は形状の保存・再読込、`checks.json` は取外しと締結経路、`mesh_checks.json` は閉メッシュとOpenSCAD照合、`slice_checks.json` はスライサ処理結果。実物の印刷・実配線・保持強度は未検証。

X1C／0.4 mm・PETG・積層0.2 mm、4壁、充填100%の既存プロファイルでスライスを確認した。支持材検出45°を有効にし、本体は上記穴内禁止設定を併用。最終結果は本体・蓋とも支持材0。実造形の保証ではない。PC上の一時CAD／スライサ処理はタイムアウト付きで実行し、PIDと終了状態を解析フォルダへ記録している。

全体の既存ツールテストは42件中41件成功。電池変更とは別の `test_clamp_bambu_material` は、子機クランプの既存材料JSON欠落でエラー。今回そのファイルや子機形状は変更していない。

対象 `parent_hand_service` の印刷一式チェックと作業ファイル配置チェックはPASS。全構成チェックには子機の未管理3MF、および旧親機構成の出所・文書不一致が残る（`_work/logs/battery_top_lid_all_parts_check.log`）。この電池変更で旧構成を一括更新せず、検証済み範囲を本構成へ限定した。共有生成元の更新をフォルダ単位で検出するため、同梱の他部品は既存STEPを再メッシュし、形状の保存・再読込と閉メッシュを照合した。これらの部品を新設計へ置き換えたものではない。

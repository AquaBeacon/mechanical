# parent_rope_keel_adapter

浮きを紐で接続する親機用。デッキ中央下面HP40から32角の印刷支柱へ接続する。浮きには接続しない。

外形60×60×48 mm。上板8、支柱差込み40、角穴32.5。M5通し穴4個（40角ピッチ）、横M6通し穴1個。M5×16×4はデッキ既存インサートへ、横M6×60はナットへ締結する。角を開いた4面の支持部により、M5ねじ頭・座金・工具の空間を確保。

`part="print"` が印刷姿勢。上板のデッキ接触面を下にして印刷し、ソケットを上へ向ける。X1 Carbon、0.4 mm、0.20 mm、PETGの既存試作設定を使用。実負荷での強度・疲労・嵌合試験は未実施。

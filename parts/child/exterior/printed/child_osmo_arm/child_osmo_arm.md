# child_osmo_arm — 子機 カメラアーム (GoPro 互換)

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_osmo_arm.scad` |
| 個数 | 2 (**左右共通。左舷はミラーせず同じ物を裏返して使う設計**) |
| 外形 | 125.5 × 80 × 22 mm |
| 体積 | 50.0 cm³ |
| STEP | 1 ソリッド / 56 面 |

## 役割

`child_frame_plate` の側縁に M5×4 で固定し、GoPro 互換 2 フィンガーマウントを
**基線 250 / 300 / 350 mm** (片側 125 / 150 / 175) の 3 位置に持つ。
カメラの下向き 20° は GoPro ナックルの角度で作る (アーム側は水平)。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `hole_x / hole_y` | [70, 90] / ±30 | M5 位置 (フレーム座標) ← `child_frame_plate` と一致 |
| `pad_x0 / pad_x1 / pad_y` | 60 / 100 / 80 | 取付パッド |
| `arm_t` | 6 | 板厚 |
| `beam_w / rib_h / rib_t` | 40 / 10 / 4 | ビームと縁リブ |
| `base_line` | [125, 150, 175] | フィンガー中心 X (= 基線の半値) |
| `fin_t / fin_gap / fin_w / fin_h` | 3.0 / 3.4 / 15 / 16 | GoPro フィンガー |
| `pin_d / pin_z` | 5.2 / 10 | M5 ノブボルト穴 |

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_frame_plate` | M5 ×4、下からボルト + ナットで共締め |
| `child_osmo_holder` | GoPro 2 フィンガー + **M5 ノブボルト**。ホルダ側は 3 枚爪 |

**GoPro ナックルは不要になった。** 下向き 20° は `child_osmo_holder` に
作り込んである (このアームは水平のまま)。
ホルダは `arm_fin_t / arm_fin_gap / arm_fin_w / arm_fin_h / arm_t / arm_pin_z /
arm_beam_w / arm_rib_t / arm_rib_h / arm_pitch / pin_d` を**二重定義**で持っている。
このアームの寸法を変えたら `child_osmo_holder.scad` も必ず直すこと。

アセンブリでは右舷 = そのまま、左舷 = `mirror([1,0,0])`。

## 干渉チェック (`.scad` 冒頭の assert)

- 最内フィンガーが取付パッドに乗り上げないこと
- ピン穴がフィンガー上端に接近しすぎないこと
- フィンガー同士のピッチ ≥ `fin_w + 8` (カメラ実幅とは未照合)

## 印刷向き

平置き (このまま)。フィンガーは垂直壁なのでサポート不要。

## 部品外の考慮

- **フィンガーは折れやすい**。積層方向がフィンガーの曲げ方向と直交するよう
  平置きにしてある。壁厚 3.0mm は GoPro 規格なので厚くできない。
  → 素材は靭性のあるもの (PETG / ASA / PA) を推奨。
- カメラケーブルは**なし** (アクションカメラは独立電源・独立記録の想定)。
  有線化するならアーム上の配線路と結束点が要る (**未設計**)。
- カメラの視野にアーム自身・テザー・ライトが入らないこと。
  `assemblies/child_assembly` のプレビューで確認する。
- 基線を変えるとステレオ較正が変わる。**運用前に基線を確定し、以後変えない**こと。

## 要確認

1. 基線 (250 / 300 / 350) の決定
2. `fin_h = 16` / `pin_z = 10` は GoPro 標準より背が高い。ホルダのプロング
   (半径 10 の円板) はフィンガー上端 (ピン中心 +6) を覆えているが、
   下端の角 (ピン中心から 12.5) は覆えていない。実機で締結剛性を確認すること。

### 解決済み

- ~~カメラ + 防水ハウジングの実幅 → フィンガーピッチ 25mm で干渉しないか~~
  → 機種確定 (DJI Osmo Action 6 + 純正防水ケース 94.7 × 45.9 × 84.1)。
  **ケースは 3 箇所のフィンガーピッチ 25mm より遥かに幅広い (94.7)** ので、
  使うのは 3 箇所のうち **1 箇所だけ**。残り 2 箇所の未使用フィンガーの上を
  ケースとホルダが跨ぐ。その干渉は `child_osmo_holder.scad` の assert
  (「クレードル床/ステム/床下ガセットが隣のフィンガーに干渉」) で検査している。
- ~~ナックルの型番と 20° の出し方~~ → `child_osmo_holder` に作り込んだ。

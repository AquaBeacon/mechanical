# 子機フランジねじ穴検証

対象: `parts/child/exterior/cots/wte4_flange/BR-101040_RevC.step`

FreeCAD 1.0のCADカーネルで円筒面と円エッジを直接抽出した。外観画像やSTL三角形の目視値ではない。

## 結果

- フランジ軸中心: STEP座標 `(0, 0)`
- M3ねじ穴中心: BCD 94.000 mm（軸から半径47.000 mm）
- 穴位相: 下フランジをアセンブリ姿勢へ変換後も `0° / 90° / 180° / 270°`
- 筒側の開口面: STEP `Z=0`。下フランジ配置ではアセンブリ `Z=19`
- モデル上のねじ形状深さ: `6.049 mm`

| 下フランジ角度 | アセンブリ中心座標 (mm) | 内装で使用 |
|---:|---:|:---:|
| 0° | `(47.000, 0.000)` | ○ |
| 90° | `(0.000, 47.000)` | ○ (2026-09-03: `child_lcd_support_lower` の耳、M3×12 直接) |
| 180° | `(-47.000, 0.000)` | ○ |
| 270° | `(0.000, -47.000)` | — |

旧治具の225°/315°には実穴が存在しなかったため、`child_vtray_batt_box.scad`を0°/180°へ修正した。治具穴中心の計算値は上表と一致し、中心誤差は0.000 mmである。

治具下面はアセンブリZ=29.5、フランジ内面はZ=19のため、間隔は10.5 mm。10 mm金属スペーサ＋0.5 mm樹脂/金属シムを標準とし、M3ねじのフランジへの有効かかりは4.0–5.0 mmに制限する。6 mmを超えてねじ込まない。


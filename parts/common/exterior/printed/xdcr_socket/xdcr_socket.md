## 役割

円筒ソケットに TD04A を差し込み、結束バンド 2 本で保持する。

| バリアント | `tilt_deg` | 取付先 | 状態 |
|---|---|---|---|
| `xdcr_socket_child` | 0 (垂直)、**base_w=50** (2026-09-04) | frame2: `child_core_frame` ペデスタル HP1 (0, −85, z218.5) へ M5×4。開口 = 上向き。(旧: `child_frame_plate` 後方コーナー) | **ビルド可** |
| `xdcr_socket_parent` | **0** (2026-09-04) | `parent_deck` キール南 HP40 座 (0, −70, −60) の下面。開口 = 下向き (X 軸 180° 回転) | **ビルド可** (child と同形状 50 × 50 × 38) |

## 親機バリアント (2026-09-04 改訂: tilt 0)

親機は支柱 (マスト) 無しになり、TD04A はデッキ下面の HP40 座 (M5 ×4 @ 40 = 本部品の
`hole_p`) に**傾き無し・開口下向き**で付ける。`variants.txt` の `parent` は
`tilt_deg=0 base_w=50` で child と同形状 (アセンブリが参照する名前として分けている)。

旧 parent (tilt_deg = 20、マストヘッド用) は assert
「M5頭がスカートと干渉: 頭内縁 24.03 < スカート半径 34.03」で停止したまま**廃止**
(傾きが要るなら HP40 側に楔アダプタを作る)。
底の Ø9 は下向きでは水抜きにならないが、ソケット開口が下なので水は溜まらない。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `tilt_deg` | 0 / 20 | ソケット軸の傾き |
| `base_w / base_t` | 60 / 6 | 取付ベース |
| `hole_p / m5_d` | 40 / 5.3 | M5 4 穴ピッチ ← `child_frame_plate.xd_pitch` |
| `xdcr_d` | 26.4 | TD04A 胴径 26.0 (**要実測**) + 0.4 |
| `wall / depth / floor_t` | 5 / 32 / 6 | ソケット肉厚 / 差込み深さ / 底厚 |
| `cable_d` | 9 | 底のケーブル/水抜き穴 |
| `tie_w / tie_t / tie_z` | 5.5 / 3 / [12, 24] | 結束バンドスロット |

## 干渉チェック (`.scad` 冒頭の assert)

- 傾き ≤ 25°
- M5 穴の端距離
- 傾きでソケットがベースから大きくはみ出さないこと
- **M5 頭 (Ø8.5) がスカートに乗り上げないこと** ← 親機バリアントはここで止まる

## 印刷向き

ベースを下に平置き。ソケットは垂直円筒で無サポート
(tilt > 0 のときはスカートが 45° を保証する形状になっている)。

## 部品外の考慮

- 底の Ø9 は**ケーブル出しと水抜きを兼ねる**。塞がないこと。
  親機 (下向き) では水抜きにならないので、別途排水を考えること。
- 振動子の**放射面を塞がない**。ソケットは胴を掴むだけで、放射面は開口から出る。
- **ケーブル 3m + 3P プラグ**が付いてくる (`td04a_transducer.md` 参照)。
  プラグは水中コネクタではないので、子機では容器内 or 水面上に収める。
- 結束バンド (4.8mm 帯) は消耗品。締め直しのため**工具/指が入る**こと。
- 気泡が振動子面に残ると測距できない。設置後に**面を撫でて泡を抜く**運用手順が要る。

## 要確認

1. TD04A 胴径・胴長の実測 → `xdcr_d` / `depth` の確定 (最重要)
2. 親機バリアントの設計方針決定 (上記 3 案)
3. ケーブル外径 → ペネトレータ型番

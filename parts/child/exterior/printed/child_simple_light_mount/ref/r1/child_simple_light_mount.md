# 子機シンプル筐体用 水中ライトマウント（試作）

2026-09-17。ユーザー確認済み：背面中央のM3・40×40 mm接続、参考STLの短い筒がライト用。
元STLは `ref/Light_Gassyli_Holder.stl` に保存。短い筒の内径33・外径39・高さ81 mmを測定。
**33 mmは参考ホルダーの内径であり、ライト実物の測定値ではない。**
ガスボンベ保持部は含めず、ライトを横から着脱する二分割クランプとして再設計した。

## 寸法と取り付け

| 項目 | mm |
|---|---:|
| クランプ公称内径 / 保持長 | 33 / 81 |
| 筒の肉厚 | 4 |
| 半割間の締め隙間 | 1.5 |
| 接続板 | 60×60×6 |
| 筐体接続穴 | 40×40、4×Ø3.45（24角補正） |
| 全体外形 | 65×61×81 |
| 接続面からライト中心まで | 40.5 |
| 接続板と筒の最小隙間 | 14 |

CHILD-SIMPLE-M3-40x40 Rev.1に対応。共通寸法は `scad/lib/child_simple_frame.scad` から読み込む。
ローカル原点は接続面中心。+Yが筐体から外向き、Zがライト軸。
機体配置は `translate([0,-82,100]) rotate([0,0,180])`。
ライト軸は機体 (0,-122.5) に位置し、保持部はz=59.5～140.5。
TD04A座面下端z=160に対してマウント本体は19.5 mm下。
上下が対称なので反転取付可。ライトの発光端・スイッチ・頭部形状と照射方向は未確定。

## 締結と組立

- 筐体接続：M3×20ボルト4本、M3ナット4個、平ワッシャ8枚。
- クランプ：M3×20ボルト4本、M3ナット4個、平ワッシャ8枚。
- ナット厚は3～4 mm、ワッシャは各0.5 mm想定。実際のねじ先端と掛かりを確認する。
- 埋め込みナット・インサートは不要。

1. 穴のバリとサポートを取り、必要ならØ3.4～3.5で通し穴を仕上げる。
2. 接続板の外側からボルトを通し、筐体裏にワッシャとナットを取り付ける。
   外側は14 mmの隙間へ短腕のL型六角レンチを横差しする。長いドライバーの直進経路は筒が遮る。
3. ライトを本体の半円へ載せて押さえを取り付け、4本を均等に締める。
   半割の隙間を無理にゼロにしない。33 mmより細い場合は実測して `lm_holder_id` を変更する。
   肉厚、レンズ、ボタン、防水シール部を圧迫しない。
4. ライト自身のストラップ穴から機体へ独立した落下防止コードを掛ける。
   この部品は底止めのない摩擦保持なので、上下方向の抜け止めを実物で確認する。

## 荷重と検証

仮定：ライト0.5 kg、取り回し係数5、25 N。実重量・水流・引っ掛け荷重は未確定。
荷重は保持部から中央の幅10×高さ50の支持部、接続板、4本のボルトへ流れる。
支持部の単純梁概算（PETG層間24 MPa、安全率3、L35、50×10、25 N）は応力1.05 MPa、変位0.065 mm。
これは支持部だけの概算で、クランプ摩擦やねじ締付けの評価ではない。

- 本体・押さえ：各1ソリッド、閉じたSTL。STEPとの外形差は表示精度で0.00 mm、体積差0.1%未満。
- [CAD検査](verification/cad_checks.json)：23/23 PASS。筐体との接触、干渉、穴・頭・L型レンチ・裏側Ø10工具空間。
- 組立STEP配置：10部品、0 NG。ボルト、ライト、コードは未収録。
- X1C・Z軸縦置きの造形性：両部品PASS、要サポート面積は本体5.2%、押さえ4.7%。サポート不要という意味ではない。
- [FEA収束結果](verification/fea/child_simple_light_mount_base_fea_convergence.json)：3/1.5/0.75 mmの3段階。
  横25 Nだけ収束PASS、最細変位0.117 mm、安全率p99.5=42.14、最悪要素=13.15。
  縦25 Nと引き離し25 Nは収束FAIL。**全体として強度合格にはしていない。**
  4 mmの粗い格子では保持部が連結成分として残らず、3 mmからやり直した。
  本体のみ・PETG充実材・ボルト周辺固定の仮定で、接触/摩擦・押さえ・締付け力・疲労・クリープは未評価。

## 部品外の考慮・要確認

参考は保持具だけなので、ライト頭部の外形・長さ・ボタン位置・電池交換方向・ケーブルの有無は不明。
ライト実体を含めたTD04A・ケーブル・照射範囲との干渉確認は完了していない。
端部は貫通して水抜きを確保。実際のケーブルは筒端から出し、曲げ半径と余長を実物で決め、筐体側へ別固定する。
筒で覆われる長さは81 mm。放熱部や操作部がこの区間にあるライトは、保持位置または窓形状の変更が必要。
まず嵌合と脱着を確認する試作とし、実使用前に抜け・緩み・変形を実物で確認する。

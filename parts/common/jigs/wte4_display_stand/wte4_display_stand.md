# wte4_display_stand — WTE4 耐圧容器 展示台 (転がり止め)

**機体部品ではなく、展示用の治具。** Blue Robotics WTE4 アクリルチューブ
(OD 114.3 / 200 mm) をフランジ+エンドキャップ付きのまま横置きで展示し、
転がらないように受ける台。薄板 4 枚を十字相欠き (cross-lap) で組む。
**ねじ・接着なし。** 円筒部だけを受け、フランジ・キャップ・ドームは支えない。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / 治具 (展示用) / 3Dプリント |
| 設計ソース | `wte4_display_stand.scad` (バリアント定義 `variants.txt`) |
| 個数 | cradle (受け板) ×2 / rail (横桟) ×2 |
| 外形 (cradle) | 4 × 150 × 48 mm / 16.4 cm³ / STEP 16 面 |
| 外形 (rail) | 160 × 4 × 35 mm / 21.8 cm³ / STEP 14 面 |
| 外形 (組立) | 160 × 150 × 48 mm (`asm` バリアント。相欠きを融合した 1 ソリッド / 37 面) |
| 取合い | `wte4_acrylic_tube` (`interfaces.json` で人間確認済み・固定) |

![組立状態 (チューブは円筒部のみのゴースト)](_work/images/wte4_display_stand_demo.png)

## 役割・構造

- **受け板 (cradle)**: YZ 面の板。上端に半径 57.65 (= OD/2 + 0.5) の円弧受け。
  円弧中心を板上端より 20 mm 上に置いているので抱き角は **139°**、上から
  そのまま落とし込める。チューブ最下点は机から **10.35 mm** 浮く。
  下端に横桟用スロット (幅 4.2、深さ 17.5) ×2。
- **横桟 (rail)**: XZ 面の板。上端に受け板用スロット (幅 4.2、深さ 17.5) ×2。
  受け板の外側 (Y = ±65) を通るのでチューブとは接触しない。
- **組立**: 横桟 2 本を机に置き、受け板 2 枚を上から差し込むだけ。
  4 枚が相欠きで直交し、それだけで矩形が保たれる。

チューブ軸 = X、受け板は X = ±55 (間隔 110)。チューブ長 200 に対し
両端 45 mm ずつ内側なので、フランジのカラー (露出 8 mm) やエンドキャップ
(Ø120.3、キャップ外面までチューブ端から +13.8 mm) とは干渉しない。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `tube_od / tube_len` | 114.3 / 200 | 相手チューブ (公称値。`interfaces.json`) |
| `fit_clear` | 0.5 | 半径方向の余裕。EVA/フェルトを貼るならその厚みを足す |
| `t / slot_clear` | 4 / 0.2 | 板厚 / 相欠きスロットの総クリアランス (**要フィットテスト**) |
| `cr_w / cr_h / arc_rise` | 150 / 48 / 20 | 受け板 幅 / 高さ / 円弧中心の上端からの高さ |
| `cradle_x` | 55 | 受け板位置 (±X)。300 mm チューブなら 90〜100 に |
| `rail_len / rail_h / rail_y` | 160 / 35 / 65 | 横桟 長さ / 高さ / 位置 (±Y) |
| `min_wall / lig_min / end_keep` | 6 / 8 / 10 | assert の閾値 |

導出値 (ビルド時に `echo` される): `r_fit` 57.65、`z_c` (チューブ中心高さ) 68、
`gap_z` 10.35、抱き角 139.4°、板上端での円弧半幅 54.07、`slot_w` 4.2。

## インタフェース (二重定義なし)

チューブ寸法はこの `.scad` のみが持つ。`child_clamp_base` 等とは独立
(同じ `tube_od = 114.3` を持つが、治具なので追従義務はない)。

## 干渉チェック (`.scad` 冒頭の assert)

| 検査 | 内容 |
|---|---|
| `arc_rise >= 0` | 抱き角 ≤ 180° (上から入る) |
| `gap_z >= lig_min` | 円弧最下部と底面の間に 8 mm 以上 |
| 横桟スロット ↔ 円弧 | 板上端で円弧縁とスロットの間に 6 mm 以上 (現状 8.8) |
| 横桟スロット ↔ 受け板外縁 | 6 mm 以上 (現状 7.9) |
| 受け板スロット ↔ 横桟端 | 6 mm 以上 (現状 22.9) |
| `rail_y - slot_w/2 >= tube_od/2` | 横桟がチューブの真下に入らない |
| `cradle_x + t/2 <= tube_len/2 - end_keep` | 受け板がチューブの円筒部に載る |
| 最大寸法 ≤ 250 | X1C 造形枠 |

プレビュー (`*_preview.png`) の side/front で目視確認済み: 円弧とスロットは離れている。

## 荷重ケースと安全率・たわみ

想定質量: チューブ 200 (488 g) + フランジ ×2 (214 g) + エンドキャップ ×2 (446 g)
+ 内装 ≤ 1 kg ≈ **2.2 kg = 21.6 N**。係数 3 (取り回し)。

| ケース | 荷重 | 材料 / 造形軸 | 安全率 (最悪 / p99.5) | 最大たわみ | 判定 |
|---|---|---|---|---|---|
| 受け板: チューブ荷重 ÷2 ×3 | 35 N (円弧面 → 底面固定) | PLA / X (平置き) | 317 / 453 | 0.002 mm | PASS |
| 横桟: チューブごと横桟 1 本の中央を持ち上げる ×3 | 70 N (スロット底 ×2 → 中央固定) | PLA / Y (平置き) | 7.7 / 21.9 | 0.086 mm | PASS |

`topopt fea`、ボクセル 0.65〜0.71 mm、mesh resolution PASS。
スタディは `fea_cradle_study.json` / `fea_rail_study.json`、結果は `fea_v1/`。
横桟の最弱点はスロット底の角 (応力集中)。Fusion で R1 程度を付けると更に余裕が出る。

閉形式 (`quick_strength.py beam`) は片持ち梁モデルなので過大評価になる。
単純支持 (支点間 160、4 × 35 断面、I = 14292 mm⁴) で手計算すると横桟中央 70 N: 曲げ応力 3.4 MPa、たわみ 0.14 mm。

## 印刷指示

| 項目 | 指示 |
|---|---|
| 材料 | **PLA** (剛性が高く平板が反りにくい。PETG でも可) |
| 造形方向 | **どちらも平置き** (最大面を下)。cradle は X が上、rail は Y が上 |
| サポート | **不要** (`topopt overhang` 実測 0 mm²) |
| インフィル | **25%** グリッド/ジャイロイド、外周 3 本、上下 4 層 |
| 個数 | cradle ×2、rail ×2 (1 プレートに 4 枚まとめて載る: 150×48 + 160×35 ×2) |
| 後処理 | スロットが固ければヤスリで 0.1 ずつ広げる。緩ければ `slot_clear` を 0.1 に |

`topopt print` は平置きを「オーバーハング 40%」と評価するが、これはベッド接触面
自体を数えているため。`topopt overhang --axis X/Y` で必要サポート 0 を確認済み。
立てて印刷する意味はない (層間に荷重が乗る)。

## 部品外の考慮

- **アクリル保護**: 受け円弧に 0.5 mm の余裕を取ってある。フェルト/EVA を貼るなら
  `fit_clear` にその厚みを足す (1 mm シートなら `fit_clear = 1.5`)。
  PLA の角がアクリルに直接当たるのを避けたいなら貼ること。
- **軸方向のずれ止めはない** (円筒部だけを受ける仕様)。傾いた台では滑るので
  水平な机で使う。
- **重心**: チューブ+キャップの全長は約 228 mm、受け板間隔 110 なので、
  内装が片側に偏っていても受け板の外側に重心は出ない。
- ドーム (`wte4_dome_cap`) を付けた場合、ドームは受け板より外側 (X > 100) に
  突き出るだけで台には触れない。
- 300 / 400 mm チューブを展示するときは `cradle_x` と `rail_len` を変える
  (300: `cradle_x = 90`, `rail_len = 230`)。

## 要確認

1. **相欠きの嵌合** (`slot_clear = 0.2`): 実機でフィットテスト。固ければ 0.3。
2. **`fit_clear`**: 緩衝シートを貼るかどうかで決める。
3. 相手 `wte4_acrylic_tube` は公称値 (OD ± 0.8) のみ。実測 OD が 114.3 から外れていたら
   `interfaces.json` を更新して再ビルド。

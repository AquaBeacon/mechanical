# 公式4インチ取合いのPETGクランプ

2026-10-07ユーザー指定「Blue Robotics公式4インチクランプを元に、PETG用の改良版を今回作る」を実装する独立部品。**fit_prototype**。既存 `child_wte4_suspension_clamp` の最適化メッシュや原本を変更せず、この新設計を最適化後処理と称さない。

公式 [製品](https://bluerobotics.com/store/watertight-enclosures/enclosure-clamp/) と [取付ガイド](https://bluerobotics.com/learn/watertight-enclosure-clamps-guide/) の4インチを参照する。メーカーSTEP原本は [BR-102678-004 Rev C](../child_wte4_suspension_clamp/ref/WTE4_CLAMP_BR-102710-004/BR-102678-004_RevC.STEP) にある。元の取付面は中心から62.8 mm、取付軸X±20・軸方向±10（40×20 mm）。締結軸X−67.848に2本、X+67.848に1本を解析面から読み取った。参照は購入品寸法の利用で、メーカー材質/耐荷重を印刷品へ引き継がない。

## 改良内容

- 取付面62.8 mm・40×20 mmの穴配置を保持する。クランプからフレームに向かう延長脚・長い耳を作らない。フレームの支持面をこの位置へ合わせる。
- 帯幅を30から40 mm、外周肉厚を8 mmにする。取付面では外周を62.8 mmに切りそろえる。最大横幅は元CADより増えるが、増分はリング・締結部の局所肉厚でありフレームへ届かせる腕ではない。耳のねじへφ8工具を入れる通路を確保する。
- アルミ用M4ねじ穴をM3普通ナット方式へ変更する。φ3.5穴、二面幅5.8・厚2.8のポケット。M3 AF5.5・厚2.4普通ナットのモデルで確認する。取付ナットは軸方向両面から差す。溝の二面幅を保ち、上下ナットの入口を分離する。
- 2026-10-08ユーザー指定で、前後120 mm間隔の2組を上側どうし・下側どうしで連結する。`upper_linked` と `lower_linked` を各1個、計2個印刷する。帯幅40 mmと前後の取付位置を保ち、全長160 mm。左右45°の肩に幅12×厚5.2 mmの連結材を2本ずつ設け、根元は1 mmの45°面取り、縦の稜線はR2、端部は0.6 mm面取りとする。連結材と根元は既存リングの肉厚範囲内に収める。
- 下側だけ耳の外面に普通ナットの受けを持つ。耳の締結はM3×30、各位置3本・計6本。上下は分離でき、下側を側板へ固定して容器を上から載せ、前後一体の上側を被せる。取付ねじ、ナット差込み溝、保護材4枚は従来どおり。単独の `upper` / `lower` は同じ設計元に比較・履歴用バリアントとして保持し、このassemblyの印刷対象から外す。
- ゴム厚は1 mmで確定（2026-10-08ユーザー確認）。内径は114.3 mmの容器と1 mm保護材を前提にφ115.9 mm。これは片側のゴムを1.0から0.8 mmへ圧縮する計算で、圧縮量0.2 mm（20%）と合わせ面隙間1.6 mmは仮値。容器の径公差±0.8 mmを締付けで無理に吸収せず、実物の寸法と保持力を確認して保護材/圧縮設定を調整する。

寸法は [共有インターフェース](../../../../../scad/lib/child_horizontal_plate_interfaces.scad)、形状は [SCAD](child_wte4_petg_clamp.scad)。上固定はM3×18を各半体4本、下固定はM3×25を各半体4本。φ7・厚0.5ワッシャを使用し、変更するとねじ先端余裕が変わる。取付ねじ先端はアクリル外形と直接干渉しないことを実メッシュでも確認する。締付トルク値はまだ指定しない。

X1 Carbon / PETG Basic / 0.4 mmノズル / 0.2 mm積層 / 8周 / 100%インフィル / 5 mmブリム。断面をベッドへ、軸方向+Zに160 mm積層する。上の帯の下面、横穴、ナット溝と連結材の内側は自動サポートを検査・除去する。80 mmの帯間を無支持で橋渡ししない。外周/断面入口0.6 mm、穴0.3 mm、ナット入口0.25 mm、面内R2。ナット回り止めの内角・平面座面は機能上保持する。

印刷一式・配置・ねじ数量は [assembly](../../../../../assemblies/child_horizontal_plate_frame/README.md) の正本へ集約する。荷重解析・造形実験・湿潤保持/クリープ試験による認証はまだない。保護材の実厚と圧縮量を確認してから本容器を締める。

STEPの全体変換は未完了。今回の現行モデルはSCADとSTLを参照する。

`python tools/check_child_horizontal_clamp_links.py` は既存半体2個ぶんの材料保持、前後一体の閉メッシュ、中央断面の連結材2本と寸法、容器の上からの挿入を検査する。全体のねじ・工具・配線予約はassemblyの通常検査を併用する。軸方向連結の追加による強度向上は実物試験前で主張しない。

## X1 Carbon向けトポロジー最適化（2026-10-08〜09、試行不採用）

ユーザー指定により対象を前後一体のクランプ上下に限定する。現行STLは軸方向+Z、全長160 mmで縦に印刷している。24姿勢の造形性比較でも+Zが最良だが、これは荷重未入力の印刷指標だけの順位で、強度による順位ではない。上側の帯の下面と穴にはサポートが必要。上半体の45°判定で、ベッド接触を除く要サポート表面は2144.7 mm²。

`spec/prepare_topology_inputs.py` は既存SCADの輪郭と各半体から、連続した半円筒状の設計領域、ゴム接触面・取付座・締結耳の保持領域、既存の穴とナット差込み経路を生成する。探索を既存2本の連結材の形だけに制限しない。入力形状は `_work/analysis/topology_print/`、入力生成SCADは `_work/intermediate/topology_print/` に保存し、印刷用部品として配布しない。

条件正本は `spec/print_topology_request.json`。材料はBambu PETG Basic、X1C 0.4 mmノズル・0.2 mm積層を引き継ぎ、Z積層の異方性と自己支持条件を入れる。密度場を直接平滑化し、機能寸法だけ局所復元する。長い水平ブリッジ、閉じ込めたサポート、接触面のサポート傷、連結性・最小肉厚を検査し、完成形状を再解析・実スライスしてから採用する。

容器と中身は1 kg未満、取り扱いは自重の2倍で十分とのユーザー回答（2026-10-08）により、上限1 kg・2g・合力19.6133 Nとする。`spec/author_print_topology_studies.py` が上下のnative topopt studyを生成する。3軸の取り扱い、組立途中で片側ステーションだけが固定された場合の3軸伝達、仮の締付軸力150 N/本を別ケースで扱う。線形解析で50/100/150 N/本の感度を確認するが、実測値や締付トルクの指定ではない。要求安全率2、変位上限1 mmは解析上の仮条件。汎用PETG異方性カードを用い、X1C実測の層間特性・湿潤滑り・クリープを保証しない。

実行済みの探索は2 mm解析ボクセル・6 mmフィルタ・+Z自己支持条件・自由領域体積率0.35、100反復。保持領域は予想完成体積の約63%を占め、主な自由領域は帯間の接続と非機能部分である。上下とも700回の線形ソルブは収束したが、最適化の終了理由は `max_iterations`。密度変数の収束、しきい値0.5の体積上限、4 mm部分を2 mmボクセルで評価する解像度は不合格であり、全体合格とは扱わない。

`upper_run03` と `lower_run05` の保存密度場をnative `extract` で直接平滑化し、`finish_print_topology.py` で機能CADを局所復元した。下側にはplacementから算出したC押さえのφ8工具通路＋片側0.5 mm余裕を設計障害物として加えた。単純な梁・リングへの再構成は行っていない。`quality_finish_surface.py` は密度由来の表面をMeshLabで整理する。数値不正面を除くためのMeshFixは体積・連結・Euler数を検査し、穴が埋まった試行は棄却した。

干渉検査を通った候補は `_work/analysis/topology_print/upper_run03/local_finish_clearance/simplified_0.0001.stl` と `lower_run05/local_finish_clearance/finished_interfaces.stl`。各1個の閉メッシュで自己交差なし。ナット入口に片側0.05 mmの仕上げ余裕（平行面間5.9 mm、深さ2.9 mm）を追加し、上側ワッシャ座面を0.05 mmだけ局所的にさらった。`check_topology_assembly.py` で構造部品、ねじ、工具、ナット挿入、配線・手・保護帯、容器の10段階の持上げ経路を検査した。これは現行の印刷用STLではない。

候補上側を実際のBambu Studioで縦向き・0.2 mm・8周・100%・PETG Basicとしてスライスした結果、樹状サポート込み238.78 g・28,914秒（約8時間2分）、サポート25.44 g。現行上側も同じ樹状設定で比較すると216.26 g・24,419秒（約6時間47分）、サポート24.95 g。候補は総量が約10.4%、時間が約18.4%増え、印刷改善にならなかった。記録は `baseline/slice_upper_tree` と `upper_run03/slice_local_tree`。通常サポートと樹状サポートを混ぜた比較で軽量化を主張しない。樹状設定は比較試験のみで、現行の製造設定は変更していない。

完成形状のCalculiX再解析は収束を確認できず、不採用とした。上側の局所仕上げ後メッシュに対し、片側固定X荷重の最悪要素安全率は12 mmで1.027、6 mmで0.447。3 mmではGmshが終了コード3221225477で停止し、収束結果はない。p99.5の値だけで局所不合格を隠さない。下側でも数値不正面やメモリ不足が生じ、完成品の強度を確認できていない。記録は `upper_run03/ccx_finished_bounded`。解析領域を狭めて軽くする操作は行っていない。

最初の最適化で仮定した広い締付パッチの一部が拘束領域と重なっていた。元studyは `_work/intermediate/topology_print/*_study_preload_broad_patch.json` に保存した。現在のstudyは実際の6か所のねじ座面へ150 Nずつ（合計900 N）を与える条件で、荷重を減らしていない。下記の連結部分の再最適化は、この修正済み条件で最初から実行した。

次に `spec/prepare_connection_topology.py` で、元の滑らかな40 mm帯を全体保持領域とし、帯間だけを自由領域にした。これは再最適化前の入力条件であり、最適化結果を単純な帯・梁へ置き換える処理ではない。現行CADの体積から1%減を目標に自由領域率を約0.0514と算出した。保持領域は予想完成体積の約95%なので、クランプ全体を最適化したとは扱わない。上下とも2 mmボクセル・6 mmフィルタ・+Z自己支持・100反復を実行し、700/700ソルブ、保持領域の連結、体積制約は合格した。しかし密度・目的関数・形状は未収束で、終了理由は `max_iterations`。

この連結案も不採用。両端固定の取り扱いでは変位約0.052 mm以下だが、片側ステーションだけの固定では、上側は57.6〜106.5 mm、下側は252.2〜421.5 mmの線形解析変位となり、仮の1 mm上限を大幅に超える。この大変形値は実際の変形量の予測には使わず、連結部の剛性が不足する診断とする。片側固定のp99.5安全率も上側最小1.15・下側最小0.59で要求2を満たさない。全ケースで最小4 mm部分が2要素しかなく、解像度検査も不合格。これを平滑化・局所復元だけで合格品にすることはしない。完成形状のCalculiX収束・実スライス・サポート除去性の検査へ進めていない。記録は `connection_only/{upper,lower}_run01/opt` と `connection_only/rejection_summary.json`。

**トポロジー最適化による採用形状は得られていない。** 現行の連結版SCAD/STL・印刷姿勢・製造設定を保持し、探索メッシュを印刷一式へ配布しない。現行品も耐荷重認証済みではない。再開する場合は、必要な組立荷重条件、自由領域の体積配分・最小部材厚、ボクセル解像度と反復収束を見直し、完成形状の再解析と同条件のスライス比較をやり直す。状態の記録は `_work/analysis/topology_print/execution.json`。

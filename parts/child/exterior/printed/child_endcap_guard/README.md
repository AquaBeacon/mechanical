# 子機・一体式エンドキャップガード

2026-09-27ユーザー訂正: **エンドキャップへかぶさる受けとガードを1つの可動部品にする**。受け全体が蓋のように蝶番で動き、閉じたときに左右突起へはまる。固定側の蝶番取付部は未設計なので、位置と開閉検証用の仮部品を置く。

中央Ø75 mmは全高さで侵入禁止。キャップ外面から80 mm。先端は完全に開放し、蓋・端面格子を付けない。側面は八角形の8枚の枠と大きな尖りアーチ窓で囲う。現在のM3/PETGクランプへの実固定と一体化は今後行う。

印刷入口: [parts/PRINT.md](../../../../../assemblies/child_endcap_guard/parts/PRINT.md)。印刷するのは `child_endcap_guard_integrated` **1個のみ**。`child_endcap_guard_hinge_reference` は未固定の仮配置で、実用取付部ではない。印刷対象から除外する。

## 設計元と構成

正本は `spec/build_child_endcap_guard.py` と `parameters.json`。FreeCADでメーカーSTEPのZ=8断面から左右突起を含む最大輪郭を取得し、一体の受け・ケージ・可動ナックルを生成する。同名SCADは生成STLを読む確認ラッパーで、直接編集しない。曲面を保持したSTEPとSTLは同一形状から生成する。

```powershell

.\build.ps1 -Assemblies assemblies\child_endcap_guard
python spec\render_child_endcap_guard.py
python tools/assembly_parts.py check
```

以前の二分割カラー・独立ケージ案は廃止。原本・出力・組立記録を `_work/analysis/split_collar_history/` へ保存し、`migration.json` に旧ファイルの移動先を記録した。現行印刷一式へ旧STLを混ぜない。

## かぶせる受けと開閉

- 受けは左右突起の輪郭に片側0.55 mmの仮FDM隙間で合わせる。キャップ外面より容器側へ2.5 mmかぶさり、上側の受けも同じ可動部品へ一体化する。
- 2026-09-27追記: 面下Z=-2.5〜-0.6 mmの帯は、**左右の突起部分だけ凹ませ、残りを内側へ張り出させる**。この帯の内周は円形の貫通カットで消さない。上側は別にR58 mmでねじ頭を逃がす。実形状断面をassemblyの `_work/images/key_receiver_section.png` に保存する。
- 突起の裏へ掛かる肩、二分割締結耳、カラー結合ボルトを廃止。固定カラーをキャップに残す構造ではない。閉じると左右突起へはまり、開くと受けごと離れる。
- 受けの中心は大きく開放し、キャップ固定ねじ6本を変更しない。各頭の仮予約空間Ø7×H4 mmを閉状態・開閉中とも避ける。工具は一体ガードを開けて入れる。
- 仮の蝶番軸は局所+Y側、X方向。軸の正確な位置は `parameters.json` の `hinge_y` / `hinge_z`。クランプ側を設計するときに位置を確定し、その位置で再度開閉検査する。
- 固定側仮部品は2枚ナックルと簡易支持ブロック。**容器・エンドキャップへ実固定されていない**。将来のクランプに置換するための参考体であり、保持荷重や取付強度を主張しない。
- 可動側には閉止機構用のM3穴付き耳を残すが、固定側受け・ラッチは未設計。旧ラッチねじを実在しない固定部へ置かない。現在のモデルだけで閉止保持できるとは扱わない。
- 左右突起が対称なので180°反転は許容する。5°/15°/30°/90°の方位ずれでは受けが干渉する。厳密な単一方向化が必要なら追加キーを今後設ける。

蝶番の参考金属品: M3×45×1、M3ナット2、外径7/厚0.5 mmワッシャ2。軸孔Ø3.5、ナックル軸方向隙間片側0.5 mm。固定側の取付が決まった後に、ダブルナット等で軸を抜け止めし、樹脂を締め潰さない。参考体の寸法を、そのまま購入・製作確定値として扱わない。

## 造形・フィレット・検証

PETG、0.20 mm、0.4 mmノズル、外周6本、上下6層、40%インフィル、ブリム5 mmを出発条件とする。受け側を下にし、局所+Zへ積み上げる。印刷STLは仮蝶番を含む全体のZ最小をベッドへ移動済み。仮蝶番が受け底面より6.5 mm下に出るため、現状の全体STLでは受け底面・蝶番・耳の下にサポートを入れる。仮蝶番の造形最適化は今回対象外。ガード本体の改善を「部品全体サポート不要」と扱わない。受けの実はまりは試作で確認する。

印刷しやすさの修正: 上側の長い水平橋を廃止し、窓の上端を鉛直から45°の尖りアーチにした。下側は鉛直から約33°の裾とし、浮いたリングの張り出しをなくす。ガード壁の最小内接半径59 mm（根元の棚は内径Ø113 mm）、Ø75×H80、先端開放、左右突起だけの凹みは維持する。窓の幅40 mm、縦の肩Z=56 mm、丸め前の頂点Z=76 mm。窓の平面内の角R3、枠の内外縁・縦角・受け外周の底角R1.5。残りの取合い・孔縁・仮蝶番はR0.1。円筒の接線継ぎ目は既に滑らか。R0.1は小さいCAD上の丸みであり、0.4 mmノズルでの再現は小さいためバリ除去が必要。強度・衝撃・長期クリープは未検証。

`_work/logs/geometry_checks.json` に、一体の1ソリッド、キャップ・フランジ・仮蝶番・金属品との干渉、中央Ø75×H80予約空間、6本のねじ頭、方位ずれ、開閉検査を保存する。閉じ際0〜10°は1°刻み、15〜35°も1°刻み、それ以外は110°まで5°刻み。連続軌跡全体の証明ではなく、このサンプル角でのBRep確認である。

実ペネトレーター・センサはユーザー側で確定済みだが、型番・配線は今回未提示。中央Ø75×H80の予約空間を守り、別途仮Ø26×H26を5穴へ置いた検査も行う。実ケーブルの張力・曲げ・開閉時の引掛かり、水流・センサ応答は実物確認待ち。ガードはストレインリリーフ・耐圧・吊り下げ部品ではない。

座標: キャップ外面中心原点、+Zが容器外へ向く、左右突起±X。assemblyは外面Z=-14.0、X180°回転。既存別assemblyの旧Z=-13.8配置は今回変更していない。

開閉GIFは修正ごとに `python spec/render_child_endcap_guard.py` で再生成する。印刷形状の検査は `python spec/verify_child_endcap_guard_print.py --slice`。この検査の急な下面の面積比較はガード上部に限定し、実印刷や強度の認証ではない。

フィレット増量: ガードと受けの内外の根元はR2。根元に肉を足すため、裾上端の半径を72 mmとし、面上Z=4.4〜7.6 mmに内半径58→56.5 mmの傾斜棚を設けた。Ø75 mmの空間とねじ頭予約高さ4 mmを避け、同じ開閉検査で確認する。大きなフィレットで実際の窓頂点付近は丸くなり、小さい橋渡しは残る。変更後もサポート付きでスライス確認する。根元拡大画像は `_work/images/root_fillet_closeup.png`（assembly内）。

根元R2化後の開閉で中央予約空間を避けるため、仮蝶番軸を局所Y=120→135 mmへ移した。固定側参考体と金属品の配置も同じ位置へ更新した。クランプ取付確定時にこの位置を再検証する。

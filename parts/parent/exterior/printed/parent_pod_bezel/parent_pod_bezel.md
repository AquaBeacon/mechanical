# parent_pod_bezel — 親機 カメラポッド ベゼル (窓押えリング)

| 項目 | 値 |
|---|---|
| 区分 | 親機 / 外装 / 3Dプリント |
| 設計ソース | `parent_pod_bezel.scad` |
| 個数 | 1 |
| 外形 | 94 × 94 × 8 mm |
| 体積 | 28.4 cm³ |
| STEP | 1 ソリッド / 24 面 |

## 役割

`parent_pod_body` のフランジに M3×6 で締結し、アクリル窓 (Ø76 × t4) を
O リングに押し付けてシールする。窓は裏面のポケットに収まる。

## 主要寸法 (**すべて `parent_pod_body` と一致させること**)

| 変数 | 値 | 意味 |
|---|---|---|
| `od` | 94 | 外径 (= pod の `flange_od`) |
| `aperture` | 54 | 開口 Ø (4mm レンズの視野。**要確認**) |
| `t` | 8 | 厚 |
| `win_d / win_t` | 76 / 4 | アクリル窓 |
| `win_clear` | 0.6 | 窓ポケット径余裕 |
| `squeeze` | 0.6 | O リング押し込み量 |
| `m3_bcd / m3_d` | 84 / 3.4 | M3 ×6 (= pod の `m3_bcd`) |
| `head_d / head_t` | 6.5 / 3.2 | M3 キャップ頭 座グリ |

導出: ポケット径 76.6 / ポケット深さ 3.4 (= `win_t − squeeze`)。
窓はポケット底と O リングに挟まれる。

## 干渉チェック (`.scad` 冒頭の assert)

- 開口が窓の縁に接近しすぎないこと (押え代 4mm 以上)
- M3 穴が窓ポケットと干渉しないこと
- M3 頭座グリが外周と干渉しないこと
- ポケット深さが妥当 / ポケット上の残り肉厚 ≥ 3mm

## 印刷向き

平置き (表面 = 座グリ側を上)。

## 部品外の考慮

- **アクリル窓 (Ø76 × t4) は別途調達**。切り出し精度が ±0.3 を超えると
  ポケット余裕 0.6 に入らない。
- **開口 54 がレンズ視野を蹴らないか未確認**。4mm レンズ + フードの
  実視野角で計算し、蹴るなら `aperture` を広げる (押え代 4mm を下回らない範囲で)。
- M3 ×6 を均等に締めること。片締めすると O リングの面圧が偏ってリークする。
  対角順で少しずつ。
- ベゼルもプリント品なので、**締結力で反る**可能性がある。厚 8mm で
  剛性は取ってあるが、実機で面圧の均一性を確認すること。
- 窓の外面は水滴が付く。**撥水処理**や運用前の拭き取り手順を決めること。

## 要確認

1. レンズ実視野 → `aperture` の確定
2. アクリル窓の入手先と切り出し公差
3. O リング型番 (pod 側と共通、AS568-235 近辺)

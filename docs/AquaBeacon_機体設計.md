# AquaBeacon 機体設計 — 3Dプリント部品一式

`../docs/AquaBeacon_詳細設計書.md` 第3部の下流実装。全部品はパラメトリック OpenSCAD
で、`build.ps1` により STL(確認用) + STEP(Fusion編集用) + プレビュー PNG を
**各部品フォルダ** (`parts/<ユニット>/<内装|外装>/printed/<部品名>/`) に出力済み。
**寸法の多くは仮値**（各ファイル冒頭の Customizer 変数を実測値に差し替えて
再ビルドする運用）。

部品ごとの詳細は各フォルダの `<部品名>.md`、索引は `docs/部品一覧.md`、
ケーブル等の部品外事項は `docs/配線・ケーブル計画.md` を参照。

### なぜチューブ 200mm か

縦置きにすると容器の長さがそのまま全高になる。実測 (STL) では
**容器全長 = チューブ長 + 27.6mm** (両端アルミキャップ時)。
300mm チューブ + ドームだと約 370mm で、下部ガードを足すと 399mm。
**200mm チューブでないと 300mm 枠に入らない。**

代償: 幅の要る物を置ける「幅広部」(Ø101.6) が **z = 20..180 の 160mm しかない**
(両端 19mm はフランジのピストンが占める)。既存の `child_tray_deck` (281mm) は入らない。

**縦置き用の内装は 2026-07-31 に新規設計した** (`child_vtray_deck` /
`child_vtray_batt_box` / `child_vtray_rib`)。KiCad の実基板モデルと実購入 LiPo
(Zeee 3S 2200) から配置を決めており、仮値ではない。詳細は
`docs/子機内装_収まり検討.md`。

**ただし `CHILD_PWR` (100.4 × 70) は 160mm の幅広部に `CHILD_MAIN` (112) と
並べて入らない。** 未発注なので軸長 68mm 以下へ縮めるのが推奨 (同 §4)。

### なぜ基線 150mm か

| 案 | 全幅 | 水平FOV | 判定 |
|---|---|---|---|
| 150 / 横向き | 240.4 | **145°** | ✅ 採用 |
| 180 / 縦向き | 約 242 | 105° | 深度精度 1.2 倍だが FOV が落ちる。VSLAM は広 FOV が効く |
| 120 / 横向き | 約 204 | 145° | 余裕はあるが深度精度で不利 |

カメラ実幅 72.8 + ポッド壁 + 蓋 = 片側 45.2 → **250 枠に入る最大の切りのいい値が 150**。

### 保護と画角のトレードオフ (**設計上の割り切り**)

FOV 155° (対角) を蹴らずにレンズの前へ構造物を置くのは幾何学的に不可能。

- **側壁と床がレンズ面より 8mm 前へ出る「フード」まで**が限界
  (`8 × tan(77.5°) = 36.1 < 対角基準 43.8`、余裕 7.7mm)
- 正面衝突は**底デッキ前縁 (カメラより 4mm 前)** で受ける
- ライト・前縁リム・抜け止めタブ・デッキが画角外にあることを `.scad` の assert で検査
- **VSLAM では自機の写り込みを必ずマスクすること**

### 質量・浮力 (**仮値。進水前にプールで実測**)

| | 質量 | 排水量 |
|---|---|---|
| 耐圧容器一式 | 1.05 kg | 2.56 L |
| 3Dプリント部品 (PETG) | 1.41 kg | 1.11 L |
| 内装 (未設計) + カメラ + ライト + TD04A + 締結 | 1.72 kg | 0.53 L |
| **合計 (バラスト前)** | **4.18 kgf** | **4.20 L** |

→ **ほぼ中性浮力。鉛 1.1〜2.2 kg を下部ガードに足して -1.0〜-2.0 kgf にする。**
バラスト 1.5kg のとき重心 z≈69 / 浮心 z≈110 → **GM ≈ 41mm で直立安定**。
**取付位置 (M6 ×5) を前後に振って吊り姿勢をトリムする。**

### 強度 (PETG / X1-Carbon)

設計許容応力 **XY 12 MPa / Z(層間) 6 MPa** (極限 45 / 25 MPa に安全率 4)。

| 項目 | 応力 | 安全率 |
|---|---|---|
| 吊り耳 (全備 5.7kg × 3g、ブライドル 30° → 99 N/耳) | 0.21 MPa | **29** |
| 吊り耳 根元の曲げ | 1.17 MPa | 10 |
| 下部ガードの脚 (容器 1.85kg × 3g) | 0.03 MPa | 大 |
| カメラポッドの片持ち (0.3kg × 3g) | 0.005 MPa | 大 |

**律速は強度ではなく大面積 (237mm) の反り**。ブリム必須、ベッド中央に置く。
吊り耳は積層に垂直な引張を受けるので**壁 5 本以上・インフィル 40% 以上**。

### assert が実際に止めた設計ミス (縦置き構成)

1. 取っ手バーが屋根の中央リブと干渉 → リブを 128 → 145 へ
2. **TD04A 下穴の真上をスキンの外向きカラーが覆い、下穴が「閉じた空洞」になった**
   (ソリッドが 3 個に分離。組立もできない) → 上カラーを廃止
3. 結束スロットの角が 45° 斜面にちょうど接して非マニフォールド → スロット位置を逃がす
4. ポッド後壁がスキンに 0.05mm 食い込む → `lens_y` を 106 → 110
5. 蓋ねじの外側端距離が 0.25mm 足りない → 蓋をポッドより 1.5mm 広く
6. 下部ガードの脚の根元がリング帯からはみ出して宙に浮く → リング幅 12 → 20mm
7. 結束スロットがブロックからはみ出す (ライトクランプ) → M4 の間へ移動

**どれも「assert を緩める」のではなく形状を直した。**
assert で捕まらなかったもの (ポッド前面開放カットがフード側壁ごと削っていた) は
モジュールの読み直しで見つけた。**preview の目視は省略できない。**

## 設計規約 (全ファイル共通で実施済み)

- cube/cylinder/polygon+ブーリアンのみ → STEPが真平面/真円柱 (Fusionで編集可)。
  角丸・フィレットはFusion側で付ける。
- フィーチャ位置はパラメータから導出し、冒頭 `assert()` で干渉・端距離・
  収容チェック (今回も pod のOリング溝/内腔干渉、parent_plate のスロット/SPRESENSE
  干渉、クランプのM5/ボルト柱干渉を assert が実際に検出→修正済み)。
- 印刷向きは各ファイル冒頭コメント参照 (全部品サポートレス設計)。

## ビルド

```powershell
.\build.ps1                                                  # 3Dプリント部品を全部
.\build.ps1 parts\common\exterior\printed\xdcr_socket        # 個別 (フォルダ指定)
.\build.ps1 -Assemblies assemblies\child_assembly            # アセンブリ STEP + 4面PNG
```

- 出力は入力と同じ部品フォルダに出る (`<name>.stl` / `.step` / `_preview.png`)。
- 同じ `.scad` から寸法違いを出す場合は部品フォルダの `variants.txt` に定義する
  (例: `xdcr_socket` の `child` = tilt 0 / `parent` = tilt 20)。
- `xdcr_socket` の `parent` バリアントは **tilt 0 (child と同形状)** に変更 (2026-09-04)。
  旧 20° 版は assert 停止のまま廃止 (`parts/common/exterior/printed/xdcr_socket/xdcr_socket.md`)。

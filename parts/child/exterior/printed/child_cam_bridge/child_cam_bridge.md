## 役割

`child_jaw_gate` の HP4 (z170) / HP5 (z100) 座に中央柱で共締めし、左右へ張り出した
ウイングの上に `child_cam_mount` (横向き、90° 回転) を M5×4 ずつ載せる。
左右カメラのレンズは x=±75。輸送時は M5×8 を外してブリッジごと取り外す (C7)。

## v1 からの変更 (最適化の所見)

1. **後ウェブ (x27..120, y67..73, z44.95..160、約 128 cm³) を全廃**。
   最適化はこの面 (y67..73) に薄い斜材しか置かず、材料の 26 % (47.8 cm³) を
   **中央柱と同じ y73..79 の面**に集めた。
2. **全面デッキ (x−120..120, y67..124, t8、109 cm³) を荷重経路の帯だけに削減**。
   最適化のデッキ層は 782→628 ボクセルと穴だらけだった。
3. **アッパーデッキ (z64.95..72.95) を新設**。最適化が中央上部に作ったアーチ
   (x±55,z50 → x0,z105) と同じ役割 = −Y 荷重を y 方向の深さを保ったまま
   HP5 座の高さまで運ぶ。**アーチそのものは cube では作れない**:
   工具アクセス Ø12 (x±20, z80/120/150/190、y≥80.35 から +Y) が x14..26 を
   z74..86 で塞ぎ、カメラケース (x≥27.65) が z82.95 以上を塞ぐため、
   アーチ脚が通る隙間は x26..27.65 の 1.65mm しかない。
   最適化はこの境界をボクセル 1 個ぶんかすめて通していた
   (セル中心 (22.5, 85.45) が円柱表面ちょうど r=6.0)。
   **z を工具アクセスの下 (74 未満) に置けば x−57..57 を連続で渡せる**ので、
   アーチを「低いアッパーデッキ」に置き換えた。

荷重は最適化 study (`topo_v1/child_cam_bridge_v1_study.json`) と同一。

合格基準: **全ケース たわみ ≤ 1.0 mm、安全率 (p99.5) ≥ 3.0**。

### 実効的な律速 (FEA で見えないもの)

HP4/HP5 の **M5 熱圧入インサート 8 本の引抜き**。L2 輸送 300 N 時、
M_y = 300 N × 95 mm = 28,500 N·mm を 40mm ピッチのボルト対で受けると
約 355 N/本。PETG の M5 インサート引抜き耐力は 400〜800 N 程度なので、
**引抜き試験を推奨** (v1 から継続の未解決項目)。座面 xyz を fix する解析では
この項目は原理的に出ない。

## 体積目標について (未達、数値で報告)

指示された目標は **≤ 230 cm³ (v1 の 70 %)**。到達値は **266.45 cm³ (81.2 %)**、
**36.5 cm³ 超過**。理由:

1. **preserve だけで 124.0 cm³** (最適形状 181.4 cm³ の 68 %、本部品の 47 %)。
   自由に設計できるのは実質 106 cm³ で、最適化は同じ機能を 57.4 cm³ で
   実現している。cube/cylinder 縛りでこの 1.9 倍の効率差が埋まらなかった。
2. **最適化の主部材 2 つが cube では再現できない**。
   - アーチ (swept な傾斜面、約 20 cm³) → 工具アクセス Ø12 とカメラケースの
     間に 1.65mm の隙間しか無く、6mm 以上の部材を通せない。代替の
     アッパーデッキは z を下げるぶん経路が長く、45 cm³ 必要だった。
   - ステー (y70..73 の厚さ 1 ボクセル = 3mm の斜材、両側で 1.5 cm³) →
     FEA の mesh resolution (最薄 6mm 以上) と印刷最小肉厚の制約から
     3mm では作れず、実装した 9×7mm 版は 19.5 cm³ かかって費用対効果が
     合わなかった (#m→#n)。
3. 235 cm³ まで削った版 (#o) は L6 1.306 mm、252 cm³ 版 (#r) は L6 1.147 mm で
   いずれも合格基準 (≤1.0 mm) を割った。**230 cm³ 以下でこの荷重条件を
   満たす cube 構成は見つかっていない。**

さらに削るなら次のどれかを人間に判断してもらう必要がある:
(a) 工具アクセスを Ø12 → Ø10 に緩める、または HP4/HP5 の M5 をボールポイント
六角で斜め挿入する前提にする (アーチが通せるようになる)、
(b) 前縁バンパ preserve の z 範囲 (44.95..80、37.9 cm³) を縮める、
(c) L6 の判定を「たわみ ≤ 1.5 mm」に緩める (SF は 14 あり強度は余っている)。

## 部品外の考慮

- `child_cam_mount` 本体・防水ケースは本部品に含まない (`placement.json` で別配置)。
  ケース AABB と cam_mount 本体 AABB は assert の除外ボックスとして持っている
- **HP4/HP5 の M5×8 の工具アクセス Ø12** を除外ボックスとして明示的に持つように
  なった (v1 は未検査)。中央柱前面 y=80.35 から前方へ Ø12 が通る
- バンパ (`child_side_bumper`) の M5×2×2 は端板フランジのナットトラップで受ける
- FOV 余裕は 2.4° (79.9° vs 77.5°)。`lens_off_bot`/`case_h`/`case_w` の実測で
  変わるので実測後に必ず再検査

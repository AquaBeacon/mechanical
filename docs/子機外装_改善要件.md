# 子機外装 改善要件 (2026-09-04)

`child_frame2_assembly` (ワニ顎構成、[再設計要件 2026-08-02](子機外装フレーム再設計_要件.md)) を
評価し、次の 4 目的に対する改善案をまとめる。再設計要件を置き換えるのではなく**上書き追記**する
(矛盾する項目はこの文書が優先)。

| 目的 | 現状 |
|---|---|
| G1 拡張性: 振動子・カメラ・ライトの固定ジグをあとから付けられる | ❌ 取付パターンが部品ごとに違い、空き座は屋根 1 面のみ |
| G2 ドームが上に来る | ✅ 達成済み。ただしドーム頂点はフレーム上端 z218 より 43mm 露出 |
| G3 エンドキャップから出る配線をガードする | ❌ 後方 ±40° が素通しで、ペネトレータとケーブルが後方にむき出し |
| G4 輸送で特定部品だけがはみ出して折れない | ❌ 下記「残る突出物」 |

## 1. 2026-09-04 に緩和・確定した条件 (ユーザ確認)

| # | 条件 | 旧 | 新 |
|---|---|---|---|
| C1 | 全高 | 300 mm 厳守 | **400 mm まで許容** (幅・奥行 250 は据え置き) |
| C2 | カメラ | — | **DJI Osmo Action 6 + 純正防水ケース**で確定 (縦向き搭載は R1 のまま) |
| C3 | ドーム | 蓋のみ | **将来ドーム内から LED 光源を照らす**可能性あり → ドームの上半球を不透明部品で覆わない。輸送キャップは運用時に外す |
| C4 | 水中ライト | 前向き固定のみ | **横向き (軸水平) と縦向き (軸鉛直) の両方で固定できる**こと。クランプはユーザが別途設計するので、**クランプを固定する座**をフレーム側に用意する |
| C5 | 幅 (基線方向) | 250 mm | **280 mm まで許容** (2026-09-04「厳しい制約を緩和してもいい」)。奥行は 250 のまま |

C1 により、旧要件で 300 枠に張り付いていた制約 (ガード高さ 23mm、ドーム保護なし、耳の高さ) が解ける。
C5 により縦向き搭載の理由が消える (要件書 §6 は履歴)。`child_cam_mount` のフィンガー形状はそのままで、
ブリッジ上の取付向きだけ 90° 変わる。250 幅検査は `280 − 保護代 9×2` に書き換える。

## 2. 現状の問題点 (数値の根拠)

### 2.1 キャップ下の高さ不足 (G3 / G4)

| 項目 | z |
|---|---|
| アルミキャップ下面 | −13.8 |
| ペネトレータ先端 (突出 20 仮) | −33.8 |
| スキッド底 (`ring_z0`) | −37 |

キャップ下面からスキッド底まで **23 mm** しかなく、ペネトレータを引くと 3 mm。
ケーブルは真下に出てから曲がるので、曲げ半径 (20〜40) のぶん**スキッドより下に垂れる**。
機体を床に立てるとケーブルを踏む。旧 300 枠ではガードを下げられなかった。

### 2.2 輸送時に残る突出物 (G4)

アセンブリ md は「カメラ・ライト・吊り耳・TD04A を外せば突出物なし」としていたが、実際には残る:

| 部品 | 状態 | R4 判定 |
|---|---|---|
| ドーム | 頂点 z261、フレーム上端 218 → 43 mm 露出。保護なし | ❌ |
| カメラブレード (`child_jaw_gate`) | 厚 5.9 の板が前方へ約 42 mm 片持ち。横 (X) 荷重に最弱の向き。600 N 側方で板単体なら曲げ ~130 MPa ≫ 許容 12 (ガセット込みでも桁が足りない見込み) | ❌ |
| M5 蝶ボルト ×2 | +X 面から翼が突き出す。引っ掛けて曲がる・緩む | ❌ |
| TD04A + ソケット | ケーブルを切って容器内で終端するため**実質外せない**。屋根上 z190〜245 に残る | ❌ |
| ヒンジピン上端 | 抜け止め (止め輪) が z218 より上に出る | △ 小 |
| ガードリング Ø170 | 最下部で最も広い。リング自体は面内荷重で PASS | ✅ |

### 2.3 取付座の不統一 (G1)

| 部品 | パターン |
|---|---|
| `xdcr_socket` → 屋根 | M5 ×4 @ 40×40 |
| `child_cam_mount` → ブレード | M5 ×4 @ 32×22 |
| `child_light_saddle` → ゲート前面 | M4 ×4 @ 36×28 |
| `child_lug` → 耳ボス | M5 ×2 @ 12 |

## 3. 改善案

### 3.1 ハードポイント規格 HP40 (G1 / C4)

全アクセサリの取付を **1 つの規格**に統一する。既存の `xdcr_socket` (M5 ×4 ピッチ 40) に合わせる。

| 項目 | 値 |
|---|---|
| 締結 | M5 熱圧入インサート ×4、正方 40×40 (±20, ±20) |
| 下穴 | Ø6.4 × 深さ 8 (インサート M5×8 用) |
| 座面 | 平面 ≥ 50×50。**外形包絡より 2 mm 引っ込める** (何も付けないときに突出しない) |
| 中央穴 | Ø14 貫通 (ケーブル通し / 水抜き)。不要な面は塞いでよい |
| 向き記号 | 座面に Y 方向を示す矢印 (刻印 0.6 深) |

アクセサリ側は **40×40 のアダプタ板 (t6、M5 バカ穴 Ø5.4 ×4)** を持つ。
カメラ用アダプタは **GoPro 2 フィンガー**を持たせ、市販ジグと互換にする。
ユーザ設計のライトクランプ (C4) もこの板に載せる。

**配置 (実装 6 面、2026-09-04 実装時に確定)**:

| # | 場所 | 座面 / 座中心 | 穴 (機体座標) | 主用途 |
|---|---|---|---|---|
| HP1 | ペデスタル上 (2026-09-04 移設) | z 218.5 / (0, −85) | (±20, −105/−65) | TD04A ソケット。ソケット台座が容器に貫通していたため z 190→z 218.5、中心 y −75→−85 に移動 |
| HP2 / HP3 | パイロン側面 | x = ±44 / (y −75, z 100) | (y −95/−55, z 80/120) | ライト縦向き (軸 Z)、側方・下向き振動子 |
| HP4 | ゲート前面 上 | y = 74.35 / (0, 170) | (±20, z 150/190) | カメラブリッジ (§3.2) |
| HP5 | ゲート前面 下 | y = 74.35 / (0, 100) | (±20, z 80/120) | カメラブリッジ |
| HP-L | ゲート前面 最下 | y = 74.35 / (0, 15) | (±20, z −5/35) | 前向きライト (軸 Y)。カメラデッキ (z 45..53) の下に収まる高さ |

見送った座 (理由): ガードリング上面 (リング幅 20 < 座 50。Ø200 に広げれば置ける)、
トップクラウン側面 (LED を遮らないためカラー高さを 14 に抑えた。50 角が載らない)。
下向きアクセサリは HP2/3 に L 形アダプタで付ける。

ライトは HP2/3 に縦向き (軸 Z)、HP-L に横向き (軸 Y) で付くので C4 を満たす。
ライトのケーブルは HP2/3 の中央 Ø14 からパイロン内空洞へ、HP-L は座内で止まる穴から外周を回して
**パイロン背面溝 (§3.3)** へ落とす。HP2/3 の座は側壁から x 44 まで張り出すが、
ヒンジ (x −80) / ラッチ (x 72) の包絡の内側なので突出にはならない。

### 3.2 カメラブリッジ (G4、C2)

ゲート一体のブレード + ガセットデッキを廃止し、**HP4 と HP5 に 4 本ずつボルト留めする門型部品
`child_cam_bridge`** にする。

- 左右 2 本の柱 (x ±26、t8) と横桁で `child_cam_mount` ×2 を背中合わせに保持。片持ちをやめる
- **カメラは横向き (C8)**。マウントはブリッジの横桁に 90° 回して付く
- 前縁 (レンズ面より 2 mm 前) が前突バンパを兼ねる。**左右端にも側面バンパ (t9、ケース側面より外)**
  を立て、全幅 280 に収める。ケース側面は横向きで x=±(75+47.35)=±122.35 → バンパ外面 ±131.35 ≤ 140
- **輸送時はブリッジごと外す** (M5 ×8)。ゲート単体は円筒に戻る (C7 の「外せる部品」)
- 基線 150 はブリッジの左右マウント座面間距離で決める (単一部品の面精度、現行と同じ)
- 幅の検査は `base_line/2 + case_w/2 + bumper_t ≤ 140` に書き換える (`child_cam_bridge.scad` の assert)

### 3.3 パイロン背面のケーブル溝 (G3)

パイロン背面壁 (y −101..−95、t6) を **t14** にし、取っ手の左右に**幅 10 × 深さ 8 の溝 ×2**
(x ±18 中心、z −17..190) を彫る。テザーと TD04A ケーブル (と将来のライトケーブル) を溝内に通す。

- 結束スロット (5.5×3) を **30 mm 間隔**で溝底に貫通
- 上端 z190 で屋根の Ø14 (HP1) と合流し、ブライドルへ
- 背面からの衝撃は壁が受ける。溝のふちは 45° 面取り (サポートレス)
- 取っ手の手穴 (z 115..145) と溝は 8 mm 以上離す (assert)

### 3.4 下部ケーブルトンネル + ガード高さ (G3 / G4、C1)

1. **`ring_z0` を −37 → −60** に下げる (C1 で許容)。キャップ下面からスキッド底まで 46 mm
   → ペネトレータ 20 + 曲げ半径 25 が収まり、**床に立ててもケーブルを踏まない**
2. ガードリング後方セクタ (230..310) に **ボルト 2 本で外せるケーブルカバー `child_cable_cover`** を被せる
   - 出口はカバー**側面の横穴** (Ø14 ×3、−Y 向き) にし、真後ろに開口を作らない
   - 内側に **ケーブルクランプ座 (EVA 挟み込み、M5 ×2)** → テザー張力はここで受ける
     (結束バンド頼みをやめる)
   - トルクレンチのアクセスはカバーを外して確保 (中央 r<55 素通しは維持)
3. 脚 ×3 は −60 まで伸びるので、柱座屈を `quick_strength column` で再確認
4. 全高: −60 .. 261 = **321 mm** (< 400)。ドーム保護 (§3.5) を足しても ≤ 340

### 3.5 トップクラウン + 輸送キャップ (G2 / G4、C3)

吊り耳 ×2 を **1 部品 `child_top_crown`** に置き換える。既存の耳ボス M5 ×4 (±66, y −4/−16, z218) に載せる。

- ドーム根元 (押えリング) を囲む **カラー、内径 Ø126、高さ z218..232 (14 mm。実装時に LED の側方光を遮らないよう 245 から下げた)**。ドーム赤道より下なので
  **LED の上半球を遮らない** (C3)
- カラー左右に**吊り耳 (Ø16、z240、Y 軸)** 一体化。横倒しではドームより先にカラーが着地する
- **ドーム頂点の保護は輸送専用キャップ `child_dome_cap_transport`** (印刷、内 R60 の椀、クラウンに
  バヨネット 1/8 回転)。運用時は外す → LED を遮らない
- 吊りアーチ (門型でドーム上を跨ぐ) は LED に影を作るので**採用しない**

### 3.6 ラッチの蝶ボルト廃止 (G4)

+X のラッチを **M5 ノブボルト (頭 Ø16)** にし、コアフレーム側ボスに **Ø18 × 深さ 12 のポケット**を
彫ってノブを沈める。r80 の包絡から出ない。ゲート側は通し穴のまま。

### 3.7 ヒンジピンの抜け止め (G4、小)

ピン上端の止め輪を、コアフレーム頂面の **Ø10 × 深さ 4 のざぐり**に沈める。

### 3.8 輸送姿勢と自動検査 (G4)

- 輸送構成: **カメラブリッジ・ライト・クランプを外し、ドームキャップを付ける**。TD04A は付けたまま
  (ケーブルが切れないため)。HP に何も付いていない面は 2 mm 引っ込んでいる
- 推奨姿勢: **ヒンジ側 (−X) を下にした横倒し**。接地点 = ヒンジ柱・ガードリング・トップクラウンの 3 点
  (立て置きも §3.4 で可能になるが、スーツケース内は横倒しが安定)
- `assemblies/child_frame2_assembly/placement.json` に **`transport` 構成** (group 切替) を持たせ、
  `scad/lib/check_transport_hull.py` (新規) で **26 方向 (面 6 + 稜 12 + 頂点 8) の最初の接地部品**を列挙、
  各部品の根元断面を `quick_strength` で 600 N 評価する。R4 の合否をビルドごとに出す

## 4. 制約の緩和 (2026-09-04 ユーザ確定「厳しい制約を緩和してもいい」)

| # | 制約 | 現状の影響 | 決定 |
|---|---|---|---|
| Q1 | 幅 250 | カメラ縦向きで片側 8mm しか残らず、ケース側面のバンパが置けない。横向き (FOV 145°) は 262 で入らない | ✅ **280 に緩和 (C5)**。カメラ横向きに復帰 (C8)、側面バンパ追加 |
| Q2 | L2 輸送 600 N (6 kg × 10g) | 突出部品の根元がすべてこれで決まる | ✅ **ハードケース前提 5g = 300 N (C6)**。コアフレーム FEA の L2 ケースも 300 N で再実行 |
| Q3 | R4「単独で突き出た部品を作らない」 | 全アクセサリを引っ込めるか外す設計になる | ✅ **読み替え採用 (C7)**。カメラブリッジ・ライトクランプ・輸送キャップは「外せる部品」 |
| Q4 | 全部品 X1C 250³ 印刷 (R7) | コアフレーム 235 高でぎりぎり。§3.4 で脚が伸びるガードリングは Ø170×72 で問題なし | 据え置き (緩和不要) |
| Q5 | チューブ 200 | 内装幅広部 160mm。CHILD_PWR が並ばない問題は内装側で解決済み | 据え置き。300 チューブは全高 411 で C1 にも入らない |
| Q6 | FOV 内に構造物なし | 前突保護がレンズ面 +8mm のフードまで | 据え置き。C5 で側方、C1 で上下から囲めるので十分 |

**輸送の前提 (C6 の根拠)**: 全備をパッド入りハードケースに、§3.8 の輸送構成・横倒し姿勢で収納する。
裸でスーツケースに入れる運用はしない (それをするなら 10g に戻す)。

## 6. 仮値・要実測 (この改善で新たに効くもの)

1. ペネトレータ突出量 (`pene_len=20` 仮) → `ring_z0=−60` の余裕の根拠
2. テザー外径と最小曲げ半径 (未選定) → トンネル横穴 Ø14 と曲げ半径 25 の根拠
3. ドーム押えリング OD (仮 120.3) と `dome_h` (仮 53.25) → クラウン内径 Ø126 と輸送キャップ内 R
4. 防水ケース実寸・レンズ位置 (要件書 §5、据え置き)
5. ユーザ設計ライトクランプの外形 → HP2/3 での隣接部品との干渉

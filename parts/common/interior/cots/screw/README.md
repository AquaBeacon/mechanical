# 共通ねじ・ナット・ワッシャの購入品モデル

正本は `screw.scad` と `variants.txt`。ねじ山を省略した配置・干渉確認用モデルで、印刷部品ではありません。寸法の意味と座標軸はSCAD冒頭を参照してください。頭形状は簡略化しているため、購入品の実寸と使用工具の取合いを確認します。

2026-10-05：子機の軽量クランプ検討用に `m3x70` を追加。呼び径3 mm、首下70 mm、頭の包絡Ø5.5×3 mm。耳厚28 mmの半割り2個、分割隙間1.6 mm、ワッシャ厚1 mm×2、ナット厚2.4 mmを通すため、全ねじを使用します。旧 `m3x60` ほか既存バリアントは保持しています。

配置・採用状況は各assemblyの `placement.json` が正本です。STLは同じSCADから生成し、STEPはその寸法・体積を保持したCAD変換です。


2026-10-09 親機床のケース固定に m4x8_button を追加。ISO7380 M4×8、ピッチ0.7、最大頭径7.6／頭高2.2／六角穴2.5 mm。[HPC BHC4-8/SS/B寸法表](https://shop.hpceurope.com/pdf/gb/BHC.pdf)。共通SCADの頭は最大円柱包絡で、ねじ山と六角穴は省略。ケース実インサートの有効深さとボス高さ10 mmは実測待ち。床座Z16.8、モデル頭上端19.0、モデルねじ込み5.04 mm。先端底付き・樹脂過締めを避け、長さは実物で照合する。

2026-10-09 子機のB錘固定用に `m5x12`（φ5×首下12、頭φ9×3.3）、`nut_m5_4`（AF8×厚4）、`washer_m5_10x1`（内径5.3／外径10／厚1）を追加。各16個、購入金属部品。なべ頭包絡は[廣杉計器 U-0512](https://hirosugi.co.jp/products/U/U.html)、ナット包絡は[NBK SHNJ-M5](https://static.nbk1560.com/products/specialscrew/nedzicom/cleanscrew/SHNJ/SHNJ-M5/SHNJ-M5/)の寸法表を参照。ワッシャは指定包絡。特定材質の製品へ限定するものではなく、購入時に上記寸法と実ナット厚を照合する。ナット底Z0.4、ワッシャ上面Z12、ねじ先端Z0。印刷対象に含めない。

2026-10-10 親機 `parent_oneplate` 箱ロケータ／カメラストップ用にM4金具を使用。側面ロケータはM4×16・ナット各4、端面ロケータはM4×14（またはM4×16を2 mm短縮）・ナット各4。三つの圧力パッドにM4×25ねじ・捕捉ナット・外側ロックナット各3。カメラストップ固定にM4×20・ナット各2、調整ねじにM4×12・捕捉ナット・ロックナット各2。購入品は金属ねじ・ナットで、印刷部品には含めない。ねじ先端と箱底とのクリアランス、実ナット・工具の取合いは組立時に確認する。

# 親機・TD04Aブラケット支持部 Rev.6

平板へ後付けする支持治具。上面Z=-20を主プレート下面へ当て、M5×40皿ねじ2本・M5ワッシャ2枚・M5ナット2個で固定する。取付XY=(65,-55),(85,-55)、M4クランプ穴のピッチ36 mm・Z=-35を維持。旧M5×30は使わない。

金属ブラケットは左基準X=43と上端Z=-27へ当て、既存の押さえ金具とM4ねじ2本で締結する。左側の位置決め部と上端ストップを連続させ、右側の余分な頬を廃止。右側シムを挟む方式は用いない。ブラケット幅24 mm・板厚2 mmは既存視覚モデルの仮寸法で、実測済みではない。

印刷はY=-90°、L字の端面X=25をベッドへ置く。長い二面を斜めに浮かせる姿勢をやめ、L字断面をX方向へ積層する。左ストップの根元は印刷時約55°の斜面、M4/M5穴は55°屋根の上向き涙滴にし、円形の必要クリアランスを残す。PETG Basic・X1C・0.4 mm・0.2 mm層・8壁・100%・ブリム6 mm。自動サポート検出の結果はassembly READMEを参照。実印刷と反復荷重・クリープは未認定。

正本はspec/prepare_parent_oneplate.pyとspec/parent_oneplate_sensor_sources.py。配置はassemblies/parent_exterior/placement.json。SCADを直接編集しない。実ブラケットの着座、押さえ金具と工具、ケーブル通路は初回組立で確かめる。地上自立時は支持治具をフレームへ残せる。

# 親機・再現位置決めフレーム

親機のBCAS212310G箱、既存カメラマウント、TD04Aブラケットを、開放型フレーム上へ再現可能に配置する設計。配置と部品数の正本は [placement.json](placement.json)、印刷ファイルの入口は [parts/PRINT.md](parts/PRINT.md)。本構成は箱を全面で受けるプレートではなく、三点基準と局所ストップで位置を決める。

## 基準と位置決め

座標は箱底をZ=0とする。フレーム外形は232×134×42 mm。上面の主デッキは基準面より0.8 mm下げ、箱底の支持点だけをZ=0に置く。三点はXY=(-96,-55)、(-96,55)、(96,0) mm。支持面を削って高さを変えないこと。印刷後の支持痕・バリは取り除くが、3点の高さを崩す研磨はしない。

箱は公称210×230 mmで、左側面X=-105 mmをY=±38 mmの2点で受ける。側面ストップの取付穴はY=±8 mm。右側の押しねじはX=105 mm付近の2点で当て、側面タワーX=111..116 mmが箱の移動を止める。端面はY=115 mmの固定ストップ（アームX=84..104 mm）と反対側の押しねじで決める。側面・端面のストップはフレームに常設し、箱を外す日常作業では取り外さない。押しねじは位置を保持する程度に締め、箱壁を変形させない。

3つの圧力パッドは右側2点（ねじ軸Z=12 mm）と端側1点（Z=9 mm）で使う。M4×25ねじ、捕捉ナット、外側ロックナットで調整する設計。パッドはねじ頭に被せるカップなので、箱を外す際は脱落・紛失に注意する。箱底下の端ストップ固定ねじとカメラマウントのM3ねじ先端は、箱底Z=0より上へ突出しない（公称で約0.4 mmの余裕）。実物のねじ長さと箱底との隙間を確認する。

## TD04Aとカメラ

TD支持部はフレーム上の12×12 mmキー溝へ差し込み、M5×30ねじ2本で固定する。金属ブラケットは左側面と上端の基準へ当てる。ブラケット幅24 mm、板厚2 mm、上端Z=-27 mmは現時点で視覚参照形状に基づく仮寸法。実物を測り、必要なら0.4 mmの右側すきまへシムを入れて合わせる。実測適合済みとは扱わない。

既存のDJI Osmo Action 6用マウントは変更せず、フレーム下面の既存取付面（右端X=2 mm、後端Y=44.5 mm）に取り付ける。新しいカメラストップはマウント前壁の既存φ5 mm工具穴2個（局所X=±20 mm、Z=20 mm）へM4×20ねじで固定し、2本のM4×12調整ねじでケース接触高さを個別調整する。ねじ先端の初期接触位置は局所Y=20、Z=36.5 mm（支持足の前端はY=16 mm）。ケース形状も暫定参照である。実ケースを据えて角度と接触を調整し、ロックナットで保持する。マウントのM3工具アクセスが必要な場合はストップだけを一旦外し、作業後に同じ穴・壁上面へ戻す。

## 組立と日常着脱

1. 支持面と箱底を清掃し、異物がないことを確認する。
2. 箱を三つのZ=0基準点へ載せる。
3. 左側と固定端へ箱を当てる。
4. 右側・反対端の押しねじを軽く当て、箱の位置を保持する。
5. 上側バー2本を交互に少しずつ締め、ゴムパッドを均等に当てる。
6. 取り外し時は締結を緩めて箱を真上へ外す。常設ストップ、TD支持部、カメラストップは設定を保つ。

初回は箱とストップの隙間を測り、横・端方向の位置が再現することを確認してから使用する。設計上の位置決め機能を示すもので、反復着脱試験や保持力試験が完了したことを意味しない。

## 印刷と金具

既定材料はPETG。X1 Carbon向けの現行個別STL、個数、向き、スライス結果は [parts/PRINT.md](parts/PRINT.md) と [print_jobs/repeatable_mount/](print_jobs/repeatable_mount/) を参照する。新規ジョブは2プレート・13点で、既存カメラマウントは再利用する。0.20 mm、壁6周、上下6層、40%インフィル、ブリム5 mm、通常サポートON。スライサの見積もりはプレート1が約256 g・8時間57分、プレート2が約154 g・5時間15分、合計約410 g・14時間13分（サポート込み）。両プレートのスライスは警告なしで完了した。使用プリンタのフィラメント・プレート設定を確認して印刷する。

ルートの `parent_oneplate_X1C.3mf`、`parent_oneplate_all.stl`、`prints/`、既存ZIPは以前の5点構成の履歴資料で、今回の箱位置決めストップを含まない。

主要金具は、箱側面ストップM4×16ねじ・ナット各4、端ストップM4×14（またはM4×16を先端2 mm短縮）・ナット各4、圧力パッド用M4×25ねじ・捕捉ナット・ロックナット各3、TD支持部M5×30皿ねじ2、カメラストップM4×20ねじ・ナット各2、調整M4×12ねじ・捕捉ナット・ロックナット各2。インサートは使わない。ねじ先端と実物の座面・工具アクセスは組立時に確認する。

上側バー2本、M5全ねじ4本、既存TD押さえ板、カメラマウントは従来部品を再利用する。印刷ジョブには上側バーとTD押さえ板の再印刷分も含む。箱・TD金具・カメラケースの実寸照合、締結試験、強度、実ケーブルと工具の通路確認は別途必要。

生成STLの閉メッシュ・一体性、箱／センサ参照形状／追加金具との干渉、基準面、カメラ取付穴の貫通、新規金具の工具通路は [geometry_checks.json](_work/analysis/repeatable_mount/geometry_checks.json) で合格した。これは公称・仮寸法によるCAD上の検査で、実物適合や繰り返し精度の実証ではない。スライスと部品ハッシュの記録は [slice_report.json](print_jobs/repeatable_mount/slice_report.json) に保存している。

部品STEPの有効ソリッド・外形・体積照合は [step_checks.json](_work/analysis/repeatable_mount/step_checks.json) で合格。全体の [parent_oneplate.step](parent_oneplate.step) は89部品すべて配置照合に合格し、構造モデルの既存別名 `parent_oneplate_structure.step` も更新した。保存3MFの位置・外形・体積・部品数・ハッシュ照合は [print_job_checks.json](_work/analysis/repeatable_mount/print_job_checks.json) で合格した。

`assembly_parts.py check parent_oneplate` とワークスペース整理検査は合格。共通ツールのテストは19件中18件合格、1件は今回と別の旧 `child_wte4_suspension_clamp` 材料カード欠落による既存エラー。全構成の印刷一式検査には `child_interior` の未管理3MFと `over_center_latch` の配置／出力不一致が残る。対象構成の合格とは分けて [検査記録](_work/analysis/repeatable_mount/verification_summary.json) に保存している。

## 設計元と記録

新規SCADは `python spec/prepare_parent_oneplate.py` から生成される。生成器はフレーム、TD支持部、箱ロケータ、カメラストップのソースを組み立てる。組立配置は本フォルダの `placement.json` が正本。生成SCADを直接編集せず、生成元または共有インターフェースを更新する。

旧説明は [`_work/analysis/repeatable_mount/history/README_before_locators.md`](_work/analysis/repeatable_mount/history/README_before_locators.md) に保存されている。旧構成の記録として参照し、現行手順としては使用しない。

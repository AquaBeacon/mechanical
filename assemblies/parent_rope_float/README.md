# 親機：左右2個の浮きを紐で接続

**この版は旧配置です。現行は[下向きカメラ・TD04A／一体型フィン版](../parent_bottom_sensors/README.md)。以下は上部カメラ配置時点の記録です。**

今回のユーザー指定を反映した現行外装。**浮きは2個、親機のすぐ左右に配置し、紐だけで接続する。浮きは剛体接続しない。**

先の `parent_spar_bolted` の印刷円柱浮体・浮体の上下端板・タイロッド・長ナットはこの構成に含めない。浮きを挟むヨークやクランプも使わない。以前の5.2 kg・151時間の印刷見積もりはこの版には適用しない。

## 紐の経路

片側につき、既存デッキの前側紐穴 → 浮きの中心貫通穴 → 後側紐穴という経路を示した。紐穴は既存の直径8、左右の側壁に前後各1個（合計4個）。図の紐径4は経路表示用の仮値で、結び目と締結の細部は未指定。

浮きは既存の市販フェンダー仮モデルを2個使用。各直径100・全長300・中心穴15は実測未確定。中心X=±178、Y=0、Z=0とした表示姿勢では、デッキ側面と浮き胴の間に20 mmの隙間がある。表示の位置と紐の曲線は代表姿勢であり、現物をこの位置・角度へ固定する意味ではない。

紐は張力だけで浮きの離れすぎを抑える接続として扱う。実際の浮きの上下動・回転・親機との接触は許容し、剛体アームで止めない。紐の長さと結び方は実物で調整し、張り切った状態で固定ヨークの代わりに使う想定はしない。

浮きの実寸・紐の余長が未確定なので、可動範囲や接触の有無は未検証。旧双胴の剛体配置に基づく復原性の計算を、この紐接続にそのまま適用しない。

## 親機側の構造

箱・デッキ・カメラ支持部・GPS支持部・下部フィン・錘ケースのねじ固定は維持する。「全てねじ等で固定」という前回条件のうち、浮きの接続は今回の指示に従って紐に変更した。

浮体の縦積みを取り除いたため、下部フィン支柱は新しい `parent_rope_keel_adapter` を介してデッキ中央HP40座へ直接固定する。アダプターはM5×16×4＋座金、支柱はM6×60＋座金・ナットで固定。60×60×48で印刷可能。角部を開いたソケットで、M5ボルトの工具経路を確保する。

円盤は直径225、垂直フィンは125×65の4枚。カメラは前版と同じ箱のすぐ下。浮き・紐は購入品で、印刷部品には含めない。箱底Z=0、円盤Z=-360、カメラケース上端Z=-18.5（仮包絡）。

## ファイル

- `parent_rope_float.step`：組立STEP。
- `parent_rope_float_view.scad`：全体表示用。`placement.json`から生成する。
- `rope_routes.scad`：柔らかい紐の経路の模式表示。印刷しない。
- `print_jobs/parent_rope_float/`：今回使用する印刷向きのSTLのみ。
- `print_checks.json`：印刷向き・寸法の検査。
- `fasteners.json`：今回残るねじ類。印刷円柱浮体用のねじは除外済み。

再生成：`python spec/build_parent_rope_float.py`。保持した造形部品は前版と同一形状で、X1 Carbonのスライス検査済みSTLを使用する。新しいアダプターは別途スライス確認する。

現行版は印刷13種類18点。新アダプターはX1 Carbon設定でスライス終了コード0、残りは前版の検査済みSTLとのSHA256一致を確認。親機のねじ固定部品と金具の接触検査は浮き0・貫通0（可動浮体・紐・未測定のケース包絡は対象外）。紐のSTEPは表示用メッシュ由来。

カメラケース実測、GPSの実物適合、浮きの実測、浮力・復原性・強度の実機試験、TD04A・テザー取付の未確定事項は残る。紐接続で自由に動く浮き・紐・ケース包絡は、ねじ固定部品の接触検査とは分けて扱う。

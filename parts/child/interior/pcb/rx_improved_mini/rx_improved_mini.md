# rx_improved_mini — 子機 音響 RX 基板 (小型版)

KiCad で設計した自作基板の 3D モデル。**このリポジトリでは編集しない** —
`hardware/pcb/RX_improved_mini/` が設計ソースで、ここには成果物を置くだけ。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 基板 |
| 生成元 | `hardware/pcb/3d/RX_improved_mini.step` / `RX_improved_mini_mech.stl` |
| 生成コマンド | `python -X utf8 pcb\export_3d.py RX_improved_mini` (Kicad_project 側) |
| 使用数 | 1 |

## 寸法 (`_mech.stl` の実測。仮値ではない)

| 項目 | 値 |
|---|---|
| 外形 (W × D) | **68.0 × 46.0 mm** |
| 板厚 | 1.6 mm (STL の z = 0 〜 1.6) |
| **基板上面からの最大部品高さ** | **13.79 mm** (STL z = 15.39) |
| **裏面リード突出** | **1.91 mm** (STL z = -1.91) |

| 体積 (部品込み) | 7.6 cm³ |
| 高背部品 | 2.54mm ピンソケット (8.5) + Bourns 3386P 半固定VR |

## 座標系

STL / STEP とも **X = 0..68.0 / Y = -46.0..0 / Z = 板が 0..1.6、部品が +Z**。
KiCad の基板左上が原点なので **Y が負**になる。`placement.json` の `ops` は
これを前提に書いてある。

## 取付穴 (H1〜H4)

(2.5, 2.5) / (65.5, 2.5) / (2.5, 43.5) / (65.5, 43.5)

→ 四隅 inset **2.5**、ピッチ **63 × 41 mm**。**Ø2.2 NPTH = M2**。

## 実装位置

`child_vtray_deck` の**下面** z=134..180。**90度回して** 68mm 側を機体 X、
46mm 側をチューブ Z に置き、**M2 オスメススペーサ 6mm ×4** で吊る
(部品面は −Y = 下向き)。デッキ側は Ø2.4 の貫通穴で、ねじはデッキ上面から入れる。
機体座標での穴位置は **X = ±31.5 / Z = 136.5, 177.5**。

## 部品外の考慮

- **コネクタの抜き差し空間**を基板の外に取ること。上表の位置は基板座標なので、
  `placement.json` の変換を通して機体座標に直してから干渉を見る。
- ケーブルは `docs/配線・ケーブル計画.md` に集約する。
- 基板を**アセンブリでビルドすると STEP が重い** (この基板の STEP は銅箔・
  ベタ・シルクまで入っている)。プレビューだけでよいときは `-NoStep` を使う。
- `_mech.stl` は KiCad の STEP エクスポータ由来なので、
  **水密でない場合がある** (部品ソリッドが基板に食い込んでいる箇所)。
  干渉確認には使えるが、体積・浮力計算には使わないこと。

## 要確認

**2026-07-12 にガーバー発注済み = 外形も穴も変更不可**。子機の RX はこの mini 版を使う
(`AquaBeacon_MAIN_UI_GPIO_コネクタ表` より)。

取付穴が M2 なので、**M3 へ拡張しようとしないこと** — 製造済み基板を Ø2.2 から
Ø3.2 へ広げると、NPTH 周りの銅・レジストの残り代が保証できない。締結は M2 で行う。

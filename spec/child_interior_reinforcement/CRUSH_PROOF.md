# 破損報告を受けた再補強版

ユーザー報告：左右のデッキ固定耳が折れ、グルーガンで補修している。
ねじを強く締めると割れる。2026-09-26。

## 現行変更

- 固定耳厚5.5→12 mm。半径方向の薄い閉じた輪を、外向きに開いたフォークへ変更。
- 根元幅8.7 mm、接続長Z20..41の21 mm。内側の橋も広げて一体で荷重を伝える。
- 鋼製スリーブと押さえ板を追加。樹脂の上に0.2 mmの隙間を残し、
  ねじの締め付け力を金属同士で受ける。
- C-MAINのボスを7→9 mm、基板下面Y1→3へ2 mm上げ、根元の内側空間を確保。
  X/Z取付穴位置は維持。MAIN側のハーネス起点も2 mm上げた。
- 下ブレースは8 mm厚にし、皿ねじを廃止。通常頭ねじ、スリーブ、金属板で固定。
  右側の金属スペーサはMF17からMF12に変更（左MF30は再使用）。
- LCDは撤去したまま。下フランジ3点固定を維持。

## 交換・追加するもの

デッキt200とchild_flange_braceを再印刷する。割れた旧デッキは再使用しない。
金属加工部品の一覧は [金属部品の寸法表](../../parts/common/interior/cots/child_mount_metal/child_mount_metal.md)。
金属押さえ板の加工用DXFと参照STEPを同フォルダに用意した。

固定ねじはフランジ3点にM3×18各1本、ブレース2点にM3×12各1本。
左右は既存MF10へ4.3 mm、前側はフランジへ4.3 mmねじ込む。
右ブレース用M3 MF12を1本用意する。上側MAINのM3×8は2本とも再使用。

## 印刷・組立

デッキは板をベッドに寝かせ、ボスを上へ。ブレースは適宜平らな面を下に置き、
下面へ出る固定耳と横穴に必要なサポートを使う。
0.4 mmノズルなら外周6周、固定耳・根元は密な充填を目安にする。
スリーブ座は圧入しない。押さえ板が樹脂より先に金属へ当たることを実測確認。
金属が当たった後も過大な力で締め続ける用途は想定しない。

## 検証

最終変更部の接触検査、容器包絡、基板穴照合は `crush_proof_*` ログに記録。
再補強部の容器までの最小すきまはデッキ・前側ブレースとも1.00 mm。
最終STEPを読み戻して配置照合：内装82部品、縦置き全体89部品ともNGゼロ。
全内装接触検査は浮き部品ゼロ、補強部と周辺部品・金属部品の干渉ゼロ。
既存のハーネス包絡同士やハーネスと基板の重なりは残っており、全配線を
干渉ゼロとしたわけではない。
デッキのSTEPは検証済みSTLからのファセット表現。寸法変更は元のSCADを使う。
検証対象はユーザー確認済みの200 mm構成。300 mmバリアントは本作業の検証対象外。
構造の実物破壊試験と保証締め付けトルクの測定は未実施。

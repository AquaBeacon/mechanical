## 今回の修正

電源基板PWRの裏面リード8.15 mmに対し元の支持高さは6 mmだった。
統合用 `parent_plate_integrated` ではPWRボスだけ9.5 mmにし、
PWR下面をZ=28.3へ3.5 mm上げた。プレート上面Z=18.8との
リード最小隙間は1.35 mm。MAIN、電池、TX、SPRESENSEの高さは継承する。
既存のP1/P2アセンブリは履歴・比較用に残る。

## 検証と未解決

統合STEP/STLは198部品、欠落0。STEP読み戻し検査は198部品・配置不一致0
（既存検査の外形許容0.5 mm）。全体図と箱まわり拡大図をレンダーして目視確認した。
統合用プレートは閉じたメッシュ・STEP 1ソリッドで、STEP/STL外形差0.00 mm。

内装・箱・ペネトレータ14部品のサンプル検査で浮き0。
PWRとプレートの干渉指摘は解消。SPRESENSEとプレートの干渉指摘は残る。
SPRESENSEの簡易モデルには穴がなく、下面リードも大きな直方体のため、
これを実物の干渉と断定してボスを削らない。実測した穴・下面形状に置換して再検査する。

全外装に対する内装の交差候補4組も別検査した。テザーペネトレータと
電池トレイ南東レールに内部サンプルが検出された。
追加50000点のトレイ側検査でも36点を検出し、範囲は概ね
X=14.10..19.67、Y=−95.91..−95.12、Z=60.08..63.30 mm。
これは既存接触検査の「表面距離0.3 mm未満なら内部判定」という条件では拾えなかった。
保存済みペネトレータSTLは内側Y=−95（箱座標20）まであり、
旧資料の14.5 mmとは一致しない。実物突出量と工具空間を確認して、
トレイ端の逃げまたは引込位置を決める。プラグ切断は前提にしない。

`_work/logs/interior_contacts.log/json` と `cross_contacts.json` が結果。
サンプル検査は厳密な全体積ブーリアン検査ではない。
TXのメッシュが閉じていないため、TX内部を判定する方向の検査は省略される。
ねじ山接触は内装検査の除外対象。固定ねじ全数、配線、LCD、実形状の蓋、
パッキン、工具の動線が未反映なので、干渉確認全体は未完了。

## 実測後に仕上げる順番

1. 箱、SPRESENSE、引込部を実測形状へ更新し、残る2箇所の干渉を解消する。
2. 内装固定ねじ、LCD支持、端子台、GPS引込、配線固定を追加する。
3. 蓋の着脱、電池の上抜き、基板スイッチ操作、工具アクセスを確認する。
4. 内装・外装の検査を再実行し、荷重条件に基づく強度と印刷姿勢を確定する。
5. 確定した内装を含めて印刷リストを更新する。旧外装ZIPに新プレートは含まれない。

## 再生成

```powershell
./build.ps1 parts/parent/interior/printed/parent_plate_integrated
python spec/integrate_parent.py --check
./build.ps1 -Assemblies assemblies/parent_integrated
```

現時点の`--check`は未解決干渉により終了コード1が正しい。
元P1の箱座標から最新外装の箱座標へ変換するので、旧外装内にある内装コピーに依存しない。
PWRの移動量はビルド済みプレートの高さ差から導出する。元プレートの最高ボスを
別途変更した場合はこの導出方法も見直す。回転の異なる箱座標系には明示的に停止する。

# MAIN枠の下面と独立スペーサの改訂（2026-10-24）

印刷入口は [parts/PRINT.md](parts/PRINT.md)。本書を、それ以前の「全スペーサを2.8 mm下穴へ直接締結」「整備用M3×8」「最長30 mm」の記述に優先する。基板に一体化したねじ座と、独立したスペーサを区別する。

## 変更

- MAIN固定枠：従来は脚下面Z33.4に対し格子下面Z37.1で、格子の下に3.7 mmの空間があった。実際の格子下面を下方へ延ばし、脚と同じ印刷面に揃える。基板座面Z44.95と格子上面Z39.5は保持する。電源基板の裏を広く逃がし、逃げの上を斜面でつなぐ。個々の電子部品に合わせた小穴にはしない。
- 独立スペーサ：床側受け4本、GNSS側4軸、Sony側4軸、計12軸を対辺3.5 mmの補正八角穴にする。M3ねじの直径に対し公称0.5 mmの余裕。外形は床側受けが八角形、GNSS/Sony柱が面取りした角柱。位置決めキーの丸形状は相手穴との嵌合寸法を保持する。
- MAIN/PWR基板の一体ねじ座とアンテナ棚接合部のねじ込み先は、対辺2.8 mmの樹脂下穴を維持する。通し穴へ広げない。
- 共有柱のSony側1軸は直下にケースボスがあり、床への貫通固定を使えない。穴自体は3.5 mmで全長を通し、Z55.5–58.1の側面挿入ナットを上の屋根で受ける。床への固定は隣のGNSS軸を通るねじと下端の橋で行う。

追加するナットは計12個、床裏の座金は計11枚。旧スペーサの上下から入れる短いねじ23本を、表の通しねじ12本へ置き換える。これらを重複して入れない。MAIN/PWR基板固定ねじは従来どおりM3×8/M3×6を各4本。Sony基板のM2.5ねじ、その他の基板・電池・ケース固定は既存構成に従う。

裏ナット下面はZ5.94、上面Z8.34、座金上面Z8.84で床の下面に当たる。締付けるとナットは+Zへ引かれ、座金と床板がこれを止める。スペーサと上板だけを締める経路にはしない。MAINねじ先端Z5.6、GNSS先端Z3.5、Sony長ねじ先端Z3.7。呼び寸法で全ナット厚2.4 mmを通る。GNSS先端とケース床との公称余裕が小さいため、実ねじ長とケースの実寸を確認する。

共有柱のナットは+Y側から挿入する。六角面が回り止め、Z58.1の屋根が+Z方向の抜け止めとなり、上面開放穴ではない。内側の六角面と反力面の稜は機能寸法を保持し、外側の挿入口だけを0.1 mm面取りする。MAIN枠の長い直線のベッド側稜は0.05 mm、電源側の扱い稜は生成元の面取り値を使用。基板座との曲面交差、穴の多角形の稜、共面の接合境界は機能面として保持する。

## 組立と印刷

床板をケースから取り出して組む。裏ナットは工具で保持して締める。裏ナットの回り止めを樹脂へ新設した構造ではなく、ナットを押さえる作業が必要。旧床板の上面開放ナット穴を、この締結の抜け止めとして使わない。

1. 共有柱のSony側ナットを側面から入れる。ねじが掛かるまでは手で仮保持する。
2. 柱、GNSS/Sony固定板を置き、長ねじを上から通し、床裏の座金とナットで挟む。共有柱のSony側はM3×10で固定する。締付け前後にキーの着座と先端の突出を確認する。
3. 同軸リング、床側受け、MAIN枠を置き、M3×30を上から通して床裏の座金・ナットへ締める。その後、基板とアンテナ棚を取り付ける。
4. ケースへ戻す前に、全ナット・座金と基板裏の隙間を確認する。分解時も床板ごとケースから取り出し、裏ナットを保持して外す。MAINの4本を抜くと床側受けも未固定になるので、受けとナットを回収する。従来の「床側受けを固定したまま上からM3×8だけ外す」手順は使わない。

16種類16個のSTL一式。今回形状が変わるのはMAIN枠1個と独立スペーサ11個。MAIN枠・柱・受けは原姿勢の下面をベッドへ向ける。同梱STLは製造メタデータに従って変換済み。アンテナ棚のみX180°。PETG、X1C/0.4 mm、0.2 mm積層、4周壁、100%充填、外側3 mmブリムでスライス確認する。新しい共有柱のナットポケットも支持材禁止モディファイアに含める。上の短い橋は工具経路画像で確認し、実物で印刷品質を確認する。

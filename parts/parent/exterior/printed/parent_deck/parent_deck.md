## 役割 (2026-09-04 人間決定の親機外装構成)

- **浮子 2 個・支柱 (マスト) 無し・カメラは Osmo Action 6 + 純正防水ケース (ジグは後日)**。
- タカチ **BCAS212310G** を上に載せ、箱底コーナーの**外部取付穴 Ø4.2 ×4** (図面 E-E、
  箱中心から (±96, ±106)) に上から M4 を通し、デッキの **M4 熱圧入インサート** ×4 で受ける。
- 左右 (±X) 側壁の外面に **HP40 座 ×2 / 側** (Y ±70, z −25) → `parent_float_yoke` (浮子の端受け、
  2026-09-05 にアーチ式クレードルから置換) を M5 ×4 で締結。ヨークを外せば同じ座に別のアクセサリを付けられる (拡張性)。
- 下面中央の**キール** (壁 2 枚 + 端壁 2 枚 + 座板 3 枚) の底面 (z −60) に **HP40 座 ×3**
  (Y −70 / 0 / +70) → 南 = TD04A ソケット (`xdcr_socket_parent`, 開口下向き)、
  北 = **Osmo 固定ジグ用 (予約)**、中央 = 予備。
- 紐穴: 側壁両端 **Ø8 ×4** (X 貫通、Y ±108, z −35) = 吊り索 / 浮子の紐の予備の結び点 (ヨークのフィンに同軸の Ø8 穴があり塞がれない)。
- **南縁ケーブル切欠き** (X −30..25、深さ 8) = 南壁ペネトレータ ×2 (箱 x=85/120 →
  デッキ X −20/+15) から降りるケーブルをデッキ下へ回す。キール南端壁の **Ø8 フェアリード ×2**
  (X ±9, z −30) でテザー / TD04A ケーブルの張力止め (結束バンド or 結び目)。

## 座標系

箱中心 = 原点、デッキ上面 (= 箱底外面) z=0、+Y = 北 (箱の北壁側)。
**箱座標 (x, y) → デッキ (x − 105, y − 115)**。

## 干渉チェック (`.scad` 冒頭の assert)

- 箱の取付穴 Ø5.6 が側壁の板厚 (X 91..108) に収まる / インサート下穴が側壁を突き抜けない
- 側壁の YZ 面フィーチャ表 (HP40 下穴 ×8 + 中央穴 ×2 + 紐穴 ×2 + 箱取付穴 ×2) を**総当り**で離隔 ≥ 3
- 軽量窓が HP40 座・側壁下端・デッキ板 (45° 屋根の頂点) から離れる
- キール座の HP40 下穴 Ø6.4 @ ±20 が壁 (X ±16..±24) の真下にある (母材) / 座同士 ≥ 座 + 10 / 端壁と重ならない
- フェアリード穴がキール壁・端壁高さに収まる
- 南縁切欠きが箱の胴体壁の下を 3 以上残す / ペネトレータ直下を覆う / 側壁に掛からない
- 250³ 造形枠

実際に止めたもの (2026-09-04): 箱取付穴が側壁板厚 14 に収まらない → 17 へ /
キール座下穴が壁の真下に無い → 壁 X 17 → 16 / キール座が端壁に掛かる → 壁半長 100 → 105。

## 印刷 (X1-Carbon)

- **上下反転** (デッキ上面をベッドに)。側壁・キール壁・座がベッドから立つ。`topopt overhang`
  (反転 STL): **要サポート面積 3.6 %** = キール座板 (t10) の壁間 32 mm ブリッジ ×3 と側壁窓の
  45° 屋根。**サポート不要** (X1C のブリッジで可。気になれば座板下のみサポート)。
- 主引張 (側壁の曲げ = Y 方向、板の曲げ = XY 面内) は層面内。`topopt print --keep-flat Z` の
  「load vs layers FAIL」は `--load-axis 0,0,1` を与えたためで、実荷重方向 (Y) では PASS。
- 材料 PETG (屋外・水・紫外線なら ASA)。壁 4 本 / インフィル 25 % (ジャイロイド) / 上下 5 層。
- HP40 のインサート下穴 (Ø6.4) は反転印刷で座板側が上面になるので、印刷後にそのまま熱圧入できる。
  側壁の横穴 (Ø6.4 / Ø8 / Ø14) は水平穴 = 上面がやや垂れる。Ø6.4 は熱圧入時に馴染む。
- 反り対策: 216 × 236 の全面ベッド接触。ブリム 5 mm、ベッド中央。

## 部品外の考慮

- **ケーブル**: 南壁ペネトレータ (箱外 z 65) → 南縁切欠き → キール南端フェアリード →
  南座ソケットの底穴 Ø9 / HP40 中央 Ø14。TD04A の 3P プラグは通らないので**箱内で切って
  端子台**に落とす (`wetlink_penetrator_m10.md`)。テザーは南端フェアリードで**張力止め**を
  してからペネトレータへ (シール部に引張をかけない)。
- **喫水**: 浮子軸 z 0・総質量 3.14 kg で喫水線は **z ≈ −2.7** (`spec/parent_hydrostatics.py`) = デッキ板がほぼ全部水中、
  箱底が水面。側壁・キール・TD04A 面 (−104) は水中。デッキは密閉インフィルの PETG なので 0.84 L の浮力体でもある。
  水抜き穴 (キール座の Ø14、側壁窓) から水が入っても抜けるので問題なし。
- **水抜き**: デッキ板上面は箱が覆う。側壁の軽量窓とキール壁間の通路は水が抜ける。
  キール座の中央 Ø14 はケーブル穴兼水抜き。
- **GPS アンテナ**: 箱の蓋の上 (最頂部)。デッキは関与しない。北壁の引込みグランドは未定。
- **工具アクセス**: 箱固定 M4 は蓋を開けて上から (箱内側から) 締める前提。ヨークの M5 は
  ヨーク外面のざぐりから六角レンチで締める (デッキ側はインサート)。
- **持ち上げ**: 側壁の紐穴 ×4 に吊り索を通す。箱の蓋やペネトレータを掴まないこと。

## 要確認

1. **箱の外部取付穴の使い方** (ねじを箱内側から下へ通せるか / 穴が貫通か)。現物で確認 →
   通せなければ下から M4 + 箱内ナット (要防水) に変更
2. 浮子実測 → ヨーク・喫水の再計算 (デッキ自体は変わらない)
3. Osmo 固定ジグ (北座) の設計: 座面 (z −60) が喫水線 (≈ −3) より下なので、ケースをそのまま座に付ければ水中
4. ペネトレータ頭 (箱外 22 mm) とケーブルの曲げ半径 (切欠きまでの落差 65 mm)

# Sony固定板3.2 mm版 — 1個

`sony_mount_plate.3mf` はX1 Carbon・0.4 mmノズル・Generic PETG、0.2 mm層、4周壁、100%充填、3 mm外ブリム。材料見積り9.34 g、時間約30分29秒。材料とSTL/3MFのSHA-256は `manifest.json`。

原本の印刷入口は [../../parts/PRINT.md](../../parts/PRINT.md)。このジョブは固定板1個だけで、内装一式を含まない。板下面を下にする。45°自動支持を全表面で有効にし、橋の支持除外を無効にした実スライスでは支持材の押出し104移動がある。下面の位置決め穴付近の支持材を印刷後に除去し、穴と支柱の着座を確認する。支持材を残したまま締め付けない。

初層、キー穴天井付近、板上面、上部ねじ座の実経路を [確認画像](../../_work/images/sony_plate_thickened_toolpaths.png) で確認。実印刷・締付け強度は未検証。

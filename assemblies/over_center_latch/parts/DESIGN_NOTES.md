# DJI式・80°溝・締付力40 Nのラッチ

[印刷入口](../../../../assemblies/over_center_latch/parts/PRINT.md)。2026-10-10。Bambu Lab PETG Basic、M3金属軸を使う試作です。40 Nは閉状態で台同士を引き寄せる**水平締付力**の設計目標です。外力耐力や手の操作力とは区別します。実物の40 Nは未測定です。

## 構造と寸法

**強度検証は未完了です。** 最終CADの形状検査は合格していますが、今回の爪位置と閉じ角では構造解析を再実行していません。以前の解析は旧形状の記録です。100 N手押し耐力を認定していません。40 Nは実測校正が必要な設計目標で、実用強度を保証する完成版ではありません。

固定台のA軸から左右の短いリンクを介し、B軸で爪付き上蓋レバーを支えます。操作部はBより爪と反対側へ約43.1 mm延長。爪は複雑な曲がりと丸棒を廃止した台形で、高さ2.4 mm、幅30 mm。受けの傾斜した荷重面は台上面に対して80°、受けの浅いくぼみ内の保持段へ掛けます。荷重面の角度と掛かり代を残し、根元R1.2、一般外角R0.6、一般エッジ面取り0.25 mm、爪のエッジ0.15 mm、穴入口0.2 mmで仕上げます。

台は固定側6 mm・受け側8 mm（従来は両側17 mm）。受けのくぼみ底Z=-6 mm、底肉2 mm。保持段の下面Z=-1.6 mm。台幅70 mm、継ぎ目X=2.1 mm。専用ストッパーは設けず、レバーの後端下面が台上面Z=0へ直接着座します。操作時は後端を持ち上げてリンクを開き、爪を抜きます。閉じる際は爪を溝へ入れ、延長した後端を押し下げます。

軸間AB=8 mm、A高さ6 mm、閉リンク角150°。固定側の台取付穴X=-26/-8、Y=±30、受けの局所穴X=18.6、Y=±30、φ3.5 mm。穴のX/Y配置は従来を維持しますが、受けの閉配置はX=12.4 mmへ変更し、ねじ長さは薄い台と実取付先へ合わせます。位置決めキーも薄い台用に変更しており、旧樹脂部品と混用しません。

設計正本はparameters.json、spec/over_center_latch/latch_body.scadと生成コード。over_center_latch.scadは生成結果で、直接編集しません。配置はassemblyのplacement.json。

継ぎ目X=2.1から爪の80°接触面中心X=9.6まで7.5 mm（実際の分布反力中心は約7.47 mm）。保持段の接触点は約7.81 mm。B軸から接触面までの水平距離は約16.53 mmです。台の外形・取付穴の世界座標は維持し、受けの局所取付穴X=18.6へ補正しました。閉じ角150°に合わせ、死点付近の過大なゴム圧縮を抑えています。

## 必要な購入品と組立

近接配置では開き角100°までリンクを開き、保持段を抜けてから上蓋を持ち上げます。爪の外側の下面だけ0.4 mm逃がし、溝底との開閉干渉を避けています。80°荷重面と爪の接触高さ2.4 mmは維持しています。B軸の座金・頭・ナットが上蓋に干渉しないよう、左右の軸受面より外側の屋根にも逃げを設けています。

上蓋高さ15 mm、屋根厚4 mm、左右壁厚5.5 mm、爪背後の全幅補強、A軸台の側面R0.8で補強しています。爪先の高さ2.4 mm、80°の接触面、受けの底肉2 mmを維持しました。

- A軸：M3×20皿ねじ1本、標準ナット厚2.4 mm 1個。
- B軸：M3×35キャップねじ1本、同ナット1個、外径7 mm・厚0.5 mmのM3座金2枚。従来の40 mmでは台の取付ねじの工具通路へ張り出すため短縮しました。
- ゴム：既存のWAKI EPGR-01、厚1 mm。下記3片を積層して使用。
- 台を取付先へ固定するM3ねじ6本。長さは取付先厚さで選びます。

樹脂は台1、左右共通リンク2、爪付きレバー1、受け付き台1の計5点。リンクのA側には片面だけ皿穴があります。左リンクの外側に皿穴、右リンクの外側に平面が来る配置にします。左右は同じ部品の2個で、鏡像部品ではありません。A/Bともナットで回転を締め殺さず、適切に緩み止めします。初期組立には工具を使い、日常開閉は手で行います。

## ゴムと40 Nへの合わせ方

EPGR-01を30×1.8×1 mmに3片切り、合計3 mmとして**受け側の80°面**へ貼ります。貼付中心は爪面中心より斜面に沿って0.2 mm下寄せ。裏面を全面支持する平面をCADで検査します。接着層は公称3 mmへ含めていないため、接着後の厚みを測って調整してください。

硬度65をショアA65と仮定した自由膨張neo-Hookean概算では、閉状態の面法線圧縮約0.433 mmで水平締付力40 N。実材料・接着・3層の界面・摩擦・PETGの変形により変わります。計算値を実測値として扱いません。ゴム厚や接着条件を変更したら再生成と検査が必要です。

同じ3層の貼付試験片を同じ80°爪面で圧縮し、最終的には組立状態の水平反力を測って40 Nへ調整します。薄い硬質シムで圧縮を増やし、厚さ調整で減らします。手の操作力を測って締付力へ読み替えないでください。閉状態に加え、死点付近の最大反力と開き始めも確認します。

## 印刷

X1 Carbon / PETG Basic / 0.4 mmノズル / 0.2 mm積層 / 6周壁 / 100%インフィル / 乾燥材料。印刷用コピーにはY側面下の姿勢を反映済みです。STLを再回転して組立姿勢で印刷しないでください。荷重方向X/Zを層内へ配置します。薄い台の側面印刷にはブリムを使い、長いレバーと受け溝・キー・横向き穴の局所サポートはスライサで確認します。軸穴、80°面、保持段、台への着座面からサポートを除去します。

φ3.3の軸穴とφ3.5の取付穴を実物で確認。溝へ爪が無理なく入ること、リンクが自由に回ること、ゴムが巻き込まれないことを荷重を掛ける前に確認します。40 Nへ調整した後、繰返し開閉による摩耗・ゴムのへたり・ナットの緩みを確認します。

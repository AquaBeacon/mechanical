## 荷重と検証 (v4 確定・2026-09-04)

**トポロジー最適化** (`topo/`, 7595 ボクセル @4.14mm, filter 6.2, X 対称, 40 反復) は v3 のまま。
v4 の追加肉 (背面壁 t14、HP2/3 座、HP1 ペデスタル) は機能面なので最適化対象外。
幾何比較 `topo_cmp/` は v3 の「最適解ボクセルの 97.2% 包含」を維持 (肉は増える方向にしか変えていない)。

**FEA** (`fea_v4/`, voxel 1.73, `child_core_frame_topo.json` の 4 ケース。
改善要件 C6/Q2 により **L2 を 600 N → 300 N** に変更。L1 / L5 は据え置き):

|---|---|---|---|---|
| L1 吊り上げ 3g (耳固定・搭載物自重) | 205 N | 0.489 mm | 5.17 / 30.07 | **PASS** |
| L2 輸送・側方 (C6 で 600→300) | 300 N | 0.120 mm | 6.09 / 28.02 | **PASS** |
| L2 輸送・後方 (C6 で 600→300) | 300 N | 0.116 mm | 9.89 / 31.91 | **PASS** |
| L5 着底 (ガードボス経由) | 600 N | 0.009 mm | 17.29 / 63.15 | **PASS** |

- 126,555 要素 / voxel 1.730 mm / 部品体積 655.3 cm³ (ボクセル値)。**4 ケースとも
  `mesh resolution` が PASS** (最薄 6.92 mm = 4.0 要素 / 典型 6.92 mm = 4.0 要素)。
  v3 では最薄局所が常に 2.8 要素で FAIL していた (45° 面取り先端を追うアーティファクト) が、
  背面壁 t14 化と HP2/3 座・ペデスタルで最薄部が厚くなり、v4 では素直に PASS する
- v3 (L2=600 N) との比較: 側方 SF 2.05→**6.09**、後方 4.13→**9.89**。荷重半減 (×2) に対して
  さらに肉が増えたぶん (×1.2〜1.5) が効いている。L1 は 4.26→5.17、L5 は 17.4→17.29 (ほぼ同じ)
- 最悪要素の位置: L1 = 吊り耳ボス根元 (±56, −21, 204)、L2 側方 = HP2/3 座ブロックの下端まわり
  (±31, −66, −2)、L2 後方 = HP2/3 座の前縁 (±45, −44, 100)、L5 = ガードボス。
  いずれも `max/p99.5` 比が 3.5〜5.0 の階段状アーティファクトなので、規約どおり **p99.5 で判定**
- **4 ケースは 2 回に分けて解いた** (L1+L2側方 → L2後方+L5)。1 回のバックグラウンド実行が
  セッションの時間上限を超えるため。STL・study 領域・voxel 1.730 は同一で、結果は
  `fea_v4/child_core_frame_fea.json` に 4 ケースぶん統合してある (`fea_v4/run.log` が生ログ)

## 部品外の考慮

- **配線の正規ルート (§3.3)**: テザー / TD04A / ライトケーブルは背面溝 (x ±18) を通すが、
  **溝 (x 13..23) は取っ手の手穴 (z 115..145、x ±26) を横切る**。手穴の中をケーブルが走ると
  握った指がケーブルを直に押さえるので、**z 115..145 は溝を使わず、パイロン内空洞を迂回させる**:
  下から溝 → **z=90 のスロットで空洞へ入れる** → 空洞内 (y −87..−64) を手穴の裏側で上へ →
  **z=155 のスロットで溝へ戻す** → 溝の上端付近で **ペデスタル縦穴 Ø12 (±18, −92)** に入り、
  **座面 z218.5 へ抜ける** → HP1 中央 Ø14 経由で `xdcr_socket` 底へ。
  結束バンドは z 0/30/60/90 (溝側) と z 155 (溝復帰点)
- **HP2/3 のケーブル**: 座の中央 Ø14 → パイロン空洞 → 背面溝の結束スロット、が正規ルート
- **HP1 ペデスタルは突出物**: 座面 z218.5 はフレーム頂面 218 より 0.5 mm 高い。`child_top_crown`
  (カラー z218..245) と同じ高さ帯に入るので、**クラウン側の後方セクタが y −110..−60 / x ±30 を
  空けているか要確認** (改善要件 §3.5)
- **HP2/3 の座は突出物ではない**: 座面 x=±44 は包絡 (ラッチ側 x=72 / ヒンジ側 x=−80) の内側
- **内装アクセス**: 「ゲートを開けて容器を前方へ出してから」上フランジを抜く
  (ノブボルト 2 本 + 顎の開閉 ≈ 30 秒。v4 で蝶ボルト → ノブボルトに変更)
- ヒンジピン Ø5×240 は上から挿入する。**最上段の止め輪はゲート側ナックル頂面 (z218) に載る** —
  コアフレーム側のざぐり (z187.6) は下向き抜け止めの座

## 要確認

1. **`dome_r_ped = 56.7` は仮値** (z218.5 のドーム断面半径、発注元指定 2026-09-04)。ドーム実測が
   出たら `assert(abs(ped_y0) - dome_r_ped >= 3.0)` が生きるので、ペデスタル前端 y=−60 を再確認する
2. **ヒンジピン抜け止めざぐりの位置 (要判断)**: 改善要件 §3.7 は「コアフレーム頂面 z218 のざぐり」と
   書いているが、(−72, 10) の z218 は **`child_jaw_gate` の最上ナックル (z 188..218)** の材料で、
   コアフレームはそこに何も持っていない。v4 ではコアフレームの上アフトナックル頂面 (z 187.6) に彫った。
   このざぐりは床 z183.6 とゲート最上ナックル下面 z188 (遊び 0.4) の間に E リングを閉じ込めるので
   **軸方向の拘束としては上下とも効く**。問題は**組立て**で、ピンを抜いた状態でも z 183.6..187.6 へ
   横から手が入らないため、**この位置に E リングを後から嵌められない**。
   → 実用的な抜け止めは `child_jaw_gate` 最上ナックル頂面 (z218) のざぐり。**ゲート側で彫るか、
   ピンを段付きにするかの判断待ち**
3. **HP1 前列インサート (±20, −65) とペデスタル前面 (y=−60) の残り肉は 1.8 mm** (発注元の
   「≥ 2 mm」に 0.2 足りない)。HP40 のピッチ 40 + Ø6.4 = 46.4 に対し座の奥行きが 50 なので、
   前後とも 1.8 mm が上限 (2 mm には奥行き 52.8 が要る)。**z ≤ 218 ではシェル (r64.35) が前面を
   裏打ちして実効 7.0 mm** になるため、薄いのは最上部 0.5 mm の縁だけ。座を 52 深くしてよいか判断待ち
4. **ペデスタル縦穴を y=−97 → −92 に変更**した (上表の理由)。ケーブルカバー側の想定と合うか確認
5. M5 ノブボルトの頭 Ø16 ポケット (深さ 12) は `child_jaw_gate` 側で未実装
6. **溝の x 位置と手穴の矛盾 (要判断)**: 改善要件 §3.3 は「取っ手の**左右に**溝 ×2」と書きつつ
   「中心 x ±18」も指定しており、手穴 (x ±26) と必ず重なる。外へ逃がすとパイロン側壁 (x 24..30) と
   背面壁の端 (x ±36) に挟まれて置けない。v4 は **x ±18 のまま残し、手穴帯だけ空洞へ迂回させる運用**
   で解いた。物理的に離すなら手穴の半幅 26 を縮めるしかない
7. **HP2/3 座ブロック下面のサポート**: z=72 の水平オーバーハングを 45° 面取りでサポートレスにできるが、
   その分ブロックが z<72 へ伸びる (指定は z 72..128)。面取りを入れてよいか判断待ち
8. 熱圧入インサートの引抜き耐力 (吊り耳ボス・HP1/HP2/HP3 は実測推奨)
9. v4 で体積が +36% (477.7 → 650.0 cm³、PETG 約 520 g) 増えた。全備重量の見直しが要るか
10. ドームリム実寸 (`dome_ring_od/t` 仮) — gate と共通

## 役割

耐圧容器を挟む 2 枚シェルの**ゲート側**。M5 蝶ボルト 4 本を外すと、
カメラ 2 台とライトごと丸ごと前へ抜け、容器が真上に取り出せる。

### ★ 基線 150.0mm を 1 部品で持つ

左右のカメラポッドを**分けずに 1 部品に一体化**してある。
組立誤差でレンズ間隔が変わらないので、**基線 150.0mm は「単一部品の寸法」として
後の解析で信頼できる**。レンズ位置は機体座標で **(±75.0, 110.0, 115.0)**。

ただし絶対値の保証は設計の役目ではない。**運用前にステレオキャリブレーションで
実測すること。** この部品の役目は「基線を安定させ、着脱で変わらないようにする」こと。

## カメラの保持

上から落とし込むクレードル + 押え蓋 (M4 蝶ボルト ×2)。**着脱 5 秒**。

| 基準 | 実装 |
|---|---|
| Z | 床の位置決めパッド ×3 (Ø8 × 0.8)。カメラ底面が z=91.4 |
| XY | クレードル内寸 73.4 × 33.7 (片側 0.3mm クリア) |
| 押え | 蓋のパッドに EVA 2mm → 締結で 0.6mm 潰れて予圧 |
| 前抜け止め | 側壁内側の 3mm タブ (z 90.6..102)。上から落とし込むときは当たらない |

## 画角 (FOV 155° 対角) の扱い

**前面は完全開放**。155° の画角を蹴らずにレンズの前へ構造物を置くのは幾何学的に
不可能なので、「前は開ける・横と上下と下からの衝撃だけ受ける」という割り切りにした。

- **フード**: 側壁と床がレンズ面より 8mm 前へ出る。
  `8 × tan(77.5°) = 36.1mm < 対角基準 43.8mm` → **余裕 7.7mm** で画角を蹴らない (assert)
- **前方衝突**: 底デッキ前縁 (y=122) がカメラ (y=118) より 4mm 前に出て最初に当たる
- **画角に入らないことを assert で検査しているもの**: フード側壁 / フード床 /
  前抜け止めタブ / ライト (上端 z=78, 前端 y=118) / 前縁リム (z=46) / 底デッキ (z=30)

**VSLAM では自機の写り込みを必ずマスクすること。** 上記は「画角の外」を計算で
保証しているが、`cam_fov_h/v` は 155° 対角からの**推定値**なので実機で 1 枚撮って確認する。

## 干渉チェック (`.scad` 冒頭の assert — 実際に止まったもの)

1. **ポッド後壁がスキンに 0.05mm 食い込む** → `lens_y` を 106 → 110 に前進させた
2. **蓋ねじの外側端距離が 0.25mm 足りない** → 蓋を側壁より 1.5mm 広げた (`lid_ov`)

そのほか常時検査しているもの: 全幅 ≤250 / 前端 ≤125 / **ベッド 256 に入ること** /
フードの画角余裕 / ライト・リム・デッキが画角外 / 締結 M5 とピン穴の位置 /
左右ポッドが中央で衝突しないこと / ライト鞍座とポッドの干渉 (Z で逃げている) /
**フィン間隔 ≤40mm** (ポッド床をブリッジで架けられる上限) / 通水穴がフィン・レール・鞍座に
掛からないこと / 蓋ねじまわりの側壁残肉。

**カメラポッドの前面開放カットがフード側壁と抜け止めタブまで削っていた**のは
assert では捕まらず、モジュールの読み直しで見つけた。preview の目視は必須。

## 強度

| 項目 | 値 |
|---|---|
| カメラ+ポッドの片持ち (0.3kg × 3g = 9N、腕 100mm) | フィン 4 枚で受けて **0.005 MPa** |
| 底デッキ (バンパ) の局所曲げ | 衝撃は塑性変形で吸収する前提。**割れたら刷り直す消耗品** |

構造的な律速はここではなく、**大面積 (237mm) の反り**。ブリム必須。

## 印刷向き

- **このまま (Z が積層方向)。サポート不要。**
- 底デッキ (z 18..30) が約 200cm² のベッド接地面 → 反りに強い
- カメラクレードルは**開口が上**なので無サポート
- ポッド床はフィン間 (最大 34mm) のブリッジ
- **幅 237.4mm は X1-Carbon (256) にブリム 3mm 込みでぎりぎり。ベッド中央に置くこと**
  (`assert(2*half_w + 6 <= 256)` で検査している)

## 部品外の考慮

- **ライトのケーブル**: 下のキャップ → ガード後方 → 機体外周 → デッキの結束スロット
  (x=±60/±100, y=96) → ライト。**前半シェルを外すときに突っ張らないよう、
  サービスループを 150mm 以上取ること。**
- **バックスキャッタ**: ライトがレンズから 75mm しか離れていない。濁った水では
  後方散乱が出る。ライトは鞍座の 40mm 範囲で軸方向に下げられるので現場で調整する。
- **ライトの光がレンズに直接入らない**こと。ライト上端 z=78 はレンズ軸 115 より
  37mm 下、かつ前へ 8mm しか出ていないので直射は入らない。
- カメラの**背面スクリーンは装着状態では見えない** (ポッド後壁の Ø14 通水穴から
  一部のみ)。**前面スクリーンは前が開いているので見える** → 録画状態はこれで確認する。
- 電池・SD の交換は蓋を開けてカメラを外して行う。**入水前に充電・設定・時刻同期を済ませる**。
- 前半シェルを外すと**カメラ 2 台ごと外れる**。基線は変わらないが、
  **容器に対する相対位置は再現しない**ので、外部標定が要る用途では毎回較正する。

## 要確認

1. **レンズ軸の本体X中心からのずれ** → `lens_dx` (現在 0)。ずれると全幅が変わる
2. 水平/垂直の実画角 → `cam_fov_h=145` / `cam_fov_v=105` (155° 対角からの推定)
3. **ライトの選定** → `light_d = 40` は仮値。決まったら
   `child_light_clamp` と**両方**再ビルドする
4. レンズ前面が本体前面からどれだけ凹んでいるか (フード 8mm の余裕に効く。有利側)
5. PETG 237mm 幅の反り。1 枚目でだめならブリム幅を増やす / `base_line` を 120 に落とす

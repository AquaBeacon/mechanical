正本はspec/parent_exterior_revision_sources.py（prepare_parent_oneplate.py経由）。従来の中実バー2本を、幅16 mm・厚20 mmの左右レールで一体化する。外形244×146×20 mm、中央開口は直線部180×74 mm、内隅R4。バー断面244×36×20 mm、M5穴4個のピッチ220×110 mm、箱上パッド4箇所と座面高さは維持する。追加レールは箱の蓋上面から2 mm離す設計。旧バー2個の代わりに本品1個を使用する。

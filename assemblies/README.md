# assemblyと印刷一式

全体モデル・組立説明と、その構成の印刷用partsを同じフォルダにまとめています。`parts/` 内のSTLを、PRINT.mdの個数だけ印刷します。各構成の試作・未検証事項は説明を確認してください。

子機内装は [child_interior](child_interior/README.md)、親機の現行内装は [parent_hand_service](parent_hand_service/README.md)。全体表示は [child_vertical_assembly](child_vertical_assembly/README.md) と [parent_integrated](parent_integrated/README.md) を参照できます。構成ごとに部品の組合せが異なります。

# 下フランジ固定状態でのバッテリー交換 / ペネトレータ対応

2026-09-27現行版。200 mm縦置き構成。ユーザー確認：WetLink M10を5穴に実装、配線の余裕も必要。

## 構造と交換手順

下円形センタリングリブとその抜け止めねじを廃止。デッキ下尾部も廃止し、デッキ材料の始点を世界Z20に変更。
左右の補強耳と前側ブレースの3点で下フランジへ固定。上リブは保持。
キャップの外面Z-13.8、板厚10。WetLink M10ねじ長20なので内側先端はZ6.2。
ナットはAF16 / 高さ8（Z-3.8..4.2）。全5穴に占有モデルを実配置した。
外側形状は総高26の保守的占有モデル、頭とプラグの境界は仮値。

電池のサービスねじは世界(X,Y,Z)=(22.5,-43,36)へ移設。既存M3×8皿ねじを使用。
床板の下端はZ22.5。ねじを外し、床板を-Zへ2 mm動かすと下端Z20.5となり、
フランジ内面Z19に対して1.5 mmの余裕が残る。その後-Yへ抜いて電池を取り出す。
箱側壁にはスライドするタブの逃げと深さ6の下穴を追加。
側面フォームは長さ102、Z23..125に短縮し、+X側は新ボス周辺に切欠きを追加。
チューブとバッテリーのXT30を外して交換する。内装の下フランジ固定は外さない。
チューブ装着中の交換には対応しない。

## 配線空間 / 検証

非製造の配線余裕モデル：5本それぞれ直径9、内側先端から中心Z14まで。
球状端を含む上端はZ18.5で、デッキ始点まで1.5 mmの余裕。
これは出口付近の余裕空間であり、全コネクタまでの配線形状を確定したものではない。
実配線束径・曲げ半径・サービスループ量は実機に合わせて確認する。

verify_service_access.py / service_checks.json：体積交差をManifoldカーネルで確認。
- 変更した印刷部品と近傍剛体・フォーム：交差なし（ねじの噛み合い・既存ハーネス包絡は対象外）。
- 5本のペネトレータとキャップ穴：交差体積0。
- 直径9の配線余裕と変更印刷部品：交差なし。
- 直径6の工具軸、-Y側からねじ座まで：交差なし（チューブを外した状態）。
- 床板の-Z 2 mm / -Y 45 mmまで、29姿勢で干渉なし。
- PCB穴12箇所はKiCad基板と一致。変更部品STLは閉じた一体立体。
- 組立STEPはchild_interior 75部品、child_vertical_assembly 82部品、いずれも配置検証0 NG。
- 箱・床板STEPはFreeCADでvalid / 1 solid。デッキSTEPは検証済みのファセットソリッド。
- 旧サンプル検査で見逃していたMAIN裏面ピンとの小さな交差も、デッキの局所逃げで解消。

新しい補強部の強度解析は、材料・搭載重量・荷重条件の回答待ち。安全率・締付トルクは未保証。
既存ハーネス包絡モデル同士やPCBとの重なりは残り、本検証は配線全体の無干渉を保証しない。

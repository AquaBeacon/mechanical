# 対辺10 mm 六角ナット回し（片面蓋・指穴付き）

独立した手回し治具1個。構成の正本は `placement.json`、設計正本は [共通治具](../../parts/common/jigs/nut_driver_af10/README.md)。2026-10-25に片面蓋と指穴を追加した現行版。

印刷は [parts/PRINT.md](parts/PRINT.md) から。本体72 × 32 × 10 mm、六角ポケット対辺10.05 mm、指穴径22 mmを両端に配置。ナット軸から20 mmの位置に指先を掛けてぐるぐる回す。

片面の一体蓋は厚さ3 mmでナットの飛び出しを止める。開口側からは取り外せる。**ポケット深さ7 mmと蓋のボルト逃げ穴径7 mmは、ナット厚み・ボルト径未確認の仮設定**。実寸を確認して印刷する。

蓋の平面をベッドへ、六角開口を上に印刷する。PETGまたはPLA、0.4 mmノズル、0.2 mm積層、外周6周以上、充填80〜100%を試作条件とする。CAD上のナット挿入・蓋方向の通過阻止と閉メッシュを確認。実物嵌合・スライス・操作感・実機干渉・許容トルクは未検証。手回しの仮締め用。

2026-10-26：対辺全体の余裕を0.05 mm（片側0.025 mm）に変更。

# gs_camera_m12 — RPi Global Shutter Camera + M12 4mm レンズ (購入品・簡易モデル)

親機カメラ パターン2 の撮像部。箱底ビューポート Ø30 (箱中心 +X53) へ
**レンズ下向き**で `parent_cam_mount` (未設計) に保持される。

| 項目 | 値 |
|---|---|
| 基板 | 38 × 38 × 1.6 (RPi 公称) |
| 取付穴 | 4-Ø2.6、ピッチ **34 仮 (要確認: 公式図面と照合)** |
| レンズ | M12 4mm (Ø17 × 基板下面から 28 — 仮)。**Cマウントは前玉が Ø30 窓でケラれるため不可** |
| 配置 | ビューポート中心 = `parent_plate` (144.5, 101.5)、基板下面 z=33 (箱床基準)、レンズ前面 z≈5 |

`gs_camera_m12.scad` はプレースホルダ (印刷対象外)。原点 = 基板下面中心、
レンズは -Z (下向き) に伸びる。

## 要確認

- [ ] 取付穴ピッチの実測/公式図面 → `parent_plate` の `cam_hole_sq` と `parent_cam_mount`
- [ ] M12 4mm レンズ型番選定 (水中換算 FOV≈48°、520nm BPF の挿入位置含む)
- [ ] レンズ前面〜基板下面の実寸 (ビューポート窓との距離・ケラれ確認)

# 親機：MAIN／SPRESENSEの固定板

2026-10-11。両基板に固定板を設ける。板は大きな矩形肉抜きで軽量化し、4か所のねじ座だけを上げる。ピンごとの逃げ加工はしない。基板高さ42/65.6 mmを維持。

MAIN板はZ33.1から厚2.4、ねじ座上面41.95。Sony板はZ60.5から厚1.6、ねじ座上面65.55。MAINの裏面実装最下端37.245に1.745 mm、Sony最下端62.65に0.55 mmの板上余裕。TX予約上端60.195とSony板下面の公称隙間は0.305 mm。実物公差は未検証。

下のスペーサを分離し、両板の平らな下面を印刷ベッドに向ける。MAIN柱4本は14.3 mm、Sony柱4本は41.7 mm＋キー0.8 mm。Sony床固定はM3×50の4本、頭座62.1。MAIN・PCBのねじと高さは従来どおり。GNSS柱4本と合わせ12本を切離しランナー1枚で印刷。

印刷入口は[parts/PRINT.md](parts/PRINT.md)。11種類各1個、ランナー切離し後22部品。PETG0.2 mm、4周壁、100%インフィル。座面・穴・キーを削らず側面首とバリだけを除く。現行の剛性・締付け・波浪・クリープ・実嵌合は未認定。

OpenSCAD独立レンダリングとSTEP/STL外形・体積、閉メッシュ、2つの組立STEP、12本のランナー部品と切離し後13連結成分（廃棄ランナー含む）も確認。首の0.2/0.4 mm両層に実G-codeの押出しを確認した。

X1 Carbon・0.4 mmノズル・PETG・0.2 mm積層・4周壁・100%インフィルで全11形状を実スライス。合計470.25 g（固定板を追加する前の459.19 gとの差は+11.06 g）、サポート6.93 g。12本ランナーのサポートは0.00 g。結果・3MF・設定は_work/analysis/fixed_plates_20261011/slicing/。

両固定板は平らな下面をベッドに向ける。MAIN板のサポートは0 g、Sony板は局所に約0.04 g、柱セットは0 g。固定板の穴は一定幅の矩形肉抜きで、部品・ピン形状に沿う加工ではない。基板裏面と板の公称余裕はMAIN1.745 mm、Sony0.55 mm。CAD形状・操作と印刷姿勢の検証であり、実物の公差を保証しない。

現行支持の剛性解析・メッシュ収束、実締結・波浪・クリープは未実施。旧解析は現行の合格根拠に使用しない。取合い試作の状態を維持する。前の独立支持具と検証は_work/analysis/fixed_plates_20261011/before/へ保存。

## 役割 (2026-09-05 人間指摘への対応)

> **2026-09-05 (2 回目)**: 「バランスが悪そう、浮子を箱と同じ高さに」「箱は防水なので浸かってよい、転倒しない
> ことが優先」→ 浮子軸を z −83 → −40 → **0** (デッキ上面 = 箱底) へ。`spec/parent_hydrostatics.py` で箱・デッキ・
> ヨークの排水量込みの喫水線と GM を掃引し、**縦揺れ GM が最大 (201 mm) になる高さ**を採った。喫水線 z −2.7
> (箱底がほぼ水面)、ペネトレータ (z 65) は水面上 68。`.scad` は `waterline_z` を転記して「ペネトレータ ≥ 30 上」を assert。

浮子は**完全な円筒ではなく、胴を挟んで固定できない**。代わりに**中心の空洞に紐を通し、
両端で受ける**。本部品はその「両端の受け」で、旧 `parent_float_cradle` (アーチで抱える方式) を置き換える。

- `parent_deck` の側壁 HP40 座 (Y ±70, z −25) に **アダプタ板 (56 角、t18、M5 ×4 ざぐり付き)** でボルト留め。
- アダプタ板をそのまま浮子の端まで延ばした**フィン** (縦板 t18、高さ −28..+68 = 96、箱の胴体の脇に沿う) の端に**柱** (t32) を立てる。
  フィンと柱の上端は同じ高さ (グローバル +43、蓋の張出し z 80 より下)。
  **2026-09-05 変更**: 当初の水平の腕 (t10) は FEA でたわみ 1.9〜3.9 mm (許容 1.0) だったため、
  ねじれ・曲げとも一桁硬い縦板に変えた。フィンにはデッキ側壁の紐穴 Ø8 と同軸の通し穴を開け、紐穴を塞がない。
- 柱の内面に **45° の円錐座** (口径 70 → 底径 30、深さ 20)。浮子の先細り端 (仮 Ø40 端面) が
  深さ 15 で座のリムに当たり**自動調心**する。浮力・横力はこの座で受ける (胴には触れない)。
- 柱の軸上に**紐穴 Ø10**、その下に**紐留め穴 Ø8 ×2**。紐は「前ヨーク → 浮子の空洞 → 後ヨーク」と
  通し、外面で結んで張る。張ると浮子の端面リムが円錐座 (深さ 15 の位置) に引き寄せられる (中央にあるとき片側余裕 2)。

## 座標系

ローカル原点 = デッキ側壁 HP40 座の中心 (座面上)。X = 外向き (側壁法線)、Y = 浮子の端の方向
(hand で反転)、Z = 上。デッキ上面 = ローカル z +25。
アセンブリ: 右舷後 `a` を `translate([108, 70, −25])`、右舷前 `b` を `translate([108, −70, −25])`、
左舷は `b` / `a` を `rotate 180°` して `translate([−108, ±70, −25])`。

## 干渉チェック (`.scad` 冒頭の assert)

- 浮子の胴がフィン外面 (X=18) から 2 以上離れる / **ペネトレータ軸・蓋の合わせ目が喫水線より 30 以上上** / フィン上端が蓋の張出し (z 80) より下 / 浮子上端が蓋より下
- 円錐座の底径が空洞より大きく端面径より小さい (端面のリムで座る) / 端面が座に入る深さ (15) が座の深さ内で、
  片側余裕 (2) より大きい
- ざぐりがアダプタ板に収まる / ざぐり下の板厚 ≥ 5 / フィンの紐通し穴がざぐり・縁・柱から離れる
- 紐留め穴が円錐座・柱の縁から離れる / 浮子の先細り (半角) が円錐座 45° より緩い (リムだけで当たる) / 250³ 枠

実際に止めたもの (2026-09-05): ざぐり Ø10 が座 50 角からはみ出す → アダプタ板を 56 角・ざぐり Ø9.5 に。
`mirror([0,0,0])` (零ベクトル) で非マニフォールド → `if` で分岐。assert で捕まらなかったもの: 浮子とアダプタ板厚の
干渉 (側壁面 X=0 だけ見ていた) → アセンブリの接触検査で貫通 7.6 として発覚、浮子軸を +14 外へ。

## 印刷 (X1-Carbon)

- **フィンの内面 (X=0 面) をベッドに、+X を上** (横倒し)。フィンは 18 mm 厚の板 (127 × 96) が寝た状態、柱がベッドから立つ壁 (高さ 113)。
  円錐座は 45° で自己支持、紐穴・留め穴は水平穴、ざぐりは垂直穴。**サポート不要**: `topopt overhang` (X 上に回した STL)
  で要サポート面積 **0.8 %** (水平穴の天井のみ)。`topopt print` の「overhang FAIL」はベッド接触面を含む値。
- 主引張: フィンのねじれ・曲げ (Y 方向)・紐の張力 (Y) → 層面内 (層は YZ 面)。
- 材料 PETG (屋外は ASA)。壁 4 本 / インフィル 25 %。a ×2 + b ×2 (スライサでミラーしても可)。

## 部品外の考慮

- **紐の掛け方**: 一方の柱の外面から紐穴 → 円錐座 → 浮子の空洞 → 反対の円錐座 → 紐穴 → 外面で
  留め穴 ×2 に絡めて結ぶ。**張力で浮子を座に引き寄せる**のが固定の本体なので、伸びない紐 (ポリエステル) を使う。
- 浮子の先細り形状が仮値と違えば `seat_od / seat_depth / end_d` を実測に合わせる。端が平ら (先細り無し) なら
  円錐座を浅い皿 (座ぐり) に変える。
- 浮子は端だけで支持されるので、**胴の中央は自由**。波で胴が上下に叩かれる荷重は座のリムに集中する。
  硬い浮子 (EVA) なら問題ないが、柔らかい空気入りなら座に当て板 (ゴム) を入れる。
- 喫水線は `spec/parent_hydrostatics.py` (質量 3.14 kg、箱・デッキ・ヨークの排水量込み) で **z −2.7** = 箱底がほぼ水面。
  浮子は 50 % 強が水中、フィン・柱の下半分とデッキ・キールは水中 (PETG なので問題なし)。箱は防水 (IP65) で人間了承済み。
- 復原力 (同スクリプト): 横揺れ GM 639 mm / 縦揺れ GM 201 mm。浮子軸を −40 に下げると縦揺れ 107、+50 (箱中央) に上げると 169。
- 浮子軸 ±178、全幅 456。浮子 (−50..+50) が箱の下半分と同じ高さにあり、見た目の重心も低い。

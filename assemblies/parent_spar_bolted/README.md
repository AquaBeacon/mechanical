# 親機外装：ねじ固定・X1 Carbon対応版

**旧案**：その後のユーザー指定により、浮きは左右2個を紐で接続する構成へ変更。[現行の親機外装](../parent_rope_float/README.md)。このフォルダの円柱浮体・タイロッドは現行版には使用しない。

2026-09-10。水色の円柱は**浮力を作る浮体**。前案の配置用円柱を、上下2個の中空浮体・ねじ蓋・端板・分割タイロッドで固定する構造へ変更した。親機の箱は承認済みのタカチBCAS212310Gを使う。

完成組立形状は `parent_spar_bolted.step`、表示用は `parent_spar_bolted_view.scad`、配置の正は `placement.json`。部品形状の正は `scad/lib/parent_spar_bolted.scad`。旧 `parent_spar_concept` と旧双胴 `parent_assembly` は履歴として残す。

## 今回の変更

- 水平円盤：直径225×厚さ5。垂直フィン：高さ125×幅65×厚さ4を4枚、90度間隔。幅には根元の差込み14を含む。
- フィンは上下ハブへねじ止め。ハブも支柱へ横ボルトで固定する。フィンのねじと支柱固定ねじは高さを分け、互いに交差させない。
- 支柱は印刷可能な180 mmと107 mmの2本。2つ割り継手は横ボルト2本＋合わせボルト4本で固定し、回転と抜けを拘束する。
- 浮体は胴直径200・高さ180を2個。最大径はフランジの225。蓋は別部品で厚さ6、各8本のM4で締結。内外2本の環状パッキン溝を設ける。
- 浮体全体は上下端板と4列のM6タイロッドで締結。各列は長さ205の金属ねじ棒2本を長ナットで接続し、輸送時に短く分けられる。
- 錘を収納するケースもねじ蓋式。内部の金属リングは中央M8で固定し、単にケース内に置くだけにはしない。
- カメラは既存のOsmo用マウントを短い支持部でデッキ北側へ固定する。ケース上端は箱底の**18.5 mm下**、ケース底面は93.5 mm下（現在の仮包絡）。下部フィンまでカメラを下げない。
- GPSは既存計画のANN-MB1のM4×2用支持台を設計。デッキ側面HP40へM5×4で固定し、箱の蓋へ新しい取付穴を開けない。
- IMUは既存の箱内SPRESENSEロガー配置を引き継ぎ、外装に仮の緑色ブロックを追加する表現を廃止。

## スライス条件

設置済みBambu Studio 2.8.2.61、X1 Carbon 0.4 mm、0.20 mm Standardを基に、Generic PETG、Textured PEI Plate、壁6周、上下各6層、Gyroid 40%、外側ブリム5 mm、自動通常サポートでオフラインスライスする。機体やアカウントへの送信は行わない。

- 支柱は横置き。長手方向の負荷を層面内で受ける向きとする。
- 継手は割り面を上へ向けた2部品とし、閉じた角穴内部のサポート除去を避ける。
- 浮体胴は底を下、開口を上。外周フランジ下面は45度。内部をサポートで埋めない形状。
- 浮体蓋はシール溝を上。造形後、溝の傷・糸引き・バリを除去し、シール面の状態を確認する。
- フィンと円盤は広い面を下。横穴や支持部は、同梱の印刷向きと自動サポートを前提とする。
- 上端板の下面ねじ頭逃げ・カウンターボアなどに発生するサポートは、浮体を組む前に除去する。

スライス成功は造形領域・スライサー処理の確認であり、実プリントの反り、嵌合、水密性、耐久強度を保証するものではない。量産前に継手と穴の小試験を行う。

## 締結と組立順

詳細な数量は `fasteners.json` と `fastener_bom.md`。ねじ穴はクリアランス穴、ねじ山は金属ナットまたは既存デッキのインサートが受ける。印刷ねじは使わない。

1. **箱とデッキ**：既存外部取付穴M4×4とデッキ側M4インサートを使用。既存の箱・内装はそのまま。箱側のアクセスは従来モデルの条件を引き継ぐ。
2. **浮体上端板とデッキ**：中央HP40へM5×20を4本、各2枚の1 mm座金で固定。ボルトが入る方向は下から上。浮体を付ける前に行う。
3. **カメラ支持部**：北側下面HP40へM5×16を4本。既存マウントをM5×25×4＋ナットで支持部へ固定。カメラケースの爪は純正互換のM5ねじとマウント内ナットで締結する。
4. **GPS支持部**：右側後方HP40へM5×20×4。アンテナの耳をM4×25×2＋ナットで棚へ固定。GPSを外さなくても箱の蓋の上方空間を確保するが、全開ストロークは実機で確認。
5. **浮体各段**：パッキンを入れ、M4×20×8＋座金・ナットで蓋を対角順に締める。フランジ下面の工具逃げからナットを保持する。上端板には蓋ねじ頭・座金の逃げ穴を設けた。
6. **浮体の積層**：4列のM6ねじ棒で端板・2段の浮体を挟む。205 mmのねじ棒を1列に2本使用。長ナット18 mmに下側9 mm・上側8 mmをねじ込み、棒先端間1 mmを残す設定。印を付けてかかり長を管理する。蓋・胴の直径13の逃げ穴に長ナットを通す。上下端板を座金＋M6ナットで締結する。工具で保持できる位置で先に長ナットを接続してから浮体を通す。
7. **支柱**：下端板のソケットへ上支柱を差し込み、M6×60＋ナットで固定。上下支柱の突合せ部を2つ割り継手で挟み、M6×70×2で各支柱を貫通、M5×65×4で継手半体を結合する。
8. **フィン**：ハブへフィン4枚を差し込み、M5×40を各2本（計8本）。ハブから支柱への固定はM6×100×2。ハブ穴の位置がずれたまま締め込まない。
9. **円盤と錘ケース**：下ハブ・円盤・ケース天板をM5×55×4で共締め。ナットはケース内側にあるため、錘を入れる前に締める。金属リング（仮：外径50・内径9、計高さ30）を中央M8×50で固定。ケース蓋はM5×20×4。ケースは水抜き穴付きで、ここに浮力は期待しない。

搬送時は支柱継手で上部と下部を分離できる。さらに浮体を2段に分け、ねじ棒を205 mmに分解し、フィン4枚を重ねられる。シール蓋を開けずに浮体段を分けられる構成。深い分解ほど工具作業が増えるため、現場ではフィンユニットを組んだまま運ぶ方法も選べる。

## シール、浮力、搭載機器の確認事項

浮体の内外2本のシール溝は幅2.4・深さ1.5、中心半径32 / 98。断面2 mmのリングなら、溝が完全に閉じたときの圧縮量は0.5 mm。各径2本、合計4本が必要。既製リングの寸法目安は内径62×線径2、内径194×線径2。材料と適合性は購入時に確認する。

**浮体は実物で浸水試験が必要。** FDM外壁やシール面は、閉じたメッシュでも漏水しうる。空の浮体を個別に試験し、必要な表面処理とシールの調整を済ませてから機器を載せる。

直径200・中央穴60・総高さ372の単純な環状包絡は約10.63 L。これは設計上の比較用体積で、積載許容値ではない。外周形状、樹脂・金具の重量、乾舷、吸水、波、傾斜を含めた実喫水と復原性は未検証。旧双胴の静水力学計算値は流用しない。錘の仮リングは鋼密度7.85 g/cm³で約0.447 kg。必要な錘質量は実機の重心・傾斜試験で決める。

カメラは質問への返答待ちのため、既存のOsmo Action 6＋純正防水ケース用マウントを使用する前提。ケース包絡95×45.9×75とケース背面形状は既存設計にも実測待ちが残る。ケース上端を箱底に近づけたが、**レンズが実喫水より下かどうかは未確定**。水中撮影が必須なら、実喫水を測定して支持高さを調整する。

GPSは既存配線計画のANN-MB1を前提に、[u-blox機械図](https://content.u-blox.com/sites/default/files/ANN-MB1_DataSheet_UBX-21005551.pdf)の82×60×22.5、M4×2（ピッチ68）を使用。表示モデルは簡易包絡。箱内IMUは既存SPRESENSE構成を保持しており、その取付穴・積み上げ高さの実測待ちは今回解消していない。

TD04Aの取付、テザー張力止め、GPSケーブルの箱への引込みはこの外装改訂に未追加。既存南壁ペネトレータを保持し、カメラを北側へ置いて経路を分ける。余ったケーブルをフィン周囲へ垂らさない。実荷重FEA・波浪試験は未実施。

## 再生成

```powershell
python spec/build_parent_spar_bolted.py
python assemblies/parent_spar_bolted/prepare_reused_prints.py
python spec/assemble_parent_spar_bolted.py
python spec/slice_parent_spar_bolted.py
```

幾何検査は `print_checks.json`、外装＋金具の接触検査は `hardware_contacts.json/.txt`、スライス結果は印刷フォルダの `slice_validation/*/result.json` に保存。接触検査は表面サンプリングであり、厳密な全点干渉検査ではない。カメラ・GPSの実物適合性や強度まで完了したとは扱わない。

最終の外装・金具・GPS/錘参照形状（`exterior,hardware,reference`）はFLOATING 0、貫通0。既存内装と箱、未測定のカメラケース・箱蓋包絡はこの検査対象外。後者は表示専用の `envelope` グループであり、実物の取付検証の代用にはしない。

印刷16種類・23点は全て閉じた単一メッシュで、Bambu Studioのスライス終了コード0・警告メッセージなし。数量分の見積合計は約5.2 kg・約151時間（サポート・ブリムを含む。完成品の重量ではない）。詳しくは印刷フォルダの `PRINT.md`。

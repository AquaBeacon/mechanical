## 5. パターン 2 — 親機カメラ = Pi Zero 2W + GS カメラ内蔵

**カメラは下向き、箱底の Ø30 ビューポート越しに水中を見る。**

### ビューポートの幾何 (ここがパターン 2 の律速)

箱底中央にはマストクランプのフランジ 70 角 + M5×4 (±28) が付き、箱の下は浮子
開口 Ø140。ビューポート (半径 r) の中心オフセット d は
`35 + r + 2 ≤ d ≤ 70 − r` を満たす必要があり、**Ø40 では解なし・Ø30 で
d = 52..55 のみ成立**。→ **Ø30 を箱中心から +X (東) 53mm** に配置。
Ø30 窓は C マウントレンズ (前玉 Ø28+) ではケラれるため **M12 4mm レンズ前提**。

| 品目 | 位置 | 天面 z |
|---|---|---|
| P-MAIN / P-PWR / SPRESENSE / LiPo / LCD | パターン 1 と同一 | 同左 |
| GS カメラ (レンズ下向き, `parent_cam_mount` 脚 15 + t3 上) | ゾーン (124.5,80.5)–(166.5,122.5)、VP 中心 (**145.5**,101.5) (`VP_OFF=54`) | ≈57 (基板下面 33、レンズ前面 5) |
| Pi Zero 2W | (127,135)–(157,200) プレート直付け | 34 |
| TX | (117,127)–(167,201) **z+31 高架** (ボス 6 + M3 MF スペーサ 25、Pi Zero の上) | 61.4 |

- TX 高架: `hex_spacer` m3_mf25 ×4 をプレートの TX ボス (下穴 Ø2.6) にセルフタップで
  立てる。Pi Zero 天面 34 と TX 裏リード下面 40.3 の隙間 6.3mm。Pi Zero の保守は
  TX を外して行う (低頻度)。蓋までの余裕 25.7
- CSI ケーブル: Pi Zero (y135) → カメラ (y≤122.5) 約 60mm。標準 200mm で余裕
- 給電: `5V_CAMERA` (P-PWR の独立 5V) → Pi Zero。仕様書の系統どおり

### パターン 2 の注意 (要判断・要評価)

1. **仕様書との差分**: 上流仕様 (詳細設計書 §1.6/§3.1) は測角カメラを
   「マスト下端の別体防水ポッド (水中)」としている。本パターンは
   「水上の箱から水面越しに見る」構成で、**水面の波・屈折の影響を受ける**。
   光学性能が要件 (±10° 円錐の子機マーカー検出) を満たすかは実験検証が必要。
2. マストがビューポート視野の中心から約 6° に写り込む (M12 4mm 水中 FOV≈48°)。
   子機マーカーがマスト裏に隠れる時間帯が発生し得る。
3. 箱底 Ø30 穴あけ + アクリル窓 t4 + O リング (またはレンズポート部品) の
   防水設計が必要 (`parent_cam_port` として未設計)。
4. ビューポートと浮子開口の位置関係はマスト・浮子と**同軸前提**。
   防水ボックスマウント (未設計) 側で箱の向き (+X = 東) を拘束すること。

| 壁 | 貫通 | 中身 | 落とし先 |

  (c) P-MAIN (天面 箱 z=49.7) の上を通るが、ナット下端 55.2 との隙間 5.5 mm
  (d) 南西のカバービス柱 (箱 X=9, Ø10.5, 全高) から 61 mm
  (e) 2 本のピッチ 35 で 16 mm トルクレンチ (3.5 N·m) が振れる
  → (b)-(e) は `bcas212310g.scad` の assert、(a)-(c) は

  プレートの結束バンドスロット (プレート x≈115 / 176) で押さえること

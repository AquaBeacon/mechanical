# 子機左前・カメラ通常向き用メス（C面内90°）

[専用メス3MF](child_horizontal_twist_mount_camera_receiver/child_horizontal_twist_mount_camera_receiver.3mf)は1個入り。X1C・0.4 mm・Generic PETG、0.1 mm、6壁、15% Gyroid、5 mmブリム。自動支持を有効・ベッドからのみとし、実支持経路は初層0.2 mmのみ。約1時間16分・20.5 g。設定・STL/3MFハッシュと実経路は[検査記録](child_horizontal_twist_mount_camera_receiver/validation.json)。一体カメラ1個と既存ノブ追加1個も必要。全印刷部品は[現行PRINT.md](../../parts/PRINT.md)。実印刷・嵌合・強度は未検証。

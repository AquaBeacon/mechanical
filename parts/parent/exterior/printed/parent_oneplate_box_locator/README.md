# 親機箱の側面・端面ロケータ

BCAS212310G箱を三点支持フレーム上で位置決めし、日常の着脱後もストップ位置を保つ部品群。単一SCADの `variants.txt` で次の5形状を選ぶ。

| バリアント | 数 | 役割 |
|---|---:|---|
| `side_left` | 1 | 左側面の2点基準 |
| `side_right` | 1 | 反対側の常設ストップ |
| `end_fixed` | 1 | Y=115 mm側の固定端 |
| `end_push` | 1 | 対向端から押す調整腕 |
| `pressure_pad` | 3 | 右側2点と端側1点でねじ力を分散 |

側面・端面ロケータはフレームへM4ねじとナットで固定する。押しねじは圧力パッドを介して軽く当て、箱を変形させない。取付穴、ねじ長さ、ナット位置は `assemblies/parent_oneplate/placement.json` とassembly READMEを参照する。部品はフレームへ常設する想定で、箱の着脱ごとに外さない。

圧力パッドはM4ソケットねじ頭（径7 mm・高さ4 mm）へ被せるカップ。右側ねじ軸はZ=12 mm、端側はZ=9 mm。箱を外すとパッドが脱落し得るため、取り外し時に回収して紛失を防ぐ。接触面を箱へ向け、ねじ頭がカップ内へ十分入ることを確認する。

設計元は `spec/prepare_parent_oneplate.py` と `spec/parent_oneplate_frame_sources.py`。側面・端面接触補正はSCAD変数で調整できるが、初回の実箱計測に基づいて設定する。生成SCADを直接編集しない。

箱の実外形・接触隙間・ねじ先端の箱底からの突出を確認すること。反復位置決め試験や締付力の認定はない。

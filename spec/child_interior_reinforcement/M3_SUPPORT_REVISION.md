# M3統一とサポート削減（2026-09-27）

現行対象は200 mm耐圧容器の子機縦置き内装。印刷の入口は `assemblies/child_interior/parts/PRINT.md`。このpartsフォルダには印刷姿勢を反映したSTL・鏡像部品・モディファイアを実ファイルとして同梱する。

## 変更

- デッキ左右固定座のY=-10より下の張り出しをなくし、板と固定座の印刷底面をそろえた。デッキ全体を浮かせるサポートを避ける。
- 横向きのフランジねじ穴・頭の逃げ・スペーサ逃げに45°屋根を追加。ブレースの横向きM3穴にも屋根を追加。
- 前側ブレースの梁底面を固定耳とそろえ、梁下のサポートを避ける。
- 電池箱の約40 mmの横桁を、左右の45°付き端受けに置き換える。床板フック先端の下面も45°へ変更。
- RX基板は外周を押さえるM3クランプ4組へ変更。元のØ2.2穴はそのまま残し、使用しない。PCBのドリル径や購入基板を変更していない。
- 上側リブの抜け止めはM3×6へ変更し、デッキ先端に0.5 mmの肉を追加。リブ側にねじ頭の逃げを設けた。
- なべ頭の空間はØ6.6 mmで検査。加工する逃げ穴は多角形の誤差を見込みØ6.8 mm。電池サービスねじの皿頭座は既存Ø5.8、直径6 mm工具経路を維持。

「M3」は呼び径。通し穴はØ3.4、樹脂セルフタップ下穴はØ2.5〜2.8であり、すべての穴を直径3 mmにする意味ではない。既存ねじ・スペーサ以外の金属補強を追加しない。

## 印刷

| 部品 | 設計座標からのX回転 | ベッド面 |
|---|---:|---|
| デッキt200 | +90° | Y=-10 |
| 前側ブレース | 0° | Z=-3 |
| 電池箱 | -90° | Y=-10 |
| 電池床板 | +90° | Y=-43 |
| RXベース | -90° | Y=-10 |
| RX押さえ板 | +90° | Y=-20.6 |

印刷一式は上記回転済みなので、スライサで再度90°回転しない。平面を下に置く。壁8周、層0.2 mm、通常インフィル15%、固定根元は同梱モディファイアで100%、ブレースとRXクランプは100%を出発点とする。

長い浮いた面をなくし、横穴の屋根と張り出しを45°へ変更した。小さい角丸・フックの切欠きなどには短いブリッジが残る。スライサ実行によるサポート量の測定はしていないため、全条件でサポートゼロとは断定しない。最初はサポートOFFでプレビューし、必要な箇所だけペイント指定する。ねじ穴・座面・PCBの当たり面にサポートを詰め込まない。

## 取付と検証

RXはベースを先にデッキへM3×8で固定し、基板を受けに載せ、押さえ板をM3×8で留める。PWR基板を載せる前にベース側ねじを締める。基板が反るほど締め込まない。外縁の部品・銅箔は実物も確認する。

上側RX取付座はフランジの貫通口へ入るため、デッキ側の追加幅とクランプの尾部を容器内へ絞った。最小公称隙間はデッキ0.59 mm、上側クランプ0.70 mm。既存の上側リブ0.50 mmとLED配線0.54 mmも狭隙間なので、反り・バリを除いて仮組みする。デッキ先端Z202.5は上キャップ内面Z203.8より内側に収まる。

根元は60 mm・固定座20 mmを維持。今回形状の強度解析は更新しておらず、以前の未収束解析を今回の安全率として流用しない。

## 最終検査

- 変更した印刷STLは水密、一体形状。対応STEPは有効な単一ソリッドで、STLとの体積差0.005%未満。
- MAIN / PWRの取付穴8点は実KiCadと一致。RXクランプの4か所は実基板外形・組立ねじ配置と一致し、既存穴を使わないことを検査。
- 印刷部品と周辺部品・工具・床板移動の107交差検査でエラー0。上側リブと上下フランジも対象。
- なべ頭Ø6.6予約空間の78交差検査でエラー0。内装の固定ねじにM2 / M2.5が残っていない。
- 主要6部品の指定姿勢で平坦なベッド接触面を確認。スライサによる実サポート量の測定は未実施。
- 組立STEPの内装79項目、子機全体86項目で配置検査0 NG。容器包絡にFAILなし。狭隙間WARNは上記のとおり。

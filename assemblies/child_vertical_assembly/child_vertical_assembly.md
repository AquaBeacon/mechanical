## 組立・分解の順序

```
組立: 下部ガード → 後半シェルへ M5×4 → 容器を上から落とし込む
      → 前半シェルを前から合わせ、位置決めピン ×2 で合わせて M5 蝶ボルト ×4
      → カメラを落とし込んで蓋 (M4 蝶ボルト ×2 /台)
      → ライトを鞍座へ、クランプを M4 ×4
      → TD04A ソケットをパイロン屋根へ M5×4、振動子を差して結束バンド ×2
```

| やりたいこと | 外すもの | 所要 |
|---|---|---|
| **内部 (基板・電池) にアクセス** | **ドームの M3 + 上フランジ (ロッキングコード)** | シェルもガードも外さない。内装の幅広部 93mm は貫通口 Ø88.5 を通らないので**フランジを抜かないと引き出せない** |
| カメラの着脱 | 押え蓋の M4 蝶ボルト ×2 | 約 5 秒 |
| 容器を機体から降ろす | 前半シェルの M5 蝶ボルト ×4 → 真上へ | 約 1 分 |
| ペネトレータの締付け | 下部ガードの M5 ×4 | 工具アクセス確保のため |

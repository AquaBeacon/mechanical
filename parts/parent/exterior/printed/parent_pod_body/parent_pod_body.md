## 役割

Pi Zero 2W + GS カメラ + 4mm レンズ + 520nm BPF を同軸実装する円筒容器 (深度 ~0.5m 用)。

| 面 | 内容 |
|---|---|
| 前面 | アクリルフラットポート (Ø76 × t4) + 面シール O リング + `parent_pod_bezel` を M3×6 |
| 後面 | WetLink M10 ペネトレータ ×1 (電源 2 線) |
| 側面 | マストヘッドへの M4 セルフタップボス ×4 (2 段: z = 30, 75) |

## ⚠ 3Dプリント防水の注意

**PETG/ASA・壁 4mm・内面エポキシコート + 気密試験が必須**
(`../docs/AquaBeacon_詳細設計書.md` 1.6 節)。プリント品は層間から浸水する。

`.scad` の assert が O リング溝と内腔の干渉を検出 → 修正済み
(`docs/AquaBeacon_機体設計.md` 参照)。

## 印刷向き

後面 (閉端) を下に立てて印刷。フランジ下の 45° コーンで無サポート。

## 部品外の考慮

- **O リングの型番が未選定**。溝中心 Ø68・線径 2.62 想定 → AS568-235 近辺。
  実際に入手できる型番で溝寸法を再計算すること。
- 後面ペネトレータの **M10 ねじをプリントで作らない**。タップ立てか
  インサート。壁厚 8mm (rear_t) に対し 3.5 N·m の締付は要検証。
- ケーブルはポッド後面 → マストを伝ってボックスへ。**ポッドを回転させると
  ケーブルが捻れる**。側面ボス 4 本で向きが決まるので、組付け時に
  ケーブルの逃げ方向を確認すること。
- 内部の Pi Zero + カメラは**発熱する**。密閉 + 水冷 (水上なので空冷) の
  熱設計は未検討。長時間運用で確認が要る。
- 窓の**曇り**対策 (乾燥剤の同梱スペース) が未検討。内径 60 に対し
  カメラスタックの実寸が分かってから余白を確認すること。
- 気密試験の手順と治具が未整備。

## 要確認

1. O リング型番の選定 → 溝寸法の再計算
2. M10 ペネトレータの締結方法 (タップ / インサート) と耐トルク
3. カメラスタックの実寸 → 内径 60 × 内長 90 で足りるか
4. 気密試験 (加圧 or 真空) の手順

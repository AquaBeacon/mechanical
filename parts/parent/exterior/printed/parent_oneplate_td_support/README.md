# 親機・TD04Aブラケット支持部

親機の再現位置決めフレームに取り付けるTD04A金属ブラケット用の支持部。フレーム underside の12×12×2 mmキー溝へ11.6 mm幅のキーを差し込み、M5×30皿ねじ2本で固定する。既存M4クランプ穴はピッチ36 mm。配置は `assemblies/parent_oneplate/placement.json` を参照する。

ブラケットを左側面と上端へ当てて位置を決める設計。ブラケット幅24 mm、板厚2 mm、上端基準Z=-27 mmは仮寸法で、視覚参照モデルから置いた。右側には公称0.4 mmの調整すきまがあり、実測後にシムで調整する。実ブラケットと一致確認済みとは扱わない。

設計元は `spec/prepare_parent_oneplate.py` と `spec/parent_oneplate_sensor_sources.py`。SCADを直接編集せず生成元を更新する。印刷方向は `manufacturing.json` を参照する。

実ブラケットとの寸法・着座、M4クランプねじの工具アクセス、ケーブル取り回しは組立時に確認する。強度やセンサ精度の検証結果はまだ示していない。

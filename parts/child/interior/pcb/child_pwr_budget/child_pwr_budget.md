# child_pwr_budget — CHILD_PWR (縮小版) の外形予算

**基板ではない。機体側から KiCad 側へ返す外形制約そのものを立体にしたもの。**
この中に収まる基板を設計すれば、機体側を変えずに 200mm チューブへ収まる。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 基板 (制約モデル) |
| 設計ソース | `child_pwr_budget.scad` |
| 外形 | 56 × 70 × 33.3 mm |
| 印刷 | **しない** (確認用) |

## 背景

現行 `CHILD_PWR` は **100.35 × 70**。200mm チューブの「幅広部」(Ø101.6 の範囲) は
軸方向に **160mm** しかなく、`CHILD_MAIN` (112mm) と並べて入らない。
2026-07-31 のユーザー判断で **A案 = CHILD_PWR を縮小する**を採用した。
検討の全体は [`docs/子機内装_収まり検討.md`](../../../../../docs/子機内装_収まり検討.md)。

## KiCad 側へ返す制約

| 項目 | 予算 | 現行 CHILD_PWR |
|---|---|---|
| 外形 | **56 × 70 mm** (面積 3,920 mm²) | 100.35 × 70 (7,025 mm²) |
| 取付穴 | 四隅 inset 2.4 → **ピッチ 51.2 × 65.2**、Ø3.2 | inset 2.4 / 92 × 62 |
| 部品高さ (基板下面から) | 端から **0〜46mm の範囲は 25.1mm まで** | 25.12 (2MD1 トグル) |
| 同上 | 端から **46〜56mm の範囲は 21.0mm まで** | — |
| 裏面リード突出 | **8.2mm 以下** | 8.15 |

### なぜ高さが 2 段になるのか

基板は `z = 134..190` に置く。チューブの断面はこう変わる:

```
   z = 134..180   Ø101.6 (幅広部)      → 幅70 の基板は高さ 29.3mm まで許される
   z = 180..190   Ø88.5  (上フランジ)  → 幅70 の基板は高さ 22.2mm まで
```

先端 10mm だけが上フランジの貫通口へ頭を出す。したがって
**背の高い部品 (トグルスイッチ・ヒューズホルダ・電解コン) は基板の
「下端から 46mm」の範囲に置くこと。** 先端 10mm は低背部品だけにする。

余裕を見て予算は 21.0mm にしてある (幾何学上の限界は 22.25mm)。

### 高さの段が面倒な場合

先端 10mm を捨てて **46 × 70 (3,220 mm²)** にすれば、高さは全域 25.1mm でよい。
面積が 18% 減るのとのトレードオフ。

## 座標系

他の基板モデルと同じ並びにしてある。

- **X = 0..56** … 軸方向 (チューブ Z へ写る)。**X=0 が下 = `CHILD_MAIN` 側**
- **Y = -70..0** … 幅方向 (機体 X へ写る)
- **Z** … 高さ。基板下面が Z=0、部品が +Z、裏面リードが −Z

`assemblies/child_vertical_assembly/placement.json` では
`translate([35, 4, 134]) rotate([0,-90,-90])` で置いている
(= `child_main` と同じ変換規則)。

## 実装位置

`child_vtray_deck` のデッキ上面、M3 ボス ×4 (高さ 10mm)。
`CHILD_MAIN` の真上 (Z 方向に続けて) に載る。

## 部品外の考慮

- **XT30 コネクタ 3 個 (J_BAT / J_LED / J_RXP) の抜き差し空間**が面積予算に
  含まれていない。基板の縁に寄せ、ケーブルはデッキの配線スリット
  (X = ±36, Z = 159) へ落とすこと。
- **電源スイッチ (2MD1 トグル) は密閉容器の中**なので、投入・遮断は容器を
  開けたときにしか操作できない。運用上それでよいかを確認すること
  (外部に出すなら追加のペネトレータが要る)。
- **発熱**: LDO とライト定電流回路がここに集まる。密閉容器なので放熱は
  アクリル壁のみ。基板をチューブ壁に近い側 (X の外側) へ寄せると多少有利。
- 基板を縮めた結果、`CHILD_MAIN` との配線 (`J_MAIN` / `J_CTL` / `J_RXA`) が
  近くなるのは有利。

## 要確認

1. **3,920 mm² に現行の回路が入るか** — 入らなければ 300mm チューブ (t300) へ
   戻すか、機能を分ける判断が要る
2. 取付穴ピッチ 51.2 × 65.2 で KiCad 側を作ること

3. 縮小後の実基板ができたら `child_pwr/` を差し替え、このフォルダは役目を終える

# child_top_crown — 子機 トップクラウン (吊り耳 ×2 + ドーム根元カラー)

[docs/子機外装_改善要件.md](../../../../../docs/子機外装_改善要件.md) §3.5 (G2/G4, C3)。
`child_lug` ×2 (2026-09-04 廃止、[child_lug.md](../child_lug/child_lug.md) 参照) を
1 部品に置き換える。ドーム押えリングを囲むカラーと、左右の吊り耳を一体化。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 個数 | 1 (左右の耳を .scad 内で mirror して 1 部品) |
| 外形 | 150 × 128 × 38 mm |
| 体積 | 62.7 cm³ → PETG 約 79.6 g |
| STEP | 1 ソリッド / 26 面 (open edge 2、丸め誤差) |

## 役割

- コアフレームの吊り耳ボス (頂面 z=218、M5 熱圧入インサート ×4 @
  x=±66, y=−4/−16) に M5 ×4 で載る
- ドーム押えリング (`wte4_dome_cap`, OD 仮 120.3) を囲む C 形カラー
  (内径 Ø126、z 218..232)。**ドーム赤道より下**なので上半球を覆わない
  (C3、将来ドーム内から LED で照らす)
- 左右の吊り耳 (シャックル Ø16、Y 軸) を一体化。輸送キャップ固定用の
  M5 熱圧入インサートを耳の外側面に持つ

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `lug_x` / `lug_bolt_y` | 66 / [-4,-16] | 取付ボルト位置 (`child_core_frame` と二重定義) |
| `r_in` / `r_out` | 63 / 75 | カラー内径 Ø126 / 外径 Ø150 |
| `ring_z0` / `ring_z1` | 218 / 232 | カラー高さ (14mm) |
| `front_raise` | 0.5 | ゲート側 (y>0) の底上げ量 |
| `aft_az0/1` | 225 / 315 | アフトカットアウト (xdcr_socket 逃げ、-Y±45°) |
| `ear_x0/1` | 58 / 75 | 耳の x 範囲 (機体 x=lug_x を挟む) |
| `ear_y0/1` | -22 / 0 | 耳の y 範囲 (フレームボスと同じ) |
| `ear_z1` | 256 | 耳上端 (ドーム頂点 261.25 手前) |
| `hole_d` / `hole_z` | 16 / 240 | シャックル穴 (Ø10 ロープ / M10 シャックル) |
| `cap_bolt_x/z` | 75 / 227 | 輸送キャップ用 M5 インサート位置 (`child_dome_cap_transport` と二重定義) |

## インタフェース (二重定義)

- **`child_core_frame`** (編集していない、値を借用のみ): `lug_x=66`,
  `lug_bolt_y=[-4,-16]`, 取付面 z=218, パイロン屋根 y −101..−50 / z 182..190,
  `xdcr_socket` 座 中心 (0,−75)
- **`wte4_dome_cap`** (仮値): 押えリング OD=120.3 (`child_core_frame` /
  `child_jaw_gate` の `dome_ring_od` と同じ)、座面 z=208、頂点 z=261.25
- **`child_dome_cap_transport`**: `cap_bolt_x`(75) / `cap_bolt_z`(227) を
  一致させること (M5 熱圧入インサート、軸 X)

## 干渉チェック (`.scad` 冒頭の assert)

- カラー内径 (126) > 押えリング OD (120.3) + 5 → 126 > 125.3 (margin 0.7mm、
  実測でリングが 120.3 を超えたら要再設計)
- 耳上端 ≤ 256、全幅 ≤ 152 (実測 150)
- シャックル穴の上下マージン ≥6mm、輸送キャップインサートとシャックル穴/台座の距離 ≥3mm
- アフトカットアウト端から xdcr_socket 中心までの距離 ≥21 (実測 57.4、余裕大)
- カラー下端 (218) > パイロン屋根上端 (190)

シャックル穴中心は当初目標 z=248 (`child_lug` と同じ) から **z=240 に下げてある**。
z=248/Φ16 のままだと穴の上端がちょうど耳上端 z=256 と一致し実質マージン 0mm に
なるため (旧 `child_lug` の assert はこの base_t 二重加算のため見かけ上 8mm と
出ていたが、実際には 0mm だった)。z=240 なら上端マージン 8mm・下端 (台座天面
z=222) までも 10mm 確保できる。

## 荷重と安全率 (`quick_strength.py`)

L1 吊り 99 N/耳 (全備 5.7kg × 3g、ブライドル ~30°)、L2 輸送 300 N (2026-09-04
緩和、5g)。いずれも interlayer (層をまたぐ、保守的) の許容応力で評価。

- **lug** (シャックル穴、hole16 edge10 t22):
  F=300N → 純断面 0.68 / ベアリング 0.85 / ティアアウト 0.68 MPa (limit 12/18/7.2) PASS
  F=99N → さらに余裕 PASS
- **beam** (耳根元 曲げ、L=22 [根元→シャックル穴中心], b=22[y], t=17[x]):
  F=300N → 曲げ 6.23 MPa (limit 12) / たわみ 0.127mm (limit 1) PASS
  F=99N → PASS (さらに余裕)

`quick_strength` は idealised section の一次チェック。荷重が集中する
シャックル穴周りは `topopt fea` での確認が望ましい (未実施)。

## 印刷 (X1C, `topopt print --load-axis 0,0,1`)

**PASS**。推奨姿勢 **+Y up** (機体 Y 軸を印刷の鉛直軸にする):
サイズ 150×38×128mm、オーバーハング 7.5%、1層目張り出しなし、
主荷重 (Z, シャックル引張) が層面内 (`cos=0.00`)。この 1 部品構成で
`child_lug` のような分割は不要だった。

## 部品外の考慮

- **ゲート開閉クリアランス**: y>0 (ゲート側、可動側) のカラー下端は z≥218.5
  に浮かせてある (`front_raise`)。y≤0 側 (固定側、耳の台座) は z=218 に密着
- **LED を遮らない**: カラーはドーム赤道より下 (z218..232、頂点まで 29mm 以上
  残す) にしか材料が無い。上半球は完全に開放
- **シャックル回転クリアランス**: 耳の外側面から M10 シャックルがドーム面へ
  当たらないか実物で要確認 (旧 `child_lug` から引き継いだ要確認事項)
- **輸送キャップとの取合い**: `child_dome_cap_transport` がこの部品の
  カラー/耳を丸ごと覆うスカートで嵌る。運用時はキャップを外す

## 要確認

1. ドーム押えリング OD (現仮値 120.3) の実測 → カラー内径のマージン 0.7mm
   しかないため、実測が 120.3 を超えたら `r_in` を広げる
2. `dome_h` (53.25仮) の実測 → クラウン自体は影響を受けないが輸送キャップの
   頂点クリアランスに影響
3. シャックル/ブライドルの実物でのクリアランス確認 (旧 `child_lug` の要確認 2 を継承)

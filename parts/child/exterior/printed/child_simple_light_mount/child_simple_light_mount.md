## 寸法と取り付け

| 項目 | mm |
|---|---:|
| クランプ公称内径 / 保持長 | 33 / 81 |
| 筒の肉厚 | 4 |
| 半割間の締め隙間 | 1.5 |
| 接続板の規格座面 / 下側の造形用延長 | 60×60×6 / 10.5 |
| 筐体接続穴 | 40×40、4×Ø3.45（24角補正） |
| 全体外形 | 65×61×81 |
| 接続面からライト中心まで | 40.5 |
| 接続板と筒の最小隙間 | 14 |

CHILD-SIMPLE-M3-40x40 Rev.1に対応。共通寸法は `scad/lib/child_simple_frame.scad` から読み込む。
ローカル原点は接続面中心。+Yが筐体から外向き、Zがライト軸。
機体配置は `translate([0,-82,100]) rotate([0,0,180])`。
ライト軸は機体 (0,-122.5) に位置し、保持部はz=59.5～140.5。
TD04A座面下端z=160に対してマウント本体は19.5 mm下。
取付穴配列は上下反転取付可。r2の造形向きは必ず指定の+Zを上にする。ライトの発光端・スイッチ・頭部形状と照射方向は未確定。

## 締結と組立

- 筐体接続：M3×20ボルト4本、M3ナット4個、平ワッシャ8枚。
- クランプ：M3×20ボルト4本、M3ナット4個、平ワッシャ8枚。
- ナット厚は3～4 mm、ワッシャは各0.5 mm想定。実際のねじ先端と掛かりを確認する。
- 埋め込みナット・インサートは不要。

1. 穴のバリとサポートを取り、必要ならØ3.4～3.5で通し穴を仕上げる。
2. 接続板の外側からボルトを通し、筐体裏にワッシャとナットを取り付ける。
   外側は14 mmの隙間へ短腕のL型六角レンチを横差しする。長いドライバーの直進経路は筒が遮る。
3. ライトを本体の半円へ載せて押さえを取り付け、4本を均等に締める。
   半割の隙間を無理にゼロにしない。33 mmより細い場合は実測して `lm_holder_id` を変更する。
   肉厚、レンズ、ボタン、防水シール部を圧迫しない。
4. ライト自身のストラップ穴から機体へ独立した落下防止コードを掛ける。
   この部品は底止めのない摩擦保持なので、上下方向の抜け止めを実物で確認する。

## r2：サポート削減・肉抜き

保持径33、長さ81、M3・40×40の穴中心、筐体上の位置は維持。
接続板と中央支持部を印刷底面までつなぎ、下側のねじ耳の1 mmの浮きを解消。
上側の耳は約54°で立ち上がる斜面。横向きの穴はM3円形クリアランスを含む尖り屋根付きに変更。
接続板に20×30の菱形窓を2個、筒の側面に幅14×高さ46の菱形窓を追加。
上下のクランプ帯、中央支持部、ねじ座を残した。印刷底面が広がり、初層で全体が連続する。

## 荷重と検証

仮定：ライト0.5 kg、取り回し係数5、25 N。実重量・水流・引っ掛け荷重は未確定。
本体の4ボルト周辺を固定し保持部に3方向から25 Nを加え、PETG充実材・Z積層で再解析した。

- 本体・押さえ：trimeshで閉メッシュ・各1連結ソリッド、FreeCADで有効ソリッドを確認。
  簡易inspect_meshの1 µm丸め検査は微小辺を潰し「open edge」を表示するが、
  高精度頂点による全辺の共有数検査とFreeCAD検査では閉じている。
- STEPは今回CSG変換器の押出し処理が失敗したため、STLからのファセットソリッド。
  パラメトリック修正はSCADを使用する。STLとSTEPの形状を照合する。
- [CAD検査](verification/cad_checks.json)：23/23 PASS。筐体接触、干渉、穴・頭・横差しレンチ・裏側工具空間。
- [FEA収束結果](verification/fea/child_simple_light_mount_base_fea_convergence.json)：3/1.5/0.75 mm。
  **3ケースとも収束未合格。改訂前の解析値はこの形状に適用しない。**
  最細格子の横荷重変位0.215 mmは参考値に留め、強度認定には使用しない。
  接触/摩擦、押さえ、締付け力、疲労・クリープは未評価で、引き続き嵌合確認用試作。

## 部品外の考慮・要確認

参考は保持具だけなので、ライト頭部の外形・長さ・ボタン位置・電池交換方向・ケーブルの有無は不明。
ライト実体を含めたTD04A・ケーブル・照射範囲との干渉確認は完了していない。
端部は貫通して水抜きを確保。実際のケーブルは筒端から出し、曲げ半径と余長を実物で決め、筐体側へ別固定する。
筒で覆われる長さは81 mm。放熱部や操作部がこの区間にあるライトは、保持位置または窓形状の変更が必要。
まず嵌合と脱着を確認する試作とし、実使用前に抜け・緩み・変形を実物で確認する。

# child_osmo_holder — 子機 Osmo Action 6 防水ケース ホルダ

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_osmo_holder.scad` (バリアント定義 `variants.txt`) |
| 個数 | cradle ×2 / strap ×2 (左右のアームに 1 セットずつ) |
| 外形 (cradle) | 121.9 × 85.4 × 131.3 mm / 190.8 cm³ |
| 外形 (strap) | 121.9 × 26.0 × 7.0 mm / 21.6 cm³ |
| STEP | cradle 1 ソリッド / 124 面、strap 1 ソリッド / 12 面 |

## 役割

DJI Osmo Action 6 + **純正防水ケース (60m)** を `child_osmo_arm` の GoPro 互換
2 フィンガーに固定する。**下向き 20° を部品側に作り込んである**ので、
`action_camera.md` に「別途購入」と書いていた **GoPro ナックルは不要**になる。

ケース底面のクイックリリース (デュアルタブ) 形状には**依存しない**。
ケースの外形を床レール・端壁・後壁で受け、上からストラップで押さえる方式。

```
        ┌──── strap (M4 ×2) ────┐
  ┌─────┤   DJI 防水ケース       ├─────┐   端壁 86.8 高
  │ 端壁│  94.7 × 45.9 × 84.1   │ 端壁│
  └─────┴──[床レール ×2]────────┴─────┘   ← 底面タブはレール間に落ちる
          後壁40 / 前リップ31.5     │
                            [ステム + ガセット]
                                   │
                        [ヨーク + 足 ×2] ─ プロング3枚 ─ Ø5.2 ピン
        ══════════ child_osmo_arm のビーム上面 ══════════
```

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_osmo_arm` | GoPro 2 フィンガー + **M5 ノブボルト** (ピン穴 Ø5.2)。ナックルは不要 |
| `action_camera` (防水ケース) | 床レールで受け、strap を M4 ×2 (ナットトラップ) で締結 |

**`child_osmo_arm` と二重定義している値** — 片方だけ直さないこと:
`arm_fin_t=3.0` / `arm_fin_gap=3.4` / `arm_fin_w=15` / `arm_fin_h=16` /
`arm_t=6` / `arm_pin_z=10` / `arm_beam_w=40` / `arm_rib_t=4` / `arm_rib_h=10` /
`arm_pitch=25` / `pin_d=5.2`。
`child_clamp_base` とは `tube_od=114.3` を共有 (チューブ干渉 assert 用)。

プロングはアーム側 2 フィンガーと噛み合う **3 枚爪**。
アームの隙間 3.4 に中央プロング 3.0 が入り、アームの爪 3.0 をプロングの隙間 3.4 が
受ける (`fit_j = 0.4` を合計クリアランスとして両方から導出)。

## 干渉チェック (`.scad` 冒頭の assert)

自動チェック (watertight/ソリッド数) では**絶対に捕まらない**ものを assert にしてある。
`stem_len` を 20 にしていたときは「ステム前下角が自分の載るフィンガー上端に干渉」で
実際にビルドが止まった (0.6mm 食い込み) ので、形状側 (14 に短縮) を直した。

- ジョイント: 中央プロング厚 / プロング半径 / ピン穴まわり肉厚 / ヨーク下面とフィンガー上端
- 足: アームのフィンガー (Y±7.5) と縁リブ (Y±16) の**間**に収まること
- 隣の未使用フィンガー (X ±25 ピッチ): ステム幅 / クレードル床 / 床下ガセットの垂れ下がり
- ステムがヨークに届くこと (`stem_low_z < yoke_z1`。届かないと union が分離する)
- ケース保持: 床レールが底面タブに当たらない / 前リップが高すぎない
- **カメラ画角 155°**: ケース前面より前に出る構造は前リップだけ。その内側上角が
  レンズ光軸となす角を計算し、対角半画角 77.5° + 2° より外にあることを検査する
  (現在 **83.3°、余裕 5.8°**)
- 肉抜き窓・水抜き穴が床レールを削らないこと / 水抜き穴がステムで塞がれないこと
- ボルト柱の肉厚がナット二面幅に対して足りること
- **耐圧チューブ**: 最内基線 250 (X=125) でケースがチューブに当たらないこと
  (現在 **すきま 6.9mm**)
- **前後のチューブクランプ**: クランプのボルト柱は X=±90 まで来るので、ホルダとは
  X 方向で必ず重なる。Y 方向で逃げ切れているかを検査する
  (現在 **後 4.1mm / 前 4.5mm**)。`child_clamp_base` の `y=±60` と
  `saddle_d/band_w=26` を二重定義で持っている

ビルド後は `_work/images/child_osmo_holder_cradle_preview.png` の front/top/side を目視すること。

## 印刷向き

- **cradle**: モデルは「設置姿勢」なので、スライサで X 軸まわりに +90° 回して
  **後壁の外面をベッドに置く**。105.9 × 46 の平面が接地し、端壁・床・ボルト柱は
  すべてベッドに垂直な壁になる。**プロング板もベッドに垂直**になるので、
  曲げ方向が層内に入り折れにくい。ヨーク / プロング / 床下ガセットは
  片持ちになるのでサポートを付ける。
- **strap**: そのまま平置き (座グリが上)。
- 素材は靭性のある **PETG / ASA / PA**。PLA は不可 (紫外線・吸水・低温脆化)。

## 部品外の考慮

- **カメラの視野 (FOV 155°)**。ケース前面より前に出る構造を前リップだけに限り、
  その角度余裕を assert で検査している。ただし `lens_z` が仮値なので、
  **現物でレンズ中心高さを測るまで画角の保証は仮**。実機で 1 枚撮って確認すること。
  ケースのレンズポートは前面より前に張り出すはずで、その分は有利側に働く。
- **ケースのラッチ位置が未確認**。ストラップは `strap_y = -8` (やや後ろ) に置いて
  あるが、ラッチと干渉するなら `strap_y` を動かす。電池 / SD 交換のたびに
  M4 ×2 を緩めてストラップを外す運用になる。**潜行前に充電・設定・SD を済ませる**。
- **水抜き**。床に Ø5 ×8 (ステムの真上を外してある) と後壁の肉抜き窓。
  引き上げ後にケース下に水が溜まらないこと。20° 前傾なので水は前へ流れる。
- **カメラケーブルは無し** (独立電源・独立記録)。有線化するならアーム上の配線路と
  結束点が要る (**未設計**)。`docs/配線・ケーブル計画.md` 参照。
- **重心とモーメント**。ケース 110g + カメラ 149g = 約 260g が Ø5 ピン 1 本の
  ジョイントに載る。回り止めの**足 2 個**がビーム上面に着座して 20° を positive に
  決めるので、M5 ノブボルトの摩擦だけに頼っていない。
  ただし足の着座面は印刷精度が出る面ではないので、**組付け時に 20° を実測**し、
  必要なら足の底面を削って合わせること。
- **左右で同じ物を使う**。クレードルは X 対称なので左舷も同じ物でよい
  (アセンブリでは `mirror([1,0,0])` を掛けているが形状は変わらない)。
- 基線を変えるとステレオ較正が変わる。**運用前に基線を確定し、以後変えない**。
- ケースと樹脂が直接こすれるので、床レール・端壁・後壁・ストラップ下面に
  **EVA / 薄ゴムシート (2mm) を貼る**。締め代 0.8mm はその圧縮で取る。

## 要確認

1. **防水ケースの外形と軸の対応**。DJI 公称は 94.7 × 45.9 × 84.1 mm (長さ×幅×高さ)
   だが、カメラ本体の公称 (72.8 × 47.2 × 33.1) と表記の軸が揃っていない。
   本設計は「94.7 = 基線方向 / 45.9 = 前後 / 84.1 = 上下 (底面タブ込み)」と解釈した。
   **現物で 3 軸を測って `case_w / case_d / case_h` を確定すること。**
2. **底面クイックリリースタブの寸法** (`tab_w = 40` / `tab_h = 18` は仮値)。
   `tab_h` が変わると `rail_h` = 床レール高さが変わり、`wall_h` も動く。
   `tab_w` が変わると `rail_x0` の assert が効く。
3. **レンズ中心の高さ** `lens_z = 52` (仮値)。前リップの画角 assert がこれに依存する。
4. **ケースのラッチ位置** → `strap_y` の決定。
5. 基線 (250 / 300 / 350) の決定。アセンブリは現在**最内の 250 (X=125)** で
   置いてある (チューブに一番近い = 最悪ケース)。
6. 20° が `../docs/AquaBeacon_確定仕様メモ.md` の想定と合っているか (ナックル廃止の可否)。

# child_clamp_base — 子機 チューブクランプ ベース

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_clamp_base.scad` |
| 個数 | 2 |
| 外形 | 180 × 54 × 60 mm |
| 体積 | 200.2 cm³ |
| STEP | 1 ソリッド / 34 面 |

## 役割

BlueRobotics WTE4 4" チューブ (OD 114.3) を下から受けるサドル。
`child_clamp_strap` (上バンド) と左右の M4 ボルトで締結し、
ベース底面の M5×4 で `child_frame_plate` に固定する。

## 主要寸法 (`.scad` の Customizer 変数)

| 変数 | 値 | 意味 |
|---|---|---|
| `tube_od` | 114.3 | チューブ実測 OD ← `wte4_acrylic_tube` |
| `fit_clear` | 0.5 | 径クリアランス (保護シート厚を含めて調整) |
| `plate_w / plate_d / plate_t` | 180 / 54 / 8 | 底板 |
| `block_w / block_h` | 132 / 60 | サドルブロック |
| `saddle_d` | 26 | サドル幅 (Y) = strap の `band_w` |
| `m5_x / m5_y` | ±80 / ±20 | フレームプレートへの M5 (20mm グリッド上) |
| `m4_x` | ±78 | ストラップ締結 M4 |
| `nut_w / nut_t / nut_z` | 7.8 / 3.6 / 38 | M4 横挿しナットトラップ |

導出: チューブ軸心高さ `center_z = plate_t + (tube_od+fit_clear)/2` = **65.4 mm**
(アセンブリではプレート厚 6 を足して z = 71.35)。

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_frame_plate` | M5 ×4 (x = ±80, y = 中心±20) |
| `child_clamp_strap` | M4 ×2 (x = ±78)、ナットはベース側の横挿しトラップ |
| `wte4_acrylic_tube` | サドル面で受け (薄ゴム/EVA シート介在) |

## 干渉チェック (`.scad` 冒頭の assert)

- ブロック上端の壁厚 ≥ 6mm
- M4 ボルトがサドルブロックと干渉しないこと
- ボルト柱が底板からはみ出さないこと
- M5 頭 (Ø8.5 + 余裕) がサドル/ボルト柱と干渉しないこと

## 印刷向き

このまま (底面が下)。サドル曲面は上向きなのでサポート不要。

## 部品外の考慮

- **アクリル保護**: サドル面に薄ゴム/EVA シートを貼る。点当たりでチューブに
  クラックが入る。締め代はシート圧縮で確保するので、シート厚を決めたら
  `fit_clear` を再調整すること。
- M4 ナットトラップは**横から挿す**。組立順序として、ベースをプレートに付ける
  **前に**ナットを入れておくこと (プレート上だと手が入らない)。
- チューブ表面を配線が横切る場合、クランプ位置 (y = ±60) を避けて通すこと。

## 要確認

1. 保護シートの材質・厚み決定 → `fit_clear` 再調整
2. 締付トルク (アクリルを割らない範囲) の実機確認

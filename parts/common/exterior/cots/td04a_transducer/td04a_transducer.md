# TD04A 超音波振動子 (HONDEX)

購入品 (COTS)。子機・親機の**両方**で使う音響トランスデューサ。メーカーCADは未入手。2026-09-14に**製品写真を参考にした仮寸法の外観モデル**を作成。

## 外観モデル（2026-09-17更新）

ユーザー提供の `model.ply`、`model.ply.json`、実物写真2枚を参考に更新。単純な円筒を、上部が丸く底辺が平らな本体へ修正。背面の取付部、ねじ頭2個、ケーブル根元、長穴付き金属ブラケットの簡略形状を追加した。ブラケットは本体と一体の参照ソリッドであり、分解・可動モデルではない。

- `td04a_transducer.step`：Fusion 360用。単一ソリッド、42面。
- `td04a_transducer.stl`：閉じた確認用メッシュ。
- `td04a_transducer.scad`：編集可能な寸法パラメータ。
- `_work/images/td04a_transducer_preview.png`：4方向プレビュー。
- `ref/td04a_scan_crop.ply` / `_work/images/ref/scan_crop.png`：台紙面を推定して傾きを補正したスキャン切出し。ケーブルとブラケットの一部を含む。底面から2 mm未満を除いた未修復の参照メッシュ。
- `ref/scan_alignment.npz`：元の座標から補正座標への変換（vertices-origin）@rotation.T。
- `ref/td04a_provisional_v1.scad`：以前の仮モデルの保存。

**全寸法は未検証。** 本体は幅`width=46`、高さ`height=48`、厚さ`depth=20` mmの丸めた推定値。補正スキャンの本体付近の幅・高さ範囲を参考にし、写真で輪郭を補った。厳密な曲面フィッティングではない。ブラケット幅24・板厚2・後方延長48、ねじピッチ12、ケーブル径5 mm等は写真に合わせた仮値で、スキャンから精密測定した値ではない。全体外形46×48×73 mm。

JSONは「見た目モデル・寸法保証なし」、自動校正失敗、尺度はmanual-two-point。export_unit=mmのためPLYを再スケールしていない。元メッシュ408371頂点・816609面、境界エッジ175（JSON値）。台紙・床・ケーブルを含み、黒い本体に欠測あり。全体の閉じていないスキャンをそのままSTEP化せず、観察できる外形を簡略CADとして再構成した。

原点は正面の底辺中央。X=幅、Y=高さ、Z=背面方向。旧版の原点・形状とは異なるため、組立に使用する際は配置し直すこと。既存アセンブリ・ソケットは変更していない。メーカーCADではなく、取付適合は未確認。実物の幅・高さ・厚さ、ねじピッチ、金属板寸法の実測が必要。

再生成：`./build.ps1 -Paths parts/common/exterior/cots/td04a_transducer`。

検証：OpenSCAD STL生成、閉じたメッシュを確認。FreeCAD STEPは1ソリッド。STLとの外形差は表示精度で0.00 mm、体積差約0.03%。プレビューを確認。形状ファイルの整合性検証であり、実物精度の保証ではない。

| `parts/common/jigs/xdcr_clamp` | `xdcr_d = 26.0`, `xdcr_len = 55`, `cable_d = 9` |
| `parts/common/jigs/xdcr_poolside_jig` | `clamp_axz = 20.5`, `clamp_fx = 38` (`xdcr_clamp` の導出値) |
| `parts/child/exterior/printed/child_shell_aft` (縦置き構成) | `xd_pitch = 40` (ソケットの `hole_p` と一致)。**胴長 55** が「振動子上端 z=243 < ドーム頂点 261」の根拠 |

**胴径が変われば上記 4 部品を必ず作り直すこと。** 実測後は各 `.scad` の
`xdcr_d` を書き換えて `build.ps1 <部品フォルダ>` で再ビルドする。

`xdcr_clamp` を作り直したらビルド時の `echo` に出る `axis_z` / `face_off` を
`xdcr_poolside_jig.scad` の `clamp_axz` / `clamp_fx` へ**転記する**。
転記を忘れても部品はできてしまうが、**プールサイド治具の「振動子の深さ」と
「壁面からのオフセット (= 測距の基準距離)」の計算値だけがずれる。**

## 部品外の考慮 (ケーブル)

- **ケーブル 3m は切れない/延長しにくい前提で配置を決めること**。プラグは 3P で
  水中コネクタではないため、**プラグ側は必ず水面上 or 容器内**に置く。
- **縦置き構成 (構成 B) では**、`child_shell_aft` の後部パイロン屋根 (z=182, y=-86) に
  `xdcr_socket` (child バリアント) を上向きで固定する。ケーブルはパイロン内部の
  空洞を導管として下へ降り、下キャップのペネトレータへ入る。
  **上向きビーム (指向角 22°) の中にドーム・吊り耳は入らない**が、
  **吊りロープは振動子面から約 440mm 上でビームに入る**。細径なので影響は小さいと
  見ているが、E1 の実験時に確認すること。
  取付は **Ø4.3 下穴への M5 タッピング** (パイロン屋根が厚さ 16mm)。
  着脱を繰り返すなら熱圧入インサートに置換する。
- 子機側: 振動子はフレームプレート後方コーナーの `xdcr_socket` に上向きで挿し、
  ケーブルはソケット底の Ø9 穴から出して後方キャップのペネトレータへ入る。
  ソケット底の Ø9 は**水抜きも兼ねる**ので塞がないこと。
- ペネトレータを通すためにはケーブル外径が WetLink の対応径 (4.5–8.5mm) に
  入っている必要がある。**外径未実測**。
- **3P プラグはペネトレータのボア (Ø3.3–6.5) を通らない。** WetLink は濡れ側
  だけをシールし、乾き側には素の導体しか出ない構造なので、**ペネトレータを
  使う = ケーブルを切って容器内で端子台に落とす**ということ。
  親機はこの前提で `assemblies/parent_interior_p{1,2}` の南壁 x=85, z=65 に
  `pen_td04a` を置いてある (2026-08-29)。**3m は延長できないので、切る位置
  (= 実機での据付長) を先に決めること。**
- 振動子は音響部を**気泡なく水に浸す**必要がある。ソケットは振動子の放射面を
  塞がない (現状は上向きに開口)。
- 試験治具は 2 系統ある。**ポール治具** (`xdcr_pole_jig`) は結束バンド 2 本
  (4.8mm 帯) で保持し、深さはポール上の位置で決める (E1 仕様は水面下 0.6m)。
  **プールサイド治具** (`xdcr_poolside_jig` + `xdcr_clamp`) は縁に掛けるだけで
  設置が速いが、深さは水面下 157.5mm 止まり (ベッドサイズ律速)。
  プールサイド治具ではケーブルの水中経路が約 0.4m しかないので、
  **縁から機器置き場まで 2.5m を超えると 3m のケーブルが届かない。**

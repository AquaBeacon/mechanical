## 軸方向の位置決め — ねじを使わない

デッキ中央部の幅 **93mm はフランジ貫通口 Ø88.5 を通らない**。
これを利用して、**上下フランジのピストン内端面 (z = 19 / tube_len − 19) に
突き当てて軸方向を止めている**。両端の幅 76mm の細い部分だけが貫通口へ入る。

→ 追加の固定具は不要。内装は上フランジを抜いて上から落とし込むだけ。

## 干渉チェック (`.scad` の assert)

- 断面のすべての角の**軸心距離**をチューブ内壁と比較 (デッキ隅・MAIN の高背/低背
  ゾーン・裏面リード・RX・ボス・振れ止めパッド)
- 端部とショルダーが**貫通口 Ø88.5 を通る**こと / 中央部が**通らない**こと
  (通ってしまうと軸方向ストッパにならない)
- ボス高さが各基板の裏面リード突出より大きいこと
- 軸方向に基板同士が重ならないこと、幅広部からはみ出さないこと
- **配線スリットがボスの足元を抜いていないこと** ← これを外すと
  ボスがデッキから切り離されて別ソリッドになる。**実際に起きた**ので assert を追加した
- `CHILD_PWR` が上リブ帯に食い込まないこと。**assert のメッセージが
  「軸長は最大 ○○mm」を直接教えてくれる** (t200 で 57mm)
- `CHILD_PWR` の先端が貫通口へ出るなら、その部分が Ø87.5 に収まる高さであること
- `RX` (デッキ下面) が幅広部を超えないこと (下面の RX は断面が大きく貫通口へ出せない)

ビルド後は `_preview.png` の front / top でボスとスリットが離れているか目視すること。

## 印刷向き

**デッキ板をベッドに寝かせ、ボス側を上。サポート不要。**
t200 で 204mm、t300 で 304mm と長いので**ブリム必須・ベッド中央**。
反りやすいので大面積の 1 層目に注意すること。

全てのスタンドオフは Ø8 の円筒ボスで、デッキ上面から立ち上がるだけ。
RX 用は貫通穴なので下向きの張り出しは無い → 片面だけに構造がある形になり、
寝かせて印刷できる。

## 部品外の考慮

- **内部にアクセスするには上フランジを抜く必要がある。** 幅 93mm の中央部は
  貫通口を通らないため。ドームの M3 を外すだけでは基板に手が届かない。
  ロッキングコードを抜く工具スペースを実物で確認すること。
- **ケーブルは全部 下キャップから**来る。下リブの大開口 → デッキ左右の
  配線スリット → 基板側。リブの結束スロットでストレインリリーフを取る。
- **LiPo のリードは +Z (上) 向き**。`CHILD_MAIN` の `J_PWR1` は基板下端 (z≈21) に
  あるので **110mm 以上の余長**が要る。足りなければ LiPo を逆向きに入れる。
- **上面の基板は真上 (+Y) から、RX は真下 (−Y) からねじが入る。**
  MAIN の上に棚を張り出さないので、どの基板も工具が入る。
- 組立順は **箱 → RX (スペーサ) → デッキ上面の基板 → LCD支持アーチ**。
  箱の取付ねじ頭は `CHILD_MAIN` の下に隠れるが、通常の電池交換は＋Zゲートだけを
  外すのでMAINを外す必要はない。
- RX と MAIN をつなぐ 6 芯 (`J_RX1` ↔ RX `J2`) は**デッキを貫通する**。
  配線スリット (X = ±36, Z = 159) を通すこと。
- デッキは中央 149mm が無支持。LiPo 箱 (深さ 31mm の U 溝) が梁として効いている。
  箱を外した状態で長時間立てて置かないこと。

## 要確認

1. LiPo の実測 (102 × 34 × 23 ±2) → `child_vtray_batt_box` のベイ内寸
2. 下フランジM3 BCD94の穴位相・タップ深さと10mmスペーサの現物確認
3. 上フランジを抜く運用の工具アクセス
4. 印刷後の反り。204mm の細長い板なので、実物で真直度を確認すること

# child_jaw_gate — ワニ顎ゲート (容器把持・可動側)

外装フレーム再設計 (2026-08-02, [要件](../../../../../docs/子機外装フレーム再設計_要件.md) R5/R6) の
把持機構。旧 `child_shell_fwd`/`child_shell_aft` の「蝶ボルト4本で前後を締める」方式を、
**片側ヒンジで開閉するワニ顎クラムシェル**に置き換える。本部品は可動側 (前半分)。
固定側の半殻はコアフレーム (未設計、トポロジー最適化対象) に一体化する。

2026-09-04、[改善要件](../../../../../docs/子機外装_改善要件.md) §3.1/§3.2/§3.6 により
**カメラブレード・ライトパッドを削除し、前面ハードポイント HP40 ×3 とノブボルト頭ポケットに
置き換えた** (下記「2026-09-04 改訂」参照)。

## 2026-09-04 改訂 (改善要件 §3.1/§3.2/§3.6)

### 削除

- **カメラブレード** (中央縦板 x±2.95、y60..106、z108..142) と **上下ガセットデッキ**
  (t6、x±26、z84..90/160..166) + それらの M5×4 通し穴、および関連 assert (FOV 検査等) を
  すべて削除。カメラは新部品 `child_cam_bridge` が HP4/HP5 にボルト留めして保持する
- **ライトパッド** (前面スパインの平面パッド 幅44×z40..80、前面 y=67) と
  M4 セルフタップ下穴 Ø3.3×9×4 (x±18, z46/74) を削除。相手だった `child_light_saddle` は廃止方向、
  HP-L に置き換え

### 追加: 前面ハードポイント HP40 ×3 (`scad/lib/hardpoint.scad`)

すべて法線 +Y、座面 y = 74.35 (共通平面、シェル外面 r_out=64.35 + 10)。
座は「シェルフ (x/z 中心 ±25、座面から深さ12、インサート穴+ケーブル穴を収める)」+
「ライザ (x/z 中心 ±15、シェルフ〜シェル、窓の方位角から離すため幅を絞る)」の
2 段構成 — 単純な ±25 一枚板では窓 (方位角 42.5°/137.5°) と重なるため (assert (c) で検出・回避)。

| 名前 | 座中心 (x, z) | インサート穴 (x, z) | 中央ケーブル穴 |
|---|---|---|---|
| HP4 (カメラブリッジ上) | (0, 170) | (±20, 150 / 190) | なし |
| HP5 (カメラブリッジ下) | (0, 100) | (±20, 80 / 120) | なし |
| HP-L (前向きライト) | (0, 15) ※ 2026-09-04 コーディネータ指示で z45→z15 | (±20, −5 / 35) | Ø14、座面から深さ12 (座ブロック内で止める。シェル内腔まで貫通させない) |

- 座標は `docs/子機外装_改善要件.md` §3.1/§3.2 の当初案 (HP-L z45) から、
  `child_cam_bridge` のデッキ (レンズ z125 の 72mm 下 = z45..53) との干渉を避けるため
  **z15 に変更**した (2026-09-04 コーディネータ指示)
- インサート穴 M5 (Ø6.4 × 深さ 9、hardpoint.scad 既定の 8 より深い) を軸 Y、座面から −Y へ
- 座への法線変換は `rotate(a=180, v=[0,1,1])` (hardpoint.scad のローカル+Z を機体+Y へ)。
  `hp40_arrow()` (linear_extrude+polygon) は本ファイルの STEP 規約
  (cube/cylinder+ブーリアンのみ) に反し CSG→STEP を壊すため**呼ばない** (刻印なし)
- **hp40_arrow を呼ばないため、実物では座面自体に方向の非対称性がない。** アクセサリ側
  (アダプタ板・クランプ) が方向を持つ設計で管理すること
- 二重定義相手: `child_cam_bridge` (HP4/HP5、M5×8)、ユーザ設計ライトクランプ (HP-L)

## ラッチ側ノブボルト頭ポケット ×2 (改善要件 §3.6)

+X 縁のラッチを **M5 ノブボルト (頭 Ø16)** にする。ラッチボス (現行の蝶ボルト座) を
x 方向に広げ (`boss_x0/boss_x1` = latch_hx∓10、幅20、旧16 から拡幅) 前面 (y=boss_y1=16) に
**Ø18 × 深さ12 のポケット**を彫ってノブ頭を沈め、r80 の包絡から出ないようにした。
ポケット底は横穴 (盲穴) のため 45° コーンでオーバーハングを解消 (フラット部3mm+コーン9mm)。
ポケット底の残り厚 = boss_y1 − knob_dep = 16−12 = **4mm** (assert で ≥4 を保証、等号ぎりぎり)。

| 位置 | ポケット中心 (x, y, z) |
|---|---|
| ラッチ下 | (62, 16, 40) |
| ラッチ上 | (62, 16, 170) |

## ヒンジピン抜け止めざぐり (2026-09-05 追加、改善要件 §3.7)

最上ナックル頂面 (z 218) に **Ø10 × 深さ 4** のざぐり (`pin_cb_d` / `pin_cb_h`)。ピン Ø5×240 を
上から挿入し、E リング (or 止め輪) をこのざぐりに沈めて頂面から出さない。コアフレーム側の
ざぐり (上アフトナックル z 187.6) は組立後に手が入らないため、実用の抜け止めは本部品側。
ざぐり周囲のナックル壁 3 mm (assert)。

## 役割 (R5 / R6)

- **半径方向の把持**: チューブに EVA 2mm を巻き、ラッチ締結で **0.8mm 圧縮**して
  面で挟む (アクリルに局所荷重を掛けない)。内腔 r58.35 = チューブ半径 + EVA 圧縮後
- **軸方向の固定 (形状で捕まえる、摩擦に頼らない)**:
  - 下: **アルミエンドキャップの露出リム (Ø120.3, z −13.8..−8) をポケットで捕捉**。
    下リップの半径方向掛かり 1.8mm
  - 上: **ドーム押えリング (Ø120.3 仮) をポケットで捕捉**
  - ポケットの上側遷移は 45° コーン (サポートレス)
- **開閉**: −X 縁の縦ヒンジ (M5 ピン) で前方へ開く。+X 縁の M5 ノブボルト ×2 で閉じる。
  開くと容器は**前方へ水平に抜ける** (旧設計の「真上に抜く」から変更)

## インタフェース (コアフレーム側が未設計 — **二重定義になる値**)

コアフレーム (aft 半殻) は次を**同じ値**で持つこと:
`r_in=58.35` / `shell_t=6` / ポケット z・径 (`cap_z0/z1`, `pkt_r=60.9`, `pt_z0/z1`) /
ヒンジ (`hinge_x=-72, hinge_y(コア側は −10 鏡像), knu_od=16, knu_h=30, knu_gap=0.4`) /
ラッチ (`latch_hx=62, latch_z=[40,170], m5_d`、ノブ頭 Ø16 の逃げも要確認)。
コア側ナックルは z 13.4..83.6 / 122.4..187.6 の 2 個 (ゲートの隙間に入る)。

**新規の二重定義 (2026-09-04)**:
- `child_cam_bridge`: HP4 (0,170) / HP5 (0,100)、M5 インサート下穴 Ø6.4×9、ピッチ40×40、
  座面 y=74.35 前提でブリッジ脚を設計すること
- ユーザ設計ライトクランプ: HP-L (0,15)、同上パターン。中央 Ø14 ケーブル穴 (深さ12、貫通しない)

取合いロック: `interfaces.json` (`wte4_end_cap_5xm10` 実測値 / `wte4_dome_cap` **仮値**)。
`child_light_saddle` / `child_cam_mount` の `interfaces.json` は旧ブレード/パッド値
(`pad_y`, `lm4_x`, `blade_ht` 等) を参照したまま残っている — **本改訂でその二重定義は解消済み
(ブレード/パッド自体を削除) なので、両部品側は再設計または廃止が必要** (別ワーカー対応)。

## 荷重ケースと強度 (要件書 §3、改善要件 C6 で L2 を 300N に緩和)

- **L3 把持プリロード** + **L2 輸送 300N** (旧600N から緩和) → ヒンジ/ラッチ各 ~150N:
  - `quick_strength tube_clamp` (OD114.3, t6×w36, F300): フープ 0.69 MPa / 許容 19 → **PASS**
    (300N 相当でも同様に大余裕)
  - `quick_strength lug` (Ø5.4, t20, F300): 面圧 2.8 MPa (層間許容でも) → **PASS**
- 容器慣性 (~2.6kg × 5g ≈ 130N、改善要件 C6) はポケットリップのせん断で受ける:
  リップ断面 ≈ 半周 183mm × 2.7mm、せん断 ~0.3 MPa → 大余裕
- 前面ハードポイント座 (シェルフ+ライザ) の強度は `child_cam_bridge` / ライトクランプの
  荷重が確定してから個別に評価する (本改訂では形状・干渉のみ確定)
- **FEA は Workflow F ステージ 5 でコアフレームと結合した全体系で実施**
  (単体では境界条件が人工的になるため。閉形式は全項目 1 桁以上の余裕)

## 印刷 (X1-Carbon)

- **モデル姿勢のまま (+Z up)**、全高 235 < 250。ブリム推奨 (接地 1420mm²)
- printability (`topopt print --load-axis 1,0,0`): **PASS**
  (オーバーハング 4.9%、最小肉厚 4.74mm、フープ荷重が層面内、score 3.96)
- ナックル中・上段の下面 (互い違い隙間)、ノブポケット底の 45° コーン部のみ小サポート推奨
- `--load-axis` は **1,0,0 (フープ)** で評価する。0,0,1 を渡すと縦姿勢が
  「層またぎ」と誤判定される (吊り荷重は本部品でなく吊り耳→コアフレームが受ける)

## 干渉チェック (`.scad` 冒頭の assert)

- リップの掛かり ≥ 1mm (下=キャップリム / 上=ドームリング)、ポケット径クリア ≥ 0.3
- ナックル壁厚 ≥ 4.5 / ヒンジ・ラッチの 250 枠 (ラッチは拡幅後のボス ±10 で判定)
- ラッチ穴の端距離 / 窓とフランジ平面部の方位角分離 / 全高 ≤ 250
- ノブボルト頭ポケット: 底残り厚 ≥ 4mm、r80 包絡内
- 前面ハードポイント ×3: (a) インサート穴がシェル壁に食い込まない、
  (b) HP 座同士が z 方向に重ならない (総当り)、(c) 窓とシェルフ/ライザが重ならない
  (方位角、シェルフ・ライザ別々に判定)、(e) 上ポケットと HP4 の穴の分離、
  (f) HP-L の穴が下ポケットの z 範囲・シェル外面に届かない

## 部品外の考慮

- **ヒンジピン (Ø5×240) と M5 ノブボルト ×2 + ナット類は購入品** → BOM に追加のこと
  (旧「蝶ボルト」から変更。改善要件 §3.6)
- 開閉ストローク: ゲートは前方 (+Y) へ約 90° 以上開く (ヒンジ幾何で確認済み、
  実機ではカメラ/ライトのケーブルに干渉しないことをアセンブリで確認する)
- 容器の Z 軸回転は EVA 摩擦のみで拘束 (ケーブルが柔軟なので許容)。
  問題になればペネトレータ列とガードの回り止めを追加する
- EVA シート (t2、チューブ周長 ~360mm × 幅は把持帯 2 本分) — 消耗品として BOM へ
- 下ポケット付近の中央 r<42 と後方セクタの素通し (ケーブル出口) は下部ガード側の責務
- HP-L のケーブル穴 (Ø14、深さ12) はライトクランプ側から座ブロック内で止まる。
  クランプ以遠の配線ルートは `child_cam_bridge` / ライトクランプ設計側と別途調整が必要

フックは幅20 mm。ゴム座の切欠きと、先端から付け根へ細くなる下面の斜面を廃止し、厚いL形の連続断面にしました。実STLの先端から付け根まで105断面で最小4.2 mmを確認しています。Rは主として荷重方向のXZ断面です。断面増加は確認しましたが、許容荷重や疲労寿命は未評価です。

受けの芯厚は10 mm、天井の厚さは4 mm以上。受けのくぼみを取付板の端へ向け、フック下に張り出す板をなくしました。溝は下へ開放され、固定側の奥面・天井・左右面をゴムで覆います。取付板面積は1610→912 mm²（約43%減）。受け全体は爪の張出しを含め23×48×16.5 mmで、43%は治具全体の削減率ではありません。ゴムと厚い爪を収めるため高さは増えています。

## EPDMの切出しと貼付

厚1 mm EPDMシートを3片に切ります。

- 奥面から天井へ曲げて貼る主片：幅20.8×展開長14.43 mm、1枚。
- 左右面：4×12.5 mm、上側の奥角をR3で切った片、2枚。

主片は中央厚さで計算した展開長の初期値です。実際の曲げ・接着層に合わせて現物で端を合わせます。左右片と主片を突き合わせ、重ね貼りしません。くぼみは下開きなので底面の片はありません。貼付図の緑色がゴムです。SCADの `epdm_main_template` と `epdm_side_template` で平面型紙を出力できます。

[受けの貼付位置](../../../../assemblies/dji_style_toggle_latch/_work/images/epdm_keeper.png) / [閉状態断面](../../../../assemblies/dji_style_toggle_latch/_work/images/epdm_contact_section.png)。フック側にはゴム用の溝・座を設けていません。

閉状態の奥面では裸の受けからフックまで0.85 mm、公称圧縮0.15 mm（15%）。開閉中の幾何上の最大圧縮は約0.343 mm（厚さの34%）。これは硬度に基づく推奨圧縮率ではなく、試作寸法です。天井・左右も覆いますが、全面が同時に均等圧縮する設計ではありません。接着層、横膨れ、摩擦、剥離、クリープはモデル化していません。CADのゴムは樹脂との重なりを除いた空間モデルで、弾性変形の再現ではありません。EPDMはガタ取り用であり、開放溝を防水するガスケットではありません。

EPDMと樹脂に適合する接着方法で貼り、浮きや巻込みを実物確認します。閉じにくい場合は受けを−Xへ、遊びがある場合は＋Xへ少量ずつ調整してください。長穴端までの全範囲で動作保証するものではありません。寸法変数は `epdm_thickness`、`epdm_precompression`。ゴム厚を変えたら再生成・再検査が必要です。

## 引っ掛かりと取付け

爪の公称回り込み3.15 mm。ゴムの圧縮で遊びを取り、樹脂の段差で上方向の抜けを止めます。閉状態で上へ2.3 mm動かす、B軸周り4°持ち上げる、外向き0.4 mmの遊びを加えて2.3 mm持ち上げる各条件で、受けに阻まれることを幾何確認しました。これは荷重試験ではありません。

A軸高さ10.5 mm、リンク軸間12 mm、閉リンク角185°。受け原点[26,0,0]、仮想基準C高さ8.5 mm。解除はリンク185°→115°、続いてレバーを持ち上げます。ホスト間隔は固定したままです。

**更新した台座・受け・レバーをセットで使用してください。** 台座取付板26×46×厚5 mm、受け19×48×厚5 mm。台座リンク通路のみ厚2.5 mm。台座穴x=−10,+3、y=±18、径補正付きØ3.45の4穴。受け長穴はローカルx=−12,−4、y=±19、幅3.45・X方向±1.5 mmの4個に変更しました。旧穴配置のまま取り付けられません。

印刷は台座1、受け1、レバー1、リンク2の4種類5点。購入品はM3×25（A）・M3×35（B）各1本、緩み止めナット2個、EPDM3片。金属軸モデルは購入品の包絡、EPDMも印刷対象外です。実金具の頭・ナット寸法を確認し、ナットで可動部を締め潰さないでください。

台座をホストへ固定してからA軸を入れ、受けはレバーを開いて固定・調整します。Ø6.4 mmのドライバ通路を確認済み。取付ボルトの長さはホスト厚さに合わせます。

## 設計への組込

```scad
use <path/to/dji_style_toggle_latch.scad>
union() { your_fixed_body(); latch_base(with_pad=false,with_holes=false); }
translate([26,0,0]) latch_keeper(with_pad=false,with_holes=false);
// 別々の可動部：latch_link(); latch_lever();
// ゴムは固定側の受けと同じ座標系
translate([26,0,0]) latch_epdm();
```

根元をホストへ十分重ね、受けの開口下へホストの板を張り出させないでください。フックの解除通路・軸抜き・指の空間を確保します。配置正本はassemblyのplacement.json、部品編集はSCAD。STEPは組込参照に使えます。CSG取込みに失敗した部品は検証済みSTLからのファセットソリッドです。

## 印刷・検証

試作条件はBambu Lab PETG Basic、0.4 mmノズル、0.2 mm層、6周壁、100%インフィル。Bambu StudioでPETG Basicの材料プロファイルを選択します。台座・受けは底面下、リンクは側面下、レバーは天面下。配布STLは姿勢反映済み。受けの爪下、軸穴、フック先端は局所サポートを検討し、掛かり面と貼付面を清掃します。板状シートか発泡材か、接着後の厚み、実機側の穴と荷重は現物で確定してください。

[検証JSON](../../../../assemblies/dji_style_toggle_latch/_work/analysis/geometry/report.json)：閉メッシュ・単一連結体・正体積・退化面ゼロ、固定受けに対する231姿勢の剛体干渉、全貼付面の隙間、先端から付け根までの厚さ、上方向の引っ掛かり、穴と工具通路、STEP/STL外形・体積を確認します。実荷重、積層方向別強度、疲労、保持力、接着剥離は未検証です。

再生成は部品build → `python spec/dji_style_toggle_latch/verify.py` → assembly build → 印刷一式check。退化面が生じる部品はmanufacturing.json指定のエッジ反転修復を行い、形状・体積不変を確認します。

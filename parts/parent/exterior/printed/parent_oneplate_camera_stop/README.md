# 親機・カメラ角度ストップ

既存のDJI Osmo Action 6用マウントへ後付けする、取り外し可能なケース当たりストップ。マウント前壁の既存工具穴（局所X=±20 mm、Z=20 mm）をM4×20ねじ2本で使い、穴ピッチ40 mmで固定する。2本のM4×12ねじを個別に調整してカメラケースの当たり高さを合わせ、ロックナットで保持する。

設計の初期接触位置は局所Y=16 mm、Z=36.5 mm。カメラケースは暫定参照形状であり、この位置・ケース当たりは仮設定である。実ケースを取り付けて傾きと接触を調整する。既存マウントのM3工具アクセス時はこのストップを外し、作業後に同じ壁面と穴へ戻す。カメラマウント本体は変更しない。

設計元は `spec/prepare_parent_oneplate.py` と `spec/parent_oneplate_sensor_sources.py`。座標はカメラマウントのローカル座標。生成SCADを直接編集しない。必要金具と配置は `assemblies/parent_oneplate/README.md` を参照する。

実ケースでの視野、取付強度、締結後の角度再現性は未確認。ねじ先端やストップがケースを押し過ぎないことを実機で確かめる。

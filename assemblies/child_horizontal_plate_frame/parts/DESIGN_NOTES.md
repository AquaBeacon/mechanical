## 一体化するCインターフェース

形状の正本は [quick_release_prototypes.scad](../parts/common/jigs/quick_release_prototypes/quick_release_prototypes.scad)。今回のSCADは公開モジュール `twist_female()` と `twist_male()` を直接利用し、元のCの爪・カム・ロック穴・ゴムくぼみを維持する。共通寸法は生成ツールが `scad/lib/child_horizontal_twist_interface.scad` へ出力し、手入力でコピーしない。

| 項目 | 値 |
|---|---|
| 基準板 | 40×40、既存32×32穴は位置基準として残る |
| 軸と爪 | 軸φ14×8、爪外半径10.5、リングφ28 |
| メス底面からオス外側面 | 24.5 |
| QR面内角 | U/V面で0°、横ロック穴を水平U方向へ向ける |
| 着脱 | 横ボルト全体を抜く→時計回り60°解除→外側N方向へ抜く |
| 回転中のカム移動 | 60°でN方向へ0.60 |
| ロック | 六角頭M3×40、AF5.5×厚2.4ナット、φ7×厚0.5ワッシャ、既存φ16ノブ |
| ゴム | 5×8×1を2枚、オスくぼみに薄く接着、公称圧縮0.10 |

qX=U、qY=V、qZ=N。オスはqX回り180°反転して固定する。ノブ付きボルトはqX正方向（機体+Y）へ45 mm以上抜く。ワッシャは脱落防止式ではない。回転方向は機体の右外側から側板へ見た向きで記す。

メスの非嵌合底板N=0〜4だけを、固定足と共通の平坦な外形へ置き換える。足と40×40板の入り隅をR2、縁を0.6面取りに仕上げ、既存32×32の4穴を最後に復元する。N=4以上のCリング・爪受け・カム・ロック穴は元モジュールのまま。オスの爪・カム・ゴム座も保持し、検査では元のCメッシュとの局所差分を照合する。

機器側治具はオス板の外側へ直接unionし、裏面の爪・カム・ゴム面へ材料や金具を出さない。Rev.1のライト変換板、メス取付4本、皿ねじ4本、ホルダー台座取付4本は廃止。別体オス・別体メスも今回の印刷一式に含めない。`twist_male_mount` は旧版の別体接続用として保持し、Rev.4のライトには使わない。

## ライト保持部

ユーザー確認済みの既存33×81ホルダーを流用し、上向きに照射する。元の `half_holder()` に台座を省く引数を追加した。既存ベースと押さえ分岐の外形・全頂点・体積が同じことを別出力で確認し、既存STLのバイト列を保持する。一体オスは同じ筒・耳・穴・窓を使い、旧60×60取付板と14の工具隙間を省き、C板の外側6 mmを筒の背面へ重ねて一体化する。C板側だけ筒の空間を切り抜き、既存の33径筒をunionする。重なる円周の数値的な一致を避けるため、C板の切抜きだけ半径0.02の逃げを加える。筒内径は元の33のまま、背面C板は最も薄い中央で約4 mmを残す。既存押さえをそのまま使用する。

半割の締結はM3×20 4本、ナット4個、両側ワッシャ8枚。耳の中心はローカル横±26、上下±32.5、厚6、分割隙間1.5。保持は摩擦式で底止めがなく、上下は開放。ライトから機体へ独立した落下防止コードを掛ける。

33は参考ホルダー内径で、ライト実測径ではない。実ライトの頭・ボタン・全長・電池交換部・ケーブルをモデル化していない。新しい台座接続部は外周R2、縁0.6面取り。既存の筒端・耳・窓は確認済み保持形状を維持する。Cの爪・カム・ゴムくぼみと既存ホルダーの耳・分割面・窓・端部は、確認済みの嵌合形状を保持する例外。全体への一括平滑化は行わない。

## 組立と印刷

追加の印刷部品は4種類各1個：一体フレームメス、一体ライトオス、既存押さえ、既存ノブ。追加金具はM3×18 2本、M3×20 4本、六角頭M3×40 1本、M3ナット7個、φ7×0.5ワッシャ11枚、ゴム2枚。金具・ゴムは印刷しない。

1. 一体台座を側板のY60/Z100・160へM3×18で固定する。内側の既存ナット受けを使い、ライトユニットを装着する前に締める。
2. ナットとノブ内の六角ボルト頭を元のCの手順で少量のエポキシで保持する。ゴム2枚をオスのくぼみに薄く接着し硬化させる。
3. ライトを一体オスの筒へ置き、既存押さえを4本のM3×20で均等に締める。1.5の隙間を無理に潰さない。
4. 固定姿勢から時計回り60°傾けた差込姿勢で取り付け、反時計回り60°でカムの端まで回す。ライトの照射軸が鉛直上向きに整列したら、ライト横の水平ノブ・M3ボルトとワッシャで固定する。斜めの差込位置では横ボルトが貫通しない。

印刷入口は [parts/PRINT.md](../assemblies/child_horizontal_plate_frame/parts/PRINT.md)。X1C / Bambu PETG Basic、0.4ノズル、8壁、100%充填、5 mmブリム。一体2部品は0.1 mm、押さえとノブは0.2 mm。一体メスはフレーム接触面を下、一体オスは筒軸を垂直・下端を下（製造X90°回転）。印刷STLへ姿勢を反映する。

段差をなくした一体メスは接触面全体をベッドへ置き、サポート無効。一体ライトオスだけベッドからの外部サポートを使い、横向き軸・爪・C板下面を支える。造形物上からのサポートは無効、上下離隔0.2。垂直の33径筒内へサポートを入れない。C摺動面は除去後に実物で照合する。Rev.2の段差付きメスの3MFは現行形状へ流用しない。機構内の短い橋・横穴は初回印刷で確認する。

[実メッシュ検査](../assemblies/child_horizontal_plate_frame/_work/analysis/side_twist_mount/validation.json)は閉メッシュ・単一連結、既存部品・金具の干渉、参考ゲージφ32.98×81、中央の手の予約空間、工具、5°刻みの解除回転、ボルト45抜去、N40抜去、固定時の上向き軸、水平ノブの全周回転と半径方向3 mmの操作余裕を検査する。3 mmは局所的な指の余裕で、手全体・手袋の適合モデルではない。[実スライスとサポート検出](../assemblies/child_horizontal_plate_frame/_work/analysis/side_twist_mount/slicing.json)に形状ハッシュ、積層と実3MFの設定を記録する。離散的な剛体CAD検査とスライサー検査であり、実嵌合・強度・接着・摩擦・クリープ・水流荷重は未認定。元のライト治具のFEA収束未合格を流用で合格と扱わない。

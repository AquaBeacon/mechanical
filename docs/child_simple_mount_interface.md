# 子機シンプル筐体：後付けマウント共通規格

規格名：**CHILD-SIMPLE-M3-40x40 / Rev.1**（プロジェクト内規格）。2026-09-17記録。
対象：`child_simple_front` と `child_simple_rear`。rearのライト取付面はr3から対応。
今後カメラ・TD04A・水中ライトのマウントを設計するときは、この仕様を参照する。

## 共通の取合い寸法

単位はmm。40×40は**穴中心間の水平・垂直距離**。

| 項目 | 規定 |
|---|---|
| 締結ねじ | M3、1マウントにつき4本 |
| 穴配列 | 正方形40×40、座面中心から左右±20・上下±20 |
| 筐体側の穴 | 通し穴、設計クリアランス径Ø3.45。ねじ山なし |
| 筐体側の座面 | 幅60×高さ60、厚さ8 |
| 締結方法 | 貫通ボルト＋外付けM3ナット。インサート・埋め込み・先入れ不要 |
| ボルト軸 | 座面に垂直（機体Y方向） |
| 相手マウント側 | 同じ40×40の4穴を使用。印刷する通し穴はØ3.45を基準とし、造形後に実物で確認 |
| ボルト長 | 筐体8＋相手マウント厚＋ワッシャ合計厚＋ナット厚＋先端突出約1を目安に選定 |

SCADの穴は24角形の内接径がØ3.45となる補正を使用する。
印刷後の穴径・締め代は実物で確認する。規格は許容荷重を保証するものではない。

## 用途と機体座標

原点と向き：チューブ下端z=0、+Zが上、+Yがカメラ正面、Xが左右。
以下のyは**外側座面**。穴はそこから厚さ8を貫通する。

| 用途 | 部品・位置 | 座面中心(x,y,z) | 穴中心(x,z)：4通り | 座面の外向き |
|---|---|---|---|---|
| カメラ用ブリッジ | front中央 | (0,+82,100) | (±20,80)、(±20,120) | +Y |
| TD04A用マウント | rear上部 | (0,-82,190) | (±20,170)、(±20,210) | -Y |
| 水中ライト用マウント | rear中央・r3追加 | (0,-82,100) | (±20,80)、(±20,120) | -Y |

rearのTD04A用とライト用は別々の4穴セット。座面中心の上下間隔は90。
外側から見た模式図（各座面共通）：

## 後付けマウント設計時の確認

- この規格は**筐体と後付けマウントの接続側**。カメラ・TD04A・ライト本体側の穴やクランプ径は、各機器の実寸に合わせて別途設計する。
- 既存HP40のM5規格とは異なる。カメラ間の基線距離とも別の寸法。
- ナットと工具を着脱できる空間を残す。現状は座面裏側の外径10の工具空間をCAD検査済み。
- ボルト先端、機器、ケーブル、ドーム、隣のマウントの干渉を、最終形状で再確認する。
- frontはユーザーが印刷済み。今後のマウント設計でfrontの穴位置・座面・締結位置を変更しない。変更が必要な場合は印刷済み部品との互換性を明示する。

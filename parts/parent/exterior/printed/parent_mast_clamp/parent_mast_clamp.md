## 役割

φ20 アルミパイプ (マスト) を掴むスリット式ピンチクランプ + 70 角取付フランジ。
上側は防水ボックス底に、下側はマストヘッドプレートに M5×4 で固定する。
パイプは貫通穴に通し、M4 ピンチボルト 2 本で締める。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `pipe_d` | 20.4 | アルミパイプ実測 OD + 0.4 (**要フィットテスト**) |
| `flange_w / flange_t` | 70 / 6 | フランジ |
| `m5_p / m5_d` | 56 (±28) / 5.3 | フランジ M5 4 穴 |
| `block_w / block_h` | 44 / 50 | クランプブロック |
| `slit_w` | 3 | スリット幅 |
| `m4_x / m4_z` | 16 / [15, 36] | ピンチボルト位置 |
| `nut_w / nut_t` | 7.8 / 3.6 | M4 ナットトラップ |

## インタフェース

| 相手 | 締結 |
|---|---|
| 防水ボックス底 / マストヘッドプレート | M5 ×4 (±28) — **70 角フランジが親機側の共通インタフェース** |
| `mast_pipe_al20` | 貫通穴 Ø20.4 + M4 ピンチ ×2 |

## 干渉チェック (`.scad` 冒頭の assert)

- ピンチボルトがパイプ穴と干渉しないこと / ブロック外に出ないこと
- ブロック肉厚 (片側 6mm 以上)
- M5 頭 (Ø8.5) がクランプブロック側面と干渉しないこと
- M5 穴の端距離 ≥ 4mm
- ピンチボルト高さがブロック内に収まること

## 印刷向き

フランジを下に平置き。パイプ穴は垂直なので真円が出る。

## 部品外の考慮

- **3Dプリント品でアルミパイプの片持ち 600mm を支える**構成。ピンチクランプは
  締め付けで摩擦保持するので、**層間剥離**が効く方向に力が掛かる。
  積層方向 (フランジ面が下 = Z 積層) で、パイプ軸まわりのトルクは層をせん断する。
  素材は PETG/ASA 以上、壁厚と充填率を上げること。実機で緩みを確認する。
- ボックス底に貫通する場合、**その穴の防水**が別途必要 (M5×4 とパイプ穴)。
  現状クランプはボックス底の**外側**に付ける想定だが、未確定。
- ケーブルをパイプ内に通すなら、クランプの貫通穴を通ってボックスに入る。
  M4 ピンチボルトが**ケーブルを潰さない**位置か要確認 (現状ボルトは
  パイプ中心から x=16 でパイプ穴 (r=10.2) の外だが、ケーブルはパイプ内なので影響なし)。
- バラスト 0.4 kg はパイプ下端。クランプ位置より下に付くこと。

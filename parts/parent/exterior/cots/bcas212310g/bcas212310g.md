## 寸法と座標

X=210辺、Y=230辺。DXF内視図のXYを入れ替え、主床外面をZ=0とする。公称外形210×230×100.3。DXF外側ボス足はZ=-1まで出るため、主床基準のCAD全高とカタログHは測り方が異なる。

| 取合い | 現行値／出典 |
|---|---|
| 床厚 | **3 mm**：B-Bの3寸法、DXF13601/135F4の差 |
| 内側ボス | 床上**7 mm**、上面**Z=10**。インサート4個＋タッピング12個 |
| インサートXY | (25,25)、(185,25)、(25,205)、(185,205)。ピッチ160×180 |
| タッピングXY | X25/185・Y75/115/155の6個、X65/105/145・Y25/205の6個 |
| 四隅 | カバー軸X9/201・Y9/221と、主室に張り出すC形隔壁。円柱4本だけでは表せない |
| 側壁 | 断面の抜き勾配を反映。全高さ一定6.1 mm壁を廃止 |
| 本体とふた | 継ぎ面Z80、嵌合舌Z83.5。ふたは組立差0.3を加えZ80.3から |
| ふた内面 | 主面Z97.1。側壁と溝は別形状。溝は左右0.2の余裕を仮設定 |
| 内寸 | カタログ197.8×193.2×87.1は障害物込みの有効寸法。最大幅217.8等を全域で使える矩形空間として扱わない |

ボス円錐・外側小足・カバー軸穴は図面包絡を再現。細部の根元丸み、外観ガイドマーク、インサート金属とねじの個別実体は省略。実物申告質量644.5 gをCAD体積から上書きしない。

## 誤りの訂正と利用範囲

旧モデルはカバー側壁3.84を床厚に用い、床厚3を中央の中実リブ台と解釈していた。ボス高さ10を仮置きし、2本のボスと四隅の隔壁、壁の勾配、ふたの別体を欠いていた。旧検査結果を実物適合の根拠に使わない。旧CAD・文書は_work/analysis/cad_correction_20261010/before/に保持。

現行内装parent_hand_serviceはこのCADで再照合。他構成の既存STEPは再生成・再検証していない。外装の位置決め・取付穴へ旧モデルを使った構成は別途照合する。

本体モデルには自作ペネトレータ穴を入れない。南壁テザーX28／TD04A X120・Z65は加工計画。旧6.1 mm壁用のナット配置を実壁の座面適合や防水保証へ転用しない。実壁厚・勾配とコネクタ実物を確認してから加工する。

## 確認結果と残件

本体・ふたは各1閉ソリッド。独立OpenSCADレンダリングとSTEP/STL寸法・体積の記録は_work/analysis/cad_correction_20261010/。内装と挿入経路はassemblyのcase_fit_report.mdを参照。

メーカー3D原本はユーザーも未所有（2026-10-11確認）。四隅の勾配、ボス座面とインサート深さ、蓋の溝・圧縮、公差を実物で確認する。負形0.5 mmは設計余裕で、実物嵌合の保証ではない。

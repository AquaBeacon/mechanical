外形の6面は平面、縦の角はR0.2、上下端と穴入口は0.2 mm面取り。

12角穴の縦稜線は機能断面を維持し、ねじ山を利かせず使用する。

## 金属部品と組立

左右フランジは**首下26 mmのM3なべねじ2本**。12 mm座＋10 mm本体を貫通して
フランジに4 mm入る。必要なら既存M3×30を首下26 mmに切り、切断端を面取りする。
M3×25ではかかりが3 mmとなるため使用しない。M3×30をそのままねじ込まない。
ここは周囲のデッキに通常ソケットが当たるため、従来と同じなべ頭＋軸径4 mmドライバーを使う。

ブレースは金属M3×30／×45の全ねじスタッド各1本と普通M3ナット2個
（二面幅5.5／厚さ2.4 mm）。平先の全ねじ棒または頭なしねじを使用する。
スタッドの工具用穴／把持方法は実物に合わせ、スペーサの穴内でねじ止めしない。
以前の短いM3×8／×10スタッドと、左右M3×16・ブレースM3×12の上ねじ4本は使わない。

1. スペーサを冷却後にランナーから折り離し、つなぎ跡とバリを面一に除く。
2. M3ねじが全長を手で滑って通ることを確認する。実印刷の収縮は機種・材料に依存する。
   渋い場合は穴だけを3.5 mmドリルで軽くさらう。圧入・ねじ込みはしない。
3. 左右フランジはM3×26なべねじを12 mm座とスペーサへ通し、フランジに4 mm入れる。
   フランジの底付きと着座を確認する。
4. ブレース用スタッドの下端はMAIN基板1.6 mm＋デッキ4.4 mmの計6 mm入れる。
   スペーサと5.5 mm取付座を通し、上側から普通M3ナットを締める。
   座面が接したところで止める。緩み・樹脂の潰れは実物確認。

ナット外側への公称ねじ突出はブレース右4.1 mm、左1.1 mm。
相対する2本のねじを穴内で突き合わせる構成は廃止。ブレース右は長めの先端を指や配線へ当てない。
ブレースの工具検査は外径8 mm／内径6.6 mm／長さ50 mmのソケット包絡。
左右フランジを含むなべねじには軸径4 mm／長さ50 mmドライバー包絡。
チューブを外して締める。ソケット実物とナットの回転・保持は仮組みで確認する。

## 印刷

PETG、0.4 mmノズル、積層0.20 mm、壁4周以上、100%充填を推奨。
軸をZに立て、Z0をベッドへ置く。つなぎは2層、ランナーは幅2×厚0.6 mm。
本体の根元を支えてランナーを曲げて折る。長い本体の先端を持ってねじらず、
折れにくければニッパーでつなぎのみ切る。破断用のつなぎの縁は面取りの例外。
スライサのオブジェクト分割は使わない。支持が必要な閉じた屋根や水平穴は設けていない。

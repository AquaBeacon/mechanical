# DJI純正Action 6防水ケース 取り付け試験片

2026-09-09、ユーザーが純正ケースを確認し、爪厚3 mm、爪の内側間隔3 mm、穴径5 mm、ケース本体底面から穴中心12.5 mmを実測。磁気クイックリリースではなく一体型2枚爪。写真によるねじ露出長17〜18 mmは概算で未確定。

本品は3枚爪の嵌合と純正ねじ到達を確認する試験片。実機用マウントではなく、回転止め・ケース押さえ・機体接続は含まない。既存アセンブリは変更しない。

## 試作寸法

- 中央爪2.7 mm、溝幅3.3 mm×2、通し穴5.2 mm。
- 下爪6 mm、上爪3 mm、全積層幅18.3 mm。
- 下面六角ナット座：二面幅8.2 mm、深さ4.2 mm。普通のM5ナットを仮定。純正ねじのピッチ・ナット適合は未検証。ナットは付属しない。
- 上爪外面からナット入口14.1 mm。ねじ露出長17〜18 mmなら幾何上の到達量2.9〜3.9 mm。先端の不完全ねじ山やナット面取りを含めた有効かかり長は別途確認。実使用強度の判定には使わない。
- 穴中心からケース側の爪先端7 mm、実測の底面位置まで5.5 mmの名目余裕。ヒンジ・リブの実形状との干渉は未確認。

## 印刷と確認

SCADのZ=0面をベッドに置く。PETG、0.2 mm層を出発点とし、3.3 mmの隙間は短いブリッジになる。ナット座天井もブリッジ。下面のバリと溝の垂れを除去してから確認する。

1. カメラを抜いたケースで、2枚爪が手で無理なく入るか確認する。
2. ケースの穴と試験片の穴が合うこと、ヒンジやリブに接触しないことを確認する。
3. 純正ねじは上爪側、ナットは下面側。合うナットに手でねじ込めることを確認。強い締付けで隙間を潰さない。
4. 入らない・穴が合わない・柄が干渉する場合、その箇所を記録する。本品では角度保持や荷重試験を行わない。

本設計ではケース本体を基準面に予圧して回転を止め、解除可能な押さえを追加する。ヒンジ、蓋合わせ面、ボタン、レンズ窓には押さえ荷重をかけない。接触面形状、許容姿勢ずれ、使用荷重、着脱再現性は未検証。

# xdcr_pole_jig — TD04A ポール治具 (実験用)

**機体部品ではなく、対面測距試験 (E1) 用の治具。**

| 項目 | 値 |
|---|---|
| 区分 | 共通 / 治具 / 3Dプリント |
| 設計ソース | `xdcr_pole_jig.scad` (バリアント定義 `variants.txt`) |
| 個数 | body ×2 / cap ×2 (送受のポールに 1 セットずつ) |
| 外形 (body) | 76.4 × 75.4 × 40 mm / 167.8 cm³ |
| 外形 (cap) | 76.4 × 9.0 × 40 mm / 25.7 cm³ |
| STEP | body 438 面 / cap 443 面 (下記参照) |

## 役割

VP25 塩ビポール (縦) にクランプし、TD04A を水平に保持する。
`part="body"` (本体) と `part="cap"` (クランプ蓋) を M4 ×2 で締める。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `pole_d` | 32.4 | VP25 実測外径 ~32 + すべり嵌め余裕 (**要フィットテスト**) |
| `clamp_h / clamp_gap` | 40 / 3 | ポールを掴む高さ / 締め代ギャップ |
| `xdcr_d / xdcr_len` | 26.0 / 55 | TD04A 胴径 (**要実測**) + 0.5 / クレードル長 |
| `tie_w / tie_t / tie_n` | 5.5 / 2.5 / 2 | 結束バンド (4.8mm 帯) ×2 |
| `wall / bolt_d / bolt_head` | 6 / 4 / 8 | 主要肉厚 / M4 クランプボルト |
| `arm_len` | 18 | ポール中心 → クレードル中心の水平距離 (短いほど剛) |
| `chamf` | 0.8 | 底面チャンファ (エレファントフット対策) |

## 印刷向き

body / cap とも底面 (ポール溝と直交の平面) を下にしてそのまま印刷。

## 既知の観察事項 — STEP が 438 / 443 面

`scad/lib/util.scad` の `box_rounded()` (hull / offset ベース) を使っているため、
角丸が STEP で**微小平面にファセット化**されている。
これはリポジトリの設計規約「角丸は Fusion 側で付ける」に反するが、
**治具は STL から直接印刷する前提**なので実害はない。

機体部品として作り直す場合は `box_rounded` を使わず、cube/cylinder +
ブーリアンで組み直すこと (`CLAUDE.md` の設計規約参照)。

## 部品外の考慮

- **ポール実測が必要**。VP25 の呼び径と実外径は違う (呼び 25 → 外径 ~32)。
  ロットでもばらつくので、使う現物で測ること。
- 試験時の**水深と向き**を再現できること。ポール上の高さ位置は治具では決まらないので、
  ポール側にマーキングするなど運用で担保する。
- TD04A のケーブル 3m がポールを伝って水面上に出る。**結束バンドで固定**し、
  振動子を引っ張らないこと。
- 送受 2 本のポールの**距離と平行度**が測距結果に直結する。
  設置手順は `../docs/AquaBeacon_実験検証仕様書.md` 参照。
- 屋外・水中での使用。**紫外線と吸水**で寸法が変わるので長期保管しない。

## 要確認

1. VP25 実外径 → `pole_d` を更新して再ビルド、フィットテスト
2. TD04A 胴径・胴長 → `xdcr_d` / `xdcr_len` (`xdcr_socket` と共通の実測項目)

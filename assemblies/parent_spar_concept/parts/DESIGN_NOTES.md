# 親機・縦長外装案（2026-09-09）

2026-09-10改訂版は [ねじ固定・X1 Carbon対応版](../parent_spar_bolted/README.md)。本フォルダは旧配置検討案として保存。

既存タカチ BCAS212310G を使うという今回の確認を反映した外装の一次設計。旧 `parent_assembly` は変更していない。OpenSCAD の `part` を切り替えて全体・分解配置・個別部品を表示する。全体の浮体、錘、カメラ、GPS、IMU、蓋は配置用包絡形状であり、製造用の防水部品ではない。

## 搬送と組立

1. 上部（箱・デッキ・浮体・上側支柱）を一体で運ぶ。最大高さ約418.3。上部筐体のシールを開けずに下部を外せる方針。
2. 下部支柱を継手に差し込み、M6通しピンを抜止め付きで固定する。モデルのピン中心は継手中心から上下20。実際の金属角管にも対応する加工が必要。
3. 垂直フィンを上下ハブに差し込み、M5通しボルト・座金・ナットで固定する。上下ハブ間のフィン穴ピッチは101。
4. 円盤は下ハブ底面へM5×4で固定。ハブを支柱に軸方向固定するストッパーと、錘の荷重を受ける金属金具は別途必要。現モデルはこれらの詳細を含まない。
5. 完全分解すれば円盤は225×225×5、フィン4枚は65×125×16に重ねられる。`packed` は部品の平置き表示であり、収納箱の最適化結果ではない。部品の枚数・ナット数が多いため、現場ではフィンユニットを組んだまま継手だけを外す運用も可能。

## 波による揺れへの設計意図

下部の錘で重心を下げ、水平円盤と垂直4枚の水中抵抗で揺れを減らすことを狙う。効果の大きさや転覆しないことは未検証。旧双胴フロート用 `parent_hydrostatics.py` のGM・喫水値はこの構成には適用できない。

浮体の外形体積は約6.11 Lだが、中心穴と上部切欠きがあるため有効排水量はこれより小さい。これを積載可能重量として扱わない。総重量、浮体材の吸水・密度、上部機器の重心、テザー張力、錘の水中重量から喫水・復原性を再計算する必要がある。円盤と4枚のフィンが常時水中にある喫水を目標とする。

## 製作前に確定する項目

- 浮体の現物・材質・固定方式。フォームの包絡形状を中空FDM容器として印刷しない。
- 錘の質量と金属による荷重経路。プリント継手だけで吊り荷重を保証しない。
- カメラ（現行のOsmo防水ケースか別機種か）、撮影方向、GPSアンテナ、IMUの型番と固定穴。表示は70×30×50、直径60×18、30×30×6の予約空間であり、実機の寸法保証ではない。
- 上部のM6ピンへアクセスするための浮体分割または工具窓。浮体は着脱できるクランプ方式等を次工程で設計する。
- テザー・TD04Aの取付とケーブル経路。今回の構成に未配置。円盤への巻付きやフィンとの接触を避ける配索と張力止めが必要。
- 金属角管と穴の公差、抜止め、座金、ハブの軸方向ストッパー。スライド嵌合は全幅+0.5の仮値。
- 箱上の蓋・ケーブル引込み・カメラ取付の防水方法。既存箱の密閉性を変更する加工は未設計。

## 出力と検証

`disk / fin / hub / coupler / adapter` のSTLは印刷方向で出力。フィンは広い面を下、円盤は水平、ハブ・継手は軸方向を立て、アダプタはデッキ接触面を下にする。横穴は穴仕上げを前提とする。PETG等での試作を想定し、強度・耐候性・水密性の評価は別途。

`verify.py` はOpenSCADで5種類をレンダリングし、trimeshで寸法・単一ボディ・閉じたメッシュを検査して `mesh_checks.json` に保存する。閉じたメッシュという判定は実物の水密性・強度を意味しない。全体プレビューを目視確認。製品全体の接触検査・波浪試験・浮力試験は未実施。

`export_step.py` は既存のCSG→STEP変換器で部品ごとのSTEPを出力し、STLとの外形・体積照合を行う。全体は配置検討用SCAD、部品STL/STEPは形状試作用。量産・実海域投入用の完成設計ではない。

## 印刷 (X1-Carbon)

- **上下反転** (デッキ上面をベッドに)。側壁・キール壁・座がベッドから立つ。`topopt overhang`
  (反転 STL): **要サポート面積 3.6 %** = キール座板 (t10) の壁間 32 mm ブリッジ ×3 と側壁窓の
  45° 屋根。**サポート不要** (X1C のブリッジで可。気になれば座板下のみサポート)。
- 主引張 (側壁の曲げ = Y 方向、板の曲げ = XY 面内) は層面内。`topopt print --keep-flat Z` の
  「load vs layers FAIL」は `--load-axis 0,0,1` を与えたためで、実荷重方向 (Y) では PASS。
- 材料 PETG (屋外・水・紫外線なら ASA)。壁 4 本 / インフィル 25 % (ジャイロイド) / 上下 5 層。
- HP40 のインサート下穴 (Ø6.4) は反転印刷で座板側が上面になるので、印刷後にそのまま熱圧入できる。
  側壁の横穴 (Ø6.4 / Ø8 / Ø14) は水平穴 = 上面がやや垂れる。Ø6.4 は熱圧入時に馴染む。
- 反り対策: 216 × 236 の全面ベッド接触。ブリム 5 mm、ベッド中央。

## 部品外の考慮

- **ケーブル**: 南壁ペネトレータ (箱外 z 65) → 南縁切欠き → キール南端フェアリード →
  南座ソケットの底穴 Ø9 / HP40 中央 Ø14。TD04A の 3P プラグは通らないので**箱内で切って
  端子台**に落とす (`wetlink_penetrator_m10.md`)。テザーは南端フェアリードで**張力止め**を
  してからペネトレータへ (シール部に引張をかけない)。
- **喫水**: 浮子軸 z 0・総質量 3.14 kg で喫水線は **z ≈ −2.7** (`spec/parent_hydrostatics.py`) = デッキ板がほぼ全部水中、
  箱底が水面。側壁・キール・TD04A 面 (−104) は水中。デッキは密閉インフィルの PETG なので 0.84 L の浮力体でもある。
  水抜き穴 (キール座の Ø14、側壁窓) から水が入っても抜けるので問題なし。
- **水抜き**: デッキ板上面は箱が覆う。側壁の軽量窓とキール壁間の通路は水が抜ける。
  キール座の中央 Ø14 はケーブル穴兼水抜き。
- **GPS アンテナ**: 箱の蓋の上 (最頂部)。デッキは関与しない。北壁の引込みグランドは未定。
- **工具アクセス**: 箱固定 M4 は蓋を開けて上から (箱内側から) 締める前提。ヨークの M5 は
  ヨーク外面のざぐりから六角レンチで締める (デッキ側はインサート)。
- **持ち上げ**: 側壁の紐穴 ×4 に吊り索を通す。箱の蓋やペネトレータを掴まないこと。

## 要確認

1. **箱の外部取付穴の使い方** (ねじを箱内側から下へ通せるか / 穴が貫通か)。現物で確認 →
   通せなければ下から M4 + 箱内ナット (要防水) に変更
2. 浮子実測 → ヨーク・喫水の再計算 (デッキ自体は変わらない)
3. Osmo 固定ジグ (北座) の設計: 座面 (z −60) が喫水線 (≈ −3) より下なので、ケースをそのまま座に付ければ水中
4. ペネトレータ頭 (箱外 22 mm) とケーブルの曲げ半径 (切欠きまでの落差 65 mm)

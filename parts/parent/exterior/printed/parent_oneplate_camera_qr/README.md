正本はspec/parent_exterior_revision_sources.py。共通quick_release_prototypes.scadのtwist_female()/twist_male()を直接再利用する。子機のC式と同じ60°回転・M3横ロック・厚1 mmゴム2枚。嵌合面・爪・カム・ゴム座は形状保持の例外とし、加工や一括丸めをしない。追加60×60取付板（female厚10、male厚6 mm）はR3・縁0.5 mm、穴入口0.3 mm。

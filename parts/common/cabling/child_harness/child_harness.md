## 役割

CHILD_MAIN / CHILD_PWR / RX 基板間の JST-XH ハーネス、電池 XT30 リンク、
LED・外部センサのピグテールを **ワールド座標のキープアウト立体** として
モデル化する。実配線が確定する前に `check_asm_contacts.py` / `verify_child_interior.py`
で他部品との干渉・チューブ包絡を機械検証するためのもので、印刷対象ではない。

- 1 ポリライン = 直線区間ごとの `cylinder` + 内部関節ごとの `sphere`。
  メッシュ品質のため (下記) 全頂点に球を置き、円柱を両端 0.03mm 延長して
  重ねている — モデルとしての経路は変わらない。`$fn=24`。
- XH プラグ筐体は `xh_plug()` が **ピン数・ピッチ・行方向** から自動算出する
  cube (行方向 = `2.5*n+2.4`、直交方向 5.75、ヘッダ 7.0 の上に高さ 7.4)。
  ワイヤ引出点はプラグの基板と反対側の面の中心 (`conn_wire()`)。
- 座標系: X=幅 / Y=積み方向 (+Y=LCD 側) / Z=チューブ軸。デッキ下面 y=-10、
  デッキ上面 y=-6 (`assemblies/child_interior/placement.json` と同一)。

### STEP について

`csg_to_step.py` の体積照合で全バリアントが STL フォールバックになる
(union する円柱・球の数が多く CSG→B-Rep 変換が体積不一致と判定するため)。
**ケーブル形状は面が多くファセット化された STEP でよい** — Fusion で
編集する対象ではなく、干渉確認・可視化用の骨格である。

## 配線区間の説明

- **-X スリット (z 96、長さ 26) / -X ケーブルレール (x=-36, z 20-130)**:
  `xh6_rx` / `xh3_teth` / `xh4_temp` / `xh2_leak` / `led` が共有する。
  レール底に**窓** (ローカル y 70..84 = 世界 z 90..104、チャンネル幅 8 で底板を貫通) があり、
  これによってデッキの中段スリット (z 83..109) がレール底板で塞がれないようになっている。
  レールのトラフ内は 5 本まとめて x=-36 (チャンネル中心) を通し、touching は
  許容 (ブリーフの「ハーネス同士は接触可」)。
- **+X スリット (z 96、窓経由) / +X ケーブルレール (x=36)**: `xh4_prs` と `bat` (電池リード・
  XT30 ペア・ピグテールの一部) が共有。同じく−X側と同様に窓を通して通す。
- **底リブ ダクト (`child_vtray_rib.scad`: x -20..20, y -36..-14, z 2.5..8.5)**:
  `xh3_teth` / `xh4_temp` / `xh2_leak` / `xh4_prs` / `led` の外部行き 5 本が
  ここを通る。実測寸法 (ブリーフの「x ±20」は概算だったので `.scad` の
  `duct_w=40`/`duct_y0=-36`/`duct_y1=-14` から取得) を基に、通過点を
  \|x\|≤16 に集約して 1.0mm 以上のマージンを確保した。
- **結束点**: 各ケーブルレールには `tie_y=[10,35,62,92,105]` (レール ローカル
  Y、レール取付 z0=20 を足すと機体 Z) の結束バンド スロットが、底リブには
  `tie_x=±26, tie_y=-19` のスロットがある。実配線時はここで結束すること。

## J_BAT / J_LED について

CHILD_PWR の `J_BAT` (XT30PW-M) と `J_LED` は **未実装 (部品未実装)**。
ピグテールは基板のパッドへ直接はんだ付けする想定 (コネクタを介さない)。
モデルでは `J_BAT_C = (21.4, 5.6, 145)` (2 パッド 147.5/142.5 の中点) /
`J_LED_C = (-21.4, 5.6, 146)` にワイヤ始点を置いている。

電池側 XT30 (メス、ケーブル取付済み) は `+X` レールのトラフ内に
x 32.5..39.5 / y -22.4..-12.4 / z 25..55 の直方体で表現。

## メッシュ品質について (要確認への影響なし)

初回ビルドで各 STL が 8〜50 本の open edge (non-manifold) を持っていた
(円柱同士・円柱と球が正接するだけで面が共有されない箇所)。
`polyline()` を全頂点に球 (`d*1.02`) を置き、`seg()` の円柱を両端 0.03mm
延長する実装に変更し、6/9 バリアントは "watertight: looks closed" まで、
残り (`xh6_rx`=2 / `xh4_temp`=10 / `xh2_leak`=16 / `xh4_prs`=6 / `bat`=8) も
大幅に減少した。残存分は急な折れ (>90°) 付近の facet 継ぎ目とみられ、
クリアランス判定 (`check_asm_contacts.py` の inward-sample 法) には
影響しない範囲であることを確認済み (下記の検証結果を参照)。

## 干渉確認 (2026-09-03 最終)

`scad/lib/check_asm_contacts.py --ignore-threads` (interior グループ全 85 アイテム +
本ハーネス 9 種) と `scad/lib/verify_child_interior.py` を実行。

- **貫通 (penetration>0) は全て許容設計**:
  - ハーネス ↔ 接続先基板 (`child_main` / `child_pwr` / `rx_improved_mini`):
    プラグが基板 STL のヘッダ上に載る設計どおり (ブリーフの許容例外)。
  - ハーネス同士: 許容 (ブリーフの許容例外)。
  - ピグテール始点 ↔ 基板 STL 内の XT30PW モデル (未実装): `J_BAT` / `J_LED` パッドへの直付け設計。
  - 電池リード始点 ↔ リードスタブ: `lipo_35x26x110_leads.stl` のスタブ先端との合致。
- **レール底の窓と経路修正によってレール貫通は 0**:
  旧設計の「組立順序に依存する許容」(トラフ床への上からの進入) は、
  z 90..104 の窓と −Z 端からのハーネス出入りで解消。
- **`verify_child_interior.py`: 9 バリアント全て PASS** (チューブ包絡に対し
  最小径方向クリアランス 3.05〜12.38mm)。床板タブは貫通口内で余裕 0.68 = WARN、意図どおり。

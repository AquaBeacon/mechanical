# child_clamp_strap — 子機 チューブクランプ 上ストラップ

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_clamp_strap.scad` |
| 個数 | 2 |
| 外形 | 180 × 70.8 × 26 mm |
| 体積 | 57.0 cm³ |
| STEP | **5 ソリッド** / 35 面 (下記参照) |

## 役割

`child_clamp_base` に M4×2 で締結する上側半リング。クランプ面には
薄ゴム/EVA シートを貼り、締め代はシート圧縮で確保する。

## 主要寸法 (`.scad` の Customizer 変数)

| 変数 | 値 | 意味 |
|---|---|---|
| `tube_od` / `fit_clear` | 114.3 / 0.5 | **base と一致させること** |
| `band_t` | 8 | バンド肉厚 (半径方向) |
| `band_w` | 26 | バンド幅 (軸方向) = base の `saddle_d` |
| `m4_x` | ±78 | M4 位置 = base と一致 |
| `head_d / head_t` | 8.5 / 4.5 | M4 頭の座グリ |

導出: 外半径 `r_out = 65.4`、耳の下面高さ `chord_z = -5.4` (base ブロック上面と整合)。

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_clamp_base` | M4 ×2 (x = ±78)。ナットは base 側 |
| `wte4_acrylic_tube` | リング内面で押さえ (保護シート介在) |

## 干渉チェック (`.scad` 冒頭の assert)

- M4 穴・M4 座グリがリング外周と干渉しないこと
- 耳がチューブ断面より外側にあること

## 印刷向き

平置き (リング面を下)。M4 穴は垂直に開くのできれいに出る。

## 既知の観察事項

CSG→STEP 変換の結果が **5 ソリッド**になっている (メッシュは watertight、
体積・外形は設計どおり)。`linear_extrude` した 2D ブーリアンが FreeCAD 側で
分割されたためと思われる。**Fusion 360 で読み込んだ際に 1 ボディに結合できるか
確認すること**。印刷用の STL には影響しない。

## 部品外の考慮

- 座グリがあるので M4 ボルトの**頭が沈む**。ボルト長は「バンド厚 8 − 座グリ 4.5
  + base 側のねじ込み代」で選ぶこと。
- 締め込み過ぎるとアクリルが割れる。保護シートの圧縮量で管理する。
- リング上面を配線・結束バンドが通る場合、M4 頭の座グリ位置を避ける。

## 要確認

1. `child_clamp_base` と `tube_od` / `fit_clear` / `m4_x` / `band_w` が一致しているか
   (両ファイルに同じ値が二重定義されている。片方だけ直さないこと)
2. STEP の 5 ソリッドが Fusion で問題にならないか

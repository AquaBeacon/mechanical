# parent_pwr — 親機 電源・配電基板

KiCad で設計した自作基板の 3D モデル。**このリポジトリでは編集しない** —
`hardware/pcb/PARENT_PWR/` が設計ソースで、ここには成果物を置くだけ。

| 項目 | 値 |
|---|---|
| 区分 | 親機 / 内装 / 基板 |
| 生成元 | `hardware/pcb/3d/PARENT_PWR.step` / `PARENT_PWR_mech.stl` |
| 生成コマンド | `python -X utf8 pcb\export_3d.py PARENT_PWR` (Kicad_project 側) |
| 使用数 | 1 |

## 寸法 (`_mech.stl` の実測。仮値ではない)

|---|---|
| 外形 (W × D) | **100.0 × 84.0 mm** |
| 板厚 | 1.6 mm (STL の z = 0 〜 1.6) |
| **基板上面からの最大部品高さ** | **23.52 mm** (STL z = 25.12) |
| **裏面リード突出** | **8.15 mm** (STL z = -8.15) |
| 全高 | 33.27 mm |
| 体積 (部品込み) | 24.0 cm³ |
| 高背部品 | Cosland 2MD1 トグルスイッチ ×2 = 23.52 |

## 座標系

STL / STEP とも **X = 0..100.0 / Y = -84.0..0 / Z = 板が 0..1.6、部品が +Z**。
KiCad の基板左上が原点なので **Y が負**になる。`placement.json` の `ops` は
これを前提に書いてある。

## 取付穴 (H1〜H4)

`.kicad_pcb` の実座標 (基板左下を原点、Y は上向き正):

(3.4, 77.4) / (93.4, 77.4) / (3.4, 3.4) / (93.4, 3.4)

→ ピッチ **90 × 74 mm**。Ø3.2 (M3 クリアランス)。

## 部品外の考慮

- **コネクタの抜き差し空間**を基板の外に取ること。上表の位置は基板座標なので、
  `placement.json` の変換を通して機体座標に直してから干渉を見る。
- ケーブルは `docs/配線・ケーブル計画.md` に集約する。
- 基板を**アセンブリでビルドすると STEP が重い** (この基板の STEP は銅箔・
  ベタ・シルクまで入っている)。プレビューだけでよいときは `-NoStep` を使う。
- `_mech.stl` は KiCad の STEP エクスポータ由来なので、
  **水密でない場合がある** (部品ソリッドが基板に食い込んでいる箇所)。
  干渉確認には使えるが、体積・浮力計算には使わないこと。

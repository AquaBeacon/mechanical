# DJI式・80°溝・締付力40 Nのラッチ

**[印刷一式：parts/PRINT.md](parts/PRINT.md)**。樹脂4種類5点を一式交換する試作です。

**強度検証は未完了です。** CADの開閉・工具通路・STL/STEP一致は確認済みですが、爪・受けを継ぎ目へ寄せた今回の形状は構造解析を再実行していません。以前の解析は旧形状の記録です。実用強度を保証する完成版として扱わず、詳細は下記計算文書を確認してください。

左右の短いリンクと、B軸で支持する爪付き上蓋レバーを使います。操作部をBより外側へ約43 mm延ばし、台の80°溝へシンプルな台形の爪を掛けます。専用ストッパーは設けず、レバー後端が台へ直接着座します。

台厚は固定側17→6 mm、受け側17→8 mm。受けのくぼみ下には2 mmの底肉を残します。台取付穴6本のX/Y配置は維持し、受けの閉配置はX=12.4 mm。旧樹脂部品との混用はしません。

40 Nは閉時の**水平締付力**の目標です。外力耐力や手の操作力を意味しません。WAKI EPGR-01の1 mmシートを30×1.8 mmで3枚積層し、硬度を仮定した概算から閉圧縮約0.433 mmを設定しています。実物の締付力を測り、接着後の厚みに合わせて調整してください。

A軸M3×20皿ねじを継続、B軸は工具通路のためM3×35キャップねじへ変更。PETG Basic・0.4 mmノズル・0.2 mm層・6周壁・100%インフィル。印刷姿勢はparts内STLへ反映済みです。

[組立・ゴム・印刷の詳細](../../parts/common/jigs/over_center_latch/README.md) / [機構計算と構造検証](../../spec/over_center_latch/HOLDING_CALCULATION.md) / [組立STEP](over_center_latch.step) / [形状プレビュー](_work/images/over_center_latch_iso.png) / [動作動画](_work/images/operation.mp4)。配置の正本はplacement.json。

CADと構造解析の結果は上記計算文書に記録しています。40 Nの実測校正、疲労・クリープ・防水性は未確認です。実機取付先・周辺部品・ケーブルはこの独立治具に含まれず、組込時の干渉・取付強度は別途確認が必要です。

継ぎ目X=2.1から爪の80°接触面中心X=9.6まで7.5 mm（実際の分布反力中心は約7.47 mm）。保持段の接触点は約7.81 mm。B軸から接触面までの水平距離は約16.53 mmです。台の外形・取付穴の世界座標は維持し、受けの局所取付穴X=18.6へ補正しました。閉じ角150°に合わせ、死点付近の過大なゴム圧縮を抑えています。

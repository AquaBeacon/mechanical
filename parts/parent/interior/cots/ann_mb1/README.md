# ANN-MB1-00ケース内使用

Switch Science 9455。ref/ANN-MB1_UBX-21005551_R04.pdfを参照。外形82×60×22.5 mm、M4穴ピッチ68、穴Ø4.5、RG174 5 m。質量164 gはケーブル込みのメーカー値。磁石とねじ固定に対応。

完成品CADは未取得。ann_mb1.stepはメーカー図面の取付包絡。丸み・ケーブル根元・磁石などの内部詳細は省略し、原寸図面の代わりには使わない。

ground_plate_internalは購入鋼板88×60×1 mm。メーカー性能測定用Ø120 mmの円形グランドプレーンより小さい。ケース内で蓋を閉じ受信・RTK性能を確認。アンテナ上に基板・金属・束線を置かない。

鋼板穴位置は板中心を原点にmm：Ø3.5を(X,Y)=(±40,±25)の4か所、Ø4.5を(±34,0)の2か所。外周・穴縁はバリ取りする。機械加工用形状は`ground_plate_internal.step`。印刷セットへ含めない。

coax_routeは固定側SMAまでの径2.8 mm・経路曲げR20以上の仮同軸。coax_route_clearanceはキャリア切欠き用の径5 mm逃げ。coax_coil_keepoutは巻取り予約体積で、実際の巻き・尾線ではない。実ケーブル外径・許容曲げ半径・引張り逃がしを確認する。すべて非印刷。

GNSS抜出し時はSMAを外し、`coax_parked`・`sma_plug_parked`の参考姿勢でアンテナ側へ退避させる。接続状態の同軸は基板の抜出し経路と交差する。退避経路はR20で、巻取りの尾線・実際の余長は現物確認。アンテナ包絡のM4頭逃げR4・高さZ6以上は仮の細部形状であり、実物ハウジングへ穴あけする指示ではない。

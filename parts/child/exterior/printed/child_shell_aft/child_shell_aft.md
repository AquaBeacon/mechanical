## 役割

耐圧容器 (WTE4 4″×200mm) を縦置きで抱える 2 枚シェルの**常設側**。
manafish ROV と同じく「容器を 3Dプリント部品で挟む」構成で、
前半シェル (`child_shell_fwd`) を M5 蝶ボルト 4 本で外すと容器が真上に抜ける。

1 部品で以下を兼ねる。

| 機能 | 実装 |
|---|---|
| 容器の保持 | 内径 Ø116.7 の半円筒スキン (肉厚 6)。EVA/ゴムシート 1.2mm を貼って締める |
| **吊り点** | 吊り耳 ×2 (x=±80, z=234, Ø16 穴)。ロープは**2点ブライドル**で上へ |
| **取っ手** | 後部パイロン内の六角バー (握り径 26、指スペース 43mm) |
| TD04A の保持 | パイロン屋根 (z=182, y=-86) に `xdcr_socket` を M5×4 で上向き固定 |
| ケーブル導管 | パイロン内部が後方に開いた空洞。下から上まで素通し |
| 下部ガード取付 | 底フレアのボス ×4 (r=70, 方位角 ±40 / ±68) |
| ドームの保護 | 吊り耳がドーム両脇に立ち上がり、横倒し時の当たりを受ける |

## インタフェース (**二重定義。片方だけ直さないこと**)

| 相手 | 共有している値 |
|---|---|
| `child_shell_fwd` | `skin_t=6` / `shell_z0=18` / `shell_z1=190` / `rail_x0=56` / `rail_x1=80` / `rail_t=10` / `bolt_x=70` / `bolt_z=[42,150]` / `pin_z=100` / `flare_r=78` / `flare_h=10` / `tube_od=114.3` / `pad_t=1.2` |
| `child_bottom_guard` | `guard_r=70` / `guard_a=[40,-40,68,-68]` / `shell_z0=18` (= ガードの `lug_r` / `lug_a` / `lug_z1`) |
| `xdcr_socket` | `base_w=60` / `hole_p=40` (ソケット側) ↔ `xd_pitch=40` |
| `wte4_dome_cap` | `dome_ring_od=114.3` → 逃げ径 Ø122.3 |

ボルトボスは **y = -24..0 の 24mm 厚**。前半シェルのボス 14mm と合わせて
M5×35 蝶ボルトが、後半シェルのナットトラップ (y=-16..-20.4、横挿し) に届く。

## 干渉チェック (`.scad` 冒頭の assert — 実際に止まったもの)

自動チェック (watertight / ソリッド数) では**捕まらない**ものだけを assert にしてある。
下の 3 つは今回の設計中に実際に assert が止めて、**形状の方を直した**。

1. **取っ手バーが屋根の中央リブと干渉** → リブ下端を 128 → 145 へ上げた
2. **TD04A の前側取付穴の真上をスキンの外向きカラーが覆い、下穴が「閉じた空洞」になった**
   → 上カラーを廃止 (丸めは Fusion で付ける)。ソリッドが 3 個に分離していた
3. **結束スロットの角がパイロン下面の 45° 斜面にちょうど接して非マニフォールド**
   → スロット z を 70 → 74 に逃がし、斜面との離れを検査する assert を追加

そのほか常時検査しているもの:

- 吊り耳ボスの最内点がドーム抜き取り経路 (Ø122.3) の外にあること (**現在 r=65.8 / 必要 62.2**)
- 締結 M5 とナットがチューブ穴に噛まないこと / ナットがレール内に収まること
- 吊り耳がボルトボスと重ならないこと (重なるとナットの横挿しスロットが塞がれて**組めない**)
- 取っ手の指スペース ≥ 35mm (**現在 43mm**)、握り径 24〜34 (**現在 26.0**)
- 内部空洞がスキンを食わないこと (食うとチューブが露出して保護にならない)
- ガード取付ボスが空洞/レールに掛からないこと・底フレア内に収まること
- 通水穴・結束スロットがレール/パイロン/吊り耳/45°斜面に掛からないこと
- 全幅 ≤ 250 / 後端 ≤ 125

ビルド後は `_work/images/child_shell_aft_preview.png` の front / top / side を目視すること。

## 強度

| 項目 | 値 |
|---|---|
| PETG 設計許容応力 | XY 12 MPa / Z(層間) 6 MPa (極限 45 / 25 MPa に安全率 4) |
| 吊り荷重 (全備 5.7kg × 動的 3g、ブライドル 30°) | **1 耳あたり 99 N** |
| ロープ穴上部のせん断抜け (10mm × 24mm × 2面) | 0.21 MPa → **安全率 29** |
| Ø16 穴の支圧 (16 × 24) | 0.26 MPa |
| 吊り耳 根元の曲げ (16 × 40 断面、腕 50mm) | 1.17 MPa → 安全率 10 |

吊り耳は**積層に垂直な引張**を受ける最悪方向なので、スライサで
**壁 5 本以上・インフィル 40% 以上**にすること。それでも上表の余裕がある。

## 印刷向き

- **このまま (Z が積層方向)。サポート不要。**
- 底フレア (z 18..28) がベッド接地面。**ブリム 3mm 推奨**
- パイロン下面は 45°、吊り耳の外側下面も 45° に逃がしてある
- 取っ手バーは六角の頂点下向き (下面 60°)、横穴はすべてティアドロップ

## 部品外の考慮

- **ロープは 2 点ブライドル**。1 点吊りにすると吊り耳 1 個に全荷重が掛かり、
  さらに機体が回りやすくなる。ブライドルの脚長で吊り姿勢 (前後の傾き) を調整する。
  重心が吊り点より約 6mm 前にあるので、**バラストを後ろ寄りに置いて合わせる**
  (`child_bottom_guard` の M6 穴 5 箇所)。
- **テザーは下のキャップから出て、機体の外を回って上へ戻る**。パイロン側壁の
  結束スロット (y=-85/-100 × z=74/92/158) に沿わせ、上端でロープに巻き付ける。
  **テザーの張力はロープで受け、ペネトレータには掛けない。**
- **TD04A のビーム (指向角 22°) は上向き**。ドーム・吊り耳・ロープのどれも
  ビーム内に入らない配置にしてある (振動子軸 r=86、最寄りの吊り耳まで 110mm、
  11° の円錐がそこへ届くのは面から 567mm 上)。**ただしブライドルのロープは
  約 440mm 上でビームに入る** — 細径なので影響は小さいが、実験時に確認すること。
- **取っ手はパイロンの後ろから手を入れて握る**。窓は下端 (45°斜面) から z=140 まで
  開いているので、グローブをしたままでも入る。
- パイロン内部は下も後ろも開いているので**水は溜まらない**。前面には Ø16 の
  通水穴 ×6 を開けてチューブの目視点検もできるようにしてある。
- **陸上ではドームが上を向く**。`child_bottom_guard` の脚で自立するので、
  ドームを直接接地させない。
- アクリル/PC は有機溶剤に弱い。スキン内面に貼る EVA シートの接着剤に注意。

## 要確認

1. `wte4_dome_cap` の押えリング OD → 逃げ径 Ø122.3 の妥当性 (現在 114.3+8 で設計)
2. TD04A の胴長 → 振動子上端が z=243 でドーム頂点 (261) より低いことの確認。
   胴長 73mm を超えるとドームより高くなる (全高は変わらないが見た目と保護が変わる)
3. M5 蝶ボルトの入手 (M5×35、4 本)。ナットは M5 六角 ×4 (横挿し)
4. スキン内面の EVA/ゴムシートの厚み実測 → `pad_t = 1.2` の調整

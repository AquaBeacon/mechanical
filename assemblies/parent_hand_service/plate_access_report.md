# 北側ペネトレータと床板の改訂（2026-10-27）

印刷入口は [parts/PRINT.md](parts/PRINT.md)。この改訂では床板も交換する。以前の「床板は無加工で再使用」「床裏のナットと座金を押さえて締める」という手順に優先する。状態は実物嵌合確認用の試作。強度・実印刷・実工具での操作は未認定。

## 確認した取合い

- WetLink M10をA側（北壁。本体側面外面Y=228.3、蓋外形の北端Y=230）に2個。A面を外から見た左端から35／60 mmで、箱座標X=175／150 mm。穴中心高さは外底面から30〜35 mm。表示モデルは32.5 mm、引抜き検査は高さ範囲全体を含む包絡で行う。
- 付属ナットも取付状態のまま残す。メーカーのナット・専用レンチのSTEPを使用する。対辺16 mmは[メーカーの組立資料](https://bluerobotics.com/learn/wetlink-penetrator-installation-guide/)でも確認した。
- ケース固定ねじはM4、頭径は約10 mm。頭の逃げは内接径10.8 mm。検査用の頭包絡は直径10×高さ5 mm、首下12 mmは旧モデルから引き継いだ仮定。高さ5 mmや首下12 mmを実物の確定寸法として扱わない。実ねじの頭高さ・首下長さ・工具は要確認。

ケース購入品の原本は未加工の参照モデルを維持する。ペネトレータは指定された既存穴の取付位置へ表示しており、ケース壁と本体ねじ部が重なる箇所は穴加工を前提とする。この改訂でケースへの穴加工や密閉の検証を完了した意味ではない。

## 変更した形状と配置

床の北端に、ねじ部とナットの通過幅を分けた開放切欠きを作った。ねじ部はX=144.2〜180.8、Y=207.2125から北側へ、ナット部はX=140.2〜184.8、Y=215.2から北側へ開放する。内部突出部に片側0.8 mmの設計すきまを取る。2本の溝の間に孤立する格子片を残さず、まとめて取り除く。ケース取付の使用3点は維持し、北東のM4穴は従来どおり使わない。

TX基板は西1 mm・南5 mmへ移動し、原点をX147／Y135.5／Z24.8にした。取付穴と床の支持座、上部20 mmの予約空間も追従する。基板自体のCAD・穴配置は変更しない。

Sony側の床取付軸は次のとおり。基板の4穴と高さ、板厚3.2 mm、支柱接合面Z60.5は維持する。移動後の格子から離れるPCBねじ座には短い支持腕をつなぎ、浮いたねじ座を残さない。

| 軸 | 改訂後X／Y [mm] | 対応する支持部品 |
|---|---|---|
| 前左0 | 142.5／134.5 | sony_fixed_column_0 |
| 前右1 | 201／134.5 | sony_fixed_column_1（形状・位置は従来どおり） |
| 後左2 | 142.5／202.5 | gnss_sony_shared_column |
| 後右3 | 201／204.5 | sony_fixed_column_3（形状・位置は従来どおり） |

同軸リング下面もM4頭に合わせて逃がす。電池台の旧8 mm工具穴は10.8 mmへ広げ、配線側の端まで開放して薄い残片を作らない。電池の収納・蓋の固定・ケースのM4座面高さは維持する。

## ナットの保持と締結経路

床側のM3ナット11か所を、上面開放穴と床裏の座金から、床の内部へ横から挿入するナット座へ変更した。六角穴は対辺5.8 mm、底Z13.0、屋根下面Z15.6。標準の対辺5.5×厚2.4 mmナットは締結後の下面Z13.2／上面Z15.6。屋根厚は端部面取りを除いて公称3.2 mm。

| 締結 | 継続使用するねじ | 反力までの経路 |
|---|---|---|
| MAIN枠4軸 | M3×30、4本 | 頭 → MAIN枠 → 床側受け → 同軸リング → 床 → 床の屋根 → M3ナット |
| GNSS4軸 | M3×65、4本 | 頭 → GNSS台 → 支柱 → 床 → 床の屋根 → M3ナット |
| Sony独立3軸 | M3×60、3本 | 頭 → Sony固定板 → 支柱 → 床 → 床の屋根 → M3ナット |
| 共有柱のSony側1軸 | M3×10、1本 | 頭 → Sony固定板 → 共有柱の上面・屋根 → 側面挿入ナット。共有柱は連続した橋と隣のGNSS床軸で固定 |

床ナット11個は再使用できる。従来の床裏の座金11枚はこの改訂では使わない。他の基板・アンテナ・電池のナットと混同しない。ねじ長さと先端位置は従来と同じで、GNSSねじ先端とケース床との公称余裕は0.5 mm。実ねじ長さ・有効ねじ部・実ケース床との余裕は実物で確認する。

六角面は回り止め、屋根は締付け時の+Z方向の抜け止め、底は逆向きの脱落止めとなる。挿入中は横口から出られるため、ねじが掛かるまでは指・工具で仮保持する。ねじが掛かった後は軸が横抜けを止める。ナットの挿入口、平らな反力面、六角の機能稜は指定断面を維持し、面取りで保持面を削らない。床外周・切欠き・M4口の扱い稜は面取りする。

挿入方向と作業セルの座標は [_work/analysis/plate_access_20261027/candidate_checks.json](_work/analysis/plate_access_20261027/candidate_checks.json) の各ラベルに記録する。床をケースへ入れる前に、上の板・支柱を載せない状態でナットを入れる。

## 組立と整備

1. 床板をケースの外で組む。床ナット11個を横から入れ、ねじが掛かるまで仮保持する。共有柱のSony側ナットも側面から入れる。
2. 支柱・同軸リング・固定板を載せ、表のM3ねじで固定する。固定対象の床を必ず締結経路に含める。TX基板を改訂後の4座へ取り付ける。
3. 2個のペネトレータとナットをケースへ残した状態で、北側切欠きを合わせて内装を下ろす。M4ねじ3本でケースへ固定し、配線を接続する。
4. 取り出すときは、蓋を外し、電源を切り、ケース側の配線を解放する。M4固定3本を外し、内装一式をまっすぐ上へ120 mm持ち上げてから横へ移す。ナット座の横口を配線で塞がない。ケーブルを引っ張って取り出さない。
5. ペネトレータのナットを操作する場合は内装を取り出してから、ケース内側へレンチを入れる。口をケース内面から約0.5 mm控え、ナットの軸長8 mmのうち約7.5 mmへ掛ける工具位置とする。検査対象はメーカーのM10専用レンチ（外径20.5、軸方向60 mm）と、挿入・360°回転の包絡。2個とも残した状態を検査する。ラチェット・横棒・任意のスパナまで共通に保証したものではない。外側本体を保持する工具も実物で確認する。

service.stepは、ケースとペネトレータを残し、内装一式を箱の横へ出した確認姿勢。実際の引抜きは最初に上方向へ行う。

## 再印刷する部品

床板、Sony固定板、Sony前左柱0、共有柱、電池台、同軸リングを各1個、計6個交換する。Sony右柱1／3など、形状が同じ部品まで重複して印刷しない。一式の入口はparts/PRINT.md。新しい床板を加えた全一式は20種類20個。既存の蓋とGNSS台も含め、このpartsだけで全体を印刷できる。既に使っている同じ形状の部品は再使用し、再印刷は上の6個に限る。

PETG、X1C／0.4 mm、0.2 mm積層、壁4周、100%充填を従来条件として引き継ぐ。6部品は原姿勢の下面をベッドへ向ける。同梱STLはベッドへ変換済み。ナット座・通し穴の支持材禁止モディファイアも同じparts内に同梱する。橋の造形と実物のねじ嵌合は試作確認が必要。

ナット座の屋根は短いブリッジを含む。G-codeの線分端と下層断面の照合では、すべての端が下層に載るという条件を満たしていない。サポートをナットの通路から排除できても、屋根の造形成立や保持耐力を保証しない。試作時は横口から屋根の垂れ・空洞・層間剥離を観察し、ナットの挿入と締付けを確認する。現段階を「サポートなし造形を実証済み」と扱わない。

## 正本と検証記録

床の既存生成元はspec/build_parent_hand_service.py／spec/parent_switch_tx_body.pyを継続する。新しい局所形状はscad/lib/parent_floor_access.py、寸法はscad/lib/parent_gnss.py。Sonyの支持形状、同軸リング、電池台も既存モジュールを更新した。生成SCADと印刷用STLを手編集しない。

メーカー原本はparts/common/exterior/cots/wetlink_penetrator_m10/ref/へ保存。ナットとレンチはメーカーSTEPを用いる。本体のメーカーSTEPは開いた面モデルを含むため、ソリッドへ補修して採用せず、従来のSCAD本体参考形状を継続する。STEPと同梱STLでは原点が異なるため、使用したSTEPからSTLを再生成する。

再生成・検証入口：

```powershell
python spec/revise_parent_floor_access.py
python spec/revise_parent_floor_access.py --related
python spec/publish_parent_plate_access.py --prepare
python spec/revise_parent_floor_access.py --verify
python spec/publish_parent_plate_access.py
python spec/publish_parent_plate_access.py --assemblies
python spec/slice_parent_plate_access.py
python spec/check_parent_plate_access_delivery.py
python tools/assembly_parts.py check parent_hand_service
```

段階ごとに成功を確認してから次のコマンドへ進む。解析・検査は_work/analysis/plate_access_20261027/、CAD基盤の入力スナップショット・再読込結果は同フォルダの*_run.jsonから参照できる。source hashを照合した床の基礎形状キャッシュのみ再利用し、条件が変われば作り直す。

閉メッシュ、STEP/STL整合、ナットの連続挿入と軸方向保持、締結座面、変更部の干渉、引抜きと工具包絡、スライス、実物試験は別々に評価する。最終の実行結果はassembly_checks.jsonとpublication.json、スライスの記録を参照。ケーブル実寸とサービスループ、実ねじ・実工具・印刷品、公差、締付けトルク、屋根の耐力、クリープ、波浪、密閉防水は未確認。旧形状のFEA・実験結果を今回の強度認定に流用しない。

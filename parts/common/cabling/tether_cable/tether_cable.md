# テザーケーブル (子機 ↔ 親機)

> 2026-09-16 購入記録照合: ワークスペース `docs/未踏ジュニア購入物品.xlsx` の24行は
> Fathom ROV Tether 4ツイストペア、1 m単位×30。以下の「未選定」は旧設計時の記載。
> 標準品公称外径7.6 mmを基に [輸送・保管リール](../../jigs/tether_storage_reel/tether_storage_reel.md) を設計した。
> 実測と既存機体のペネトレータ・配線経路への反映は未実施。

購入品 (COTS) / **未選定**。子機と親機をつなぐ唯一の物理リンク。
「部品ではないが機体形状を決める」代表例なので、部品と同じ扱いで管理する。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / ケーブル |
| 用途 | 電源供給 + RS485 データ |
| 長さ | **未定** (運用水深 + 余裕で決める) |
| 外径 | **未定** → ペネトレータ型番を決める入力になる |
| 型番 / 入手先 | **未選定** |

## 決めるべきこと (すべて機体形状に効く)

| 項目 | なぜ機体に効くか |
|---|---|
| 外径 | `wetlink_penetrator_m10` の型番 (4.5–8.5mm) を決める |
| 曲げ半径 (最小) | 後方キャップ内側のサービスループ半径、容器内の取り回し空間 |
| 質量 (kg/m) | 子機の浮力・トリム、バラスト 0.4kg の再計算 |
| 浮力 (正/負) | 中性浮力テザーでないと子機が引かれる |
| 芯線構成 | 電源断面積 (電圧降下) と RS485 のツイストペア/シールド |
| 外被材質 | 耐候・耐海水・耐摩耗 |

## 部品外の考慮

- **最小曲げ半径**は容器内で守れないことが多い。後方キャップ内側に
  半径分のスペースが取れるか、`assemblies/child_assembly` で確認すること。
  現状トレイ前端のケーブル余裕ゾーンは 30 mm しかない。
- **張力はケーブルではなくストレインリリーフで受ける**。ペネトレータのシール部に
  引張荷重をかけないこと。子機側は `child_frame_plate` の 40mm グリッド穴に
  アイボルト/結束点を設ける想定 (未設計)。**親機側も未設計**
  (南壁ペネトレータの外でテザーを受け止める点が要る)。
- **親機側の貫通位置が決まった (2026-08-29)**: ボックス南壁 (Y=0) x=120, z=65 の
  WetLink M10 (`pen_tether`)。落とし先は P-MAIN `J_TETH1` (箱 x≈123)。
  外被は箱の外で終わり、**箱内には素の導体が出る**ので端子台が要る。
- テザーの引き回しが `child_osmo_arm` のカメラ視野に入らないこと。
- 親機側の引込みは**南壁上部 z=65** (旧 `parent_plate` の引込みゾーン表は
  2026-08-28 の改版で廃止)。現行は [親機内装_収まり検討.md](../../../docs/親機内装_収まり検討.md) §7 が正。

## 要選定・要確認

1. ケーブル型番の決定 → 外径実測 → ペネトレータ型番決定
2. 電源電圧・電流から芯線断面積を計算 (`../docs/AquaBeacon_詳細設計書.md` 参照)
3. ストレインリリーフの設計 (現状 未設計。子機側・親機側とも必要)
4. 中性浮力にするか、フロートを付けるか

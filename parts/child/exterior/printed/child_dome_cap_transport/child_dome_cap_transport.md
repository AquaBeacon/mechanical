# child_dome_cap_transport — 子機 輸送専用 ドーム頂点キャップ

[docs/子機外装_改善要件.md](../../../../../docs/子機外装_改善要件.md) §3.5 (G2/G4, C3)。
運用時は取り外す部品 (C7 の「輸送時に外せる部品」に該当)。`child_top_crown` の
上に外嵌めし、ドーム頂点への打痕・傷を輸送中だけ防ぐ。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント / 輸送専用 (運用時は非装着) |
| 個数 | 1 |
| 外形 | 158 × 135 × 53.25 mm |
| 体積 | 185.6 cm³ → PETG 約 235.7 g |
| STEP | 1 ソリッド / 13 面 |

## 役割

- スカートで `child_top_crown` (カラー外径 Ø150、耳上端 z=256) に外嵌めし、
  M5 ノブボルト ×2 で工具レス固定
- 内筒はドーム (公称 OD 94.5、頂点 z=261.25仮) に対し全周・頂点とも
  ≥4mm のクリアランスを取った円筒 (円錐/球面は使わず cube/cylinder のみ)
- 後方 (−Y) はカットアウトして `xdcr_socket`/TD04A を避ける (TD04A は
  輸送時も装着したまま運用する前提)

## 形状の作り方 (段差を単一円筒で通す)

段差 (スカート ID152 → 内筒 ID123) を「別ソリッドの円板を突き合わせる」構成に
すると、境界面が接するだけで CGAL の union が **2 ソリッドに分離する**現象が
発生した (`solids=2` で検出)。対策として **外殻を単一円筒 (OD 一定 = Ø158) で
通し、内側のボア半径だけ高さで変える**構成に変更した (段差は内側だけ)。
外周に継ぎ目がないので、この種の分離は起きない。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `cover_r` / `cover_z0/1` | 61.5 / 256 / 265.75 | 内筒 (ドームクリアランス) 半径・高さ範囲 |
| `plate_t` | 6 | 天板厚 (quick_strength plate で決定) |
| `skirt_r` / `skirt_wall` | 76 / 3 | スカート内径 Ø152 / 外殻厚み (OD一定 Ø158) |
| `skirt_z0` | 218.5 | スカート内腔下端 (ゲート頂面 z218 に触れない) |
| `aft_az0/1` | 225 / 315 | 後方カットアウト (`child_top_crown` と同じ) |
| `cap_bolt_x/y/z` | 75 / -11 / 227 | M5 ノブボルト位置 (`child_top_crown` の熱圧入インサートと二重定義) |

## インタフェース (二重定義)

- **`child_top_crown`**: カラー/耳の外径 `r_out=75`(=`ear_x1`)、耳上端
  z=256、輸送キャップ用インサート `cap_bolt_x`(75) / `cap_bolt_z`(227)、
  軸 X。**この部品の同名変数と一致させること**
- **`wte4_dome_cap`** (仮値): 頂点 z=261.25 (座面208+dome_h 53.25仮)。
  実ドーム OD は `wte4_dome_cap_ref.scad` の式 `(dome_ir+dome_t)*2=94.5`
  (要件の「ドーム OD 114.3」という記述より狭い。要件書の値は旧押えリング
  OD 変数名との混同とみられるため、本部品は**より広い側の値 (114.3 相当)**
  を基準にクリアランスを取り、実測差を吸収できる方へ振ってある)
- **`child_core_frame`** (編集していない、値を借用のみ): `xdcr_socket` 座
  中心 (0,−75)

## 干渉チェック (`.scad` 冒頭の assert)

- ドーム側面クリアランス ≥4mm (実測 14.25mm、114.3 仮定でも 4.35mm)
- ドーム頂点クリアランス ≥4mm (実測 4.5mm)
- キャップ上端 ≤275mm (実測 271.75)
- キャップ外径 ≤160mm (実測 158)
- スカート下端 ≥218.5 (ゲート頂面に触れない)
- スカートがクラウン外径 (75) に嵌る (76 ≥ 75+0.5)
- ノブボルト位置がスカート内腔の高さ範囲内
- アフトカットアウト端から xdcr_socket 中心までの距離 ≥21mm

## 荷重と安全率

L2 輸送 300N (2026-09-04 緩和、5g) を天板中央で受ける想定
(円周支持相当の四辺支持で近似)。

```
quick_strength plate --a 123 --b 123 --t 6 --p 0.0252  (300N / π*61.5^2)
  曲げ応力 3.05 MPa (limit 12.0) PASS
  中央たわみ 0.71 mm (limit 1.0) PASS  (t=5 では 1.23mm で FAIL、t=6 で確定)
```

天板は逆さ印刷で第 1 層に近いため、層面内 (in-plane) の許容応力を使っても
妥当 (半径方向・接線方向の曲げ応力は印刷レイヤー面内)。interlayer (保守的)
の許容値でも PASS しているので確認不要。

## 印刷 (X1C, `topopt print --load-axis 0,0,1`)

**PASS**。`topopt print` 実測での最良姿勢は **-Y up** (オーバーハング 9.9%、
cos=0 で層をまたがない)。天板を下にした素直な逆さ置き (+Y up 相当、
オーバーハング 8.1%・1層目張り出し 0mm²) も同等に成立するので、
スライサで支持要否の少ない方を選べばよい。いずれも X1C 250³ 枠に収まる
(実寸 158 × 134.9 × 53.25)。

## 部品外の考慮

- **運用時は必ず外す** (C3: ドーム内から LED で照らすため、上半球を覆う
  部品を残さない)。忘れると光が遮られるだけでなく、実質的にキャップの
  重量 (約236g) が全高いちばん上に載ったままになり重心が高くなる
- **TD04A は輸送時も装着したまま**。後方カットアウトはソケット中心の
  真上だけでなく、TD04A の本体高さ (ソケット上端 z228 からさらに +55 ≒ z283)
  も外周に出るよう全高でカットアウトを貫通させてある (キャップの外殻は
  この方位角では最初から存在しない)
- **ノブボルトは工具レス** (M5、頭径 Ø16 程度を想定)。ケース収納時に
  手で回せることを実物で確認
- 天板厚 6mm・外殻厚 3〜17.5mm と全体に厚めで軽量化の余地がある
  (今回は「輸送専用・低頻度使用」の位置づけで安全側に振った)

## 要確認

1. `dome_h`(53.25仮) の実測 → 頂点クリアランス (現マージン 4.5mm) の再確認
2. ドーム実測 OD (公称 94.5、要件書の 114.3 との差) → クリアランスに余裕は
   十分あるので致命的ではないが、`cover_r` を絞って軽量化する余地がある
3. M5 ノブボルトの具体的な型番 (頭径・つまみ形状) → バカ穴/頭の逃げ寸法の確定

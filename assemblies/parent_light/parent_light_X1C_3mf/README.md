# 親機・一体化／肉抜き版（2026-09-18）

最新版は**4種類・計5個**を印刷する。カメラのケース保持マウントは既存品を使用し、印刷一式には含めない。カメラ用にはそのマウントを取り付ける取付台だけを用意した。

|ZIP内STL|個数|内容|
|---|---:|---|
|parent_light_frame|1|下フレーム＋浮子固定耳4か所を一体化、236×236×42 mm|
|parent_light_bar|2|肉抜きした上側押さえバー、236×24×12 mm|
|parent_light_carrier|1|既存カメラマウントとTD04A用の取付台、印刷向き210×88×67 mm|
|parent_light_jaw|1|TD04Aの金属ブラケット押さえ、50×14×8 mm|

ZIPは1種類1ファイル。上側バーだけスライサで2個にする。旧全面底板、旧下フレーム、別体浮子耳、カメラ保持マウントの新規印刷は不要。上側バーとTD押さえは旧品を印刷済みなら再利用可能。

## 統合・肉抜き

- 浮子耳4個を下フレームに統合。耳固定用M5ボルト・ナット・座金各8個を削減した。
- 浮子穴はφ10.5、横向き。穴中心Y=±85、Z=-26、板厚中心X=±114。箱の下へ移し、穴の内側から金具を扱えるようにした。前案の上向き耳とは高さが変わるため、紐長を合わせる。
- フレームの桟に窓を設け、締付け穴・座面周辺を残した。横桟は肉抜きの両側に7 mm幅、上側バーは8 mm幅のリブを残す。
- 取付台はねじ穴、TD金属板の接触面、荷重を伝える枠を残して窓を設けた。
- 取付台とフレームは別体を維持。一体にすると大きな橋渡し部分のサポートが増えるため、取付台の背面をベッドへ置く構成とした。TD押さえ板は挟む動作と着脱のため別体。

前案からカメラ保持マウントを除いた同じ範囲で比較し、CAD樹脂体積は680.46 cm³→522.13 cm³、**23.27%減**。フィラメント質量・時間の削減率ではない。実際の消費はインフィル、壁数、サポート、ブリムによる。下記の設定でスライス検証済み。

## 既存マウントとの取合い

既存カメラマウントの取付穴は22×32 mmピッチのM5×4を前提とする。前案のOsmoマウントを参考表示に残しているが、新規印刷対象から除外した。中心X=-48、Z=-66、取付面Y=0。使用する既存マウントの穴ピッチが異なる場合は取付台を合わせ直す。

TD04Aは付属金属ブラケットを取付台と押さえ板で挟む。M4×2、36 mmピッチ、ブラケット幅24・厚さ2 mmの仮値を継承。**実物の金属板寸法・平面長さは確認が必要**。旧円筒クランプは使用しない。センサーは下向き。ケーブルは側方を回し、残したφ5結束穴（X=15,Z=-35）で張力を逃がす。

## 必要な金具

|用途|数量|
|---|---|
|箱クランプ|M5全ねじ150 mm×4、M5ナット×8、外径10 mm座金×8、14×24×2 mmゴムパッド×4|
|取付台とフレーム|90°皿頭M5×30×4、M5ナット・座金各4（通常の円筒頭ねじは使用しない）|
|既存カメラマウントと取付台|M5×25目安×4、M5ナット・座金各4。実際の既存マウント厚に合わせて長さ調整|

カメラ自体の保持金具は既存マウントのものを使用する。箱底穴は使わない。取付台固定ねじは箱を置く前に締め、皿頭をフレーム上面の45°皿座へ沈める。蓋を開くときは上側バー2本を取り外す。

## 印刷・確認

ZIP内STLはベッド面Z=0、印刷向きへ回転済み。フレームは箱側の平面を下、取付台は背面を下にして印刷する。PETG、0.4 mmノズル、0.2 mm層、壁6周、上下6層、40%インフィルを初期設定とする。浮子の横穴と取付台の横向きM5穴は45°屋根形状へ変更。取付台の立つ面にある肉抜き窓も45°屋根にした。236 mm角は5 mmブリム込み246 mm。X1Cの既存禁止領域を維持し、中心(138,128)に配置してスライス成功。

4種類とも閉じた単一STL、STEP単一ソリッドを確認。FreeCADによる13部品の組立検査で印刷部品に関係する体積干渉0件（0.1 mm³超を検出）。ゴム・簡略蓋・金具・ケーブルの干渉や工具アクセスは検査対象外。実物適合、強度、締付力、樹脂クリープ、浮力・水密は未検証。肉抜きは形状設計で、強度解析による最適化ではない。

## フィレット・サポート削減の更新

外周および肉抜き窓の輪郭角にR2〜R3 mmを追加。ねじ座面、既存マウント接触面、ベッド接触面は平面を維持。すべての稜線を球状に丸める処理ではなく、印刷方向に沿った円弧フィレット。取付台の屋根形状の窓は45°直線を残す。STEPでも円弧・円筒面を保持し、メッシュ由来の平面群への置換は発生していない。

浮子用φ10.5穴は円の上側（印刷時上側）に屋根を付けた涙滴形。M10通し径を内包する。取付台の横穴にも同様の屋根を付ける。皿ねじ4本への変更により、底面の円筒座ぐり天井に発生していたサポートを解消した。

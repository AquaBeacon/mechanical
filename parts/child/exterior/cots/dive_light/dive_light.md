## この寸法に依存している自作部品

| 部品 | 依存している値 |
|---|---|
| `parts/child/exterior/printed/child_frame_plate` (構成 A) | 前縁 M4 穴: X = ±15、Y = +100 / +120 (Ø4.5) |
| `parts/child/exterior/printed/child_shell_fwd` (構成 B) | **`light_d = 40`** (鞍座の半円 / 画角 assert), `light_z = 58`, `light_y0..y1 = 78..118`, `light_m4x = 28`, `light_m4y = [86,110]`, `light_blk = 35` |
| `parts/child/exterior/printed/child_light_clamp` (構成 B) | 同上 (**二重定義。片方だけ直さない**) |

**構成 B では `light_d = 40` が仮値。** 製品決定後にこの値を実測に置き換えて
`child_shell_fwd` と `child_light_clamp` を**両方**再ビルドすること。
胴が円筒でない製品 (角形・フランジ付き) なら鞍座の形状から作り直しになる。

現状は**汎用の M4 4 点**を前縁に開けてあるだけで、特定製品の穴位置に
合わせていない。製品決定後に穴位置を実物に合わせて `.scad` を更新すること。

## 部品外の考慮

- **電源ケーブルが後方キャップのペネトレータまで届く**こと。前縁 → 後方まで
  プレート上を這わせる距離は約 250mm + 容器内サービスループ。
- ケーブルは**カメラ視野に入らない**ように、プレート下面または縁に沿わせる。
  結束点は 40mm グリッド穴を使う。
- 光がカメラに直接入る (ハレーション) 位置に付けないこと。
- 消費電力が LiPo 3S 5000mAh の稼働時間に効く。点灯時間の見積りを
  `../docs/AquaBeacon_詳細設計書.md` の電力収支に反映すること。
- 発熱。水中では冷えるが、**空中での連続点灯は避ける**運用にする。

## 要選定・要確認

1. 製品決定 → 取付穴位置・外形・ケーブル外径の実測
2. ケーブル外径 → ペネトレータ型番 (`wetlink_penetrator_m10`) 決定
3. 調光/スイッチをどこで行うか (容器内基板から制御するか、独立電源か)

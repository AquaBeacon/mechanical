# child_main — 子機 メイン基板

KiCad で設計した自作基板の 3D モデル。**このリポジトリでは編集しない** —
`hardware/pcb/CHILD_MAIN/` が設計ソースで、ここには成果物を置くだけ。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 基板 |
| 生成元 | `hardware/pcb/3d/CHILD_MAIN.step` / `CHILD_MAIN_mech.stl` |
| 生成コマンド | `python -X utf8 pcb\export_3d.py CHILD_MAIN` (Kicad_project 側) |
| 使用数 | 1 |

## 座標系

STL / STEP とも **X = 0..104.0 / Y = -88.0..0 / Z = 板が 0..1.6、部品が +Z**。
KiCad の基板左上が原点なので **Y が負**になる。`placement.json` の `ops` は
これを前提に書いてある。

## 取付穴 (H1〜H4)

`.kicad_pcb` の実座標 (基板左下を原点、Y は上向き正):

(4.5, 4.5) / (99.5, 4.5) / (4.5, 66.0) / (99.5, 66.0)

→ ピッチ **95 × 61.5 mm**。Ø3.2 (M3 クリアランス)。

## 役割

RP2040 (Pico 2 W)、BNO085、DS3231、microSD、RS485、深度・漏水・電源監視 I/F、3ボタン+LCD の UI

## 実装位置

`assemblies/child_vertical_assembly` / `child_vtray_deck` のデッキ上面 (ボス 7mm)。
基板 X(**104**) → チューブ Z、基板 Y(88) → 機体 X、部品面 → +Y。

機体座標での取付穴は **X = 88/2 − y_kicad → +39.5 (y=4.5 列) / −22.0 (y=66 列)**、
**Z = 20 + x_kicad → 24.5 / 119.5**。

> **★ X の符号に注意。** 基板 Y は STEP/STL で負 (−88..0) になるので、
> 機体 X は `main_w/2 − y_kicad` であって `y_kicad − main_w/2` ではない。
> 2026-08-03 まで `child_vtray_deck` がこれを取り違えたうえ、存在しない
> y=80 の列を使っており、ボスが実穴から 17.5 mm / 3.5 mm ずれていた。

## 部品外の考慮

- **コネクタの抜き差し空間**を基板の外に取ること。上表の位置は基板座標なので、
  `placement.json` の変換を通して機体座標に直してから干渉を見る。
- ケーブルは `docs/配線・ケーブル計画.md` に集約する。
- 基板を**アセンブリでビルドすると STEP が重い** (この基板の STEP は銅箔・
  ベタ・シルクまで入っている)。プレビューだけでよいときは `-NoStep` を使う。
- `_mech.stl` は KiCad の STEP エクスポータ由来なので、
  **水密でない場合がある** (部品ソリッドが基板に食い込んでいる箇所)。
  干渉確認には使えるが、体積・浮力計算には使わないこと。

## 要確認

幅88mmはフランジ貫通口Ø88.5を安全には通せないため、上フランジを抜いてID101.6の
チューブへ直接挿入する。USB/microSDは−X側、3ボタンは＋X側からアクセスする。

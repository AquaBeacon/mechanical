## 役割

市販円筒フェンダー (`parent_fender`、**仮 Ø100 × 300**) を上から被せて保持し、
`parent_deck` の側壁 HP40 座 ×2 に**内壁 (アダプタ板 t8)** で M5 ×4 ×2 締結する。

- **アーチリブ 3 枚** (Y −96 / 0 / +96、t8、高さ 60) が胴を受ける。リブ下端でのアーチ半角
  **79°** = 紐が無くても胴が横に逃げない抱え込み。
- **紐穴**: 両端リブに Ø7 ×2 (Y 貫通、胴中心 ±46) = 胴を下から回す**掛け紐**。
  外壁側の両端ラグ Ø8 (Y 貫通) = 浮子端アイ → ラグ / デッキ側壁 Ø8 への**ブライドル**。
- **天板中央に HP40 座 ×1 (上向き)** = ライト・GPS ポール・旗などの拡張。
- 外壁 (t9) と天板 (t5) で箱断面を作り、胴の押上げに対してリブを繋ぐ。

## 座標系

X=0 = デッキ側壁の外面 (座面)、外向き +X。Y = 浮子軸。z=0 = デッキ上面。
アセンブリでは右 (+X) を `translate([108,0,0])`、左 (−X) を `translate([-108,0,0]) rotate 180°`。

## 干渉チェック (`.scad` 冒頭の assert)

- 胴上面 (アーチ頂点) が天板ボスに当たらない (`arc_gap` 2) / 胴が内壁に当たらない / アーチが内壁を削らない
- リブ下端が胴中心より上 (差し込める) / リブ下端でアーチが内壁・外壁の足を残す (≥ 2)
- 抱え込み半角 ≥ 70°
- HP40 アダプタ穴が内壁の Y・Z 範囲内 / デッキ側壁高さ ≤ リブ高さ
- 掛け紐穴が天板 (≥ 3)・アーチ (≥ 3)・天板ボス・壁から離れる
- ラグが胴に当たらない (≥ 2) / ラグ穴の端距離 ≥ 5 / 中央リブが Y=0 にある (天板ボスの支え)
- 250³ 造形枠

実際に止めたもの (2026-09-04): アーチ頂点が天板ボスに 0.01 接触 → `arc_gap` 2 を導入し
胴中心を −68 → −70 へ。

## 印刷 (X1-Carbon)

- **上下反転** (天板をベッドに)。リブのアーチは上に行くほど細くなる形なのでオーバーハング無し。
  `topopt overhang` (反転 STL): **要サポート面積 0.9 %** (ラグ穴・横穴の上面のみ)。**サポート不要**。
- 主引張: アーチの押上げ → 天板・外壁の面内 (X)、ラグの紐引き → リブ面内 (Y)。層面内。
- 材料 PETG (屋外は ASA)。壁 4 本 / インフィル 25 % / 上下 5 層。2 個同じ物を印刷。
- 天板 HP40 の下穴は反転印刷でベッド側 = 印刷後にそのまま熱圧入。内壁の M5 バカ穴は水平穴。

## 部品外の考慮

- **紐の掛け方**: (1) 掛け紐 Ø5: 端リブの穴 → 胴の下を回す → 反対側の穴 → 天板上で結ぶ (両端 2 本)。
  (2) ブライドル: 浮子端アイ → 外側ラグ Ø8 と デッキ側壁 Ø8 (Y ±108) の 2 点。
  紐を締めると胴がアーチ頂点に密着する (アセンブリはその状態で置いている)。
- **フェンダーが空気入り**なら日射で膨らむ。隙間 3 mm と掛け紐の伸びで吸収。
- クレードルを外すと**デッキ側壁の HP40 座が空く** → 輸送時は外して平積み (137 × 200 × 86 ×2)。
- 天板 HP40 の中央 Ø14 は胴の真上に開く。ケーブルを通すなら胴を避けて外壁側へ。

## 役割

フランジ貫通口 (**Ø88.5**) から挿入するスレッドの上板。下面に
`child_tray_rib` (半円リブ) を 3 枚 M3 で固定し、チューブ内で支持する。

| ゾーン (前端 y = 0 から) | 内容 |
|---|---|
| 0 – 30 | ケーブル/ペネトレータ余裕ゾーン + Ø9 ケーブル通し穴 ×2 |
| 中央 | RX 基板ベイ (内寸 28 × 84、壁 3、壁高 20) |
| 後方 | LiPo ベイ (内寸 46 × 138、壁 3、壁高 15、面ファスナースロット) |

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `flange_bore` | 88.5 | フランジ貫通口 ← `wte4_flange` |
| `glide_clear` | 1.0 | 開口との径クリアランス |
| `deck_t / deck_drop / deck_w` | 4 / 18 / 75 | デッキ板厚 / 軸心からの落ち込み / 幅 |
| `card_in_w / card_in_l / card_h` | 28 / 84 / 20 | RX 基板ベイ |
| `bat_in_w / bat_in_l / bat_h` | 46 / 138 / 15 | LiPo ベイ |
| `rib_screw_d / rib_screw_x` | 3.4 / ±25 | リブ固定 M3 |
| `cable_d` | 9 | 前端ケーブル通し穴 ×2 |
| `std_d` | 2.8 | ベイ床の M3 セルフタップ下穴 (スタンドオフ用) |

導出: リブ半径 43.75 / デッキ下面での半弦長 `half_chd`。
**デッキ幅 75 が弦長以内であること**を assert で検査している。

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_tray_rib` ×3 | デッキ上から M3 ×2 (x = ±25)。リブ側はセルフタップ下穴 Ø2.5 |
| RX 基板 (`parts/child/interior/pcb/`) | ベイ床の M3 セルフタップ下穴 (スタンドオフ) |
| `lipo_3s_5000` | 面ファスナーストラップ (スロット 幅14 × 厚4) |

リブ位置 (`rib_cs`) は 27 / 124 / 276 mm。`assemblies/child_assembly/placement.json` と一致。

## 印刷向き

このまま (デッキ上面が上)。全フィーチャ上向きでサポート不要。

## 部品外の考慮

- **全長 281 は仮値**。チューブの有効内長 (フランジ + キャッププラグ込み) の
  実測待ち。長すぎるとキャップが閉まらない。
- 軸方向の固定が**ない**。現状リブでチューブ内壁に支持しているだけなので、
  運搬時にトレイが動く。`wte4_flange` 内面の M3 (BCD 94.0) が使えれば
  前端タブで固定できる (要実物確認)。
- 電池ベイを下に向けて重心を下げる運用が可能 (180° 回して挿入)。
  この場合ストラップと配線が下向きになるので、干渉を再確認すること。
- 基板とバッテリの**配線路が未設計**。ベイ間に明示的な通り道がない。
- 挿入・引き出し時にケーブルが突っ張らないだけの**サービスループ**を後方に取る。

## 要確認

1. チューブ有効内長の実測 → 全長 281 の確定
2. RX 基板の実寸・穴位置 → ベイ内寸 28×84 と床の下穴位置の確定
   (基板 3D モデルが来たら `parts/child/interior/pcb/` に置いて照合する)
3. LiPo の実寸 → ベイ内寸 46×138 / 高さ 35 の確定

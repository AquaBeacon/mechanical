# child_pwr — 子機 電源・ライト基板

KiCad で設計した自作基板の 3D モデル。**このリポジトリでは編集しない** —
`hardware/pcb/CHILD_PWR/` が設計ソースで、ここには成果物を置くだけ。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 基板 |
| 生成元 | `hardware/pcb/3d/CHILD_PWR.step` / `CHILD_PWR_mech.stl` |
| 生成コマンド | `python -X utf8 pcb\export_3d.py CHILD_PWR` (Kicad_project 側) |
| 使用数 | 1 |

## 座標系

STL / STEP とも **X = 0..62.0 / Y = -70.0..0 / Z = 板が 0..1.6、部品が +Z**。
KiCad の基板左上が原点なので **Y が負**になる。`placement.json` の `ops` は
これを前提に書いてある。

## 取付穴 (H1〜H4)

`.kicad_pcb` の実座標 (基板左下を原点、Y は上向き正):

(4.0, 4.0) / (58.0, 4.0) / (4.0, 66.0) / (58.0, 66.0)

→ ピッチ **54 × 62 mm**。Ø3.2 (M3 クリアランス)。

## 実装位置

200mmチューブ用 `child_vtray_deck_t200` の上面 **z=126..188** に実装する。
先端8mmはフランジ貫通口内へ入るため低背部品だけを配置済み。

機体座標での取付穴は **X = 70/2 − y_kicad → ±31.0**、**Z = 126 + x_kicad → 130 / 184**。

> 2026-08-03: z を 128 → 126 へ 2mm 下げた。デッキ下面の RX 取付ねじ (Z=136.5) の
> 頭が、旧位置の H1 列ボス (Z=132) の足元に乗っていたため。
> なお `child_vtray_deck/variants.txt` にあった `pwr_hu=[2.4,59.6]` の上書きは
> **実基板の inset 4.0 と食い違う誤り**だったので削除した。穴位置をバリアントで
> 上書きしないこと。

## 部品外の考慮

- **コネクタの抜き差し空間**を基板の外に取ること。上表の位置は基板座標なので、
  `placement.json` の変換を通して機体座標に直してから干渉を見る。
- ケーブルは `docs/配線・ケーブル計画.md` に集約する。
- 基板を**アセンブリでビルドすると STEP が重い** (この基板の STEP は銅箔・
  ベタ・シルクまで入っている)。プレビューだけでよいときは `-NoStep` を使う。
- `_mech.stl` は KiCad の STEP エクスポータ由来なので、
  **水密でない場合がある** (部品ソリッドが基板に食い込んでいる箇所)。
  干渉確認には使えるが、体積・浮力計算には使わないこと。

# 親機・既存M3カメラマウント直接固定版

ユーザー確認済みの既存マウントは `parts/child/exterior/printed/dji_osmo_action6_mount_m3/camera_mount`（後面M3・40×40 mm）。旧版の底面M5マウントを参照して追加していたカメラ用90°取付台を削除した。既存マウントの後面をフレーム下面と平行に取り付け、カメラを下向きにする。残るL字取付台はTD04A専用。

## 印刷する部品：4種類・5個

|ファイル|個数|内容|
|---|---:|---|
|parent_direct_frame.stl|1|浮子耳、カメラ取付桟、4個のスペーサーを一体化したフレーム|
|parent_light_bar.stl|2|既存の丸角・肉抜き上側バー|
|parent_td_support.stl|1|小型化したTD04A専用支持部|
|parent_light_jaw.stl|1|TD04Aブラケット押さえ板|

カメラ保持マウントは既存品を使用し、印刷ZIPに含めない。上側バーとTD押さえ板は前版から再利用できる。旧 `parent_light_frame` と `parent_light_carrier` は今回のフレームとTD支持部に置き換える。

## カメラ取付

- 後面のM3・40×40 mmを使用。フレーム側穴中心はX=-60/-20、Y=-20/+20。
- 接触面Z=-24。フレーム下面Z=-12から12 mmのスペーサーを一体化し、既存マウントの後方張り出しを箱から逃がす。曲げアダプターではない。
- 各スペーサーにM3熱圧入インサート用φ4.2×深さ7 mmの止まり下穴。M3インサート4個を別途用意する。外径・長さは購入インサート仕様に合わせて調整。
- M3×10ねじ4本を初期値とする。既存マウントの座ぐり後の厚さは4.4 mm、ねじ入り量は約5.6 mm。インサートの有効ねじ長・底付きと、実際のねじ頭が既存座ぐりに収まることを確認する。
- 既存カメラマウントに対し、回転[-90,0,0]、移動[-40,-40,-55.45]。既存後面Y=-31.45がZ=-24になり、カメラ前方+Yが世界座標−Z（下向き）になる。
- マウントの張り出し上端は箱底より約3 mm下。既存後面の穴とスペーサーの軸は一致。新規カメラ用縦板はない。

## その他の金具

- 箱クランプ：M5全ねじ150 mm×4、M5ナット・外径10 mm座金各8、14×24×2 mmゴムパッド×4。
- TD支持部とフレーム：M5×30の90°皿ねじ×2、M5ナット・座金各2。箱を載せる前に組み付ける。
- TD押さえ板：M4×30×2、M4ナット・座金各2。
- 浮子は一体耳のφ10.5を内包する屋根形穴へ紐／金具で接続。
- TD04Aの付属金属ブラケット寸法（仮値：幅24、厚さ2 mm）は実物確認が必要。胴体を挟む旧円筒クランプは使用しない。

## 印刷・検証

フィレットと45°屋根穴を継承。STLは印刷向き、ベッド面Z=0に調整済み。X1 Carbon／PETG／0.20 mm／壁6／上下6層／インフィル40%／ブリム5 mm、自動通常サポートON、しきい値30°、ブリッジにサポートを生成しない設定で全4種類スライス成功。全てSupportセクション0、警告なし。5個の合計見積もり約397.9 g・13時間3分（個別プレートの合計、ブリム込み）。

閉じた単一STLとSTEP単一ソリッドを確認。13部品の構造干渉検査で、印刷部品に関係する体積干渉0件（0.1 mm³超を検出）。金具、工具、ケーブル、ゴム・簡略蓋は干渉検査外。実物適合・強度・締付力・水密・浮力と実機印刷は未検証。M3インサート・ねじは簡略組立表示に含めていない。

`parent_direct_prints.zip`：印刷STL・数量表。`parent_direct_X1C_3mf.zip`：検証済み設定付き3MF。各3MFは部品1個なので、上側バーだけ2回印刷する。`parent_direct_structure.step`：既存マウント等を含む構造組立、金具・ゴム・簡略蓋は除外。

再生成：`python spec/prepare_parent_direct.py`、新規2種類を`build.ps1`でビルド、`python spec/build_parent_direct.py`。検証は`PARENT_VERIFY_NAME=parent_direct`でFreeCADから`spec/verify_parent_open.py`、スライスは`PARENT_SLICE_NAME=parent_direct`で`python spec/slice_parent_light.py`。

# xdcr_clamp — TD04A 固定治具 (実験用)

**機体部品ではなく、実験用の治具。** TD04A の胴をクレードル + 蓋で掴み、
裏面の M5×4 で任意の平面に固定する「振動子ホルダの共通部品」。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / 治具 / 3Dプリント |
| 設計ソース | `xdcr_clamp.scad` (バリアント定義 `variants.txt`) |
| 個数 | body ×2 / cap ×2 (送受 1 セットずつ) |
| 外形 (body) | 56.0 × 84.0 × 20.5 mm / 55.5 cm³ / STEP 48 面 |
| 外形 (cap) | 46.0 × 52.6 × 18.5 mm / 32.8 cm³ / STEP 24 面 |
| 取付先 | `xdcr_poolside_jig` の棚。ほかの平面にも M5×4 で付く |

## 役割

TD04A を**保持する部分だけ**を独立した部品にしたもの。
`xdcr_pole_jig` はポールクランプと振動子クレードルが一体だったが、
本部品はクレードルだけを切り出し、**M5×4 の共通マウント面**を持たせている。
そのため相手側 (プールサイド治具・ポール・板) を変えても振動子側は共通で使える。

相手側に 0° / 90° の 2 組のボルトパターンを用意すれば、**音響ビームの向きを
90° 単位で切り替えられる** (`xdcr_poolside_jig` の棚がそうなっている)。
壁に対して垂直 (プール両端で対面測距) と平行 (同じ壁面に沿って測距) の
両方を、治具を作り直さずに取れる。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `xdcr_d` | 26.0 | TD04A 胴径の**仮定値** (**要実測**) |
| `xdcr_len` | 55 | 胴長の仮定値 (**要実測**)。掴み代のチェックに使う |
| `cable_d` | 9 | ケーブル外径の仮定値 (**要実測**)。`xdcr_socket` と同値 |
| `squeeze` | 1.0 | 締め代。溝径 = 胴径 − squeeze = **Ø25.0** |
| `liner_t` | 0 | 溝に敷くゴムシート厚 (敷くならここに入れる) |
| `grip_len / end_t` | 40 / 6 | 掴む長さ / ケーブル側 端壁 (胴の当り面) |
| `bolt_sp / bolt_y` | 24 / 19 | 蓋 M4 の X 間隔 / Y (±) |
| `m4_pilot / pilot_dep` | 3.4 / 16 | 本体側 自己タップ下穴 |
| `base_w / base_d / base_t` | 56 / 84 / 8 | 取付ベース |
| `mount_x / mount_y` | 40 / 68 | M5 取付ピッチ (±20 / ±34) |
| `tie_w / tie_t` | 5.5 / 2.5 | 予備保持の結束バンドスロット |
| `drain_d` | 6 | 水抜き穴 ×2 (溝底 → 取付面) |

導出値: **溝軸の高さ = 取付面から 20.5 mm**、
**マウント中心 → 音響放射面 = +X に 38 mm**。この 2 つは相手側の設計に必要。

## インタフェース (**二重定義に注意**)

`xdcr_poolside_jig.scad` が同じ値を持っている。**片方だけ直さないこと。**

| 本部品 | `xdcr_poolside_jig` 側 | 値 |
|---|---|---|
| `mount_x` | `mount_x` | 40 |
| `mount_y` | `mount_y` | 68 |
| `base_w` | `clamp_bw` | 56 |
| `base_d` | `clamp_bd` | 84 |
| 導出 `axis_z` (= `base_t` + 溝径/2) | `clamp_axz` | 20.5 |
| 導出 `face_off` (= `grip_x0` + `xdcr_len`) | `clamp_fx` | 38 |

> **`xdcr_d` / `xdcr_len` を実測値に直したら `axis_z` と `face_off` が変わる。**
> ビルド時の `echo` に両方出るので、その値を `xdcr_poolside_jig.scad` の
> `clamp_axz` / `clamp_fx` に転記してから治具を作り直すこと。
> 転記を忘れると「深さと壁面オフセットの計算値」だけがずれる (形状は正しいまま)
> ため気付きにくい。**測距の基準距離に直接効く。**

締結金物:

| 箇所 | 本数 | 部品 |
|---|---|---|
| 蓋 ⇄ 本体 | 4 | M4 × 25 なべ/キャップ + 本体は自己タップ |
| ベース ⇄ 相手側 | 4 | M5 × (板厚 + 15) + 平座金 + ナイロンナット |
| 予備保持 | 2 | 結束バンド 4.8mm 帯 (蓋の上を回す) |

## 干渉チェック (`.scad` 冒頭の assert)

1. 蓋ボルト (下穴・通し穴) と**クレードル溝**の間に `min_wall` = 3mm 以上
2. 蓋ボルトの**頭座グリ**がブロック側面/端面/端壁から抜けない
3. 蓋ボルトの下穴が**取付面を貫通しない** (残り 4.5mm)
4. **M5 の平座金がクレードルブロックに乗り上げない** (乗ると締結面が浮く)
   — 座金内縁 29 vs ブロック半幅 26.3
5. M5 の縁距離 (X / Y とも 5.35mm)
6. 水抜き穴が溝底の範囲内にあり、溝底より広くない
7. 結束スロットと M5 穴が X で離れている (Y は近いので X で逃がしている)
8. 胴長がクレードル全長 (46mm) に足りている
9. `squeeze > 0` — **0 以下だと蓋が底付きして締め付け力がゼロになる**

## 印刷向き

| 部品 | 向き |
|---|---|
| body | この姿勢のまま平置き (ベースが下、溝が上)。無サポート |
| cap | **この姿勢のまま平置き (溝が上)**。組立時は上下逆さに載る |

`cap` は「印刷姿勢 = 組立姿勢ではない」点に注意。座グリは印刷時の底面側にあり、
組み立てると外面 (上) に来る。座グリ天井は Ø8.6 → Ø4.5 の 2mm 幅ブリッジなので
サポート不要。

材料は PETG 推奨 (屋外・水中・紫外線)。PLA でも試験 1 日なら持つが、
車内放置や長期保管で変形する。

## 部品外の考慮

- **ケーブル**: 端壁の上開放スロット (Ø10.5 相当) から出す。本体と蓋を合わせると
  10.5 角の開口になる。**結束バンドで必ずストレインリリーフを取り、
  振動子本体を引っ張らないこと** (TD04A のケーブルは 3m 固定で交換が効かない)。
- **水抜き**: クレードルは樋なので水が溜まる。溝底 → 取付面の Ø6 ×2 で抜く。
  **相手側の取付面でこの穴を塞がないこと** (`xdcr_poolside_jig` の棚は
  余分な取付穴があるので塞がらない)。
- **音響**: 溝は半円樋で放射面 (+X 側) は完全に開いている。
  振動子は胴長 55 に対し 40mm しか掴まないので、**放射面はブロック端から 15mm 前に出る**。
  相手側の構造物がビーム (指向角 22°) に入らないことを相手側で確認すること。
- **気泡**: 放射面に気泡が付くと減衰する。**入水後に一度振動子面を撫でて泡を落とす**。
- **締め付け**: 溝径は胴径より 1.0mm 小さい。締めたときに**本体上面と蓋が接触したら
  締め代が尽きている** → `squeeze` を増やして作り直す (assert では捕まらない、現物確認)。
  ゴムシート (`liner_t`) を敷くと保持と保護が両立し、胴径の実測誤差も吸収できる。
- **紛失防止**: 水中でボルトを落とすと回収できない。**組立は必ず陸上で行い、
  水中では触らない**運用にする。

## 要確認

1. **TD04A の胴径・胴長・ケーブル外径の実測** → `xdcr_d` / `xdcr_len` / `cable_d`
   を直して再ビルド。`echo` の `axis_z` / `face_off` を `xdcr_poolside_jig` へ転記。
2. 胴が**完全な円筒か** (テーパ・段差・ケーブルブーツの膨らみがないか)。
   段差がある場合は掴む位置 (`grip_len` / `end_t`) を見直す。
3. `squeeze = 1.0` が適切か。フィットテスト (輪切りテストピース 1 個) を先に出す。
4. 自己タップ (M4 下穴 Ø3.4) の保持力。繰返し脱着するなら
   `m4_pilot = 5.6` にして M4 熱圧入インサートへ変更する。

# child_light_clamp — 水中ライト 割りクランプ 上半分

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_light_clamp.scad` |
| 個数 | 1 |
| 外形 | 70 × 40 × 28.5 mm |
| 体積 | 52.9 cm³ (STEP) → PETG 約 47 g |
| STEP | 1 ソリッド / 20 面 |

## 役割

水中ライトの胴を挟む割りクランプの**上半分**。下半分は `child_shell_fwd` の
鞍座 (`light_saddle`) と一体。M4 ×4 で締める。

ライトはカメラと**同じ +Y 方向**を向く。ライト軸 = Y なので、**鞍座の 40mm の範囲で
前後にスライドできる** (スロットは不要)。バックスキャッタが出たら後ろへ下げる。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `light_d` | **40** | ライト胴径 **要選定・要実測** |
| `grip_clr` | 0.4 | 締め代を残すためのすきま (ゴムシート前提) |
| `blk_h` | 30 | ライト軸から上のブロック高さ (頂部肉厚 9.8) |
| `gap_z` | 1.5 | 合わせ面のすきま。締めるとゴムが潰れて効く |
| `light_m4x` / `light_m4y` | ±28 / 86, 110 | M4 (グローバル座標) |
| `tie_x` / `tie_w` / `tie_h` | ±30 / 4 / 8 | 結束スロット (前後 M4 の中間) |

## インタフェース (**二重定義。片方だけ直さないこと**)

`child_shell_fwd` と共有: `light_d=40` / `light_y0=78` / `light_y1=118` /
`light_m4x=28` / `light_m4y=[86,110]` / `light_blk=35` / `light_z=58`。

**`light_d` を変えたら両方を再ビルドすること。** シェル側は鞍座の半円と、
ライトが画角に入らないかの assert がこの値に依存している。

M4 ×4 の相手はシェル側鞍座の **Ø3.3 下穴へのタッピング** (深さ 14mm)。

## アセンブリ配置

`translate([0, 78, 58])` (= `[0, light_y0, light_z]`)。

## 干渉チェック (`.scad` 冒頭の assert)

- 鞍の頂部肉厚 ≥8mm (**現在 9.8mm**)
- M4 が鞍の半円に掛からないこと / 外側端距離
- **結束スロットがブロックからはみ出さないこと** → ここで実際に止まり、
  スロットを M4 の外側から**前後 M4 の中間**へ移した
- 結束スロットが M4 に掛からないこと
- 合わせ面のすきま `gap_z > 0.8` (締め代が取れること)

## 印刷向き

**上下逆さま** (z=`blk_h` の平面をベッドに置く)。鞍の半円が上を向くのでサポート不要。

## 部品外の考慮

- **ライトは未選定。`light_d = 40` は仮値。** 製品が決まるまでこのクランプは仮設計。
  胴が円筒でない製品 (角形・フランジ付き) なら形状から作り直しになる。
- **ゴム/EVA シート (1〜2mm) を鞍面に貼る**こと。樹脂とアルミ胴が直接こすれると
  ライトに傷が付き、締め付けも滑る。`gap_z = 1.5` はその圧縮代。
- ライトの**配線はクランプの結束スロット → デッキの結束スロット → 機体外周 →
  下のキャップのペネトレータ**。前半シェルを外すときに突っ張らないよう
  **サービスループ 150mm 以上**。
- **光量は控えめでよい** (`../docs/AquaBeacon_確定仕様メモ.md`: 親機カメラ用ビーコン、数W)。
  発熱は水中なら問題ないが、**空中での連続点灯は避ける**。
- カメラ同期用に「潜行前後に既知時刻でブリンク」させる運用がある。
  **点滅を制御できる製品か、外部から給電/制御できる製品を選ぶこと。**

## 要確認

1. **製品の選定** → 胴径・胴長・重量・配光・ケーブル外径
2. ケーブル外径 → WetLink ペネトレータの型番 (4.5〜8.5mm)
3. 点滅制御の方式 (容器内の基板から制御するか、独立電源か)
4. 浮力。ライトは中身が詰まっていて負の浮力が大きいことが多い。
   バラスト量の見積り (`docs/AquaBeacon_機体設計.md`) に反映すること

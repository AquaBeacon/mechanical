# child_tray_rib — 子機トレイ バルクヘッドリブ

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 3Dプリント |
| 設計ソース | `child_tray_rib.scad` |
| 個数 | 3 |
| 外形 | 75.62 × 21.75 × 6 mm |
| 体積 | 3.3 cm³ |
| STEP | 2 ソリッド / 16 面 (下記参照) |

## 役割

Ø87.5 (= フランジ開口 88.5 − 1.0) の円弧に沿った下側バルクヘッド。
上端フラット面を `child_tray_deck` の下面に当て、デッキ上から M3×2 で固定する。
チューブ内壁に沿ってトレイを支え、挿入時のガイドにもなる。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `flange_bore / glide_clear` | 88.5 / 1.0 | → リブ外径 Ø87.5 |
| `deck_drop / deck_t` | 18 / 4 | 上端フラット面は軸心 −22 |
| `rib_t` | 6 | リブ厚 |
| `screw_x / pilot_d / pilot_depth` | ±25 / 2.5 / 10 | M3 セルフタップ下穴 |
| `cut_w / cut_h` | 40 / 14 | 配線切欠き (軽量化兼用) |

## インタフェース

| 相手 | 締結 |
|---|---|
| `child_tray_deck` | M3 ×2 (x = ±25)。デッキ側は Ø3.4 通し穴、リブ側は Ø2.5 セルフタップ |
| `wte4_acrylic_tube` 内壁 | 摺動支持 (クリアランス 1.0) |

配置 (`placement.json`): デッキ前端から 27 / 124 / 276 mm。

## 干渉チェック (`.scad` 冒頭の assert)

- M3 下穴が配線切欠きと干渉しないこと
- 配線切欠き下端が外周に接近しすぎないこと
- M3 下穴の先端 (深さ 10) が外周を突き抜けないこと

## 印刷向き

平置き (円板面を下)。M3 下穴は層内水平になるが Ø2.5 なので実用上問題ない。

## 既知の観察事項

CSG→STEP 変換の結果が **2 ソリッド**。切欠き (幅 40) が下方で円弧の幅を
超えるため、リブの下側が左右に分かれた形状になっているのが原因と思われる。
メッシュは watertight で外形も設計どおり。**Fusion 取り込み時に確認**すること。

## 部品外の考慮

- 中央切欠き (40 × 14) が**配線の通り道**。リブ 3 枚とも同じ位置なので
  配線は一直線に通せる。ここを配線で埋めると軽量化・剛性の意図が薄れるので、
  結束バンドで壁側に寄せること。
- リブ外周がチューブ内壁を擦る。**バリ取り**をしないとアクリルに傷が付く。
  積層の段差が当たるので、外周だけ軽くヤスリがけすることを推奨。
- 挿入方向は片方向。リブの向き (切欠きの上下) を揃えて組むこと。

## 要確認

1. 前リブ (デッキ前端 27mm 位置) がペネトレータ後方空間に干渉しないか — **要実測**
2. STEP の 2 ソリッドが Fusion で問題にならないか

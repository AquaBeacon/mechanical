# 子機フレームA

最新の検討は [板厚8 mmの平板・最適化準備モデル](_work/analysis/frame_a_flat_thickness/README.md)。状態は **exploration_only**、入力検査のみ完了し、強度解析・最適化は未実行。以下の印刷一式と製造原本は、最大奥行き45 mmの試作の記録。

Blender完成イメージを参考に、下部アクセス、外周ガード、接地部、上辺の持ち手を残したフレームA。今回の対象は左右のAと分割接合板。印刷形状を仕上げた試作であり、分割接合・完成機の吊り上げ強度は未認定。

印刷入口は [PRINT.md](../../../../../assemblies/child_exterior_structure/parts/PRINT.md)。生の最適化メッシュ、解析領域、一体確認モデルは印刷部品に含めない。

## 外形と取合い

mm単位。局所XYは機体YZ、局所Zは外側への奥行き。幅340、高さ408（機体Z −132〜276）、取付座の板厚12、最大奥行き45。2026-10-01の外枠改訂では、側面・下辺の底板を12→4 mm、縦壁を4→3 mmに薄肉化した。接地・ガードの奥行き45、取付座、分割接合座、上辺の持ち手を保つ。A内面は機体X=±84.95。左右を正回転で配置し、同じ4種類の分割片を各2個使う。

下部開口は294×112、面内隅R6。中央 **270×100 mm** は奥行き45全体に材料を置かない。外周幅22、下辺高さ44、底板4・縦壁3・奥行き45のU字断面を使う。上部の指入れ開口は **100×40 mm**（隅R5、中央90×30の通過矩形）。上辺22×45の持ち手と、その下のY250以上のnative最適化形状のつなぎ目を保持する。つなぎ目まで外枠の薄肉切削範囲に入れた案は、1 mm格子で横方向変位4.36 mm・最悪要素安全率1.65となり不採用。持ち手のつなぎ目だけを残して再解析した。旧平板案・奥行き32 mmの開いた持ち手案も履歴に保持し採用しない。

変更前後の実STL断面は [外枠断面図](../../../../../assemblies/child_exterior_structure/_work/images/frame_a_rim_revision.png) を参照。

M3通し穴Ø3.5。Blenderのねじ位置は使用しない。

- クランプ穴：現行 `child_wte4_suspension_clamp.scad` の `CLAMP_INTERFACE` / `CAGE_INTERFACE` から導出。局所X=±18、Y=32/48/92/108/152/168、各Aに12穴。ゴム厚1.0、圧縮0.2を反映する。
- C接続：局所X=±158、Y=30/50/240/260、各Aに8穴。[FRAME-A-C-M3-REV1](spec/frame_a_c_interface.md) に従って今後のCを設計する。
- 分割接合：専用24穴／A。

クランプ座と高さ30/50/240のC座は奥行き12、高さ260のC座は45。低い座にはØ10.5の直線工具通路を設け、Ø9ワッシャの荷重面を想定する。吊り穴外形との干渉を避けるため、A内面の局所Y194に幅26×高さ34×深さ0.8の逃げを設ける。C・クランプ接続のねじ長さは相手の完成座厚・ねじ受けで決める。

外形の面内隅R3、板厚端R0.6、穴入口面取り0.6。球近似の外形誤差は約0.025 mm以内。最適化内部表面は1 mmで平滑化する。STEPは仕上げSTLから作るファセットソリッド。同一平面の三角形を統合したSTEP専用入力を使い、元の印刷STLと体積・外形・表面差を照合する。

## 分割・印刷・組立

局所X=0、Y=80で4分割、継ぎ目0.3。下側約170×212×45、上側約170×196×45。平置きで250 mm確認枠に5 mmブリム込みで収める。材料はBambu PETG Basic、100%インフィル、外周8、層高0.20 mm、積層Z・ラスタXを解析の前提とする。X1 Carbon・0.4 mmノズル・Textured PEI Plateで5種類の実スライスが成功した。[スライス済み3MFと設定](../../../../../assemblies/child_exterior_structure/print_jobs/README.md) を同じassemblyへ保存する。A分割片は通常自動サポートを使う。支持材の除去可能性は未検証で、穴・接合面・工具通路を確認してから印刷する。材料カードは実ツールパスで校正していない。

各Aに48×26×20の外側接合板6個。中央縦継ぎ4か所（Y −110/70/190/264）、左右外周の横継ぎ2か所（X±158、Y80）。接合板1個につきM3×50なべねじ4本、Ø7×0.5ワッシャ4枚、AF5.5×厚2.4ナット4個。左右合計は分割片8個、接合板12個、各金属部品48個。金属部品は購入品。旧8 mm厚は単体解析の最悪要素安全率が3を下回ったため、工具穴付き20 mm厚へ補強した。

ナットをA内面のAF5.8、深さ6.4の六角座へ、クランプ取付前に座底まで挿入する。ナットは局所Z4.0〜6.4、接合板本体はZ45〜65。接合板の内側面から深さ8 mmにワッシャ座を残し、Ø10の工具穴を上面まで開ける。ワッシャはZ53〜53.5、ねじ頭座はZ53.5。M3×50の先端はZ3.5に止まり、ナット全厚に届く。Ø9工具包絡で通路を検査した。ブリム除去と穴の実寸確認後、4片を仮合わせて均等に締める。PETGの締付・クリープは未検証であり、許容締付トルクは指定しない。

CAD体積・密度1.25 g/cm³による印刷部品質量は、片側A＋接合板6個で約2.32 kg、左右約4.63 kg（購入金属を除く）。前の片側2.62 kgから11.5%軽量化した。スライサ推定消費量はブリム・支持材込みで左右約4.44 kg、20回合計約104.2時間。実測質量・実印刷時間ではない。

## 最適化と解析条件

外枠改訂の現行解析は `_work/analysis/frame_a_rim_thickness/`。内部のnative最適化原本は `_work/analysis/frame_a_compact_grip/` に保持する。完成機 **10 kg**、クランプ60%・C40%の配分は暫定。全質量を取付部に配分する荷重モデルであり、完成機の実重量・重心と一致する保証はない。材料はメーカーTDSに基づく未測定定数を含む暫定異方性カード。安全率3、変位上限2 mm。

| ケース | 片側Aの荷重・支持 |
|---|---|
| 持ち上げ | 下向き98.07 N、上辺持ち手支持（左右2本で2g／片側1本で1g） |
| 直立 | 下向き49.03 N、下辺支持 |
| 横方向の取扱い | 板厚方向±98.07 N、上辺支持、2ケース |
| クランプ吊り下げ時のC | Cに下向き39.23 N、12クランプ穴支持 |
| 前後ガード荷重 | Cに面内±30 N、12クランプ穴支持、2ケース |

内部の最適化原本は3 mm格子、自由領域体積率0.24、フィルタ9 mm、応力制約SF3、MMA、50反復。元の外周・取付座・分割座などの保持部は目標体積の約63%。反復上限到達を収束と扱わない。造形方向+Z、45度自己支持条件を設定した。

今回MMAを再実行せず、このnative密度面を保持して外枠のCAD保持領域を修正した。底板4/6/8 mmの2 mm格子比較を探索に用い、最終の穴付き形状を4/2/1 mmで再解析する。粗い格子では薄肉部の解像度判定が不合格なので、探索の順位と最終強度判定を分けて記録する。旧外枠境界に残る微小な膜を除去し、持ち手のつなぎ目を保持する。C上部Y260の荷重面は実座厚45に合わせてZ33〜45へ修正し、他の座はZ0〜12を維持する。荷重量・材料・支持領域は従来の7ケースを引き継ぐ。

穴付き完成形状は同じ材料軸・荷重・拘束で再解析する。格子4/2/1 mmの収束確認とCalculiX独立解析を試行し、実際の判定は [検証結果](spec/validation_results.md) に記録する。接合板は別途5方向の98.07 Nで単体解析する。いずれも分割ボルト接合の接触・締付・クリープ、クランプ本体、落下・衝撃、水流、長期使用を認定しない。

下部開口はA自体の通路。ガードを開け、ケーブルのサービスループを退避して手を入れる。C・ガード・配線を追加した完成機の通路は別途確認する。持ち手による完成機の吊り上げは接合と実荷重の検証後。

## 再生成

生成元は `tools/prepare_child_exterior_structure.py`。SCADと `spec/design_parameters.json` は自動生成。現行の内部密度面から外枠だけを再生成する場合は、同スクリプト、`tools/finish_child_frame_a.py`、OpenSCADの6バリアント出力、形状・取合い検査を順に行う。`tools/revise_child_frame_a_grip_root.py` は今回の境界修正と1 mm格子の横方向スクリーニング、`tools/verify_child_frame_a_rim_groups.py` は7ケースの4/2/1 mm解析を実行する。GPUメモリ節約のため支持条件の3グループに分けるが、荷重ケースを省略しない。`tools/run_child_frame_a.py` は内部のnative最適化からやり直す場合の処理で、今回実施した外枠だけの改訂とは異なる。

`tools/finish_child_frame_a.py` はnativeの平滑化表面に正本SCADの保持部を合成し、開口・穴・外形・分割をManifoldで復元する。内部形状を単純な梁へ描き直さない。MeshLabの辺反転で退化三角形を除き、面数・体積・外形・表面差を検査する。Binary STLで微小座標を保持する。

CAD再生成後、`tools/package_child_frame_a.py` で配置、`scad/lib/asm_gen.py` とFreeCAD CLIで確認モデルを生成し、`python tools/assembly_parts.py sync child_exterior_structure`、`check child_exterior_structure` を実行する。`tools/rebuild_child_frame_a_steps.py` はSTLを変えず5種類のSTEPだけを再生成する。`tools/slice_child_frame_a.py` と `tools/package_child_frame_a_slices.py` が実スライスと3MF梱包を行う。`sync` だけではCADを更新しない。旧解析・中断ケースは同フォルダ内の `_work/analysis/` に保持する。

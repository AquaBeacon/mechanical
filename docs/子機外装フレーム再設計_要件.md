## 2. 維持する要件 (変更なし・ユーザ確認済み)

- **全体 ~~250~~ 280 (幅 X) × 250 (奥行 Y) × ~~300~~ 400 (高さ) mm** に収める (2026-09-04 に幅 280・高さ 400 へ緩和。改善要件 §1 C1/C5)
- 耐圧容器: WTE4 4″ **チューブ 200mm** (OD 114.3) + フランジ ×2 + 下=アルミキャップ (M10×5, BCD56, 1 穴真下) + 上=ドーム (BR-100495, 未購入)
- **ステレオ基線 150mm、カメラは水平前向き (+Y)**、FOV155° を構造物で蹴らない
  (レンズ面より前はフード 8mm 相当まで。正面衝突は別部材で受ける)
- **TD04A 上向き** (親機と対面)、**ライトは前向き・中央下** (製品未選定)
- **吊り: 2 点ブライドル** (現行実績: 耳 Ø16、全備 5.7kg × 動的 3g ≈ 99 N/耳)
- **バラスト鉛 1.8〜2.9 kg を下部**に、位置調整で吊り姿勢トリム
- ケーブルは全て下キャップ経由。**テザー張力はフレームのストレインリリーフで受け、
  ペネトレータに掛けない**。下キャップ直下の中央と後方セクタは素通し。
  ライトのサービスループ 150mm。トルクレンチのアクセス確保
- 内装アクセス: **ゲートを開けて容器を前方へ出してから**上フランジを抜く方式に変更
  (2026-08-02。R5 でドームリムを形状捕捉したため機体上では抜けない。
  蝶ボルト 2 本 + 顎の開閉で約 30 秒 — 旧方式と同等の手間)
- 組立性: カメラ・容器の着脱が工具最小で素早くできること (現行実績: カメラ数秒 / 容器 1 分)

## 3. 荷重ケース (すべて .md に安全率とたわみを記録する)

材料 PETG / X1C。設計許容応力 **XY 12 MPa / Z 層間 6 MPa** (極限 45/25 に安全率 4)。

| ケース | 荷重 | 入る場所 | 受ける場所 | 係数 |
|---|---|---|---|---|
| L1 吊り (運用) | 全備重量 × 3g、ブライドル 30° → 約 99 N/耳 | 吊り耳 ×2 | コアフレーム → 容器把持部 | 動的 3 |
| L2 輸送 (**新規**) | 全備 ~6 kg × ~~10g~~ **5g = ~300 N を任意方向から** (2026-09-04 パッド入りハードケース前提に緩和、改善要件 C6。裸でスーツケースなら 10g=600 N に戻す) | 外形の任意接地点 | フレーム全体。突出部品の根元が危険断面 | 落下 ~~10~~ 5 |
| L3 把持プリロード | 顎の締結ボルトの締付け → 容器周面の面圧 | ラッチ側ボルト | ヒンジ + 溝の段差。**アクリルチューブを局所荷重で割らない** (面で受ける + EVA) | — |
| L4 正面衝突 | 前進中の障害物接触 | 前縁バンパ | コアフレーム | 3〜5 |
| L5 着底 | 全備 × 3g | 下部ガード脚 | リング → コアフレーム | 3 |

R4 の判定基準: **突出部品はどの方向の L2 でも根元応力が許容内**であること。
満たせない場合は (a) 控え構造を足す、(b) フレーム包絡内へ引っ込める、
(c) 輸送時に取り外す部品にする (工具レス着脱 + .md に明記)。

## 5. 仮値・要実測 (再設計に効く順)

1. **防水ケースの実寸と軸の対応** — 公称 94.7×45.9×84.1 は「幅 45.9 < カメラ幅 47.2」で
   矛盾しており鵜呑みにできない。**現物実測が必須**
2. **ケースのレンズ軸位置** (ケース長手方向のどこにあるか) — §6 の幅問題の鍵
3. **フィンガー実寸** (タブ幅・厚さ・穴径・ピッチ。GoPro 互換なら 3.0t/隙間 3.4/Ø5.2 だが要確認)
4. **ドーム高さ dome_h** (公称起こしの仮値 53.25。54 超で全高 300 を割る)
5. **ペネトレータ突出量** (下部ガードの底面高さの根拠)
6. TD04A 胴径 26.4 / 胴長 55 (仮)、水中ライト (未選定, light_d=40 仮)、テザー外径 (未選定)

## 6. 幅の収まり — 縦向き搭載で解決 (2026-08-02 決定)

横向き (ランドスケープ) だとケース幅 94.7 が基線方向に来て
`75 + 47.35 + 構造` ≈ 262 > 250 で入らない (レンズ中央仮定)。

**縦向き (90° 回転) ならケース高さ 84.1 が基線方向に来て
`75 + 42.05 = 117.1/片側 → 全幅 234.2 + 保護構造`** で、
250 枠に対し片側 ~8mm の余裕が残る (レンズがケース中央にある仮定)。
この余裕は R4 (突出保護) の側面バンパに使える。

- 代償: **水平 FOV 145° → 105°** (垂直が広くなる)。VSLAM の水平視野は狭くなるが、
  ケース収容 (R1) と 250 枠の両立を優先してユーザが決定
- レンズ位置の実測でオフセット `lens_off_h` が判明したら、左右鏡像配置で
  張り出しの大きい側を内側へ向けて再最適化する
- **仮値運用**: ケース寸法・レンズ位置・フィンガー寸法はすべて公称/推定の仮値で
  設計を進め、実測後に Customizer 変数を置換して再ビルドする (2026-08-02 ユーザ指示)

## 7. 部品構成の方針 (R6 / R8)

```
コアフレーム (トポロジー最適化の対象、ワニの「下顎+頭骨」)
 ├─ 上顎 or ゲート (ヒンジ軸で開閉、ラッチ/ボルトで締結)  ← 容器の着脱はここだけ
 │    内面: チューブ用 EVA 面 + フランジカラー溝 (8mm 段) ×2 + キャップ段差受け
 ├─ カメラマウント ×2 (小部品): フィンガー受け + M5。基線 150 はコアフレーム側の
 │    取付面間距離で決める (組立誤差を面精度で管理)
 ├─ ライトクランプ (小部品, 製品未選定につき汎用 M4 パターンで仮置き)
 ├─ xdcr_socket (既存 common 部品を継続使用, パイロン/屋根側に M5×4 座を用意)
 ├─ 吊り耳 ×2 (突出させない: フレーム包絡内の貫通穴 or 控え付き)
 ├─ 取っ手 (包絡内に収める)
 └─ 下部ガード (小部品 or コアと一体判断: キャップ保護・脚・バラスト座 M6×5)
```

- 小部品 → コアフレームの締結は M4/M5 + ナットトラップ or 熱圧入インサートに統一
- 二重定義寸法 (基線・溝位置など) は最少にし、`part_index.py lock` で追従を監視

## 8. 進め方 (Workflow F: 細部品先行)

```
0. 取合いゲート: 防水ケース実測値をユーザから取得 → lock --confirmed
1. 細部品を Workflow A で設計 (各自の荷重ケース + quick_strength)
   カメラマウント → 顎の把持機構 (ヒンジ/ラッチ) → 下部ガード → 吊り/取っ手
2. placement.json (新アセンブリ or 既存を段階置換) に実配置
3. 残り空間を設計領域に、L1〜L5 の全荷重ケース同時でトポロジー最適化
   (filter_mm ≥ 4。小部品と締結座は keep-out)
4. 出力の部材リストから cube/cylinder のパラメトリック .scad へ手動再構築
5. topo_compare.py で剛性比較 → fea_check.py (mesh PASS 必須)
6. printability.py parts --audit で X1C 全数監査 (R7)
```

# フレームA–C取合い FRAME-A-C-M3-REV1

これはフレームAに設ける新しい製作用取合い。Blenderのねじオブジェクトの位置は使用しない。フレームCの製作用形状は今回の対象外であり、この穴表へ合わせて別途設計する。

寸法の正本は `design_parameters.json` の `c_holes_yz` と `inner_face_x`。この文書の数値はその説明。

| 項目 | mm |
|---|---|
| A内面の機体X座標 | ±84.95 |
| Aの基本板厚／最大奥行き | 12／45、機体外側へ |
| 穴軸 | 機体X方向 |
| AのM3通し穴径 | 3.5 |
| 機体Y座標 | −158、+158 |
| 各Y列の機体Z座標 | 30、50、240、260 |

各Aに8穴、両側で16穴。C側はA内面に接する座面とM3ナット保持部または金属ねじ受けを用意する。接地面、下部の手入れ開口、Aの分割接合板を避けてCを設計する。A側にはC接合用のねじ受けを設けていないため、ねじ長さはCの座厚・ねじ受けが決まってから選ぶ。

C穴のA外側ワッシャ座は、Z=30/50/240では局所板厚方向12 mm、Z=260では45 mm。
低い座には外側からØ10.5の直線工具空間を設ける。Ø9ワッシャの荷重面を想定する。
どちらもA内面の取合い位置は同じで、ねじ長さを列ごとの座厚へ合わせる。

Aの下部中央には270×100 mmの通過矩形を確保する。C、ガード、ケーブルを追加した完成機でもこの通路を維持する。ガードを閉じたままのアクセスは保証しない。

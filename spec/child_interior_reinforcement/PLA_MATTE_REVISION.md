# PLA Matte向けの固定根元補強（2026-09-27）

現行部品は `child_vtray_deck_t200` と `child_flange_brace`。STL / STEP / SCADを更新する。LCDと下側の円形リブは廃止したまま。

## 形状

- デッキ左右の固定座を接線方向20 mmへ拡大。根元をX37から始め、Z20..80の60 mmにわたってデッキへつなぐ。根元の内側フィレットR3、自由外縁R0.8を維持。
- 局所的な受け足を左右に追加。フランジの環状面に当たる公称Z19の面から固定座まで接続し、圧縮荷重を分散する。内径側はR44.6で逃がす。円形フレームは復活させない。
- 受け足はY-10..10に限定し、ケーブルレールと干渉しない。スペーサには直径6.8 mmの逃げを設け、既存MF10とM3×18を使用する。
- 前側ブレースの梁幅を8→10 mm、取付部のウェブ幅を16→20 mmへ拡大。
- PCB裏面ピン2本、レールねじ頭、ケーブルスリットを逃がす。取付穴位置は変更しない。

受け足の接触面は平面のまま残す。ねじを締めても割れない絶対的なトルク上限は未測定。印刷樹脂が沈むまで締め込まず、座面が接したところで止める。既存スペーサを省略しない。

## 印刷設定の出発点

0.4 mmノズルを想定。Bambu Lab PLA Matte、積層0.20 mm、壁8周、上下面6層、通常インフィル15%。デッキは板を寝かせ、ボス側を上にする（解析の積層軸Y）。ブレースは広い平面を下に置き、100%インフィル。

`pla_matte_lever/root_dense_modifier.stl` をデッキと同じオブジェクトに読み込み、Bambu Studioで「モディファイア」に変更。座標を保持し、左右の根元・受け足・固定座を100%インフィルに指定する。自動整列でモディファイアだけを移動させない。スライス断面で空洞が残らないことを確認する。壁数を増やすだけでは大型の座の内部が埋まるとは限らないため、局所100%を併用する。

寸法穴の仕上がりと受け足の接触を仮組みで確認する。造形収縮や反りで足が浮く場合は、ねじの締め付けで引き寄せない。

## 荷重と解析の限界

200 gを固定面から180 mm離した静荷重は約0.35 N·m。解析では200 gに5gの加速度を仮定した9.81 Nを先端に与え、部品自重も5gとしている。この5gは比較用の設計仮定で、実測の衝撃条件ではない。

[Bambu公式PLA Matte TDS V3.0](https://store.bblcdn.com/eff154c269404bf6a7baf48385a16e5a.pdf) はXY引張強さ30±5 MPa、Z方向22±4 MPaを掲載している。ただし試験片は100%インフィル、試験前に55℃・8時間の処理を受けている。通常15%インフィルの未処理部品へそのまま適用できない。

topoptの既存一般PLAカードで補助解析を実行する。Matte専用カードではなく、モデルは全面100%充填である。局所密度やねじの締付け、スペーサの柔軟性、接触の開閉は表現しない。左右ねじ穴のみを拘束し、前側ブレースと受け足の接触には解析上の支持を与えていない。したがって材料・組立の実物強度保証には使用しない。メッシュ収束判定と生データは `pla_matte_lever` に保存する。

更新形状を1.6 / 0.8 / 0.4 mmで計算した結果、topoptの収束判定は全4ケースFAIL。最細メッシュでは板に垂直な5g荷重の変位約12.5 mm、p99.5安全率5.39以上に対し、最悪要素の安全率は約1.3である。安全率4・変位1 mmの仮要求を満たす保証は得られていない。ねじ拘束端のホットスポットもメッシュで移動しており、これらは未収束の参考値である。以前の形状とは包絡とグリッド原点も異なるため、改善率は算出しない。

この解析を「PLA Matteで安全率5以上」として使用しない。受け足と前側支持の実接触、および通常部15%の内部構造を含む組立状態での評価と実物試験が必要。今回の納品は根元の断面拡大・荷重分散を行った試作形状であり、強度認証済み部品ではない。

## 組立とサービス

WetLink M10×5と出口付近の配線逃げ、電池サービスねじへの直径6 mm工具アクセス、床板の2 mm下降と引き抜き経路を維持する。サービス作業はアクリルチューブを外して行う。配線の全経路と曲げ半径は実配線に合わせて確認が必要。

最終の実物確認は200 g相当を搭載し、横向きの各方向で根元の浮き・白化・残留変形を確認する。初回は静荷重から始める。反復荷重と締付けに対する寿命は未測定。

## 今回の幾何検証

デッキとブレースのSTLは水密の一体形状。対応するSTEPは有効な単一ソリッドで、STLとの体積差は0.001%未満。組立STEPは内装75項目、子機全体82項目、いずれも配置検査0 NG。対象は200 mm構成（t200）。t300の既存出力は今回更新していない。

基板取付穴12点は一致。容器包絡に新規の干渉なし。元からの上側リブ0.50 mm・LED配線0.54 mmの狭隙間WARNは残る。変更した印刷部品と周辺部品の実体交差、配線出口の予約空間、工具・床板の移動検査は83交差チェックでエラー0。これは全ハーネスの実配線確認を置き換えるものではない。

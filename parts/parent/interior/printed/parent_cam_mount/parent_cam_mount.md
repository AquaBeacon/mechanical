# parent_cam_mount — GS カメラ 下向き保持フレーム (親機内装 パターン2)

**2026-08-28 新規。** `parent_interior_p2` で「宙に浮いた表示」だった GS カメラを
実体化する部品。RPi Global Shutter Camera + M12 4 mm レンズを**レンズ下向き**で
`parent_plate_p2` のビューポート開口 Ø36 上に固定する。

## 役割・主要寸法

| 項目 | 値 |
|---|---|
| 区分 | 親機 / 内装 / 3Dプリント (p2 のみ) |
| 外形 | 62 × 62 × 19.5 (脚 Ø7.5 h15 ×4 + フレーム t3 + 位置決めリム h1.5) |
| 中央開口 | 27 角 (M12 ホルダ台座 22 角 + 片側 2.5)。レンズ Ø17 も通る |
| 基板ポケット | 38.6 角 (基板 38 + 片側 0.3)、リム幅 2.5。CSI 側 (+Y) はリムを 24 幅で切欠き |
| カメラ固定 | M2.5 セルフタップ ×4、下穴 Ø2.0、ピッチ **34 (仮値)** |
| プレート固定 | M3×25 なべ ×4 (脚を貫通)、通し穴 Ø3.4、ピッチ **44 角** (`parent_plate.cam_hole_sq`)。ねじ頭座としてリム角を Ø7 で抜く |
| 位置 (箱座標) | 原点 = ビューポート中心 (**159**, 115) (箱中心 +X54)、脚下面 z=18.8 (プレート上面) |
| 高さ | カメラ基板下面 z=36.8、レンズ前面 z≈8.8 (箱床上面 3.8 から 5 mm) |

## インタフェース (二重定義の台帳)

| 変数 | 相手 | 値 |
|---|---|---|
| `foot_sq`, `foot_d`, `leg_d` ↔ `cam_hole_sq`, `cam_pilot`, `cam_leg_d` | `parent_plate.scad` | 44 / Ø3.4 / Ø7.5 ↔ 44 / Ø2.6 下穴 / Ø7.5 |
| `cam_sq`, `cam_pitch`, `base_sq`, `lens_d` | `gs_camera_m12.scad` / `.md` | 38 / 34 (仮) / 22 / 17 (仮) |
| ビューポート中心 | `parent_plate.vp_c` = (145.5, 101.5) プレート座標 (`vp_off=54`) | 箱 (159, 115) |

## 干渉チェック

`.scad` の assert: 中央開口 ↔ 台座・レンズ / カメラ穴 ↔ 中央開口の肉 ≥1.5 /
カメラ穴 ↔ 足穴 (同一対角線上) / 足穴のねじ頭座 ↔ 基板の角 / 足穴 ↔ 外縁。
プレート側は `parent_plate.scad` の総当り検査に**脚 Ø7.5** (突起扱い) が入っており、
p2 の TX ボス (121,131) と脚 (123.5,123.5) が 7.9 mm (要 7.75) で通過 — このために
`vp_off` を 53→54 にした。ビルド watertight、preview 目視済み。

## 荷重ケースと強度

カメラ ≈30 g × 落下係数 10 = 3 N をフレーム片側 (幅 35、t3、スパン 44) の梁で受ける:
応力 2.5 MPa (許容 19)、たわみ 0.6 mm — PASS (`quick_strength.py beam`, PETG 面内)。
軽荷重のため FEA 省略。

## 印刷指示

- **向き: 平置き (脚を下, +Z 上)**。脚は Ø7.5 の柱で自立、**サポート不要**
- **材料: PETG**、**インフィル 30%**、ウォール 3 周
- X1C 監査 PASS (最薄部 6.2 mm)

## 部品外の考慮

- **レンズ前面と窓の距離 5 mm (窓部品 `parent_cam_port` 未設計)**: Ø30 窓に対し
  M12 4 mm レンズの画角でケラれないかは窓部品設計時に要確認。脚高さ `leg_h` で調整できる。
- CSI フレキは +Y 側から出て Pi Zero (プレート y≥135) へ約 60 mm。リムの切欠き 24 幅を通す
- レンズ交換・ピント合わせはカメラを外して行う (M2.5 ×4)。TX 高架 (z 49.8) の下に
  手が入るかは要実機確認
- 520 nm BPF をレンズ前に入れる場合、レンズ前面〜窓の 5 mm に収まる薄型であること

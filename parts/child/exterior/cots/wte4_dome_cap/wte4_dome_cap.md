# WTE4 アクリルドームエンドキャップ (4" / 100mm シリーズ)

購入品 (COTS) / **未購入**。子機の耐圧容器の**上端**を塞ぐ。

縦置き吊り下げ構成では、ドームが上・アルミキャップ (ペネトレータ) が下になる。
ドームを上にする理由は「流線形で上向きの投影面積を減らす」「ケーブルは下から出す」
「上部に貫通部を作らない (吊り荷重とシールを分離する)」の 3 つ。

## この寸法に依存している自作部品

| 部品 | 依存している値 | 影響 |
|---|---|---|
| `child_shell_aft` | `dome_ring_od = 114.3` | ドームを真上に抜くための逃げ径 Ø122.3。吊り耳の内側位置を決めている |
| (機体全高) | `dome_h = 53.25` | **全高 = 298.25mm**。ここだけが 250×250×300 枠の残りリスク → **2026-09-04 に全高上限を 400 へ緩和** (下記の 300 前提の記述は履歴)。ガードを `ring_z0=−60` へ下げた改善案で全高 321 |

> **2026-09-04**: 将来**ドーム内から LED 光源を照らす**可能性あり。ドームの上半球を不透明部品で
> 覆わない (トップクラウンはドーム赤道より下、輸送キャップは運用時に外す)。詳細は
> [docs/子機外装_改善要件.md](../../../../../docs/子機外装_改善要件.md) §3.5。

**`dome_h` が 54mm を超えると全高 299mm を超える。** 超えた場合の調整代は
`child_bottom_guard.scad` の `ring_z0`(現 -37) を上げること。ただしペネトレータ
先端 (キャップ下面から約 20mm) より下にスキッド底面がある必要があるので、
上げられるのは実質 3mm 程度。それ以上はチューブを短くするしかない。

3Dプリント部品の**形状**は `dome_h` に依存していない (逃げ径のみに依存) ので、
実測値が違ってもプリント部品を作り直す必要はない。

## 部品外の考慮

- **吊り荷重はドームに掛けない。** ロープは `child_shell_aft` の吊り耳 2 点
  (ブライドル) で受ける。ドームまわりには構造物を置かず、真上に抜けるようにしてある
  (`child_shell_aft` の assert 1 が検査)。
- **開けるのはドーム側。** ケーブルは下のアルミキャップに集約されているので、
  内部にアクセスするときはドームの M3×12 を外して上から引き出す。
  このとき**下部ガードもシェルも外す必要がない**。
- ポリカーボネートは有機溶剤・アルカリで白化/クラックする。清掃は中性洗剤か水のみ。
  日焼け止め・防曇剤にも弱い。
- 空中で直射日光に当てると内部が高温になる。**運用前後は日陰に置く**。
- 傷が入ると耐圧が落ちる。輸送時はドームにカバーを掛けること
  (現状カバーは未設計。陸上では `child_bottom_guard` の脚で自立するのでドームは上を向く)。

## 要確認

1. **`dome_h` (座面からドーム頂点)** の実測 → 全高の確定
2. 押えリングの OD と、フランジ M3 (BCD 94.0) との適合
3. ベンダ配布 STEP/STL の入手 → 参考モデルの差し替え
4. O リングの型番・本数 (フランジ側と共通か)

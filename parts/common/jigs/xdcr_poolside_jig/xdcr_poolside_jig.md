# xdcr_poolside_jig — TD04A プールサイド L 字治具 (実験用)

**機体部品ではなく、対面測距試験 (E1) 用の治具。**
プールの縁にまたがせ、デッキ側におもりを載せて押さえる L 字 (正確には Z 字) 治具。
下端の棚に [`xdcr_clamp`](../xdcr_clamp/xdcr_clamp.md) を載せて TD04A を保持する。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / 治具 / 3Dプリント |
| 設計ソース | `xdcr_poolside_jig.scad` (バリアント定義 `variants.txt`) |
| 個数 | hook ×2 / foot ×2 (送受のプール縁に 1 セットずつ) |
| 外形 (hook) | 90.0 × 162.0 × 198.0 mm / 403.1 cm³ / STEP 41 面 |
| 外形 (foot) | 90.0 × 102.0 × 200.0 mm / 308.6 cm³ / STEP 32 面 |
| 組立 | hook + foot を重ね継ぎして M5×4 (M5×35) で締結 |

## 役割と成立させている数値

```
        陸側                     プール
  ┌──────────────────────┐  ← デッキ板 (おもりを載せる)
  │ □リブ    ▭ストラップ  ╱▌  ← ガセット + 縁の立ち上がり (おもり止め)
  └──────────────────────┘▌
                          ▌  Z=0 デッキ面
   ~~~~~~~~~~~~~~~~~~~~~~ ▌  水面 (freeboard 100 と仮定)
                          ▌  hook 支柱
                          ▓  ← 継手 (重ね継ぎ M5×4)
                          ▓  foot 立ち下がり
                          ▓
                          ▓▬▬▬▬▬▬▬  棚 (Z=-278) + xdcr_clamp
                              ◎ TD04A  軸 Z=-257.5
```

| 導出値 | 値 | 備考 |
|---|---|---|
| 総ドロップ (デッキ面 → 棚下面) | 290 mm | |
| 振動子軸 (デッキ面下) | 257.5 mm | |
| 振動子軸 (水面下) | **157.5 mm** | `freeboard = 100` のとき。**要実測** |
| 壁面 → 音響放射面 (0° 取付) | **107 mm** | 基準距離の補正に使う |
| 棚前縁 → 放射面 | 7 mm | ビームは棚に当たらない (assert 済) |

### 2 分割にした理由

必要な水深 (デッキ面下 ~290mm) は**印刷ベッドに 1 部品で載らない**。
断面 (YZ の L 形) をそのまま印刷するので、断面が 220 角に収まる必要がある。

| 部品 | 断面 (ベッド上) | ビルド高さ |
|---|---|---|
| hook | 162 × 198 | 90 (= `width`) |
| foot | 102 × 200 | 90 |

`bed_xy` / `bed_h` を実機に合わせて直すと assert が判定してくれる。
**もっと深く沈めたい場合は `foot_rise` を増やす** (ベッド上限まで)。
それでも足りないなら E1 仕様どおり VP25 ポール (`xdcr_pole_jig`) を使うこと。

### ビームの向きを 90° 変えられる

棚には `xdcr_clamp` 用のボルトパターンが **0° と 90° の 2 組**ある。

| 取付 | ビーム方向 | 使いどころ |
|---|---|---|
| 0° | 壁に垂直 (プール内側へ) | プール両端で対面させる長距離 (15–25m) |
| 90° | 壁に平行 | 同じ壁面に沿って並べる短距離 (1–5m) |

さらに `xdcr_socket` (機体側の本番ソケット、`hole_p = 40` の 40 角) 用の
4 穴も開けてある。**本番ソケットのまま水中試験ができる。**

## インタフェース (**二重定義に注意**)

`xdcr_clamp.scad` と同じ値を持っている。**片方だけ直さないこと。**

| 本部品 | `xdcr_clamp` 側 | 値 |
|---|---|---|
| `mount_x` | `mount_x` | 40 |
| `mount_y` | `mount_y` | 68 |
| `clamp_bw` | `base_w` | 56 |
| `clamp_bd` | `base_d` | 84 |
| `clamp_axz` | 導出 `axis_z` | 20.5 |
| `clamp_fx` | 導出 `face_off` | 38 |
| `sock_p` | `xdcr_socket` の `hole_p` | 40 |

> **TD04A の胴径を実測して `xdcr_clamp` を作り直したら、`clamp_axz` と `clamp_fx`
> をここへ転記すること。** この 2 つは形状ではなく「深さ」と「壁面オフセット」の
> 計算に効く。ずれても部品はできてしまうが、**測距の基準距離が狂う。**

| ケーブル固定 | 5 | 結束バンド 4.8mm 帯 |

## 干渉チェック (`.scad` 冒頭の assert)

1. **hook / foot の断面が `bed_xy` 角に収まる**、`width` が `bed_h` 以下
2. 重ね代が板厚の 4 倍以上 / 支柱が重ね代で埋まらない
3. 継手ボルトの端距離、重ね代からのはみ出し、座金が幅から出ない
4. **継手ボルト (X = ±25) と結束スロット (X = 中央) が離れている**
5. 結束スロットが**継手の重ね代に隠れない** (隠れるとバンドが通らない)
6. ストラップスロットが**ガセットの下に潜らない** / 端リブに掛からない
7. 安全ロープ穴が端リブ・ストラップスロットに掛からない
8. おもりを置く平面が 80mm 以上
9. **棚の 12 個のボルト穴の全ペアが `m5_d + 3` 以上離れている** (最小 14mm)
10. 棚のボルト穴の縁距離、**座金が立ち下がりの根元に乗り上げない**
11. `xdcr_clamp` のベースが棚に 0° / 90° の**両方で**収まる
12. **音響ビーム (半角 11°) が棚の前縁に当たらない** — 軸高さ 20.5 > 7×tan11° = 1.36

### 荷重 (ニーブレースを付けていない根拠)

水中側 (foot + clamp + TD04A) にかかる力は**上下どちらにも 0.5 kgf を超えない**。
棚の根元まわりの曲げモーメントは 0.5 kgf × 0.07 m ≒ **0.34 N·m**。
断面 90 × 12 の断面係数は 2160 mm³ なので **σ ≒ 0.16 MPa** (PETG 破断 ~45MPa)。
桁違いに小さいのでニーブレースもガセットも棚側には不要。
デッキ側のガセットは荷重ではなく**縁で受けるモーメントとおもり止め**のために付けている。

### 浮力 — **印刷部品は水中で「浮く」ことがある**

3Dプリント部品は**充填の内部に空気が残る**ので、排除体積は外形体積そのものになる。
充填 30% / 外周 4 本だと樹脂は外形の 4 割程度しか入っていない。

| 部品 | 外形体積 | 樹脂 ~40% の質量 | 排除体積による浮力 | 差引 |
|---|---|---|---|---|
| foot | 309 cm³ | ~157 g | ~309 gf | **約 150 gf 浮く** |
| xdcr_clamp (body+cap) | 88 cm³ | ~45 g | ~88 gf | 約 43 gf 浮く |
| hook の水没部 (~50mm) | 54 cm³ | ~27 g | ~54 gf | 約 27 gf 浮く |
| TD04A | **未実測** | — | — | おそらく沈む |

**合計はほぼ中性付近で、符号が確定しない** (TD04A の質量が未実測、充填率でも変わる)。
浮く側に振れると振動子が浮き上がって深さがずれ、水流でも揺れる。対策:

- 沈めたいなら **foot の充填率を上げる (50% 以上)**、または**棚におもり
  (ダイビングウェイト 0.5kg 等) を追加する**。棚の余った取付穴を使える。
- いずれにせよ**デッキ側のおもりは必須**。浮力は縁まわりに「プール側を持ち上げる」
  モーメントを作るので、押さえがないと治具が起き上がる。

## 印刷向き

**hook / foot とも「幅 (X) を Z 方向に立てて」印刷する。**
断面 (YZ の L 形) がそのままベッドに載り、全層が同じ断面になるので

- **サポートが一切要らない** (オーバーハングがどこにも無い)
- 曲げ応力が**層内**で受けられる (層間剥離しない)

スライサで X 軸まわりに 90° 回してから配置すること。
ベッド接地面が広いので反りにくいが、PETG なら念のためブリム。

水平方向の穴 (M5 継手穴・棚の取付穴) は印刷時に横穴になるので、
**上側がわずかに垂れる。Ø5.3 のリーマ or ドリルを通してから組むこと。**
結束スロット・ストラップスロットのブリッジ幅は 2.5–5mm なので支障なし。

材料は PETG 推奨。充填 25–30% / 外周 4 本で十分 (荷重は上記のとおり微小)。

## 部品外の考慮

- **プール施設を傷めない**。デッキ板の裏と支柱の壁側面に**ゴムシート (1–2mm) を貼る**。
  縁のタイル・オーバーフロー溝のグレーチングは欠けやすい。
  `corner_rl = 4` は縁の丸み逃げだが、**現物の縁形状は必ず見てから使うこと。**
  庇状にせり出している縁なら `lip_y` にその量を入れて再ビルドする
  (デッキ板が溝の上を跨ぐ形になる)。
- **おもり**: 純粋な転倒モーメントは小さい (計算 < 0.02 kgf·m) が、**上記の浮力**と
  「**蹴られた・ケーブルを引かれた**」ときの保険として **3–5 kg** 程度を
  デッキ板に載せ、ストラップで縛る。ダンベル / 水袋 / 砂袋いずれでも可。
- **安全ロープは必須**。プールに落とすと回収が面倒 (かつ施設に迷惑)。
  Ø8 穴からロープを取り、スターティング台やフェンスへ結ぶ。
- **TD04A のケーブル (3m)**: 棚 → foot 立ち下がり (結束 ×2) → 継手 → hook 支柱
  (結束 ×3) → デッキ板の縁 → 陸上へ。**3P プラグは絶対に水に浸けない。**
  ケーブル長 3m の内訳: 水中側の経路が約 0.4m、縁から機器まで残り約 2.6m。
  **プールサイドの機器置き場が縁から 2.5m 以上離れると届かない。**
- **測距の基準距離**: 振動子面は**壁面から 107mm 前**、水面下 157.5mm。
  レーザー距離計で測るのは壁面間距離なので、**両側の 107mm を引いて真距離とする**
  (対面で計 214mm)。この値は `xdcr_clamp` の実測反映で変わる。
- **マルチパス**: 振動子が壁面から 107mm しか離れておらず、水深も 157.5mm と浅い。
  `../docs/AquaBeacon_実験検証仕様書.md` の計算 (水深 1.2m・振動子深さ 0.6m 前提) より
  **水面反射・壁面反射の遅延が短くなる**ので、閾値を下げて初動 2–3 サイクルで
  検出を確定させること。**深さを稼ぎたければ `foot_rise` を増やすか、
  ポール治具 (`xdcr_pole_jig`) に切り替える。**
- **水平度**: 棚は支柱に対して直角に作ってあるが、**縁が水平でなければ振動子も傾く**。
  デッキ板に水準器を当てて確認し、必要ならデッキ板の下にシムを噛ませる。
- **工具アクセス**: 継手 M5×4 と棚 M5×4 はすべて**陸上で組む**。
  水中では触らない。棚のナットは棚の下面側に来るので、**先に棚 → clamp を組んでから
  foot と hook を継ぐ**と手が入る。
- **回収**: 使用後は真水で洗って乾燥させる。PETG でも**紫外線と吸水で寸法が変わる**ので
  シーズンをまたいで保管しない。

## 要確認

1. **プール縁の実測** → `lip_y` (せり出し) / `freeboard` (デッキ面→水面) /
   縁の丸み。オーバーフロー溝があるかどうかで成否が変わる**最重要項目**。
2. **プリンタのベッドサイズ** → `bed_xy` / `bed_h`。現在 220 角 / 250 高で assert 済み。
3. **TD04A の実測反映** → `xdcr_clamp` を作り直し、`clamp_axz` / `clamp_fx` を転記。
4. 水深 157.5mm で E1 の測距が成立するか (マルチパス)。
   足りなければ `foot_rise` 増 or `xdcr_pole_jig` へ切替。
5. **TD04A の質量**と印刷部品の充填率 → 水中側が浮くか沈むか。
   浮くなら充填率を上げるか棚におもりを追加する。
6. プール使用許可の条件 (施設に固定物を掛けてよいか、おもりの持込可否)。

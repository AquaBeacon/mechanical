# child_cam_lid — カメラポッド 押え蓋

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_cam_lid.scad` |
| 個数 | **2** (左右。形状は X 対称なので同じ物) |
| 外形 | 90.4 × 47.7 × 15 mm (板 10 + 押えパッド 5) |
| 体積 | 42.9 cm³ (STEP) → PETG 約 38 g |
| STEP | 1 ソリッド / 36 面 |

## 役割

`child_shell_fwd` のカメラポッドに落とし込んだ DJI Osmo Action 6 を上から押さえる。
**M4 蝶ボルト 2 本で着脱 (数秒)。**

押えパッドの下面に **EVA スポンジ 2mm** を貼る。締めると 0.6mm 潰れて、
カメラをポッド底の位置決めパッド ×3 へ押し付ける = **Z の再現性**が出る。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `lid_t` | 10 | 板厚 |
| `lid_ov` | 1.5 | ポッド側壁より外へ出す量 (ねじの端距離 + 水切り) |
| `lid_hw` (導出) | 45.2 | 半幅 |
| `pad_h` (導出) | 5.0 | 押えパッド高さ = `gap 6.4 − foam 2.0 + preload 0.6` |
| `rim_t` / `rim_h` / `rim_clr` | 3 / 2 / 0.5 | 位置決めリム (クレードルに落として蓋の XY を決める) |
| `sc_x` / `sc_y` (導出) | ±40.2 / 19.7 | M4 蝶ボルト |
| `win_hw` / `win_y0..y1` | 25 / 4..20 | 上面ボタンのアクセス窓 **位置は要実測** |

## インタフェース (**二重定義。片方だけ直さないこと**)

`child_shell_fwd` と共有: `cam_w=72.8` / `cam_h=47.2` / `cam_d=33.1` / `cam_clr=0.6` /
`lens_y=110` / `cam_ax_z=115` / `pod_wall=7` / `pod_rear=6` / `hood=8` /
`pod_top=145` / `lid_sc_y=90`。

ねじは **M4 蝶ボルト ×2**、相手はポッド側壁上面の **Ø3.3 下穴へのタッピング**
(深さ 12mm)。着脱を繰り返すなら Ø5.6×8 の M4 熱圧入インサートに置換すること。

## アセンブリ配置

`translate([±75, 70.3, 145])` (= `[±(base_line/2 − lens_dx), in_y0 − pod_rear, pod_top]`)。

## 干渉チェック (`.scad` 冒頭の assert)

- 押えパッド高さが正 (`pod_top` を上げすぎるとパッドが伸びて折れる)
- 押え代の計算整合 (`pad_h + foam − preload == gap`)
- 位置決めリムがカメラ上面に当たらないこと (リム 2mm < gap 6.4)
- **蓋ねじがクレードル内腔に掛からないこと** / 外側端距離 ≥2mm
  → ここで実際に 0.25mm 足りずに止まり、`lid_ov = 1.5` を追加した
- 位置決めリムがクレードルに落ちる幅であること
- **蓋込みの全幅 ≤ 250** (蓋がポッドより広いので、機体の最大幅を決めるのはこの部品)
- アクセス窓がリム/ねじに掛からないこと

## 印刷向き

**上下逆さま** (z=`lid_t` の平面をベッドに置く)。押えパッドと位置決めリムが
上を向くのでサポート不要。接地面 90.4 × 47.7 で安定。

## 部品外の考慮

- **上面ボタンのアクセス窓の位置は仮値**。実機で合わなければ `win_*` を直すか、
  `win_on = false` で塞ぐ (窓なしの方が保護は良い)。
- 蓋を開けないと電池・SD が触れない。**入水前に充電・設定・時刻同期を済ませる**。
- EVA スポンジは消耗品。潰れたら交換する (BOM に予備を入れること)。
- 蓋の水抜き穴 (Ø6 ×2、前寄り) は塞がないこと。クレードルは水没する前提。
- 蝶ボルトは水中で回すことがある。**ステンレス (A2/A4) を使い、
  PETG のタッピング部が痩せてきたらインサートへ移行する**。

## 要確認

1. Osmo Action 6 の**上面ボタンの位置** → `win_*`
2. カメラ上面が本当に平らか (突起があると押えパッドが当たる) → `pad_h`
3. M4 蝶ボルトの入手 (M4×20、4 本)

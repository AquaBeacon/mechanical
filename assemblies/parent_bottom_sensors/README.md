# 親機外装：最下部の下向きカメラ・TD04A／一体型フィン

2026-09-10 更新。既存タカチ BCAS212310G、左右の浮き2個を紐だけでつなぐ構成を継承。カメラを最下部で下向きに変更し、TD04Aもその横で下向きに保持する。金具・箱・浮き・センサーは購入品で、印刷するのは外装の支持部品。

## 今回の変更

|項目|今回の構造|
|---|---|
|カメラ|既存Osmo用マウントを90°回転。光軸を鉛直下向き（−Z）にする。ケース包絡の前面は箱底から約493 mm下|
|TD04A|カメラの横、中心X=65、Y=−40。放射面Z=−493。2分割クランプをM4×65の2本で締め、M5×25の4本で支持板へ固定|
|センサー支持部|円盤下面へM5×25の4本で固定する共通支持板。カメラ・TD04Aともボルトとナットで着脱可能|
|フィン|直径225×厚さ5の水平円盤＋125×65×厚さ4の垂直フィン4枚＋中央ソケットを一体印刷。従来の7部品を1部品へ|
|フィン固定|支柱へM6×60の横ねじ2本。従来のフィン8本＋ハブ2本の固定を2本へ削減。錘ケース固定の4本は別途必要|
|収納|センサー支持部4本と支柱固定2本を外して分離。一体フィンは225×225×130 mmなので、フィンを板状にばらす旧方式より収納時の高さは増える|

座標は箱底Z=0。円盤Z=−360..−355、錘ケースZ=−417..−360、センサー支持部下端Z=−501。カメラ包絡とTD04Aの放射面はほぼ同じ高さ。カメラマウントと支持板が約8 mm下へ出ており、レンズ前を横切る底板は設けていない。レンズ位置・画角は実物ケースで確認する。

## ねじ配置と確認方法

`placement.json`が全形状・金具の配置の正。新しい締結の基準面・締結厚・ねじ先端の突出量は`joints.json`に記録する。ねじ単体を目測で動かさず、部品の座面から座金・ねじ・ナットを生成する。

カメラの向き変更に合わせ、軸ねじと六角ナットも同じ回転で移す。六角ナットは軸方向だけでなく六角の位相もマウントの捕捉穴へ合わせる。

元のタカチ表示モデルはコーナー柱が中実で、外部固定用の座面・穴を省略していた。今回のアセンブリ専用表示モデルでは、同梱メーカー図面`ref/BCAS212310G.pdf`の2ページE-Eにある穴径4.2・座面高さ6を反映した。上側の工具通路径9.4は表示用仮値で実測未確定。**購入ボックスへの追加穴加工を指示するものではない。** 元の共通購入品モデルは変更していない。

`bearing_checks.json`は座金両面の24点ずつを、金具以外の実部品表面と照合する。ねじ・座金・ナットだけがまとめて浮いていても合格しない。接触サンプル検査とSTEP読み戻し検査も別途実施する。検査は形状・配置の検査で、耐荷重や締付トルクを保証するものではない。

## 印刷

印刷13種類14点。最大部品はデッキ216×236×60、一体フィン225×225×130。印刷向きのSTLを`parent_bottom_sensors_X1C_prints.zip`にまとめる。4種類の新部品をX1 Carbon設定でスライスし、継承品は過去のスライス済みSTLとのSHA256一致を確認する。

PETG、0.4 mmノズル、0.20 mm層、壁6周、上下6層、Gyroid 40%、外側ブリム5 mm、自動通常サポート、Textured PEI。XY中心を(138,128)へ配置し、プリンタの禁止領域を維持する。金具は印刷しない。

一体フィンは円盤を下、支持板は広い背面を下に置く。TDクランプ本体は取付面を下、蓋は外面を下。支柱の横穴などは印刷後に通りを確認する。

## 組立順

1. 箱・GPS・上部アダプター・分割支柱を組み立てる。カメラ用の旧上部ブリッジは使わない。
2. 一体フィンを下側支柱に差し、M6×60の2本を通して座金・ナットで固定する。
3. 一体フィンの4個の開放ボスからM5×35を通して錘ケースの天板を固定する。錘と蓋を取り付ける。
4. センサー支持板へカメラマウントをM5×25の4本で固定。カメラを純正仕様と照合した軸ねじで保持する。
5. TD04Aの径・長さを実測し、適合するクランプ本体と蓋で胴を挟む。M4×65の2本は均等に締め、樹脂や振動子をつぶさない。図の0.5 mmは締付前の分割面隙間。
6. 支持板を円盤下面にM5×25の4本で固定。ケーブルを背面に沿わせて既存の穴で張力を逃がす。浮き2個を左右で紐接続する。

先にセンサー支持板を外すと錘ケースへの工具アクセスが容易。M5ナットは保持工具を使用する。浮きの接続に剛体アームやクランプは使わない。

## 要実測・未評価

- TD04Aの胴径26、胴長55は既存資料の仮値。`scad/lib/parent_bottom_sensors.scad`の`td_d`、`td_len`、`clamp_gap`に依存する。段差・テーパ・ケーブル出口形状も実測前。クランプは量産用確定寸法ではない。
- カメラケース95×45.9×75の包絡と既存マウントは実物適合・レンズ位置・画角が未確認。TD04Aとの干渉は仮包絡での検査に限る。
- 浮き寸法、紐の余長、波による可動域、浮力・復原性・揺れの低減量、荷重・疲労・水密性は実機未評価。紐接続の浮きを剛体の双胴として計算しない。
- ケーブルの外径・曲げ半径・プラグ処理は未確定。プラグを切断する前提にしない。既存のIMU内装配置は継承。

## 検証結果（2026-09-10）

- 固定外装・金具・錘/GPS参照・箱/ペネトレータ：サンプル接触検査の浮き0・貫通0。自由に動く浮き・紐、仮センサー包絡、既存内装はこの検査の対象外。
- 座金80枚：実部品の座面への接触検査80/80合格。
- 組立STEPを読み戻し：198部品、配置ずれ0件（外形比較許容0.5 mm）。
- 新規4種類はX1 Carbonスライス成功、継承9種類は検査済みSTLとのSHA256一致。全印刷STLは閉じた単一メッシュで、5 mmブリム込みの保守的な配置枠に適合。
- 14点分の印刷見積もり：約2.34 kg、72.4時間（サポート・ブリム込み）。浮力計算に用いる完成品質量とは異なる。

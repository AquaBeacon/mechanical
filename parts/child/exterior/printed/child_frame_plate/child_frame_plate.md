| 項目 | 値 |

| 区分 | 子機 / 外装 / 3Dプリント |

## 役割

子機のすべてを載せる基準部品。**アセンブリの原点 (底面 z = 0)** はこの板。

| 搭載物 | 位置 |
|---|---|
| チューブクランプ ×2 (`child_clamp_base`) | 中央、y = ±60 / M5 x=±80, y=中心±20 |
| Osmo アーム ×2 (`child_osmo_arm`) | 左右端 / M5 x = ±70, ±90, y = ±30 |
| 水中ライト (`dive_light`) | 前縁 / M4 x = ±15, y = +100, +120 |
| TD04A ソケット (`xdcr_socket`) | 後方コーナー / 中心 (±70, −120)、M5 ピッチ 40 |
| おもり (バラスト) | 中央下面沿いのスロット ×2 (x = ±30, 幅 10 × 長 140) |
| 汎用 | 40mm グリッド穴 (Ø5.3) |

## 座標系

X = 左右 (基線方向) / Y = 前後 (チューブ軸・進行方向、+Y = 前) / 原点 = 板の中心。

| 変数 | 値 |
|---|---|

| `clamp_cy` | 60 |

| `xd_cx / xd_cy / xd_pitch` | ±70 / −120 / 40 |

## 印刷向き

平置き。**200 × 300 はベッドに載らない可能性が高い**。
45° 置き、または 2 分割 (要相談)。分割する場合は継ぎ手の設計が必要 (**未設計**)。

## 部品外の考慮

- 40mm グリッド穴は**結束バンドの結束点**として使う。テザー・ライト・振動子の
  ケーブルはここに固定してカメラ視野から外す。
- **テザーのストレインリリーフが未設計**。シール部に引張をかけないため、
  プレート側でテザーを受ける金具/アイボルトが要る。
- おもりスロットは下面沿い。**水中でのトリム調整**に使うので、実機で
  前後バランスを見てから位置を決められるよう長穴になっている。
- プレート下面と地面 (陸上での置き方) — 現状 脚がない。運搬・仮置き時に
  カメラやライトが直接当たらないか確認すること。

## 要確認

1. プリンタのベッドサイズ → 分割要否の判断
2. 各搭載物の実穴位置 (ライトは特に**未選定**なので仮の M4×4)
3. ストレインリリーフの追加設計

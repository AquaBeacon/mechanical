# tx_improved — 親機 音響 TX 基板

KiCad で設計した自作基板の 3D モデル。**このリポジトリでは編集しない** —
`hardware/pcb/TX_improved/` が設計ソースで、ここには成果物を置くだけ。

| 項目 | 値 |
|---|---|
| 区分 | 親機 / 内装 / 基板 |
| 生成元 | `hardware/pcb/3d/TX_improved.step` / `TX_improved_mech.stl` |
| 生成コマンド | `python -X utf8 pcb\export_3d.py TX_improved` (Kicad_project 側) |
| 使用数 | 1 |

## 寸法 (`_mech.stl` の実測。仮値ではない)

| 項目 | 値 |
|---|---|
| 外形 (W × D) | **75.43 × 50.0 mm** |
| 板厚 | 1.6 mm (STL の z = 0 〜 1.6) |
| **基板上面からの最大部品高さ** | **13.79 mm** (STL z = 15.39) |
| **裏面リード突出** | **5.74 mm** (STL z = -5.74) |
| 全高 | 21.13 mm |
| 体積 (部品込み) | 10.0 cm³ |
| 高背部品 | トロイダルコイル + 電解コンデンサ |

## 座標系

STL / STEP とも **X = 0..75.43 / Y = -50.0..0 / Z = 板が 0..1.6、部品が +Z**。
KiCad の基板左上が原点なので **Y が負**になる。`placement.json` の `ops` は
これを前提に書いてある。

## 取付穴 (H1〜H4)

`.kicad_pcb` の実座標 (基板左下を原点、Y は上向き正):

(2.4, 44.4) / (68.4, 44.4) / (2.4, 2.4) / (68.4, 2.4)

→ ピッチ **66 × 42 mm**。Ø3.2 (M3 クリアランス)。

## 役割

200kHz バースト生成、ゲートドライバ (TC4427)、MOSFET、保護、整合、TD04A 接続

## 実装位置

親機防水ボックス内。**発熱・高dv/dt があるので MAIN から離す**

## 部品外の考慮

- **コネクタの抜き差し空間**を基板の外に取ること。上表の位置は基板座標なので、
  `placement.json` の変換を通して機体座標に直してから干渉を見る。
- ケーブルは `docs/配線・ケーブル計画.md` に集約する。
- 基板を**アセンブリでビルドすると STEP が重い** (この基板の STEP は銅箔・
  ベタ・シルクまで入っている)。プレビューだけでよいときは `-NoStep` を使う。
- `_mech.stl` は KiCad の STEP エクスポータ由来なので、
  **水密でない場合がある** (部品ソリッドが基板に食い込んでいる箇所)。
  干渉確認には使えるが、体積・浮力計算には使わないこと。

# child_vtray_cable_rail

2026-10-07：ユーザーが未使用のため、現行 child_interior と child_vertical_assembly からレール2本と固定ねじ8本を撤去。以下は設計履歴。現行の印刷対象ではない。設計元は削除せず保持する。

子機縦トレイ下面へ取り付ける、PLA製の着脱式ケーブルレールです。2本使用し、`+X`側を電源、`-X`側を信号・センサ系に分離します。

- 印刷方向: SCADの向きのまま、平面をベッド側。サポート不要
- 材料: X1-Carbon / 白PLA、0.4 mmノズル、0.2 mm積層、壁4周以上
- 固定: **デッキの実肉部**（assembly Z = 37 / 77）へ各位置 M3 ×2。デッキ上面から
  Ø3.4 バカ穴を通し、レール側壁の Ø2.8 下穴へセルフタップする（ナット不要）
- 配線固定: 幅4 mm以下の結束バンドまたは再使用式タイを30 mm以下の間隔で使用
- 8 mmまでの束を想定。ケーブル外皮保護のため0.5–1 mmの独立気泡フォームを溝へ貼る

レールはRX基板の手前（assembly Z=130）で終わるため、RX基板とは重なりません。コネクタ直前には抜き差し用のサービスループを残してください。

## 2026-09-03 最終状態 — 個数 2 に復活、底の窓を追加

2026-09-03 から、電池リードの配線路が変わったことに伴い：

- **個数は 2 に復活** (XT60 硬直部がクレードル内に収まったため、+X レールの空間が不要になったわけではない)。
- **レール底に窓を追加**: ローカル y 70..84 (世界 z 90..104)、チャンネル幅 8 で底板を貫通。理由は、デッキの中段スリット (z 83..109) がレール底板で塞がれていたため、デッキ上面からトラフへ落とせなかった。
- **結束スロットを変更**: `tie_y=[10,35,62,92,105]` (世界 z 30/55/82/112/125)、間隔 ≤30mm。

## 2026-08-03 修正 — ボルトが空中にあった

旧設計は `mount_y = [40, 80]`（assembly Z = 60 / 100）で、これは
**デッキ自身の配線スリットの真ん中**でした。ねじを締める相手の材料が無く、
「ワイドワッシャで渡す」という当初の想定も、スリット幅 16 mm に対して
M3 ワイドワッシャは Ø9〜12 mm しかないため成立しません（穴へ落ちる）。

| 項目 | 旧 | 新 |
|---|---|---|
| `mount_y`（レール座標） | `[40, 80]` | `[17, 57]` |
| assembly Z | 60 / 100（**スリットの中**） | 37 / 77（**桟の上**） |
| `mount_d` | 3.4（バカ穴） | 2.8（M3セルフタップ下穴） |
| デッキ側 | 穴なし | `rail_hz = [37, 77]` に Ø3.4 ×8 |

ねじはレール側壁（`base_t + wall_h` = 8.9 mm）へ食い込むので、ねじ込み長が
十分に取れます。溝の底（`base_t` = 2.4 mm）は絶対に使わないこと
（`.scad` の assert が阻止します）。

Z = 37 / 77 は次のすべてを外して選んでいます。片方だけ動かさないでください。

- デッキ配線スリット 3 箇所（Z = 58 / 96 / 157、長さ 26）
- `CHILD_MAIN` の M3 ボス（X = +39.5、Z = 24.5 / 119.5）
  — レール外側のねじ (X = +41.7) がここに乗る
- `CHILD_PWR` の M3 ボス（X = ±31、Z = 130 / 184）
  — レール内側のねじ (X = ±30.3) がここに乗る

この 3 条件を同時に満たす帯は Z = 31〜43 と 73〜81 しかありません。
`child_vtray_deck.scad` の総当り assert が違反を検出します。

## 部品外の考慮

- レール上端（assembly Z = 130）より上、RX 基板と `CHILD_PWR` の区間には
  レールがありません。ここは結束バンドでリブ側へ寄せて処理します。
- 上側のねじ止め点を Z = 120 付近に増やすことはできません。`CHILD_PWR` の
  H1 列ボス（Z = 130）と `CHILD_MAIN` の H2/H4 ボス（Z = 119.5）が
  レールの両方のねじ位置を塞いでいます。

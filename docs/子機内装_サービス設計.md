# 子機内装 サービス設計（200 mm WTE4 / X1-Carbon 白PLA）

2026-08-02生成の `CHILD_MAIN v4.1`、`CHILD_PWR v2.1` 実モデルを使った
縦置き内装の確定設計。全体形状は
[`child_vertical_assembly_interior.step`](../assemblies/child_vertical_assembly/child_vertical_assembly_interior.step)、
外向きLCDは `child_vertical_assembly_lcd_view.png` で確認できる。

## 構成と固定

| 対象 | 固定方法 | 外し方 |
|---|---|---|
| CHILD_MAIN | デッキのM3ボス4点 | LCD支持アーチを外し、4本を＋Y側から緩める |
| CHILD_PWR | デッキのM3ボス4点 (z 126..188) | ＋Y側から4本を緩める。トグル、XT30、XH9を先に抜く |
| RX基板 | デッキ下面、**M2** 6mmスペーサ4点 | デッキを抜いた後、−Y側から外す |
| LiPo | Uベイ＋軸方向ゲート | ゲートのM3を2本外し、＋Zへスライド。MAINは外さない |
| LCD | 左M3縦ヒンジ＋右M2.5ラッチ1本＋後クランプ2本 | 内装を70 mm以上引き出し、右ラッチ1本を緩めて約100°片開き。LCD単体は後クランプM2.5×4で交換 |
| 内装全体 | 上下グライドリブ＋下フランジM3 BCD94の**3点** (0°/180° デッキラグ、90° 下LCDアーチの耳) | 上フランジを抜き、上から 0°/180° の M3×10 ×2 と 90° の M3×12 ×1 を緩めて上へ引く |

下フランジ固定は、メーカーSTEPからCADカーネルで抽出したBCD94の左右穴
（OpenSCAD角度0°/180°、中心座標 `(±47.000, 0.000)`）にM3×10 mm
オス―メススペーサ＋0.5 mmシムを立て、LiPoベイの二股アンカーをM3ねじ＋ワッシャで挟む。
これにより、基板→デッキ→LiPoベイ→スペーサ→アルミフランジ→耐圧容器が
機械的につながる。アンカー外端は半径49.5 mm、アクリルID101.6に対して1.3 mm残る。

> `BR-101040_RevC.step`で、筒側Z=0から開口する4穴（0°/90°/180°/270°）と
> モデル上のねじ深さ6.049 mmを確認済み。旧225°/315°案は実穴がなく廃止した。
> 詳細は [`子機フランジねじ穴検証.md`](子機フランジねじ穴検証.md)。実機では製造公差、
> Oリング、ロッキングコードとの非干渉を確認し、有効ねじ込みを4～5 mmに制限する。

## LCDと操作アクセス

- LCD: `NHD-C0216CiZ-FSW-FBW-3V3`（56.8×26.2×5.5 mm）を長手方向Z、
  表示面＋Yで保持。透明アクリル越しに外から読む。
- LCD前面からアクリル内壁までの最小余裕は約4.9 mm。薄い閉孔フォームを
  ベゼル前縁へ貼り、振動を止めるが、アクリルへ押し付けない。
- 8 mmピンと20×50 mmのI2Cキャリア包絡を含めても、MAIN最高部品まで約9 mm残る。
- microSDとPico USBは−X側、UP/ENTER/DOWNは＋X側。LCD幅はX±18.2以内で、
  どちらの側面アクセス線も塞がない。
- PWRのトグル、J_BAT/J_LED、J_MAINは＋Y側から見える。LCDはMAIN区画だけを覆う。

LCD支持はC-MAIN取付穴と共締めする。X=−22側にM3 35 mm、X=＋39.5側に
M3 20 mmのオス―メススペーサを各2本使う。非対称アーチで円筒断面へ沿わせ、
平板パネルより半径を節約する。

上下アーチの間には `child_lcd_hinge_frame` をM3×2で固定する。LCDベゼルは
−X側のM3縦ヒンジを残したまま、＋X側の埋込みM2.5ラッチ1本だけで開閉する。
ラッチねじは低頭をベゼル面へ沈め、裏側の小径シリコンOリングで抜け止めする。
開放角100°でLCDドアとMAIN部品面のY方向余裕は11.9 mm。筒内では開けない。

## ケーブル経路

1. 5穴エンドキャップのペネトレータから下リブの40×22 mm開口へ入れる。
2. 下リブの左右結束スロットで、ペネトレータへ引張が伝わらないよう固定する。
3. デッキ下面へケーブルレール2本を、デッキ実肉部 (Z=37/77) のØ3.4穴からM3各2本で固定し、＋Xを電源、−Xをセンサ/通信に分ける（ねじはレール側壁へセルフタップ。スリットの中には締めない）。
4. 各レールの結束穴を使い、幅4 mm以下のタイで最大30 mm間隔に固定する。
5. 各コネクタ直前に外径の4～6倍の曲げ半径と、小さなサービスループを残す。
6. LCDのXH7ハーネスは−Xヒンジ側へ寄せ、100°開放を妨げない柔らかいサービスループを残して `J_LCD1` へ落とす。

下キャップを外した状態で内装を50～60 mm引ける余長を残す。完全に抜く前に
外部センサ、ライト、テザーを基板側コネクタで切り離す。ケーブルを引張って
ペネトレータから抜こうとしない。

## 組立順

1. LiPoベイをデッキ下面へM3×4、RXを**M2** 6 mmスペーサで固定する。
2. LiPoを＋Zから入れ、リードをゲート切欠きへ出してゲートをM3×2で閉じる。
3. ケーブルレール2本をデッキ実肉部 (Z=37/77) のØ3.4穴へM3でセルフタップ固定し、MAIN/PWRをデッキへ固定する。
4. 全ハーネスを電源/信号へ分離し、レールへ最大30 mm間隔で結束する。
5. MAINの4穴へ20/35 mmオス―メススペーサを立て、LCDアーチ2枚を固定する。
6. Cフレームを上下アーチへM3×2で固定し、M2.5ヒートセットインサートを圧入する。
7. LCDをフォーム付きベゼルへ入れ、後クランプ2本をM2.5×4で締める。
8. 左ヒンジへM3×60ピンを通し、右M2.5×12ラッチを締めて表示面＋Yを確認する。
9. 内装を70 mm引き出し、ラッチ1本で100°開閉でき、XH7ループが張らないことを確認する。
10. 下フランジの0°/180°穴へ10 mmスペーサを立て、デッキのラグをM3×10で締結する。90°穴 (0, +47) は下LCDアーチの耳をM3×12で直接締結する (六角穴付き推奨、2.5 mm 六角レンチを上から (0,47) に沿って下ろす)。
11. 下キャップ配線をリブでストレインリリーフし、LCDを閉じてから上から内装を挿入する。
12. 上フランジ、Oリング、ロッキングコードを復旧し、LCD視認と全操作を確認する。


## 2026-08-03 修正 — 取付穴の実基板照合

内装を実基板の `.kicad_pcb` と突き合わせ、次の**取付穴の不一致**を修正した。
どれも `.scad` はビルドでき assert も通り、プレビューも正しく見えていた。

| 対象 | 不具合 | 実基板 | 修正後 |
|---|---|---|---|
| `CHILD_MAIN` | ボス X が **17.5 / 3.5 mm ずれ** | 穴 y = 4.5 / 66 | X = **+39.5 / −22.0** |
| `RX_improved_mini` | 穴が **1.56 mm ずれ**、かつ **M3 は通らない** | Ø2.2 NPTH (M2) / 2.5・65.5 × 2.5・43.5 | X = ±31.5、Z = 136.5 / 177.5、**Ø2.4 + M2** |
| `CHILD_PWR` | `variants.txt` が `pwr_hu=[2.4,59.6]` で上書きし、**再ビルドすると 1.6 mm ずれる** | 穴 inset 4.0 | 上書きを削除 |

原因は 3 つとも「基板座標 → 機体座標の変換結果を手で書き写していた」こと。
現在は `child_vtray_deck.scad` が `.kicad_pcb` の実座標そのものを持ち、
**変換式でボス位置を導出**する。`variants.txt` で穴位置を上書きすることは禁止。

副次的に見つかって直したもの:

- `child_vtray_batt_gate` がゲートを箱の**全長の外**に置いていたため、
  `rx_z0 >= box_z0 + box_len` の検査をすり抜けて RX 基板を 1 mm 貫通していた。
  → シェルを 109 に縮め、ゲートを全長 112 の内側 (z 129..132) に座らせた。
- `child_vtray_cable_rail` の M3 ×4 が**デッキの配線スリットの中**に落ちていて、
  締める相手の材料が無かった（ワイドワッシャでは 16 mm 幅を渡せない）。
  → 実肉部 Z = 37 / 77 へ移し、デッキ側に Ø3.4 を新設、レール側壁へセルフタップ。
- LiPo ベイのねじ頭 (Z=114) が MAIN の H3 ボスに乗っていた → ねじを Z=110 へ。
- 配線スリットを 16×30 → **14×26** に縮小。桟が 8 → 12 mm になり、
  ねじ頭の縁の肉とデッキの曲げ剛性を確保した。
- `CHILD_PWR` を z 128 → **126** へ。RX の取付ねじ頭と PWR の H1 列ボスが
  4.53 mm しか離れておらず干渉していた。MAIN との軸方向すきまは 2 mm。

### 検証

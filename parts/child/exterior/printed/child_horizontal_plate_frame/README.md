## 印刷済みと未印刷

側板2枚・底板1枚と、別設計元の上下クランプ各1個は印刷済み。形状・配置・設計元STLのSHA-256を固定する。共通SCAD更新後は照合用メッシュを別出力し、元STLと一致することを検証してバイト列を保持する。側板・底板のナット受けと丸穴は既存形状を継続する。共通のef_boreを変更せず、未印刷部品だけef_poly_boreを使う。

これから印刷するのは上部1、前保護延長左右各1、後保護延長左右各1、回転止め左右各1、支持治具4、C押さえ4の計15個。全体数量20個と取り違えない。左右側板・支持治具は180°回転で同じSTL、延長と回転止めは左右鏡像を別STLへ反映する。

## 開放ナット式

上部・支持治具・回転止めの六角ナット保持溝を廃止する。ナットを回り止めする埋込み形状を設けず、貫通ねじと普通M3ナットを使い、開放部からスパナで押さえる。既存取付穴位置は保持する。

支持治具は取付足厚8 mm、側板厚12 mm、ピッチ20×24 mm、ねじ中心Y=±50/±70・Z42/66。下クランプ取付面Z75.2と40×20 mm穴配置、支持梁厚17 mmを保持する。ナット側にもφ7×0.5 mmワッシャを置き、M3×25各4本。M3×30も幾何検査する。上段の梁には側端へ開いた工具通路と、ねじ先端を逃がす貫通穴を設ける。支持治具は広いガセット面をベッドへ向ける。

回転止めは広い底面が印刷ベッドに接するよう、manufacturing.jsonで設計元STLからX=90°回転する。配布STLではこの回転を反映済み。組立姿勢は保持する。回転止めは取付足厚8 mm、Y−98・Z122/142。M3×25各2本、M3×30も幾何検査する。工具は+Y側から入れる。公式蓋輪郭・隙間0.55 mm・受け奥行7.1 mmは保持する。取付足と受けの根元のR/面取りを継続する。

上部→側板は厚12 mmの接合座へ普通ナットとワッシャを置き、上から工具を入れる。側板厚12 mmを含みM3×30各2本、計4本。M3×40も幾何検査する。ねじ先端を逃がす穴は開放部の先まで通す。上クランプ→上部の8本は印刷済みクランプの受けを使い、M3×18を保持する。

## クランプ締付ねじへの上側工具穴

トップフレーム `top` に、クランプ上下を締めるM3×30の6軸と同軸の工具穴を追加した。既存8か所のクランプ取付穴とは用途が異なる。正本SCADの `hf_stations` と `hf_ear_rows` を使い、穴位置を別に手入力しない。機体XYの中心は左X−67.8481/Y−70・−50・50・70、右X67.8481/Y−60・60。厚10 mmを鉛直に貫通する。

工具軸は既存の仮包絡φ8×長70 mmを使い、半径1 mmの隙間から穴の内接円径φ10 mmを導出する。穴は補正した正12角形、両入口0.4 mm面取り。工具の持ち手をフレーム上へ出せる軸長を実物で確認する。縁に近い左側の内寄り2軸の周囲は局所的に広げ、穴中心から外周までの公称半径9.5 mmを確保した。外周のR2と0.6 mm面取りを維持し、入り隅も共通仕上げを通す。元のフレーム外形、接合座、取付穴、上面Z210.8は保持する。

[工具・穴断面の検査](../../../../../assemblies/child_horizontal_plate_frame/_work/analysis/top_clamp_access/validation.json)と[上面図](../../../../../assemblies/child_horizontal_plate_frame/_work/images/top_clamp_access.png)を参照。6本すべてのねじ頭からフレーム上まで、容器・クランプ・金具・ライトを装着した状態で工具軸の干渉を検査する。穴の両入口と中央断面、隣の輪郭までの残存肉厚、既存8か所の取付ねじの座面も照合する。工具径は仮定、PETGの強度認定は含まない。

6軸の工具進入、内接円径10の中央断面と入口面取り、既存8か所の座面は合格。両入口から0.001 mm内側と厚さ中央で調べた残存肉厚は最小3.3008 mm。変更したトップは閉メッシュ・単一連結・退化面0、従来の底面を下に実スライスしサポート押出0。0.2 mm層・PETG Basicの1個見積りは291.77 g・約6時間。その他9バリアントの頂点・外形・体積は変更前と一致し、全品の位置と全ねじ配置を保持した。再生成で変わったSTLの並びに合わせてスライスも更新した。

## 穴・面取り・印刷

未印刷6種類のM3穴は正八角形、内接円径3.5 mm、頂点径約3.788 mm。共通ef_poly_boreで半径をcos(180/8)により補正し、入口を0.3 mm面取りする。既存工具通路は保持し、新しい上側の工具穴φ10は正12角形・両入口0.4 mm面取り。外形R2・0.6 mm面取り、開放部のR0.5・0.3 mm面取りを使用する。印刷済み受けの六角角部は回り止めの機能形状として保持する。

保護延長厚8、前端Y174・後端Y−176、持ち手90×34、後方配線予約50 mmを保持する。C押さえの穴位置と既存底板の受けを保持する。B4個のM5固定、C2個の53 mm胴部保持、在庫質量2.24 kgは変更しない。

manufacturing.jsonの印刷姿勢を使用し、0.2 mm・8周・100%・5 mmブリム・サポート無効を使用する。支持治具の開放部の奥行を14→8 mmへ短縮し、短いブリッジとする。小径横穴は八角形の屋根を短いブリッジで印刷する。ブリムを除去して実物嵌合を確認する。旧3MFは履歴へ保存し、未印刷9種類・15個だけを現行スライス対象とする。印刷済み部品の再印刷は不要。

## 検証と制限

[開放ナット検査](../../../../../assemblies/child_horizontal_plate_frame/_work/analysis/open_nut_fastening/validation.json)は印刷済みSTLと配置、32組の開放ナット、代替ねじ、各種類の八角穴断面・座面の残存材料を検査する。スパナは頭幅10・厚2.6 mm・到達35 mmの仮包絡で、実工具を照合する。側板の取付穴・容器の挿入・回転止め・持ち手・配線予約・M5固定は既存検査を再実行する。

開放部付近の断面プローブで支持治具3.70 mm、回転止め2.50 mm、上部側方材8.50 mmの残存肉厚を確認する。開放部で支持梁の局所断面が変わるため、PETGの実荷重・締付け・層間強度・湿潤保持・クリープ試験が必要。強度認証を主張しない。全種類のSTEP変換・読戻しは未完了で、旧STEPは現行形状として使わない。

2026-10-10までの設計・検査・スライス説明は[変更前履歴](../../../../../assemblies/child_horizontal_plate_frame/_work/intermediate/history/before_open_nut_fastening/parts/child/exterior/printed/child_horizontal_plate_frame/README.md)に保持する。

[サポートなし検査](../../../../../assemblies/child_horizontal_plate_frame/_work/analysis/support_free/validation.json)は未印刷9種類・15個すべて合格。3MFのenable_support=0とG-codeのサポート押出量0、現STLのSHA、造形範囲を確認し、屋根の投影局所幅は最大7.71 mm。物理的なブリッジ品質は初回印刷で確認する。

## 内側の保護延長（Rev.3）

現構成はguard_front_inner / guard_rear_innerを使い、左X−110〜−102・右X102〜110の側板内面へ取り付ける。固定穴Y±98・Z100/176は従来位置、外側からM3×25、内側に普通ナットと0.5 mmワッシャ。左右各前後2本ずつ計8本、両側ワッシャ16枚。旧側板内側のナット受けは延長で覆われ、延長の内向き面でナットを工具保持する。M3×30も幾何検査する。

上部の12×28接合座と後部回転止めの24×35取付足には1 mmの逃げを設け、端から開ける。後部の工具は+Y側へ通せる。前後の端位置・厚8・既存固定穴は保持し、幅は260→244 mm。旧guard_front / guard_rearは外側配置の履歴用バリアントとして保持し、現行placementと印刷一式へ含めない。

後部延長の回転止めの逃げは、取付足に加えて斜めの腕まで開き、既存窓につなぐ。細い残材を作らず、上下・後端の外周材で連結する。

# 内部ハーネス (容器内・ボックス内の配線)

**未設計**。部品ではないが、内装のレイアウトを縛るので部品と同じ扱いで管理する。

| 項目 | 値 |
|---|---|
| 区分 | 共通 / ケーブル |
| 対象 | 子機容器内 / 親機防水ボックス内 |

## 子機 (WTE4 容器内)

トレイ (`child_tray_deck` + `child_tray_rib` ×3) の上に RX 基板と LiPo が載る。

| 経路 | 通り道 | 現在の設計 |
|---|---|---|
| 後方キャップ (ペネトレータ) → 基板 | チューブ内をデッキ下 or デッキ横 | リブの**中央切欠き (40 × 14)** が配線通し |
| 基板 ↔ LiPo | デッキ上 | ベイ間に明示的な配線路なし → **要検討** |
| デッキ前端 → 外 | デッキ前端の **Ø9 ケーブル通し穴 ×2** | 前端ケーブル余裕ゾーン 30mm |

- リブの切欠きは**リブ 3 枚とも同じ位置**なので、配線は一直線に通せる。
- 切欠きは軽量化も兼ねる。ここを配線で埋めるとリブの意味が薄れるので、
  結束バンドで**壁側に寄せて**通すこと。

## 親機 (防水ボックス内)

`parent_plate` に 7 モジュール + LiPo が載る。

- `parent_plate.scad` に**ケーブルグランド引込みゾーン (穴なし・部品置くな)** が
  定義されている: 下 (125, 5, 30, 25) / 上GPS (75, 150, 25, 25)。
  **このゾーンには部品も穴も置かない。**
- モジュール間配線はプレート上を這う。プレートに配線通し穴・結束点は**未設置**。
  → 要追加設計 (現状は四隅 M4 とモジュール M3 下穴のみ)。

## 部品外の考慮 (共通)

- **サービスループ**: トレイ/プレートを引き出せるだけの余長を必ず取る。
  余長がないと保守のたびにコネクタを抜くことになり、断線の原因になる。
- **最小曲げ半径**を守る。特にシールド線・同軸 (TD04A) は折り曲げに弱い。
- **結束点**: 現状 `child_frame_plate` の 40mm グリッド穴以外に結束点がない。
  トレイ上・プレート上に結束バンド用スロットの追加を検討すること。
- **コネクタの向き**: 引き出し方向に対して抜ける向きに付けない。
- **電源とデータを分離**する。RS485 はツイストペア + シールド、電源線から離す。
- 振動する場所 (マスト) では配線を必ず固定する。

## 要設計

1. 子機: 基板 ↔ LiPo の配線路とコネクタ位置
2. 親機: `parent_plate` への配線通し穴・結束スロットの追加
3. 両機: 端子台/コネクタの型番決定と、ハーネス長の確定
4. ハーネス図の作成 (`docs/配線・ケーブル計画.md` に追記)

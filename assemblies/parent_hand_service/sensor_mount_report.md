# GNSS・磁気センサ固定治具改訂（2026-10-11）

設計変更はGNSS上台と磁気センサ支持枠。床・支柱・電池・MAIN/Sony・電源/TX・ケース・アンテナの形状と位置は維持する。生成元は `spec/build_parent_gnss.py`、寸法は `scad/lib/parent_gnss.py`、配置は `placement.json`。旧版は `_work/analysis/sensor_mounts_20261011/history/` に保存した。

## 寸法と固定

ユーザーが確認したユニバーサル基板は外形60×80 mm、長辺方向75 mm／短辺方向55 mmの穴ピッチ、四隅とも端から穴中心2.5 mm、M3。箱X/Yでは55×75 mm。四隅をM3×10／M3ナット各4で貫通固定し、前後押さえとM2ねじ4本を廃止した。穴径の実測値は未受領なので、購入基板モデルの穴Ø3.2はM3用の仮包絡として残す。

支柱とナット用工具を避けてGNSS一式だけ西6 mmへ移動。外形と基板高さは維持し、基板X69–129/Y139–219/Z56–57.6、穴X71.5／126.5、Y141.5／216.5。印刷穴は対辺3.45 mmの補正八角穴、入口に0.2 mm逃げ。側梁は幅7 mm、外縁の最小穴肉厚は公称1.63 mm。M3ナット下面47.6、台下面50、頭座57.6。ねじ端はナット下面に揃う公称長さで、購入品公差とねじ掛かりは実物で確認する。

磁気センサ下面をZ76からZ56へ下げ、GNSSユニバーサル基板と揃えた。四隅の公式Ø2.5穴（ピッチ20.32×12.7）はナイロンM2×8／M2ナット各4で固定。厚4 mm・幅5.8 mmの低い矩形枠で四隅の座をつなぎ、両縦梁をGNSS後梁、前後横梁をGNSS西側梁へ接続した。立ち上げマストはない。枠下面51.5、四隅の座上面56、支持穴Ø2.45。後ろ2座にはM2ナットの局所逃げを設けた。

支持枠を二方向へつなぐ形状へ変更したが、剛性・強度の数値保証はしていない。現行部品の荷重解析、積層方向の材料試験、ねじ予圧・緩み・クリープ・波浪試験は未実施。

## 着脱と配線

GNSSはM3ねじ／ナット4組、SMAとXHを外し一式を上へ抜く。M3ナットは台の下から工具で保持する。

磁気センサは先にSMAを外し、同軸をアンテナ後方の既存退避位置へ置く。南QTを抜き、ナイロンM2ねじ／ナット4組を外して上へ抜く。南QTのプラグ自体は干渉しないが、幅12×奥行26×高さ10 mmの指の把持包絡は接続中のSMAに重なるため、この順序が必要。北QTは箱内で使わない。

同軸の受信側直線のみ6 mm短縮し、既存R20の曲げ・アンテナ・5 m同軸を維持。配線先、QTケーブル、SMA/XHの実プラグ寸法は未確定。磁石内蔵ANN-MB1があるため、位置変更後の通電・送信状態で飽和の確認と磁気測定・校正が必要。

## 印刷

再印刷は **gnss_universal_carrier.stl 1個だけ**。支柱ランナーと他の印刷部品は形状変更なし。前後押さえを現行一式から除き、印刷一式は9種類各1、切離し後20個。入口は [parts/PRINT.md](parts/PRINT.md)。

台下面をベッド、キー穴を下、座を上。PETG／0.4 mmノズル／0.2 mm積層／4周壁／100%インフィル。外形・内側の根元は0.05 mm面取り（生成形状で成立した実値）、M3穴入口0.2 mm逃げ。既存柱キーとねじ座の機能面は維持する。センサ枠下面とナット座の屋根に局所支持があり、開放した下面から除去する。

Bambu StudioのX1 Carbon 0.4／Generic PETGで自動サポートを有効にしてスライス。使用量25.25 g、うち支持0.47 g、スライサ警告なし。結果は `_work/analysis/sensor_mounts_20261011/slicing/after_slicing.json`。支持なしの設計として扱わない。実印刷と穴嵌合は未確認。

## 検証記録

`sensor_mount_checks.json`：穴ピッチ・実穴の貫通・4座の接触・同じ高さ・支持枠の連結・変更部の全周囲干渉・変更対象外の配置とSTEPハッシュ・STEP/STL照合。

`magnetometer_access_checks.json`、`gnss_access_checks.json`：実取付穴、締結具、上下工具、QT／SMA、連続上方抜出し。`switch_tx_access_checks.json`、`battery_sd_access_checks.json`、`wave_assembly_checks.json`：既存の操作と組立経路。集約は `validation_current.json`。

OpenSCADの生成SCADを別STLへレンダリングして形状・体積を照合。閉メッシュはFreeCADとtrimeshで確認する。MCPの簡易メッシュ検査は座標丸めで微小面取りの辺を開いた辺と判定するため、丸め前の共有辺によるtrimesh検査とSTEP照合を正確な検証として記録する。

`python -m unittest discover -s tools/tests` は42件中41件成功。1件は今回の変更範囲外の子機材料カード `parts/child/exterior/printed/child_wte4_suspension_clamp/spec/bambu_petg_basic_material.json` 不在でエラー。子機を変更せず記録した。

SW_TXの指の進入は公式KiCadのレバー軸を読み、Ø20の包絡に半径0.1 mmの余裕を付けて旧前押さえ座の端を逃がした。四隅の穴・座と支柱は維持。組立の連続経路は逃がす前の支持枠で合格し、最後の枠がその検証済み形状の内側に収まること（追加体積0.01 mm³未満）をsensor_mount_checks.jsonで再確認した。

現行スライスの第1層とセンサ枠の出現層、四隅の座の層を `_work/images/sensor_slice_layers.png` で確認。自動支持を使って枠下面とキー穴・ナット座を支える。全印刷一式のcheckはこの親機で合格、変更範囲外に既存エラー3件（child_interiorの同梱3MF、parent_oneplate／parent_service_reviewの古い印刷一式）が残る。前回validation_current.jsonと同じ指摘で、この作業では各構成を変更していない。

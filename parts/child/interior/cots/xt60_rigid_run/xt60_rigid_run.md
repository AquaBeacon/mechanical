# xt60_rigid_run — 電源リード硬直区間の簡易キープアウト

> **廃止 (2026-09-03 同日)**: 電池リードを切って XT30 メスを付け直す方針 (硬直部は元コネクタ側の熱収縮で、切れば無くなる) になったため不要。アセンブリから除外済み。電池〜基板の接続は `parts/common/cabling/child_harness` (`bat` バリアント) を参照。フォルダは履歴として残置 (削除可)。


**購入品ではなく、電池電源リードの「曲げ不可な硬直区間」を表す簡易モデル。**
`lipo_35x26x110` の電源リードのうち、可撓部 60mm の先につながる硬直区間
(電池側の硬直スリーブ + 嵌合した XT60 ペア + 変換ケーブルのブート) を、
断面矩形の積み木で近似したもの。**全寸法は推定** — 実測して確定させること。

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 内装 / 購入品 (簡易キープアウトモデル) |
| 対象 | XT60 プラグ (電池側) + XT60 レセプタクル (変換ケーブル側) + ブート |
| 出典 | 推定値 (実測前) |

## パラメータ

| 変数 | 値 | 意味 |
|---|---|---|
| `sleeve_l` | 50 | 硬直スリーブ長さ (電池側) |
| `sleeve_w` | 5 | 硬直スリーブ幅 (X) |
| `sleeve_h` | 9 | 硬直スリーブ高さ (Y) |
| `pair_l` | 40 | 嵌合した XT60 ペア長さ |
| `run_w` | 8.2 | XT60 ペア幅 (X) |
| `run_h` | 15.6 | XT60 ペア高さ (Y) |
| `boot_l` | 5 | 変換ケーブルのブート長さ |
| `run_l` (導出) | 95 | 全長 = `sleeve_l + pair_l + boot_l` |

## 座標

原点は底面中心 (0,0,0)。Z = 軸方向、電池側を `z=0`、変換ケーブル側を `z=run_l` とする。
各区間は X・Y とも Z 軸を中心に置いた cube。

| 区間 | Z 範囲 | 断面 |
|---|---|---|
| 硬直スリーブ (電池側) | 0〜50 | `sleeve_w` × `sleeve_h` |
| 嵌合した XT60 ペア | 50〜90 | `run_w` × `run_h` |
| 変換ケーブルのブート | 90〜95 | `sleeve_w` × `sleeve_h` |

## 依存している自作部品

| 部品 | 依存している値 |
|---|---|
| `parts/child/interior/printed/child_vtray_xt60_cradle` | `run_w` / `run_h` / `run_l` |

`assemblies/child_interior` では z 30..125 の範囲に配置する想定
(`lipo_35x26x110` の電源リード可撓部 60mm の下端に続く)。

## 部品外の考慮

- **電池側 可撓リード 60mm** がこの下端 (z<0) につながる。本モデルには含まない。
- **変換ケーブル (XT60F→XT30) の必要長 ≥ 120 mm**。ブート (z>95) から先の
  可撓線・XT30 プラグは本モデルに含まない。

## 要確認

全寸法は推定。以下を実測すること:

1. 硬直区間の長さ・断面 (`sleeve_l` / `sleeve_w` / `sleeve_h`)
2. XT60 嵌合長 (`pair_l`)
3. ブート長 (`boot_l`)
4. 変換ケーブル長

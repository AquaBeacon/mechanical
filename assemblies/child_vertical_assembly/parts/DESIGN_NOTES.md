# child_bottom_guard — 下部ガード / 脚 / バラスト座

| 項目 | 値 |
|---|---|
| 区分 | 子機 / 外装 / 3Dプリント |
| 設計ソース | `child_bottom_guard.scad` |
| 個数 | 1 |
| 外形 | **Ø198 × 55 mm** (z -37..18) |
| 体積 | 250.8 cm³ (STEP) → PETG 約 190 g |
| STEP | 1 ソリッド / 130 面 |

## 役割

縦置き子機の一番下。**4 つの役目を 1 部品で持つ**。

1. **アルミエンドキャップとペネトレータを着底衝撃から守る**
   (スキッド底面 z=-37 が、ペネトレータ先端より約 3mm 下)
2. **容器の重量を 3 点パッド (r 42..50) で受ける** — シェルのクランプ力に頼らない
   軸方向ストッパ。アクリルチューブに軸方向の摩擦荷重を掛けない
3. **陸上で自立させる脚** (スキッドリング Ø198)。ドームを接地させずに置ける
4. **バラスト (鉛) の取付座**。M6 ×5 の取付位置を変えて**吊り姿勢をトリムする**

## ケーブルの逃げ (★ 最重要)

**中央 r<42 は完全に素通し。後方 (-Y) ±40° のセクタには構造物を置いていない。**

| ケーブル | 経路 |
|---|---|
| テザー | キャップ → 真下 → リング後方の結束スロット (±10°) でストレインリリーフ → 機体外周を上へ |
| TD04A | キャップ → 後方セクタ → 後半シェルのパイロン内 (導管) → 上のソケット |
| ライト | キャップ → 後方セクタ → 機体外周 → 前半シェルのデッキ結束スロット → ライト |

**ペネトレータの締付け (バルクヘッド 3.5 N·m / プラグ 約 14 N·m) は、
このガードを外した状態で行うこと。** ガードは M5 ×4 で後半シェルの底フレアに
留まっているだけなので、工具アクセスのために外せる。

## 主要寸法

| 変数 | 値 | 意味 |
|---|---|---|
| `cap_z` | -13.8 | アルミキャップ下面 (STL 実測から導出) |
| `pad_r0..r1` / `pad_w` | 42..50 / 24 | キャップ支持パッド ×3 |
| `pen_or` | 39 | ペネトレータ外形の外端半径 (BCD/2 28 + 六角半幅 11) |
| `cap_scr_bcd` | 108 | キャップ取付 M3 の BCD **要確認** |
| `ring_r0..r1` / `ring_z0..z1` | 79..99 / -37..-25 | スキッドリング |
| `spoke_w` / `spoke_t` | 30 / 6 | スポーク ×3 (リング ↔ 支柱) |
| `arm_a` | 60 / 180 / 300 | スポーク・支柱の方位角 (0 = 真後ろ) |
| `lug_r` / `lug_a` / `lug_z1` | 70 / ±40, ±68 / 18 | シェルへの取付ラグ ×4 |
| `leg_w` / `leg_t` / `leg_ang` | 24 / 20 / 21.6° | 脚 ×4 (垂直からの傾き) |
| `bal_d` / `bal_r` / `bal_a` | 6.5 / 89 / 0, ±100, ±140 | バラスト M6 ×5 |

支持パッドの半径は「**ペネトレータ (r≤39) より外、キャップの M3 頭 (r=54) より内**」
の隙間に置いてある。r 42..50 はこの窓のほぼ中央。

## インタフェース (**二重定義。片方だけ直さないこと**)

`child_shell_aft` と共有: `lug_r=70` ↔ `guard_r=70`、`lug_a=[40,-40,68,-68]` ↔
`guard_a`、`lug_z1=18` ↔ `shell_z0=18`。

締結は **M5 ×4 (M5×30)**。ナットは後半シェル側のフレア上面のポケットに入る。

## 干渉チェック (`.scad` 冒頭の assert — 実際に止まったもの)

1. **脚の根元がリングの帯幅からはみ出して宙に浮く** → リング幅を 12 → 20mm に広げた
   (Ø190 → Ø198)。「assert を緩める」のではなく形状を直した
2. **バラスト穴の干渉判定が方位角の巻き戻しを扱えていなかった** (a=0 と a=180 を
   「同じ角度」と誤判定) → `angdiff()` を導入して弦長で判定するよう直した

常時検査しているもの:

- 支持パッドがペネトレータにもキャップの M3 頭にも掛からないこと
- **真後ろのケーブル用セクタが ±25° 以上開いていること** (**現在 ±40°**)
- 支柱がスポークの上に載ること / 支柱の下端がスポーク上面と一致すること
- 脚の傾き < 45° (**現在 21.6°** → 無サポート) / 脚がラグ下面を支えられる太さか
- スキッド径 ≤250 / 全高が 300 枠を超えないこと / ベッド高さに入ること
- バラスト穴・結束スロットが脚/スポークに掛からないこと

## 強度

| 項目 | 値 |
|---|---|
| 容器の自重 (1.85kg × 3g = 54N) を 4 本の脚で受ける | 脚断面 24×20 → **0.03 MPa** |
| 陸上で自立 (全備 5.7kg) | リング全周で受ける → 無視できる |
| 着底衝撃 | **塑性変形で吸収する前提の消耗品**。割れたら刷り直す |

ガードは「壊れることで容器とペネトレータを守る」部品。
**強度を上げすぎない方がよい** (硬くすると衝撃がキャップへ抜ける)。

## 印刷向き

**このまま。** スキッドリング底面 (z=-37) が約 6700mm² のベッド接地面。
脚は垂直から 21.6° なのでサポート不要。スポークもベッドに接する層にある。

## 部品外の考慮

- **バラストは 1.1〜2.2 kg の鉛**を M6 ×5 の好きな位置に付ける
  (浮力の見積りは `docs/AquaBeacon_機体設計.md`)。
  **前後の取付位置で吊り姿勢 (前傾/後傾) をトリムできる** — 重心が吊り点より
  約 6mm 前にあるので、後ろ寄り (a=0 付近) に置くと水平に近づく。
- 鉛は**海水で溶出する**。エポキシで包むか、ステンレスの錘を使うこと。
- **陸上での置き方**: 3 本脚 + リングで自立する。傾転角は約 33°
  (重心 z≈69 / 脚半径 99)。**波打ち際や船上では必ず固縛すること。**
- リング後方の結束スロット ×2 は**テザーのストレインリリーフ**。
  張力はここで受け、ペネトレータのシール部には掛けない。
- 砂地に着底するとリングの中に砂が入る。**引き上げ後に真水で洗うこと**
  (中央が開いているので流し落とせる)。
- ガードを外さないとペネトレータの工具が入らない。**分解順序**:
  ガード (M5×4) → 前半シェル (M5 蝶ボルト ×4) → 容器を真上へ。
  ただし**内部アクセスだけならドームを開ければよく、ガードもシェルも外さない**。

## 要確認

1. **キャップ取付 M3 の BCD** (`cap_scr_bcd = 108` は公称からの推定)。
   実物で M3 頭の位置を測り、支持パッド r 42..50 と当たらないことを確認する
2. **ペネトレータの突出量**。`ring_z0 = -37` は「キャップ下面から 23.2mm」で
   決めている。実物が長ければ `ring_z0` を下げる (ただし全高 300 の枠を食う)
3. 実際に必要なバラスト量 (浮力計算は仮値だらけ)。**進水前にプールで実測すること**
4. M5×30 ×4 / M6 ボルト (バラスト用、長さは鉛の厚みによる)

ねじは **M4 蝶ボルト ×2**、相手はポッド側壁上面の **Ø3.3 下穴へのタッピング**

`translate([±75, 70.3, 145])` (= `[±(base_line/2 − lens_dx), in_y0 − pod_rear, pod_top]`)。

- 位置決めリムがクレードルに落ちる幅であること
- **蓋込みの全幅 ≤ 250** (蓋がポッドより広いので、機体の最大幅を決めるのはこの部品)
- アクセス窓がリム/ねじに掛からないこと

**上下逆さま** (z=`lid_t` の平面をベッドに置く)。押えパッドと位置決めリムが
上を向くのでサポート不要。接地面 90.4 × 47.7 で安定。

- **上面ボタンのアクセス窓の位置は仮値**。実機で合わなければ `win_*` を直すか、
  `win_on = false` で塞ぐ (窓なしの方が保護は良い)。
- 蓋を開けないと電池・SD が触れない。**入水前に充電・設定・時刻同期を済ませる**。
- EVA スポンジは消耗品。潰れたら交換する (BOM に予備を入れること)。
- 蓋の水抜き穴 (Ø6 ×2、前寄り) は塞がないこと。クレードルは水没する前提。
- 蝶ボルトは水中で回すことがある。**ステンレス (A2/A4) を使い、
  PETG のタッピング部が痩せてきたらインサートへ移行する**。

1. Osmo Action 6 の**上面ボタンの位置** → `win_*`
2. カメラ上面が本当に平らか (突起があると押えパッドが当たる) → `pad_h`
3. M4 蝶ボルトの入手 (M4×20、4 本)

- **ゴム/EVA シート (1〜2mm) を鞍面に貼る**こと。樹脂とアルミ胴が直接こすれると
  ライトに傷が付き、締め付けも滑る。`gap_z = 1.5` はその圧縮代。
- ライトの**配線はクランプの結束スロット → デッキの結束スロット → 機体外周 →

  発熱は水中なら問題ないが、**空中での連続点灯は避ける**。
- カメラ同期用に「潜行前後に既知時刻でブリンク」させる運用がある。
  **点滅を制御できる製品か、外部から給電/制御できる製品を選ぶこと。**

## 要確認

1. **製品の選定** → 胴径・胴長・重量・配光・ケーブル外径
2. ケーブル外径 → WetLink ペネトレータの型番 (4.5〜8.5mm)
3. 点滅制御の方式 (容器内の基板から制御するか、独立電源か)
4. 浮力。ライトは中身が詰まっていて負の浮力が大きいことが多い。
   バラスト量の見積り (`docs/AquaBeacon_機体設計.md`) に反映すること

## 干渉チェック (`.scad` 冒頭の assert — 実際に止まったもの)

自動チェック (watertight / ソリッド数) では**捕まらない**ものだけを assert にしてある。
下の 3 つは今回の設計中に実際に assert が止めて、**形状の方を直した**。

1. **取っ手バーが屋根の中央リブと干渉** → リブ下端を 128 → 145 へ上げた
2. **TD04A の前側取付穴の真上をスキンの外向きカラーが覆い、下穴が「閉じた空洞」になった**
   → 上カラーを廃止 (丸めは Fusion で付ける)。ソリッドが 3 個に分離していた
3. **結束スロットの角がパイロン下面の 45° 斜面にちょうど接して非マニフォールド**
   → スロット z を 70 → 74 に逃がし、斜面との離れを検査する assert を追加

そのほか常時検査しているもの:

- 吊り耳ボスの最内点がドーム抜き取り経路 (Ø122.3) の外にあること (**現在 r=65.8 / 必要 62.2**)
- 締結 M5 とナットがチューブ穴に噛まないこと / ナットがレール内に収まること
- 吊り耳がボルトボスと重ならないこと (重なるとナットの横挿しスロットが塞がれて**組めない**)
- 取っ手の指スペース ≥ 35mm (**現在 43mm**)、握り径 24〜34 (**現在 26.0**)
- 内部空洞がスキンを食わないこと (食うとチューブが露出して保護にならない)
- ガード取付ボスが空洞/レールに掛からないこと・底フレア内に収まること
- 通水穴・結束スロットがレール/パイロン/吊り耳/45°斜面に掛からないこと
- 全幅 ≤ 250 / 後端 ≤ 125

## 干渉チェック (`.scad` 冒頭の assert)

- 傾き ≤ 25°
- M5 穴の端距離
- 傾きでソケットがベースから大きくはみ出さないこと
- **M5 頭 (Ø8.5) がスカートに乗り上げないこと** ← 親機バリアントはここで止まる

## 印刷向き

ベースを下に平置き。ソケットは垂直円筒で無サポート
(tilt > 0 のときはスカートが 45° を保証する形状になっている)。

## 部品外の考慮

- 底の Ø9 は**ケーブル出しと水抜きを兼ねる**。塞がないこと。
  親機 (下向き) では水抜きにならないので、別途排水を考えること。
- 振動子の**放射面を塞がない**。ソケットは胴を掴むだけで、放射面は開口から出る。
- **ケーブル 3m + 3P プラグ**が付いてくる (`td04a_transducer.md` 参照)。
  プラグは水中コネクタではないので、子機では容器内 or 水面上に収める。
- 結束バンド (4.8mm 帯) は消耗品。締め直しのため**工具/指が入る**こと。
- 気泡が振動子面に残ると測距できない。設置後に**面を撫でて泡を抜く**運用手順が要る。

## 要確認

1. TD04A 胴径・胴長の実測 → `xdcr_d` / `depth` の確定 (最重要)
2. 親機バリアントの設計方針決定 (上記 3 案)
3. ケーブル外径 → ペネトレータ型番

## 印刷設定の出発点

0.4 mmノズルを想定。Bambu Lab PLA Matte、積層0.20 mm、壁8周、上下面6層、通常インフィル15%。デッキは板を寝かせ、ボス側を上にする（解析の積層軸Y）。ブレースは広い平面を下に置き、100%インフィル。

`pla_matte_lever/root_dense_modifier.stl` をデッキと同じオブジェクトに読み込み、Bambu Studioで「モディファイア」に変更。座標を保持し、左右の根元・受け足・固定座を100%インフィルに指定する。自動整列でモディファイアだけを移動させない。スライス断面で空洞が残らないことを確認する。壁数を増やすだけでは大型の座の内部が埋まるとは限らないため、局所100%を併用する。

寸法穴の仕上がりと受け足の接触を仮組みで確認する。造形収縮や反りで足が浮く場合は、ねじの締め付けで引き寄せない。

## 荷重と解析の限界

200 gを固定面から180 mm離した静荷重は約0.35 N·m。解析では200 gに5gの加速度を仮定した9.81 Nを先端に与え、部品自重も5gとしている。この5gは比較用の設計仮定で、実測の衝撃条件ではない。

[Bambu公式PLA Matte TDS V3.0](https://store.bblcdn.com/eff154c269404bf6a7baf48385a16e5a.pdf) はXY引張強さ30±5 MPa、Z方向22±4 MPaを掲載している。ただし試験片は100%インフィル、試験前に55℃・8時間の処理を受けている。通常15%インフィルの未処理部品へそのまま適用できない。

topoptの既存一般PLAカードで補助解析を実行する。Matte専用カードではなく、モデルは全面100%充填である。局所密度やねじの締付け、スペーサの柔軟性、接触の開閉は表現しない。左右ねじ穴のみを拘束し、前側ブレースと受け足の接触には解析上の支持を与えていない。したがって材料・組立の実物強度保証には使用しない。メッシュ収束判定と生データは `pla_matte_lever` に保存する。

更新形状を1.6 / 0.8 / 0.4 mmで計算した結果、topoptの収束判定は全4ケースFAIL。最細メッシュでは板に垂直な5g荷重の変位約12.5 mm、p99.5安全率5.39以上に対し、最悪要素の安全率は約1.3である。安全率4・変位1 mmの仮要求を満たす保証は得られていない。ねじ拘束端のホットスポットもメッシュで移動しており、これらは未収束の参考値である。以前の形状とは包絡とグリッド原点も異なるため、改善率は算出しない。

この解析を「PLA Matteで安全率5以上」として使用しない。受け足と前側支持の実接触、および通常部15%の内部構造を含む組立状態での評価と実物試験が必要。今回の納品は根元の断面拡大・荷重分散を行った試作形状であり、強度認証済み部品ではない。

## 組立とサービス

WetLink M10×5と出口付近の配線逃げ、電池サービスねじへの直径6 mm工具アクセス、床板の2 mm下降と引き抜き経路を維持する。サービス作業はアクリルチューブを外して行う。配線の全経路と曲げ半径は実配線に合わせて確認が必要。

最終の実物確認は200 g相当を搭載し、横向きの各方向で根元の浮き・白化・残留変形を確認する。初回は静荷重から始める。反復荷重と締付けに対する寿命は未測定。

## 今回の幾何検証

デッキとブレースのSTLは水密の一体形状。対応するSTEPは有効な単一ソリッドで、STLとの体積差は0.001%未満。組立STEPは内装75項目、子機全体82項目、いずれも配置検査0 NG。対象は200 mm構成（t200）。t300の既存出力は今回更新していない。
